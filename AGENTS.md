# Norma obligatoria del proyecto

Todo cambio debe verificarse explícitamente contra todos los requisitos del prompt vigente antes de considerarse bueno, terminado o listo para entregar. No se aceptan correcciones parciales presentadas como completas. La verificación debe cubrir, según corresponda, funcionalidad, integración, interfaz visual, flujo real y despliegue. Cualquier requisito pendiente debe declararse como pendiente y seguir trabajándose, sin sustituir la solución por excusas.
