Aspose.Tasks for Java 
==========================================================================

Aspose.Tasks for Java is a project management API that enables Java application developers to provide 
Microsoft Project® document manipulation capability in their applications – all without using Microsoft Project®. 
With this powerful API, developers can control various stages of project management, such as project planning, definition and tracking.

For more info see https://www.aspose.com/products/tasks/java

This distribution contains the following directories:

- lib       : Aspose.Tasks libraries for JDK 1.7 and above
- doc 		: Aspose.Tasks documentation JAR file 


For start please check
 - Programmer's Guide in http://www.aspose.com/docs/display/TasksJava/Home
 - API Docs in aspose-tasks-x.x-javadoc.jar


Required Software and Libraries
===============================

Note that you will have to install
- Java runtime 1.7 or above
