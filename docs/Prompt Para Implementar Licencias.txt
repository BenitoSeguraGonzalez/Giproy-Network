ERES UN ARQUITECTO SENIOR FULL-STACK (PYTHON + FASTAPI + POSTGRESQL + REACT) ESPECIALISTA EN SAAS MULTI-TENANT, LICENCIAMIENTO ENTERPRISE Y SISTEMAS ESCALABLES.

TU MISIÓN ES IMPLEMENTAR UN SISTEMA COMPLETO DE LICENCIAS, ROLES Y MEDICIÓN DE USO POR EMPRESA EN UN PROYECTO YA EXISTENTE Y FUNCIONAL, SIN ROMPER NINGUNA FUNCIONALIDAD.

---

# CONTEXTO DEL SISTEMA

* Backend: Python (FastAPI)
* Frontend: React
* Base de datos: PostgreSQL
* Sistema multi-tenant basado en EMPRESAS
* Cada usuario pertenece a una empresa
* Existe sección: **"Administración Global"**
* Solo **superadministradores** pueden gestionar licencias

---

# OBJETIVOS

1. Implementar sistema de licencias completo
2. Definir roles por usuario dentro de cada empresa
3. Medir uso REAL por empresa
4. Diseñar modelo SQL robusto
5. Implementar middleware centralizado en FastAPI
6. Integrar sin romper funcionalidad existente

Empresarial:

* ilimitado (uso razonable)

# MODELO DE ROLES

* 1 ADMIN obligatorio por empresa
* N COLABORADORES

Reglas:

* nunca eliminar último admin
* usuario creador = admin
* licencias de 1 usuario → solo admin
