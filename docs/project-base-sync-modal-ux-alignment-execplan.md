# Project Base Sync Modal UX Alignment - ExecPlan

## Objetivo
Replantear el modal de sincronización de bases de proyecto para que funcione como una decisión operativa clara y rápida, con jerarquía visual correcta y sin fricción innecesaria.

## Problemas detectados
- La revisión objetivo no tenía suficiente protagonismo.
- El historial competía con el CTA principal.
- El resumen no distinguía bien impacto estructural de impacto operativo.
- El CTA `Solicitar confirmación` añadía una capa mental innecesaria.
- El modal no guiaba visualmente al usuario en un flujo natural.

## Enfoque UX
- Orden secuencial real:
  - tipo de sincronización
  - revisión objetivo
  - impacto esperado
  - confirmación
- Historial reubicado como acción secundaria.
- Resumen jerarquizado en:
  - impacto estructural
  - impacto operativo
- CTA principal directo:
  - `Continuar`

## Resultado esperado
- El usuario entiende en segundos qué hará la operación.
- La revisión objetivo se lee como dato crítico.
- La confirmación final se siente natural.
- El modal deja de parecer una combinación de ficha, preview y panel técnico.
