# Project Section Report Entry Points

## Objetivo
Crear una superficie común de entrada a reportes en los encabezados de las secciones del módulo `Proyecto`.

## Alcance
- Reutilizar el mismo lenguaje visual del botón `Reporte` de `Presupuesto`.
- Alinear el icono a la derecha en las cabeceras de sección.
- Dejar un placeholder común hasta definir el reporte específico de cada módulo.

## Resultado
- `Datos del proyecto`, `Stakeholders`, `EDO`, `EDT`, `Cronogramas` y `Desagregación` ya exponen el icono `Reporte` en su encabezado.
- El botón usa un componente reutilizable para evitar divergencias visuales.
