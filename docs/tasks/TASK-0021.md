Notas
- Se uso un unico subsistema de notas para `general` y `linea`, evitando duplicacion de backend y frontend.
- Las notas quedan registradas como bitacora inmutable con autor, fecha y texto.
- Las novedades se calculan separando notas generales y notas de linea, comparadas contra la ultima apertura del presupuesto por usuario.
- Para que el feature sea utilizable sin depender de migraciones pendientes, se crean automaticamente las tablas nuevas de notas al iniciar backend.
