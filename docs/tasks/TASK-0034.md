Ampliar la vista Pareto del editor de presupuestos para soportar analisis global y por capitulos, y permitir navegacion por doble clic desde el modal hacia el item correspondiente en el editor.

Notas
- `global` debe mantener el Pareto por lineas de todo el presupuesto.
- `capitulos` debe agrupar por nodo EDT/capitulo con monto, porcentaje y acumulado.
- El doble clic sobre una linea debe cerrar el modal, seleccionar la linea y dejar listo el flujo de tanteo.
- El doble clic sobre un capitulo debe cerrar el modal y seleccionar ese capitulo en el editor.
- El endpoint `GET /api/v1/presupuestos/{id}/pareto` ahora soporta `view=global` y `view=capitulos`.
- El modal permite doble clic tanto en tarjetas como en filas de tabla para navegar al editor.
- Se validaron sintaxis backend, build frontend y respuestas reales de ambas vistas sobre el presupuesto `2`.
