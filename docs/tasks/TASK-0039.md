## Objetivo
Añadir selección masiva de elementos visibles en `Precios Unitarios` para `Subcategorías`, `Recursos` y `APUs`, con acción explícita de limpieza de selección y comportamiento coherente con filtros de búsqueda.

## Alcance
- Incorporar control `Seleccionar visibles` en las tres pantallas.
- Incorporar acción `Limpiar` para vaciar la selección actual.
- Hacer que la selección maestra actúe solo sobre los elementos visibles en el contexto activo.
- Soportar estado total y parcial según el subconjunto actualmente filtrado.

## Implementación
- Se derivó `visibleItems` / `visibleRecursos` / `visibleApus` en:
  - `frontend/src/pages/Subcategorias.jsx`
  - `frontend/src/pages/Recursos.jsx`
  - `frontend/src/pages/APUs.jsx`
- Se añadieron los cálculos:
  - `allVisibleSelected`
  - `someVisibleSelected`
- Se implementaron handlers:
  - `toggleSelectAllVisible()`
  - `clearSelection()`
- Se añadió el bloque visual compacto de selección en la toolbar existente de cada módulo, junto a `Importar`, `Exportar` y `Borrar`.

## Criterio funcional
- `Seleccionar visibles` solo afecta a los items mostrados tras búsqueda y contexto activo.
- La selección acumulada se conserva aunque el usuario cambie el filtro.
- El control maestro entra en estado parcial cuando solo parte de los visibles está seleccionada.

## Validación
- `npm run build`

## Resultado
El usuario ya puede seleccionar o deseleccionar de una vez los elementos visibles del listado actual y limpiar la selección sin perder coherencia con filtros ni contexto activo.
