# TASK-0044

## Fecha
2026-03-11

## Estado
DONE

## Objetivo
Impedir la importación de elementos hacia la categoría `APU` desde el módulo `Subcategorías`, preservando el resto del comportamiento del módulo sin romper creación, edición ni navegación general.

## Alcance
- Excluir `APU` de las categorías destino disponibles en el modal de importación de `Subcategorías`.
- Evitar la ejecución de la importación si por estado previo la categoría activa fuese `5`.
- Reposicionar automáticamente el destino a una categoría importable al abrir el modal cuando la activa sea `APU`.

## Implementación
- Se añadió `IMPORTABLE_SUBCATEGORIAS` en `frontend/src/pages/Subcategorias.jsx`, filtrando `codigo !== 5`.
- El selector `Categoría destino` del modal de importación ya no incluye `APU`.
- Se creó `openImportModal()` para corregir el destino si la categoría activa era `APU` antes de abrir el modal.
- Se añadió una guarda adicional en `handleImport()` para bloquear la operación si el destino fuese `5`.
- Se incorporó una nota visual aclarando que `APU` no se importa desde este módulo.

## Validación
- `npm run build`

## Resultado
La categoría `APU` sigue existiendo y siendo gestionable en la pantalla de `Subcategorías`, pero queda excluida del flujo de importación masiva, evitando usos indebidos sin afectar el resto del sistema.
