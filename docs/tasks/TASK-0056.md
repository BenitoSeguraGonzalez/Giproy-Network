Descripcion
Implantar una capa frontend tenant-aware obligatoria para dominios multiempresa, eliminando la dependencia de pasar `empresa_id` manualmente y prohibiendo el uso de `api` directo en modulos operativos cuando el usuario es `Superadministrador`.

- frontend/src/context/AuthContext.jsx
- frontend/src/layouts/AppLayout.jsx

Notas
- Debe inyectarse `empresa_id` automaticamente en requests de negocio cuando exista `selectedEmpresa`.
- Si `Superadministrador` no tiene empresa activa, la UI no debe permitir abrir flujos operativos ambiguos.
- Esta TASK es prerequisito de endurecimiento para `Proyectos`, `Presupuestos` y `Precios Unitarios`.
- Se introdujo `frontend/src/api/tenant.js` como helper comun para inyeccion y bypass explicito de tenant.
- `frontend/src/api/axiosConfig.js` ahora adjunta `empresa_id` de forma automatica en requests operativas salvo endpoints marcados como globales.
- Los clientes API del dominio quedaron normalizados para usar `withTenantConfig`, `withTenantParams` y `withoutTenant`.
