Notas
- Esta TASK es de arquitectura de datos y es necesaria para el cierre definitivo del problema.
- Requiere migracion Alembic y revision de indices/constraints unicos.
- `ProyectoDetalle` ya se resuelve por `empresa_id + codigo_root` a nivel operativo; el modelo dejo de usar `codigo_root` como PK global.
- La migracion `f4c6d9b8a1e2` introduce `id` tecnico, `empresa_id`, FK a `empresas` y unicidad parcial por `empresa_id + codigo_root`.
- Los endpoints ahora validan que el `codigo_root` exista dentro de la empresa objetivo antes de leer o guardar detalles.
