# TASK-0075

## Fecha
2026-03-12

## Estado
DONE

## Objetivo
Endurecer de forma transversal las importaciones masivas de `Precios Unitarios` (`Subcategorías`, `Recursos` y `APUs`) para soportar pegados degradados sin tabulación limpia y reconstruir columnas desde el final de la fila cuando sea necesario.

## Contexto
Tras corregir la regresión de `TASK-0074`, seguía faltando un segundo nivel de robustez: muchas fuentes intermedias degradan el tabulado de Excel y dejan texto plano con columnas "visuales". En ese caso, el parser debía ser capaz de reconstruir `precio`, `unidad`, `CPC` o `unidad APU` sin depender exclusivamente del `TAB`.

## Alcance
- Mantener el parsing por `TAB` como primera opción cuando el pegado es limpio.
- Añadir fallback por texto plano para:
  - `Recursos`: reconstrucción desde el final (`precio`, `unidad`, `CPC`, `especificaciones`).
  - `APUs`: detección de unidad válida desde el final de la línea usando el catálogo real de unidades.
  - `Subcategorías`: tolerancia a filas simples y observaciones compactadas.
- Conservar la compatibilidad con etiquetas de fila/códigos cortos reales sin volver a romper descripciones normales.

## Implementación
- `frontend/src/pages/Recursos.jsx`
  - Se añadió `parseResourceImportFromPlainText(...)`.
  - Si no hay columnas tabuladas útiles, el parser reconstruye desde el final de la fila:
    - último bloque numérico largo como `CPC` si aplica
    - último valor numérico previo como `precio`
    - bloque intermedio como `unidad`
    - resto inicial como `descripción`
  - Se normaliza espaciado y se conserva la prioridad de `TAB` cuando existe.
- `frontend/src/pages/APUs.jsx`
  - `parseApuImportLine(...)` ahora recibe el catálogo de unidades.
  - Si no hay `TAB` limpio, intenta detectar la unidad como sufijo válido real desde el final de la línea.
  - Si no puede, aplica fallback controlado usando el último token como unidad provisional para que el preview informe correctamente.
- `frontend/src/pages/Subcategorias.jsx`
  - Se normaliza mejor el texto pegado.
  - Se aceptan filas simples con descripción única.
  - Las observaciones se compactan correctamente cuando vienen en texto corrido.

## Validación
- `npm run build`

## Resultado
Las importaciones masivas de `Precios Unitarios` quedaron más robustas frente a pegados reales desde Excel, portapapeles intermedios o texto sin `TAB` limpio. El sistema prioriza la estructura tabulada cuando existe y, si no, reconstruye la fila con una heurística descendente estable.
