## Fecha
2026-03-12

## Estado
DONE

## Objetivo
Adecuar finamente la importación de `Subcategorías` para que las filas de una sola celda se interpreten como descripciones completas, sin trocear por paréntesis, guiones ni observaciones implícitas.

## Problema detectado
El parser seguía aplicando inferencias demasiado agresivas:
- dividía algunas filas por ` - `
- extraía el contenido de paréntesis como descripción principal

Eso rompía casos reales como:
- `Instalaciones sanitarias (vivienda)` → `vivienda`
- `Madera aserrada, cepillada y/o escuadrada (preparada)` → `preparada`
- `Tubos y accesorios de PVC - para alcantarillado` → descripción y observación separadas artificialmente

## Implementación
- Se corrigió `frontend/src/pages/Subcategorias.jsx`.
- Cuando la fila llega como una sola celda útil, ahora se interpreta de forma conservadora:
  - toda la línea = `descripción`
  - `observaciones = ''`
- Solo se separan `descripción` y `observaciones` cuando hay columnas reales por `TAB`.
- Se eliminó la extracción del contenido entre paréntesis como descripción principal.
- Se eliminó la separación implícita por ` - ` para líneas simples.

## Validación
- `npm run build`

## Resultado
La importación de `Subcategorías` ya mantiene íntegras las descripciones largas o semánticamente compuestas, evitando falsos duplicados y previos engañosos en pegados de una sola columna desde Excel.
