## Objetivo
Corregir el layout responsive y el reseteo de estado en los modales de importación de `Subcategorías`, `Recursos` y `APUs`.

## Problemas detectados
- A resolución `1920x1080`, el modal de importación podía crecer demasiado en vertical y dejar el footer de acciones fuera de pantalla.
- Si el usuario pegaba texto, cancelaba la importación y luego abría otro importador, el buffer previo podía persistir.

## Implementación
- Se añadió altura máxima y estructura `flex` con scroll interno al cuerpo de los tres modales de importación.
- El footer de acciones quedó fijado fuera del área scrollable para mantener visible `Cancelar` / `Confirmar`.
- Se añadieron helpers de apertura/cierre para limpiar el texto pegado:
  - `openImportModal()`
  - `closeImportModal()`
- La limpieza ahora ocurre al:
  - abrir importación
  - pulsar `Cancelar`
  - cerrar con `X`
  - cerrar con `Escape`

## Archivos
- `frontend/src/pages/Subcategorias.jsx`
- `frontend/src/pages/Recursos.jsx`
- `frontend/src/pages/APUs.jsx`

## Validación

## Resultado
Los modales de importación recuperan el comportamiento responsive esperado y ya no arrastran texto pegado entre aperturas o entre importadores distintos.
