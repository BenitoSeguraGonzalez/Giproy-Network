# TASK-0081

## Fecha
2026-03-12

## Estado
DONE

## Objetivo
Diseñar e implementar el nuevo módulo exclusivo de `Superadministrador` bajo el nombre `Administración Global`, como contenedor estructurado de capacidades operativas, de gobierno y de soporte del sistema.

## Motivación
Las funcionalidades exclusivas de `Superadministrador` están creciendo y ya no escalan bien dentro de `Settings` ni como acciones aisladas. Se necesita un módulo propio que:
- agrupe capacidades globales del sistema,
- separe administración de plataforma de operación normal de negocio,
- permita crecer por submódulos sin convertir una sola pantalla en un bloque monolítico.

## Alcance global
- Nueva entrada de menú visible solo para `Superadministrador`.
- Ruta base `/admin-global`.
- Portada o panel de entrada con secciones técnicas.
- Submódulos funcionales desacoplados en TASKs hijas.
- Regla de permisos estricta: acceso exclusivo para `Superadministrador`.

## Restricción crítica
El diseño de `Administración Global` no debe simplificar incorrectamente el modelo actual de permisos.

Existen capacidades híbridas entre `Administrador` y `Superadministrador`, por lo que:
- la ubicación visual de una función no debe redefinir por sí sola su autorización real,
- no se deben mover opciones desde `Settings` o desde otros módulos sin clasificar antes si son:
  - exclusivas de `Superadministrador`,
  - híbridas,
  - exclusivas de `Administrador`,
- cualquier migración debe respetar la lógica backend vigente de permisos y no romper accesos existentes.

## Arquitectura funcional prevista
- `Administración Global`
  - `Comunicados`
  - `Empresas`
  - `Usuarios globales` / gobernanza
  - `Auditoría`
  - `Mantenimiento`
  - `Herramientas`

## TASKs dependientes
- `TASK-0082`: Shell del módulo, menú, rutas y portada inicial
- `TASK-0083`: Submódulo de Comunicados del sistema
- `TASK-0084`: Reordenación y migración de capacidades superadmin desde `Settings`
- `TASK-0085`: Submódulo de gobernanza (`Empresas`, `Usuarios globales`, políticas)
- `TASK-0086`: Submódulo de auditoría y monitoreo operativo
- `TASK-0087`: Submódulo de herramientas técnicas, saneamiento y soporte

## Criterios de aceptación
- Existe una entrada clara y exclusiva para `Superadministrador`.
- Las capacidades futuras del rol tienen una ubicación natural y estable.
- El módulo crece por subtareas sin romper arquitectura ni navegación.
- `Settings` deja de ser el cajón de sastre de funciones superadmin.
- Las capacidades híbridas no se rompen ni se convierten artificialmente en exclusivas de `Superadministrador` por efecto colateral de la reorganización.
