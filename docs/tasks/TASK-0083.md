# TASK-0083

## Fecha
2026-03-12

## Estado
DONE

## Objetivo
Implementar el submódulo `Comunicados` dentro de `Administración Global` para que `Superadministrador` pueda emitir avisos operativos a todos los usuarios o a una empresa concreta.

## Alcance
- Modelo backend de comunicados del sistema.
- CRUD básico para `Superadministrador`.
- Endpoint de comunicados activos.
- Banner global visible para usuarios finales.
- Soporte inicial para:
  - `info`
  - `warning`
  - `critical`
- Ámbito:
  - `global`
  - `empresa`
- Publicación inmediata y programada.

## Dependencia
Depende de `TASK-0081` y de la shell creada en `TASK-0082`.

## Resultado esperado
El sistema permite avisar interrupciones, mantenimientos o mensajes operativos sin recurrir a canales externos.

## Implementación realizada
- Se creó el modelo backend `SystemAnnouncement`, su schema y la migración Alembic correspondiente.
- Se expusieron endpoints para CRUD administrativo y lectura de comunicados activos.
- Se implementó el cliente frontend `systemAnnouncementsApi`.
- Se añadió la pantalla `Administración Global > Comunicados` con alta, edición y borrado.
- `AppLayout` ya muestra banners de comunicados activos para usuarios conectados y refresca su lectura cada 60 segundos.
