# TASK-0084

## Fecha
2026-03-12

## Estado
DONE

## Objetivo
Reordenar las capacidades actuales de `Superadministrador` para que dejen de crecer dentro de `Settings` y se integren progresivamente en `Administración Global`.

## Alcance
- Inventario de funciones superadmin hoy dispersas.
- Clasificación formal de cada función como:
  - `solo superadministrador`
  - `híbrida`
  - `solo administrador`
- Definición de cuáles se mantienen en `Settings` y cuáles migran.
- Reubicación visual y de navegación sin romper accesos existentes.
- Ajuste de copy y jerarquía para separar:
  - preferencias / ajustes generales
  - administración global / operación del sistema

## Dependencia
Depende de `TASK-0081` y `TASK-0082`.

## Resultado esperado
`Settings` queda limpio de responsabilidades impropias de plataforma y `Administración Global` pasa a ser el lugar natural para capacidades exclusivas del rol, sin romper funciones híbridas entre `Administrador` y `Superadministrador`.

## Clasificación resultante
- `solo superadministrador`
  - Gestión de Empresas
  - Comunicados del sistema
- `híbrida`
  - Gestión de usuarios / personal
  - Configuración de proyecto
  - Plantillas de informes
- `solo administrador / supervisor`
  - Preferencias de aplicación

## Implementación realizada
- `Gestión de Empresas` dejó de estar en la navegación lateral de `Settings`.
- `Administración Global` ya expone entrada directa a la gestión de empresas y a comunicados.
- `Settings` queda centrado en funciones híbridas o de empresa, con recordatorio explícito de que la gestión de plataforma migra a `Administración Global`.
- La vista de empresas sigue reutilizando el flujo existente vía `Settings?tab=empresas`, evitando duplicar lógica mientras se estabiliza la nueva arquitectura de navegación.
