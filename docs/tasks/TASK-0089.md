## Objetivo
Implementar un submódulo de `Estado del sistema` dentro de `Administración Global`, orientado a lectura operativa rápida por parte de `Superadministrador`.

## Alcance
- Estado general del backend
- Accesibilidad de base de datos
- Última migración aplicada
- Estado de logs básicos
- Resumen de sesiones o actividad conectada si ya existe una fuente fiable
- Indicadores simples de salud técnica

## Criterios De Diseño
- Vista técnica y sobria
- Lectura rápida, no dashboard recargado
- Sin mezclar acciones destructivas
- Compatible con el patrón visual de `Administración Global`

## Criterios De Aceptacion
- Existe pantalla propia dentro de `Administración Global`
- El submódulo presenta estado real, no datos mock
- El acceso queda restringido a `Superadministrador`
- La información puede usarse para diagnóstico operativo inmediato

## Resultado Esperado
El `Superadministrador` puede comprobar en segundos si la plataforma está sana o si hay señales básicas de degradación.

## Implementacion Realizada
- Se creó el endpoint backend `GET /api/v1/admin-system/status`.
- Se añadió el cliente frontend `frontend/src/api/adminSystem.js`.
- Se implementó la pantalla `frontend/src/pages/AdminGlobalEstado.jsx`.
- Se integró la ruta `/admin-global/estado`.
- Se añadió el acceso al submódulo desde `Administración Global`.
