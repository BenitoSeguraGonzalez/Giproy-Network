## Objetivo
Implementar la gestión de sesiones activas para `Superadministrador`, incluyendo lectura operativa y revocación controlada.

## Alcance
- Listado de sesiones activas
- Usuario asociado
- Empresa asociada
- Marca temporal de actividad
- Identificación de contexto o dispositivo si existe
- Revocación individual segura
- Posible revocación múltiple en una segunda iteración si procede

## Reglas
- No romper sesiones válidas por errores de tenant
- Toda acción de revocación debe quedar auditada
- La capacidad debe permanecer exclusiva de `Superadministrador`

## Criterios De Aceptacion
- Existe submódulo propio en `Administración Global`
- Se pueden ver sesiones reales
- Se puede invalidar una sesión concreta
- El usuario afectado pierde acceso de forma efectiva

## Resultado Esperado
El sistema gana control operativo real sobre accesos vivos, útil para soporte, seguridad y mantenimiento.
