# TASK-0093 - Auditoria Estructurada Por Evento

## Estado
DONE

## Fecha
2026-03-12

## Depende De
`TASK-0088`

## Objetivo
Evolucionar la auditoría actual basada en logs y resúmenes hacia una auditoría estructurada por evento, apta para trazabilidad operativa y administrativa real.

## Alcance
- Definir modelo de evento auditable
- Registrar acciones críticas del sistema
- Soportar consulta por:
  - usuario
  - empresa
  - módulo
  - fecha
  - severidad o tipo si aplica
- Integración de lectura en `Administración Global`

## Ejemplos De Eventos A Cubrir
- inicio y cierre de sesión
- cambio de empresa auditada por `Superadministrador`
- creación, edición o baja de empresa
- acciones críticas de plataforma
- activación de mantenimiento
- revocación de sesión

## Criterios De Aceptacion
- Existe estructura auditable más allá de logs planos
- Hay consultas útiles desde `Administración Global`
- La trazabilidad permite soporte, control y revisión histórica

## Resultado Esperado
La plataforma gana historial fiable y explotable de acciones críticas, sin depender solo de logs técnicos sueltos.

## Implementacion
- Se creó la persistencia estructurada `system_audit_events` con modelo `backend/app/models/system_audit_event.py`.
- Se añadió el schema `backend/app/schemas/system_audit_event.py`.
- Se implementó el helper `backend/app/services/audit_event.py` para registrar eventos auditables sin duplicar lógica.
- Se añadió la migración `backend/alembic/versions/d4e8f1a2b3c4_structured_audit_events.py`.
- Se amplió `backend/app/api/endpoints/admin_audit.py` con:
  - métricas de eventos estructurados
  - `GET /api/v1/admin-audit/events` con filtros por módulo, severidad, empresa, actor y texto
- La vista `frontend/src/pages/AdminGlobalAuditoria.jsx` ya prioriza la auditoría estructurada y deja los logs legacy como apoyo.
- Se instrumentaron eventos reales en:
  - `login`, `logout`, `register`
  - creación, edición y baja de empresa
  - creación, edición y eliminación de comunicados
  - actualización de mantenimiento
  - revocación de sesión administrativa
