# TASK-0103

Estado: DONE
Tipo: bugfix
Prioridad: alta

## Descripcion
Corregir el error React `Rendered more hooks than during the previous render` en `LineasPresupuestoTab` tras los ultimos refinamientos del editor de presupuestos.

## Causa
Un `useEffect` que sincroniza `selectedNodeMeta` quedo declarado despues de retornos tempranos (`loading` y `tree` vacio), alterando el orden de hooks entre renders.

## Acciones
- Reordenar hooks para que todos se declaren antes de cualquier `return` temprano.
- Mantener la logica de sincronizacion de `selectedNodeMeta` sin alterar comportamiento funcional.
- Verificar compilacion del frontend.
