Resultado
- `Comunicados` ya soporta `Fecha / hora inicio` y `Fecha / hora fin`.
- La permanencia admite `10`, `20`, `30`, `60` segundos o `indefinido`, con `30` por defecto.
- El alcance ahora permite `Global` o selección de una o varias empresas.
- El listado administrativo ya filtra por estado (`Todos`, `Vigentes`, `Próximos`, `Caducados`), tipo, empresa destinataria, texto y rangos de fecha/hora.
- `AppLayout` dejó de renderizar comunicados simultáneos y ahora los presenta en serie después de cada login, una sola vez por sesión visual.
- Los comunicados temporales avanzan automáticamente; los `indefinidos` requieren cierre manual para pasar al siguiente.
- La auditoría de creación/edición conserva el rastro de duración y destinatarios.
