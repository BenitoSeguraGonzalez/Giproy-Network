Resultado
- `utils/spellcheck` usa ahora `LanguageTool` local como motor principal para castellano.
- Se mantiene el mismo contrato de respuesta (`original`, `corrected`, `suggestions`, `has_errors`) para no romper `Comunicados`.
- La corrección automática se limita a sustituciones seguras; cuando la sugerencia no es suficientemente fiable, el servicio marca revisión manual en lugar de aplicar cambios dudosos.
- Si `LanguageTool` no está disponible o falla en runtime, el endpoint cae al corrector técnico previo como fallback.

- `python -m py_compile backend/app/api/endpoints/utils.py`
- prueba directa del corrector con frases reales en castellano
