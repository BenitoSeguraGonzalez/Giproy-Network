Resultado
- Se creo persistencia backend `cronogramas_valorados` ligada a `empresa + proyecto + presupuesto`.
- El modulo ya expone API real para leer el cronograma valorado, guardar configuracion global y ajustar o restaurar distribuciones manuales por linea.
- El `Cronograma Valorado` del frontend ya consume el API nuevo, deja de recalcular todo en cliente y permite:
  - cambiar `tipo de periodo`
  - aplicar `% Ejecucion Global` en modo `Homogeneo` o `Definido por usuario`
  - ajustar manualmente una linea concreta
  - restaurar una linea al reparto global
- El cambio de `tipo de periodo` ahora pide confirmacion si existen overrides por linea, porque recalcular destruye esos ajustes.
- La tabla sigue manteniendo visibles las columnas base del presupuesto y desplaza horizontalmente los periodos.
