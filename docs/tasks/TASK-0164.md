# TASK-0164

Estado

Tipo

Descripción
Implementación de lógica de validación para licencias especiales.
1. El middleware de licencias debe detectar los flags `is_tester`, `is_academic`, `is_training`.
2. Restricción de exportaciones comerciales si `is_academic` está habilitado (opcional).
3. Habilitación de feature flags experimentales si `is_tester` está habilitado.

Archivos afectados
- backend/app/services/license.py
- backend/app/core/license_policy.py
- backend/app/api/endpoints/admin_licenses.py
- backend/scripts/cleanup_training_licenses.py
- backend/app/tests/test_license_service_special_flags.py
