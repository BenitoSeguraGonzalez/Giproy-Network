# TASK-0182: Restauración de Módulo de Presupuestos

## Problema

1. Los presupuestos no cargan (Error 500 o similar).
2. Falla la creación automática del presupuesto base para una revisión.
3. Se ha perdido la lógica de "Un presupuesto por revisión" con EDTs precargadas.
4. La interfaz actual no cumple con los requerimientos de flujo de trabajo.
