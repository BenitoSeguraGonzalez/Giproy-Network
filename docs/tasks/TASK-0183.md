# TASK-0183: Consolidación de Correcciones - Presupuestos y Editor APU

## Problemas Detectados y Resueltos

### 1. Integridad de Presupuestos
- **Falta de Presupuesto**: Proyectos 5, 6, 7 y 8 no tenían presupuestos vinculados o estaban vacíos.
  - *Solución*: Se movieron proyectos a la Empresa 2 (Jesús Benito) según correspondía y se ejecutó un script de sincronización para inicializar los presupuestos desde el EDT.
  - *Proyecto 7*: Se detectó que no tenía nodos EDT. Se creó un nodo "GENERAL" y se inicializó su presupuesto satisfactoriamente.
- **Presupuestos Duplicados/Huérfanos**: Se eliminaron presupuestos vacíos (IDs 7, 8, 11, 12) para limpiar la base de datos.

### 2. Estabilidad del Editor APU
- **Cálculos $NaN**: Errores causados por parsing de números con comas o nulos.
  - *Solución*: Implementado `parseNumericInput` globalmente en el editor y asegurada la conversión en el guardado.
- **Error al Guardar (Empresa 3)**: Errores de unicidad por `descripcion` y `unidad`.
  - *Solución*: Añadido el filtro `base_trabajo_id` en la comprobación de unicidad del backend (`apu_service.py`) y asegurado el envío del mismo desde el frontend.

### 3. Consistencia Visual y Funcional
- **Corrupción (--- GENERAL)**: Las líneas perdían el nombre del recurso.
  - *Solución*: Añadido `joinedload` en el repositorio para asegurar que los recursos se carguen siempre con el detalle del APU.
- **Inconsistencia de Unidades en Ajuste Rápido**: El modal de edición de recurso desde APU mostraba unidades incorrectas (ej: Km en lugar de h).
  - *Solución*: Se actualizó el backend para exponer la categoría del recurso y el frontend para cargar las unidades correctas dinámicamente al abrir el modal.

### 4. Ajustes de Interfaz solicitados por el Usuario
- **Etiquetas de Moneda**: Se renombró el label "Precio dolar estadounidense (sin indirectos)*" a "Precio Dolar (sin indirectos)*" globalmente en `Recursos.jsx` y `APUs.jsx`.
- **Formato de Decimales**: Se estandarizó el uso de 2 decimales para precios moneda en los inputs de edición, evitando la visualización de 4 decimales técnicos innecesarios.
