Descripción
Endurecer el flujo inverso de `Rendimiento Global` en el editor APU: si el usuario activa el modo global sobre un APU nuevo o sin líneas elegibles previas, la UI debe exigir la definición explícita de un rendimiento base global antes de empezar a cargar `Equipos y Herramientas` o `Mano de Obra`.

Archivos afectados
- frontend/src/pages/APUs.jsx
- docs/tasks/TASK-0187.md
- docs/CHANGELOG.md
- docs/HANDOFF.md

Checklist

[x] análisis
[x] implementación
[x] pruebas
[x] documentación

Resultado
- El editor APU ahora muestra un compositor inline de `Rendimiento Base Global` cuando `Rendimiento Global` está activo y todavía no existen líneas elegibles en categorías `1` o `4`.
- La carga de nuevas líneas de `Equipos y Herramientas` y `Mano de Obra` queda bloqueada hasta que el usuario defina ese valor base.
- Las categorías con rendimiento oculto (`Materiales`, `Transporte`, APUs hijos) siguen sin exigir esta definición.
