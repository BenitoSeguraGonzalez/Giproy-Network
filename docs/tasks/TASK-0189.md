Descripción
Corregir cruces de APUs reportados en la empresa `Santiago Bermeo`. El síntoma visible era que algunos APUs parecían haberse movido, aparecido en lugares no esperados o cambiar de categoría. La causa real debía auditarse no solo en la cabecera del APU, sino también en sus `apu_lineas`, donde recursos de otra base o empresa pueden contaminar el contenido del APU y alterar su lectura operativa.

- backend/scripts/sanitize_apu_cross_integrity.py
- docs/tasks/TASK-0189.md

Resultado
- Se endureció `APUService` para impedir que un APU se cree o edite con una `subcategoria_item_id` perteneciente a otra base de trabajo.
- Se creó un saneador específico `sanitize_apu_cross_integrity.py` para corregir cruces de `APU -> subcategoría` y `apu_lineas -> recurso/APU hijo`.
- La ejecución real sobre la base local detectó y corrigió `6` líneas APU que apuntaban a recursos fuera del contexto correcto.
- Tras el saneamiento, la empresa `Santiago Bermeo` quedó en `0` cruces para:
  - `APU -> subcategoría/base`
  - `APU línea -> recurso`
  - `APU línea -> APU hijo`
