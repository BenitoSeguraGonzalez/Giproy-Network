Descripción
Corregir la mala categorización del APU `Material filtrante para drenes, suministro y colocación` en la empresa `Santiago Bermeo`. El APU había sido creado bajo `5-001 REPLANTEOS Y NIVELACIONES` con código `5-001-0002`, pero su ubicación correcta era `5-003 RELLENOS / CONFORMACIONES / COMPACTACIONES`.

Resultado
- Se identificó que la inconsistencia era real en datos y no solo visual: el APU existía mal clasificado tanto en la base maestra `32` como en la base de proyecto `34` de `Santiago Bermeo`.
- Se creó y ejecutó `fix_santiago_material_filtrante_category.py` para mover ese APU de `5-001-0002` a `5-003-0002` y reubicarlo en la subcategoría `5-003` en ambas bases.
- El cambio se aplicó sin romper referencias, porque las vinculaciones operativas se mantienen por `apu_id`.
- `APUService` quedó endurecido para rechazar creaciones cuyo código no coincida con el prefijo de la subcategoría seleccionada.
