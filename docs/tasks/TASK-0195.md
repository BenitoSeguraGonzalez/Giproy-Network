Resultado
- Se identificó que los APUs `454`, `461` y `462` de la base maestra `1` reutilizaban los códigos `5-001-0002`, `5-001-0003` y `5-001-0004`, ya usados por APUs mock distintos en la base de proyecto `16`.
- En vez de sobrescribir el catálogo del proyecto, se renumeraron de forma conservadora esos `3` APUs legacy de la base maestra a códigos libres a nivel empresa.
- El saneamiento preservó los mismos `apu_id`, por lo que las referencias internas por `apu_hijo_id` no se rompieron.
- Tras la corrección, `Administradores Generales` deja de tener colisiones activas de `mismo código / distinta descripción`.
