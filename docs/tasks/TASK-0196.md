Descripción
Ajustar el listado principal de APUs para que deje de renderizarse en dos columnas y pase a una sola columna. El objetivo es mejorar legibilidad de descripciones largas, evitando truncamientos perceptivos y manteniendo coherencia con el uso operativo del catálogo.

Plan de modificación
1. Reemplazar el contenedor actual del listado APU de `grid grid-cols-1 xl:grid-cols-2` por una única columna en todos los breakpoints operativos.
2. Revisar la tarjeta de cada APU para aprovechar el ancho completo y reducir truncamiento de título/descripción.
3. Verificar que acciones laterales (`duplicar`, `editar`, `eliminar`) mantengan alineación y no desborden en resoluciones objetivo.
4. Validar que el cambio no afecte el comportamiento del listado vacío, filtros y scroll del módulo.
5. Ejecutar build frontend y revisar visualmente el flujo APU con descripciones largas.

Impacto UI
- Mejora lectura del catálogo APU.

Notas

Resultado
- El listado principal de APUs dejó de usar el layout de dos columnas y ahora se renderiza en una sola columna.
- Las tarjetas aprovechan el ancho completo disponible y la descripción ya no queda recortada por el mosaico lateral.
- Se reforzó el comportamiento de anchura mínima para bloque económico y acciones, evitando que compriman el texto principal.
