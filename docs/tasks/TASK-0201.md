Descripción
Extender la adopción del visor común de reportes a los módulos que ya disponían de exportación documental: `Presupuesto`, `EDT`, `VAE` y `Fórmula Polinómica`.

- docs/CHANGELOG.md
- docs/HANDOFF.md

Resultado
- El contrato común de `preview` y `export` se amplió para `presupuesto`, `edt`, `vae` y `polinomica`.
- `Presupuesto`, `EDT`, `VAE` y `Fórmula Polinómica` dejaron de descargar directamente y ahora abren el visor común antes de exportar.
- La exportación Excel sigue usando el backend común y la salida PDF reutiliza el flujo transversal de impresión/guardado.
- `EDT` quedó soportado mediante `variant` para `listado`, `diccionario` y `valorada`.

Validación de licencias
- Sin impacto en licencias.
- Se mantiene validación backend por empresa para todos los reportes conectados.

Impacto UI
- La experiencia documental queda homogénea entre módulos.
- Se elimina la disparidad de flujos aislados de descarga directa.
