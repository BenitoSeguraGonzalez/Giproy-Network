# TASK-0205 - Backend y saneamiento para orden de líneas APU

## Estado
COMPLETED

## Tipo
Feature

## Prioridad
Alta

## Área
Backend

## Agentes asignados
- Arquitectura
- Backend
- QA
- Documentación

## Objetivo
Introducir soporte backend formal para el orden de líneas APU y dejar saneado el dataset existente.

## Alcance
- Agregar `orden` a `apu_lineas`.
- Definir orden por defecto y normalización de datos históricos.
- Ordenar relaciones `APU.lineas` por `orden, id`.
- Incluir `orden` en schemas `APULinea`.
- Ajustar create/update/duplicate/import para preservar o generar orden estable.
- Crear endpoint/operación backend para mover una línea dentro del APU.

## Restricciones
- No permitir movimiento entre categorías distintas en esta fase.
- No romper cálculo de precios ni referencias `apu_hijo`.
- Mantener validaciones backend como fuente de verdad.

## Validación esperada
- Las líneas nuevas quedan numeradas al final de su categoría.
- El reordenamiento persiste tras guardar y recargar.
- Los duplicados/importaciones copian el orden fuente.

## Implementación ejecutada
- `backend/app/models/apu.py` añade `orden` en `APULinea` y ordena la relación `APU.lineas`.
- `backend/app/schemas/apu.py` expone `orden` y define `APULineaMoveRequest`.
- `backend/app/repositories/apu.py` preserva `orden` en create/update y permite reordenamiento explícito.
- `backend/app/services/apu.py` recalcula usando líneas ordenadas y propaga orden en duplicado/importación.
- `backend/app/api/endpoints/apus.py` incorpora `PUT /apus/{id}/lineas/move`.
- `backend/scripts/add_apu_line_order_column.py` sanea la base local y normaliza datos existentes.
