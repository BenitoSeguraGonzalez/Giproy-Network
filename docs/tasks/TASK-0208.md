# TASK-0208 - Reorganizar layout de líneas en editor APU e incorporar % relativo

## Estado
COMPLETED

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend + Arquitectura

## Agentes asignados
- Arquitectura
- Frontend
- QA
- Documentación

## Objetivo
Corregir el layout de la tabla de líneas del editor APU para evitar solapes entre `código` y `descripción`, e incorporar el nuevo dato `% Relativo` por línea y por sección.

## Hallazgos previos
- El layout actual en `frontend/src/pages/APUs.jsx` usa una grilla de `12` columnas que ya quedó saturada tras añadir el handle de arrastre.
- El bloque visual de `código` compite por espacio con el handle y la `descripción`, generando solape.
- El editor APU ya calcula `parcial` por línea y `subtotal` por sección, pero todavía no calcula ni muestra porcentaje relativo respecto al `costo_directo`.

## Regla funcional a fijar
- `% Relativo` de línea = `subtotal_parcial / costo_directo`.
- El porcentaje debe mostrarse por línea.
- Cada sección debe mostrar el sumatorio de los `% Relativo` de sus líneas.
- La suma de todas las secciones debe representar el 100% del costo directo del APU, salvo redondeos.

## Plan de ejecución
1. Rediseñar la tabla del editor APU para separar correctamente handle, código y descripción.
2. Definir cálculo visual robusto de `% Relativo` con fallback seguro cuando `costo_directo = 0`.
3. Mostrar `% Relativo` por fila y sumatorio por sección.
4. Verificar que la densidad visual siga siendo legible en escritorio y no rompa scroll ni edición inline.

## Impacto en licencias
- Sin impacto.
- No cambia permisos ni restricciones.

## Impacto UI / diseño
- Sí, afecta la tabla principal del editor APU.
- Debe respetar el libro de estilo y priorizar legibilidad sobre densidad extrema.

## Criterio de cierre
- Código y descripción dejan de pisarse.
- Cada fila muestra `% Relativo`.
- Cada sección muestra su acumulado porcentual.
- El cálculo se mantiene consistente con el costo directo del APU.

## Resultado ejecutado
- La tabla del editor APU fue reequilibrada para separar `handle`, `código` y `descripción`.
- Se añadió `% Relativo` por fila y acumulado porcentual por sección.
- El libro de estilo quedó actualizado con la regla específica del editor APU.
