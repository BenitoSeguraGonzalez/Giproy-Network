# TASK-0209 - Cálculo y presentación de % relativo en editor APU

## Estado
COMPLETED

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Implementar el cálculo de `% Relativo` en el editor APU usando el `subtotal` de cada línea respecto al `costo_directo` total del APU en edición.

## Alcance
- Calcular `% Relativo` por línea en base al parcial visible.
- Calcular sumatorio porcentual por sección/categoría.
- Resolver caso `costo_directo = 0` sin divisiones inválidas ni ruido visual.
- Mantener coherencia con cantidades, rendimiento global y parciales recalculados en vivo.

## Restricciones
- No mezclar `% Relativo` con indirectos ni con precio unitario total.
- La referencia es exclusivamente `costo_directo`.
- El resultado debe ser visual y reactivo dentro del editor; no requiere persistencia adicional.

## Validación esperada
- Cambiar cantidad, rendimiento o composición actualiza `% Relativo` inmediatamente.
- El sumatorio de sección refleja exactamente sus filas.
- El total agregado se acerca a `100%` salvo redondeo visual.

## Implementación ejecutada
- `% Relativo` de línea se calcula como `parcial / costo_directo`.
- `% Relativo` de sección se calcula como `subtotal_sección / costo_directo`.
- El caso `costo_directo = 0` se resuelve con `0,00%` para evitar ruido visual o divisiones inválidas.
