# TASK-0210 - Refactor visual de columnas en editor APU

## Estado
COMPLETED

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Reestructurar la tabla del editor APU para que `handle`, `código`, `descripción`, `unidad`, `cantidad`, `precio`, `rendimiento`, `% Relativo` y `parcial` convivan sin solapes.

## Alcance
- Separar explícitamente handle de drag del bloque de código.
- Rebalancear anchos de columnas y permitir mejor respiración al texto principal.
- Mantener acciones de editar recurso y eliminar sin colisión visual.
- Preservar legibilidad con códigos largos, descripciones largas y badges de subcategoría.

## Reglas de UX
- El campo más importante sigue siendo la descripción.
- El código debe ser legible, pero no dominar el ancho de la fila.
- La nueva columna `% Relativo` debe quedar cerca de `Parcial`, no dispersa.

## Validación esperada
- No hay superposición entre código y descripción.
- La tabla mantiene alineación estable en categorías con una o muchas filas.
- El layout sigue siendo operativo tras drag and drop y edición inline.

## Implementación ejecutada
- La tabla del editor APU ahora usa columnas explícitas para `Orden`, `Código`, `Descripción`, `Unidad`, `Cantidad`, `Precio`, `Rendimiento`, `% Relativo`, `Parcial` y `Acciones`.
- El badge de código quedó desacoplado del handle de arrastre.
- La descripción recuperó ancho prioritario y ya no se pisa con el código.
