# TASK-0212 - Layout de dos niveles para líneas APU en ancho intermedio

## Estado
DONE

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Reorganizar cada línea del editor APU en un layout de dos niveles cuando el ancho efectivo no permita una tabla técnica completa sin pérdida de legibilidad.

## Diseño objetivo
- Nivel 1: `handle + código + descripción`
- Nivel 2: `unidad + cantidad + precio + rendimiento + % relativo + parcial + acciones`

## Alcance
- Mantener drag and drop operativo.
- Preservar edición inline de campos numéricos.
- Priorizar 1 a 2 líneas visibles de descripción antes de truncar.
- Mantener `% Relativo` y `Parcial` juntos como bloque económico.

## Restricciones
- No degradar el modo amplio actual de escritorio real.
- No convertir la fila en tarjeta “blanda”; debe seguir sintiéndose técnica y operativa.

## Validación esperada
- La descripción ya no colisiona con el código.
- La fila es legible en portátil sin reducir todo a tamaños mínimos.
- Acciones y datos económicos siguen siendo accesibles.

## Resultado
- Se reorganizó la fila del editor APU en dos niveles cuando el ancho entra en modo compacto.
- El nivel superior ahora prioriza `handle + código + descripción`.
- El nivel inferior agrupa `unidad`, `cantidad`, `precio`, `rendimiento`, `% relativo`, `parcial` y acciones.
