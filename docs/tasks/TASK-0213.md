# TASK-0213 - Ajuste del panel lateral del editor APU para portátil

## Estado
DONE

## Tipo
Feature

## Prioridad
Media-Alta

## Área
Frontend

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Reducir la presión horizontal del catálogo lateral en el editor APU cuando el ancho útil del viewport entra en rango portátil.

## Alcance
- Definir ancho más estrecho por breakpoint/intermediate mode.
- Permitir colapso más agresivo o estado inicial más compacto en edición.
- Mantener buscador y árbol de recursos utilizables.

## Restricciones
- No romper drag and drop desde el catálogo.
- No ocultar información crítica de contexto de base/categoría.

## Validación esperada
- El área central de edición gana ancho suficiente para lectura.
- El panel lateral sigue siendo operativo y no se vuelve un obstáculo visual.

## Resultado
- El panel lateral del editor APU reduce su ancho en modo compacto para liberar espacio horizontal.
- Se mantuvieron operativos el buscador, el árbol de recursos y el drag and drop desde catálogo.
