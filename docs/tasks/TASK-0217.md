# TASK-0217 - Compactación de shell global y banners para modo portátil

## Estado
DONE

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend + Documentación

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Reducir la altura consumida por `AppLayout`, banner de resolución, comunicados, mantenimiento y header global cuando el sistema opere en modo portátil.

## Alcance
- `frontend/src/layouts/AppLayout.jsx`
- banner de resolución
- banners de anuncios/mantenimiento
- navbar global y bloques de contexto

## Restricciones
- No ocultar contexto crítico de empresa/base/licencia.
- Mantener accesibles acciones de perfil, ajustes y salida.

## Validación esperada
- El header global consume menos altura.
- El banner de resolución deja de ser una franja fija dominante.
- La pantalla gana altura útil real antes de entrar al módulo.

## Resultado
- `AppLayout` ahora detecta modo portátil por viewport efectivo.
- El banner de resolución deja de ocupar una franja completa en portátil y pasa a aviso compacto integrado en header.
- Navbar global, bloques de contexto y acciones de usuario reducen altura y densidad en ese modo.
- Comunicados y mantenimiento también reducen su altura visible en portátil.
