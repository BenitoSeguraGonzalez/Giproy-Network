# TASK-0218 - Compactación de headers locales y footers fijos en módulos operativos

## Estado
DONE

## Tipo
Feature

## Prioridad
Alta

## Área
Frontend

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Reducir la altura de cabeceras locales y bloques fijos inferiores en módulos de trabajo para evitar que el viewport portátil pierda área útil antes del contenido operativo.

## Alcance
- `APUs`
- `Presupuesto`
- módulos de proyecto con shell técnica similar
- footers de totales y bandas métricas

## Restricciones
- Mantener la acción primaria visible.
- Acciones secundarias pueden pasar a overflow o composición compacta.

## Validación esperada
- Menos padding vertical.
- Títulos, acciones y métricas siguen accesibles.
- El trabajo central gana altura útil sin degradar legibilidad.

## Resultado
- `APUs` redujo padding y altura efectiva de su header local, tarjeta de detalle, área scrollable y footer de totales en modo portátil.
- `PresupuestoDetail` compactó su franja superior, padding principal y anchos laterales en viewport portátil.
- La acción primaria se mantiene visible y el área central gana altura útil real.
