# TASK-0223 - Override manual de Portable Workspace Mode para superadmin

## Estado
DONE

## Tipo
Feature

## Prioridad
Media-Alta

## Área
Frontend + Documentación

## Agentes asignados
- Frontend
- QA
- Documentación

## Objetivo
Permitir a `superadmin` forzar manualmente el `Portable Workspace Mode` para diseño y pruebas, sin afectar el comportamiento automático del resto de usuarios.

## Regla funcional
- `superadmin` puede activar o desactivar manualmente el modo portátil desde la shell global.
- El resto de roles no debe ver ni usar esta capacidad.
- Para usuarios no `superadmin`, el modo portátil sigue siendo exclusivamente automático según viewport.

## Implementación
1. Persistencia local del override en navegador.
2. Botón visible solo para `superadmin` en la shell global.
3. Reutilización del override en `AppLayout`, `APUs` y `Presupuesto`.

## Resultado
- `superadmin` puede forzar el modo portátil bajo demanda.
- El override se propaga a la shell y a los módulos ya migrados.
- El resto de usuarios mantiene comportamiento automático puro.
