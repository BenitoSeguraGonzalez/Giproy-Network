# TASK-0225 - Corrección de reordenamiento drag and drop en editor APU

## Estado
COMPLETED

## Objetivo
Corregir la regresión por la cual el arrastre y suelta de líneas dentro de una categoría del editor APU no modificaba realmente el orden visible.

## Alcance
- Frontend `APUs`
- Trazabilidad documental

## Agentes
- Frontend
- QA
- Documentación

## Causa raíz
La función de reordenamiento reconstruía la secuencia visual, pero luego la normalización volvía a ordenar usando el `orden` anterior de cada línea, anulando el cambio recién realizado.

## Ejecución
- Se reasignó `orden` a la secuencia reordenada antes de reintegrarla al formulario.
- Se mantuvo la restricción de reordenamiento dentro de la misma categoría.

## Verificación
- `npm run build`

## Resultado
El drag and drop en el editor APU vuelve a mover efectivamente las líneas dentro de su categoría y conserva el nuevo orden para el guardado.
