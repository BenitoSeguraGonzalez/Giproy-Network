# TASK-0227 - Compactación de cabecera de línea en editor APU

## Estado
COMPLETED

## Objetivo
Compactar la cabecera de cada línea del editor APU para que `código` y `descripción` compartan la misma banda visual y eliminar la etiqueta `General` cuando actúa solo como fallback irrelevante.

## Alcance
- Frontend `APUs`
- Documentación de estilo
- Trazabilidad en changelog/handoff

## Agentes
- Frontend
- Documentación
- QA

## Causa
El editor estaba desperdiciando altura al separar `código` y `descripción` en bloques distintos y además mostraba `subcategoria_nombre` con fallback `General`, un dato sin valor operativo en la línea.

## Ejecución
- `código` y `descripción` se muestran ahora en una sola banda de lectura.
- Se eliminó la línea secundaria `General` del render de líneas APU.
- Se mantiene el resto de datos económicos y acciones sin alterar el flujo de edición.

## Verificación
- `npm run build`
