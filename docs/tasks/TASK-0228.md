# TASK-0228 - Política de despliegue del panel izquierdo en editor APU

## Estado
COMPLETED

## Objetivo
Hacer que el panel izquierdo de recursos en el editor/creador APU aparezca desplegado por defecto y añadir despliegue temporal automático por hover cuando el usuario lo haya plegado manualmente.

## Alcance
- Frontend `APUs`
- Documentación de estilo
- Trazabilidad en changelog/handoff

## Agentes
- Frontend
- Documentación
- QA

## Ejecución
- El panel de recursos vuelve a abrirse por defecto al entrar al editor APU.
- Si el panel está plegado y el usuario pasa el ratón por encima, se despliega automáticamente.
- Si el despliegue fue automático por hover, al salir el ratón vuelve a plegarse.

## Verificación
- `npm run build`
