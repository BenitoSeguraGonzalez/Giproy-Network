# TASK-0234 - Españolización persistida de OmniClass

## Estado
COMPLETED

## Objetivo
Incorporar traducción persistida de OmniClass en español, reutilizable por todo el sistema, manteniendo compatibilidad con el maestro original y con búsqueda bilingüe.

## Enfoque
- No traducir al vuelo.
- No sustituir el título original.
- Añadir campo persistido `titulo_es` y consumirlo con fallback al inglés/original.

## Resultado
- Se añadió `titulo_es` al maestro OmniClass.
- Se ejecutó una carga inicial persistida copiando `titulo` hacia `titulo_es` como baseline reutilizable.
- Backend y frontend ya consumen `titulo_es` preferentemente, con fallback al original.
- La infraestructura queda lista para una futura curación terminológica sin rediseñar el sistema.
