# TASK-0260 - Vista Gráfica Jerárquica para EDT y EDO

## Estado
COMPLETED

## Objetivo
Diseñar e implementar una vista gráfica jerárquica adicional para `EDT` y `EDO`, complementaria al árbol actual, inspirada en organigramas / diagramas de estructura de desglose.

## Alcance
- Vista gráfica opcional para `EDT`
- Vista gráfica opcional para `EDO`
- Diseño responsive para escritorio, portátil y tablet
- Sin reemplazar el árbol actual; ambas vistas deben coexistir

## Criterios
- Mantener compatibilidad con la jerarquía y metadatos actuales
- Priorizar legibilidad y navegación antes que edición avanzada dentro del gráfico
- Asegurar degradación usable en modo portátil

## Verificación
- `EDT` y `EDO` exponen toggle `Árbol / Gráfico`
- La vista gráfica coexiste con el árbol sin sustituir la edición principal
- `npm run build`
