# TASK-0261 - Arquitectura y Layout de Vista Gráfica EDT/EDO

## Estado
COMPLETED

## Objetivo
Definir la arquitectura frontend de la vista gráfica jerárquica para `EDT` y `EDO`, incluyendo estrategia de layout, pan/zoom y relación con el árbol existente.

## Alcance
- Selección de motor de renderizado
- Estrategia de layout jerárquico
- Modo responsive y reglas de degradación
- Contrato de datos común para ambos módulos

## Resolución aplicada
- Se implementó layout jerárquico propio con conectores CSS y scroll/zoom controlado
- Se evitó incorporar una librería pesada adicional para mantener coste y riesgo contenidos
- La edición principal permanece en el árbol; el gráfico opera como superficie de lectura y navegación
