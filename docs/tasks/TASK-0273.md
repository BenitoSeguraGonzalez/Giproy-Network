# TASK-0273 - Modo de Enfoque por Rama en Vista Gráfica EDT/EDO

## Estado
DONE

## Resumen
Se incorpora un modo `Rama activa` en la vista gráfica de `EDT` y `EDO` para aislar el subárbol del nodo seleccionado cuando la estructura completa resulte demasiado cargada.

## Alcance
- `frontend/src/components/projects/HierarchyGraphView.jsx`
- `docs/STYLE_GUIDE.md`
- `docs/CHANGELOG.md`
- `docs/HANDOFF.md`

## Implementación
- Se añade un toggle `Rama activa / Vista total` en la barra de búsqueda del gráfico.
- Cuando existe nodo seleccionado y el modo `Rama activa` está activo, el renderer trabaja solo con el subárbol de ese nodo.
- Si la selección desaparece, la vista vuelve automáticamente a `Vista total`.
- La banda de resumen estructural adapta su copy para distinguir entre `Nodos visibles` y `Nodos de rama`.
