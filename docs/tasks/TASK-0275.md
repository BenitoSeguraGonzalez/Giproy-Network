# TASK-0275 - Minimapa Colapsable y Pan Central en Vista Gráfica EDT/EDO

## Estado
DONE

## Resumen
Se mejora la ergonomía de la vista gráfica de `EDT` y `EDO` con un minimapa colapsable, pan restringido al lienzo usando el botón central del ratón y compactación adicional de las bandas superiores para recuperar espacio útil.

## Alcance
- `frontend/src/components/projects/HierarchyGraphView.jsx`
- `docs/STYLE_GUIDE.md`
- `docs/CHANGELOG.md`
- `docs/HANDOFF.md`

## Implementación
- Se añade colapso/expansión del minimapa mediante botón lateral sobre su borde.
- El minimapa puede quedar reducido a un rail técnico estrecho con etiqueta visual.
- El área gráfica permite paneo con botón central del ratón solo dentro del viewport del gráfico.
- Se previene el autoscroll genérico del navegador sobre el lienzo del gráfico.
- Se compactan aún más las bandas previas al lienzo para maximizar la altura útil de trabajo.
