# TASK-0277 - Persistencia de UI y Zoom con Ctrl+Rueda en Vista Gráfica EDT/EDO

## Estado
DONE

## Resumen
Se añaden persistencia por sesión de las bandas plegadas del gráfico y zoom con `Ctrl + rueda` sobre el lienzo para mejorar continuidad de trabajo y ergonomía fina.

## Alcance
- `frontend/src/components/projects/HierarchyGraphView.jsx`
- `docs/STYLE_GUIDE.md`
- `docs/CHANGELOG.md`
- `docs/HANDOFF.md`

## Implementación
- Se persisten por sesión los estados de plegado de `Minimapa`, `Vista navegable`, `Ruta activa` y `Filtros y raíces`.
- La persistencia se resuelve por módulo gráfico (`EDT` / `EDO`) usando `sessionStorage`.
- El lienzo gráfico ahora soporta zoom con `Ctrl + rueda` sin depender exclusivamente de los botones de zoom.
- El comportamiento sigue siendo local al frontend y no altera contratos backend ni payloads de árbol.
