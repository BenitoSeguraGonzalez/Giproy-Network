# TASK-0278 - Minimapa Modal, Pan Nativo y Leyenda Visual en Vista Gráfica EDT/EDO

## Estado
DONE

## Resumen
Se sustituye el minimapa lateral por un minimapa modal, se endurece el paneo del lienzo con listeners nativos para bloquear el autoscroll del navegador y se añade una leyenda visual por tipo/estado de nodo.

## Alcance
- `frontend/src/components/projects/HierarchyGraphView.jsx`
- `docs/STYLE_GUIDE.md`
- `docs/CHANGELOG.md`
- `docs/HANDOFF.md`

## Implementación
- El minimapa deja de ocupar ancho estructural del gráfico y pasa a abrirse en modal desde un botón flotante.
- El paneo del gráfico se ejecuta con listeners nativos sobre el viewport para bloquear el autoscroll de botón central del navegador.
- Se mantiene el zoom con `Ctrl + rueda` sobre el lienzo.
- Se añade `Leyenda visual` plegable con semántica de tipos y estados del nodo (`principal`, `responsable`, `activo`, `búsqueda`, `colapso`).
