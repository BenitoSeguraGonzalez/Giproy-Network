# TASK-0280 - Encapsulado de Scroll EDT/EDO y Cierre de Autoscroll

## Estado
DONE

## Objetivo
Eliminar el autoscroll residual del navegador en la vista gráfica de `EDT` y `EDO` asegurando que el scroll vertical padre del módulo no siga disponible mientras el usuario trabaja dentro del lienzo.

## Diagnóstico
El viewport del gráfico ya bloqueaba el botón central localmente, pero `EDT` y `EDO` seguían montándose dentro del `main` scrollable de `Proyectos`. Eso dejaba un ancestro con `overflow-y-auto` al que el navegador podía enganchar el autoscroll.

## Cambios
- `frontend/src/pages/Proyectos.jsx`
  - `EDT` y `EDO` pasan al mismo régimen de `overflow-hidden` que `Cronogramas`.
  - se homogeneiza también el padding externo a `p-6`.
- `frontend/src/components/projects/Edt.jsx`
  - raíz principal en `h-full min-h-0 flex flex-col`.
  - contenedor operativo principal como `flex-1 min-h-0`.
- `frontend/src/components/projects/Edo.jsx`
  - misma estructura que `EDT`.
- `frontend/src/components/projects/HierarchyGraphView.jsx`
  - viewport del gráfico reforzado con `h-full min-h-0 select-none`.

## Verificación
- `npm run build`
