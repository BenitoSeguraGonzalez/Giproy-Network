# TASK-0281 - Lienzo Virtual y Recuperación de Paneo EDT/EDO

## Estado
DONE

## Objetivo
Recuperar el desplazamiento real dentro de la vista gráfica de `EDT` y `EDO` sin reabrir el scroll general de la página.

## Diagnóstico
Tras encapsular el scroll del módulo, el navegador dejó de desplazarse, pero el gráfico seguía usando un lienzo del tamaño estricto del contenido. En jerarquías pequeñas o medias no quedaba área virtual suficiente para panear, por lo que la zona de trabajo parecía inmóvil.

## Cambios
- `frontend/src/pages/Proyectos.jsx`
  - `main` y `MotionDiv` ahora aseguran `min-h-0` para permitir scroll interno real en tabs encapsuladas.
- `frontend/src/components/projects/HierarchyGraphView.jsx`
  - raíz y viewport del gráfico reforzados con `min-h-0`.
  - incorporación de un lienzo virtual mayor que el contenido (`workspaceMinWidth` / `workspaceMinHeight`) para permitir paneo útil aunque el árbol no desborde naturalmente.

## Verificación
- `npm run build`
