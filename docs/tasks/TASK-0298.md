# TASK-0298 - Saneamiento de Estructuras EDT/Presupuesto Desalineadas

Estado
COMPLETED

Fecha
2026-03-20

Objetivo
Auditar y corregir proyectos donde la numeración de `EDT` y la estructura visible en `Presupuesto` hayan quedado desalineadas por movimientos anteriores.

Alcance
- scripts de saneamiento o auditoría
- validación de ramas EDT ya movidas
- proyectos afectados en la base actual

Validaciones obligatorias
- Detectar cuentas cuyo código visible ya no coincida con su posición jerárquica real.
- Detectar ramas que en `Presupuesto` aún reflejen el padre anterior.
- Corregir sin tocar códigos de partidas/APUs.
- Registrar claramente cualquier saneamiento aplicado sobre datos existentes.
- No crear ni conservar filas estructurales presupuestarias derivadas de nodos `STAKEHOLDER`.

Resultado esperado
- La base actual queda coherente antes de endurecer la sincronización futura.

Implementación
- Se creó `backend/scripts/sanitize_edt_presupuesto_sync.py`.
- El saneamiento recalcula la raíz EDT por proyecto/empresa y luego resincroniza los presupuestos operativos relacionados.
- También deduplica filas estructurales presupuestarias que habían quedado repetidas por `edt_id`.

Resultado de ejecución local
- `projects_scanned = 4`
- `edt_branches_recalculated = 4`
- `presupuestos_synced = 2`
