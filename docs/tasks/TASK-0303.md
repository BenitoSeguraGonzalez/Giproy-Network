# TASK-0303 - QA Funcional de Plantilla APU Excel

Estado
COMPLETED

Fecha
2026-03-21

Objetivo
Validar la exportación APU Excel con plantilla real para asegurar que no queden placeholders residuales ni mapeos erróneos por categoría.

Alcance
- prueba con APU real de múltiples categorías
- exportación individual y bundle multihoja
- comprobación de placeholders visibles residuales
- auditoría de plantillas activas no APU para confirmar que siguen siendo planas y compatibles con el motor genérico

Validaciones obligatorias
- No debe quedar ningún `#CODCAT`, `#CANTIDAD`, `#PRECIO`, `#RENDIMIENTO`, `#SUBTOTAL`, `#PORCENT`, `#OMNICLASS_*`, `#TOTAL` o `TOTPORCENT` visible en el archivo final.
- Los valores por categoría deben coincidir con el editor APU.
- Las hojas múltiples deben mantener el mismo comportamiento en cada APU exportado.

Resultado esperado
- La salida Excel queda funcionalmente cerrada sobre la plantilla vigente.

Resultado ejecutado
- La auditoría del catálogo activo confirmó que `Presupuesto`, `EDT`, `VAE Proyecto`, `Polinómica`, `EDO`, `Stakeholders` y `Cronograma` siguen usando plantillas planas.
- El backend ya rechaza desde el motor genérico cualquier plantilla que contenga placeholders categorizados tipo APU, evitando regresiones silenciosas.
