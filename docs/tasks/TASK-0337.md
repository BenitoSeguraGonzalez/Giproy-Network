# TASK-0337 - Comunidad Topic-Bound Posting and Hidden Control Surface

## Objetivo
Forzar que las publicaciones de `Comunidad` nazcan siempre dentro de un tema activo y retirar la administración del flujo visible principal, concentrándola detrás de un control explícito.

## Criterios de aceptación
- No se puede publicar sin tema seleccionado.
- El compositor indica el tema activo y bloquea publicación si no existe.
- Las herramientas administrativas no quedan visibles para usuarios normales.
- El control administrativo no se presenta como lateral fijo del feed.
