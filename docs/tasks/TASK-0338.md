# TASK-0338 - Comunidad: bloqueo explícito entre usuarios en DM

## Estado
COMPLETED

## Tipo
feature

## Prioridad
high

## Descripción
Endurecer `Mensajes directos` en `Comunidad` para que el bloqueo de un hilo deje trazabilidad explícita del usuario que lo ejecutó y no pueda ser revertido por la contraparte sin una acción del mismo bloqueador.

## Archivos afectados
- `backend/app/models/community.py`
- `backend/app/schemas/community.py`
- `backend/app/api/endpoints/community.py`
- `backend/alembic/versions/`
- `backend/app/tests/test_community_permissions.py`
- `frontend/src/pages/Community.jsx`

## Checklist

- [x] análisis
- [x] implementación
- [x] pruebas
- [x] documentación

## Resultado
- `CommunityDmThread` ahora registra `blocked_by_user_id` además de `blocked_at`.
- El bloqueo de DM deja trazabilidad explícita del actor que lo ejecutó.
- Solo el mismo usuario que bloqueó el hilo puede reactivarlo.
- La UI de `Comunidad` refleja si el hilo fue bloqueado por el usuario actual o por la contraparte y ajusta el CTA de reactivación en consecuencia.
