# TASK-0340 - Comunidad: edición y borrado propio por autor

## Estado
COMPLETED

## Tipo
feature

## Prioridad
high

## Descripción
Permitir que el autor gestione su propio contenido en `Comunidad` con reglas conservadoras: edición y borrado lógico de publicaciones y respuestas dentro de una ventana limitada y sin bypass de moderación.

## Archivos afectados
- `backend/app/schemas/community.py`
- `backend/app/api/endpoints/community.py`
- `backend/app/tests/test_community_permissions.py`
- `frontend/src/api/community.js`
- `frontend/src/pages/Community.jsx`

## Checklist

- [x] análisis
- [x] implementación
- [x] pruebas
- [x] documentación

## Resultado
- El autor ya puede editar y borrar lógicamente su propia publicación o respuesta dentro de una ventana conservadora de `30 minutos`.
- El borrado propio no permite romper conversación existente:
  - una publicación con respuestas visibles no puede borrarse por autor
  - una respuesta con hijas visibles no puede borrarse por autor
- Todas las validaciones viven en backend y no sustituyen la moderación administrativa.
