# TASK-0341 - Comunidad Basic User Mentions

## Estado
COMPLETED

## Tipo
Backend + Frontend + QA + Documentation

## Objetivo
Incorporar una primera capa operativa de menciones `@usuario` en `Comunidad` sin abrir todavía un sistema de notificaciones, feeds secundarios ni entidades nuevas de seguimiento.

## Alcance
- Exponer un `community_handle` estable por usuario visible en `Comunidad`.
- Validar en backend las menciones usadas en publicaciones, respuestas y DM.
- Restringir menciones al contexto de empresa de origen; en temas internos restringidos, solo a miembros con acceso real al tema.
- Resaltar menciones resueltas en la UI y guiar al usuario con el formato `@handle`.

## Reglas
- Las menciones se resuelven en backend; el frontend no decide si una mención es válida.
- `Público` no habilita menciones multiempresa en esta fase: sigue usando el contexto de empresa de origen de la publicación.
- Si una mención no es válida en ese contexto, la operación se rechaza.
- No se crea todavía infraestructura de notificaciones o bandejas derivadas.

## Validación
- Suite backend de `community_permissions` ampliada para handles y restricciones en temas internos restringidos.
- Build frontend del módulo `Community` correcto.

## Resultado
- `Comunidad` ya soporta menciones básicas `@handle` con validación de ámbito, sin saltarse permisos ni membresías restringidas.
