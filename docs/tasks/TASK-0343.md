# TASK-0343 - Comunidad Base Attachments for Posts and Replies

## Estado
COMPLETED

## Tipo
Backend + Frontend + QA + Documentation

## Objetivo
Abrir la primera capa real de adjuntos en `Comunidad` respetando el contrato ya fijado: `Público` solo imágenes, `Interno` archivos con retención automática de `30 días`, sin ampliar todavía el alcance a DM.

## Alcance
- Tabla propia `community_attachments`.
- Adjuntos para publicaciones y respuestas.
- Validación backend por ámbito y tipo de archivo.
- Subida local en `uploads/community`.
- Script operativo de purga para adjuntos internos vencidos.

## Reglas
- `Público`: solo imágenes adjuntas.
- `Interno empresa`: archivos permitidos con `expires_at` a `30 días`.
- DM queda fuera de esta fase.
- La validación de tipo y retención vive en backend.

## Validación
- Suite `community_permissions` ampliada para política de adjuntos y purga.
- Build frontend correcto con carga y render básico de adjuntos.

## Resultado
- `Comunidad` ya soporta adjuntos base en publicaciones y respuestas sin romper el modelo multiempresa ni abrir una política no aprobada para DM.
