# TASK-0347 - Comunidad Admin Alert Drill-Down

## Estado
COMPLETED

## Tipo
Frontend + Documentation + QA

## Objetivo
Convertir las alertas e infracciones administrativas de `Comunidad` en una superficie de revisión útil, sin abrir nuevas rutas ni un centro transversal de moderación.

## Alcance
- Enlace directo `alerta -> infracción`.
- Estado visual de selección en la lista de infracciones.
- Panel contextual de detalle para la infracción seleccionada.

## Reglas
- Todo vive dentro del panel de control actual de `Comunidad`.
- No se abren rutas nuevas ni navegación externa.
- La mejora aplica solo a la superficie administrativa de `superadmin`.

## Validación
- Build frontend correcto.
- Suite backend de permisos se mantiene estable sin regresión.

## Resultado
- Las alertas administrativas de `Comunidad` ya permiten inspección contextual de la infracción relacionada sin salir del módulo.
