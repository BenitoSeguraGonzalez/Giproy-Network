# TASK-0349 - Comunidad Sanction Review Context

## Estado
COMPLETED

## Tipo
Frontend + Documentation + QA

## Objetivo
Reducir el cruce manual entre listas de sanciones, apelaciones e infracciones dentro de la moderación de `Comunidad`.

## Alcance
- Enlace `apelación -> sanción`.
- Estado visual seleccionado en sanciones.
- Panel contextual de detalle para la sanción elegida.
- Enlace opcional `sanción -> infracción` cuando la sanción proviene de una infracción automática.

## Reglas
- Todo vive dentro del `Panel de control` actual de `Comunidad`.
- No se crean rutas nuevas ni se modifica el contrato backend.
- La mejora no altera permisos ni reglas de licenciamiento; solo mejora lectura operativa.

## Validación
- Build frontend correcto.
- Suite backend de permisos se mantiene estable sin regresión.

## Resultado
- Moderación ya puede revisar sanciones y apelaciones con contexto enlazado, sin salir del módulo ni cruzar listas manualmente.
