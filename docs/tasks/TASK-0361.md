# TASK-0361 - Comunidad Load Timeout Guard

## Estado
COMPLETED

## Tipo
Frontend + Documentation + QA

## Objetivo
Evitar que `Comunidad` quede bloqueada indefinidamente en estado de carga cuando una o varias capas del arranque quedan pendientes sin responder.

## Alcance
- Timeout defensivo por capa durante `loadCommunityData()`.
- Timeout defensivo para la carga del hilo DM activo.
- Reaprovechamiento del sistema existente de `Carga parcial` para reportar timeouts como fallos parciales.

## Reglas
- No se cambia el contrato backend.
- El módulo debe salir de `loading` aunque una capa individual quede colgada.
- Los timeouts deben degradar a advertencia parcial, no vaciar toda la pantalla si `bootstrap` sí responde.

## Validación
- `npm run build`

## Resultado
- `Comunidad` ya no debe quedarse en `Cargando Comunidad...` por una promesa pendiente en alguna capa secundaria.
