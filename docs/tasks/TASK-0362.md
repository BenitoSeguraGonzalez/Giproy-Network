# TASK-0362 - Comunidad Schema Drift Diagnostic

## Estado
COMPLETED

## Tipo
Backend + Documentation

## Objetivo
Convertir fallos opacos `500` de capas críticas de `Comunidad` en un diagnóstico operativo explícito cuando el backend detecta desalineación entre código y esquema real de base de datos.

## Alcance
- Traducción defensiva de errores SQLAlchemy a `503` con mensaje de esquema desactualizado en:
  - `GET /community/posts`
  - `GET /community/dm/threads`
  - `GET /community/sanction-appeals`

## Reglas
- No se oculta la incidencia real: el módulo sigue marcando `Carga parcial`.
- No se altera el modelo de permisos ni licencias.
- El mensaje debe orientar a actualizar migraciones, no a depurar frontend.

## Validación
- `PYTHONPATH=backend python -m pytest -q backend/app/tests/test_community_permissions.py`

## Resultado
- Si la BD real está desalineada, `Comunidad` ya no devuelve un `500` genérico en estas capas y expone una causa operativa accionable.
