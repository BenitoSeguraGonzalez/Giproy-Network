# TASK-0363 - Comunidad Admin Workspace

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Convertir el antiguo panel de control disperso de `Comunidad` en una zona administrativa explícita y operativa, separada del feed normal del módulo.

Alcance
- Crear una `Zona administrativa` visible solo para perfiles con capacidades de moderación.
- Separar internamente la administración en frentes claros:
  - `Resumen`
  - `Gobernanza`
  - `Usuarios`
  - `Moderación`
- Reunir en esa superficie:
  - categorías y temas por ámbito
  - membresía restringida por tema
  - listado de usuarios asignados
  - alta de `usuario_comunidad`
  - sanciones, apelaciones, alertas e infracciones
- Mantener el feed como superficie principal para lectura/publicación cuando el usuario no está en modo administración.

Restricciones
- Sin rutas nuevas para esta fase.
- Sin romper validaciones backend existentes de licencias, roles o permisos.
- Sin reintroducir herramientas administrativas visibles por defecto dentro del feed.

Validación
- `npm run build`

Resultado
- `Comunidad` ya expone una zona administrativa dedicada y separada del feed.
- La creación de `usuario_comunidad` puede ejecutarse desde el propio módulo reutilizando el formulario de personal existente.
- La gobernanza de temas/categorías y la moderación quedan agrupadas en una sola superficie administrativa coherente.
