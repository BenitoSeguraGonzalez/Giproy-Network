# TASK-0364 - Comunidad Forum Index Layout

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Reestructurar visualmente el feed principal de `Comunidad` hacia un patrón de índice de foro por categorías y temas, inspirado en referencias clásicas de foros, pero ajustado a la identidad visual actual de GiProy.

Alcance
- Convertir la entrada principal de `Público` y `Mi empresa` en una superficie de índice:
  - bloques por categoría
  - temas clicables dentro de cada bloque
  - métricas resumidas
  - última actividad visible por bloque
- Hacer que el feed principal responda al `tema activo`, en vez de comportarse como una lista general plana.
- Mantener el compositor como superficie lateral y secundaria.
- Reutilizar colores, espaciado y tono visual del sistema actual; no introducir una estética ajena al producto.

Restricciones
- Sin cambiar contratos backend.
- Sin romper la regla `tema -> publicación`.
- Sin convertir `Mensajes directos` en parte del índice del foro.

Validación
- `npm run build`

Resultado
- `Comunidad` ya presenta una estructura más cercana a un directorio de foro: categorías arriba, temas navegables y actividad resumida.
- El feed queda reservado al tema seleccionado, reforzando la lectura estructurada del módulo.
