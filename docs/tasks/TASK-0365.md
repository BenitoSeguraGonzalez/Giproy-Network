# TASK-0365 - Comunidad Forum Index Visual Refinement

Estado: COMPLETED

Refinar visualmente el nuevo índice de foro de `Comunidad` para que tenga mejor jerarquía, lectura operativa y sensación de bloque activo sin perder alineación con la identidad de GiProy.

Alcance
- Añadir iconografía semántica por bloque/categoría.
- Dar más peso visual al bloque activo.
- Convertir los temas en botones/tarjetas compactas con mejor legibilidad.
- Hacer más clara la tarjeta de `Tema activo`.
- Reforzar el bloque de `Última actividad` con más contexto del tema relacionado.

Validación
- `npm run build`

Resultado
- El índice del foro ya no se siente como una traducción plana del layout anterior.
- La lectura de categorías, temas activos y última actividad es más directa y jerárquica.
