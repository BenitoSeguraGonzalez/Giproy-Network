# TASK-0366 - Comunidad Scope Contrast and Topic Metrics

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Media

Área: Comunidad

Objetivo
Hacer más legible la diferencia entre `Público` y `Mi empresa` dentro del nuevo índice de foro de `Comunidad`, y añadir micro-métricas por tema para que la navegación sea más operativa.

Alcance
- Dar una firma visual distinta al índice según el ámbito activo.
- Mostrar micro-resúmenes por tema dentro de cada bloque del índice.
- Enriquecer la tarjeta de `Tema activo` con métricas reales del tema seleccionado.
- Mantener el mismo contrato backend existente.

Validación
- `npm run build`

Resultado
- `Público` e `Interno` ya no se perciben como la misma pantalla con solo un cambio de texto.
- Los temas ya exponen señales útiles de actividad (`posts`, `respuestas`, `fijados`, última actividad) para facilitar la navegación.
