# TASK-0367 - Comunidad Header Navigation and Admin Entry

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Corregir la cabecera principal de `Comunidad` para que la navegación sea más clara y la entrada a `Administración` respete el ámbito operativo real del usuario.

Alcance
- Eliminar el texto explicativo redundante bajo el título de la superficie activa.
- Mover la navegación principal debajo del título.
- Fijar el orden visual:
  - `Público`
  - `Mi Empresa`
  - `Mensajes directos`
  - `Administración`
- Hacer que `Administración` sea visible así:
  - `superadministrador`: siempre
  - `administrador`: solo cuando la superficie activa es `Mi Empresa`
- Cerrar automáticamente la vista administrativa si el usuario pierde ese contexto visible.

Restricciones
- Sin cambiar permisos backend existentes.
- La moderación de `administrador` sigue limitada a la empresa activa y a su ámbito interno.
- `superadministrador` mantiene alcance global en `Comunidad`.

Validación
- `npm run build`

Resultado
- La cabecera de `Comunidad` ya responde al orden y jerarquía visual definidos.
- `Administración` ya no aparece fuera de contexto para administradores de empresa.
