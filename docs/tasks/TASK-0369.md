# TASK-0369 - Comunidad: seed ampliado para análisis fino

Estado: COMPLETED

Tipo: Backend + QA + Documentation

Prioridad: Alta

Área: Comunidad

Objetivo
Ampliar el dataset reproducible de `Comunidad` para que el módulo pueda analizarse y ajustarse con suficiente densidad operativa, sin depender de carga manual ni de una base vacía.

Alcance
- Reutilizar el entrypoint existente `backend/scripts/seed_community_demo.py`.
- Mantener limpieza idempotente limitada a tablas de `Comunidad`.
- Sembrar suficiente variedad para revisar:
  - índice de foro con varias categorías y temas,
  - posts públicos e internos con distinta antigüedad,
  - respuestas y actividad reciente,
  - temas restringidos con membresía real,
  - hilos DM con mensajes leídos/no leídos y un caso bloqueado,
  - sanciones, apelaciones, infracciones y alertas administrativas,
  - adjuntos visibles en público e interno.

Restricciones
- No crear una vía de seed paralela.
- No tocar reglas de permisos ni licencias.
- No sembrar datos irrepetibles o dependientes de intervención manual.

Validación
- `python -m py_compile backend/scripts/seed_community_demo.py`
- `python backend/scripts/seed_community_demo.py`

Resultado esperado
- `Comunidad` queda poblada con un dataset más útil para revisar lectura, densidad, navegación y moderación.

  - `4` posts internos

- El script quedó tolerante a bases locales donde alguna empresa solo tenga administrador y no usuario regular adicional.
