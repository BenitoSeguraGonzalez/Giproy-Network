# TASK-0370 - Comunidad: fail-safe contra carga infinita

Estado: COMPLETED

Tipo: Frontend + QA + Documentation

Prioridad: Alta

Área: Comunidad

Objetivo
Evitar que `Comunidad` pueda quedarse indefinidamente en `Cargando Comunidad...` cuando la carga inicial entra en un estado colgado o en una carrera de requests.

Alcance
- Endurecer el loader inicial del módulo.
- Añadir un fail-safe global de tiempo para la carga agregada.
- Ignorar resultados tardíos de requests viejas cuando ya existe una carga más nueva.

Restricciones
- No cambiar permisos ni contratos backend.
- No rehacer la estructura visual del módulo.

Resultado
- `frontend/src/pages/Community.jsx` ahora usa un `requestId` de carga y un timer fail-safe global.
- Si la carga inicial supera el umbral, el módulo deja de quedarse pegado en spinner y expone un error/warning accionable.
- Los resultados tardíos de una carga vieja ya no pisan el estado de una carga más reciente.

Validación ejecutada
- `npm run build`
