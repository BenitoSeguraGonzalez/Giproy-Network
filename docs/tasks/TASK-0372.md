# TASK-0372 - Comunidad Forum Index Compaction and Inline Topic Opening

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Remodelar el índice visual de `Comunidad` para reducir altura, quitar ruido informativo y hacer que la apertura del tema activo ocurra justo debajo del bloque/categoría donde se selecciona.

Alcance
- Compactar cada bloque de categoría a una lectura útil de dos filas.
- Reducir métricas y texto periférico que agrandan innecesariamente la tarjeta.
- Mantener `Última actividad`, pero integrada dentro del resumen superior del bloque.
- Renderizar el resumen del `Tema activo` justo debajo de la categoría que lo contiene.
- Mantener alineación con el lenguaje visual ya implantado en `Comunidad`.

Restricciones
- Sin cambiar permisos, endpoints ni comportamiento backend.
- Sin convertir el índice en una tabla administrativa.
- El feed sigue dependiendo del tema seleccionado; solo cambia su apertura visual y jerarquía.

Validación
- `npm run build`

Resultado
- El índice de `Comunidad` ya no ocupa una altura desproporcionada por bloque.
- La lectura principal queda concentrada en resumen de categoría + temas.
- El contexto del tema activo aparece pegado a su bloque, en vez de quedar separado al final de la superficie.
