# TASK-0373 - Comunidad Forum Index Activity Ordering and Control Removal

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Reducir todavía más la superficie del índice de `Comunidad` eliminando controles redundantes, quitando la tarjeta explícita de `Última actividad` y ordenando categorías/temas por actividad reciente real.

Alcance
- Convertir las métricas visibles de categoría en indicadores ligeros.
- Dejar los temas en una sola línea por tarjeta.
- Eliminar el selector de orden del feed y el selector `Abrir tema...` del encabezado del índice.
- Ordenar temas por fecha del último post/actividad.
- Ordenar categorías priorizando la actividad más reciente visible.

Restricciones
- Sin cambios backend ni de permisos.
- El orden queda fijado en `recent_activity` para esta superficie.
- El índice debe seguir leyendo como foro, no como panel administrativo.

Validación
- `npm run build`

Resultado
- El índice principal de `Comunidad` ya no dedica altura a controles ni a una tarjeta separada de actividad.
- La actividad reciente ahora se expresa implícitamente por el orden de lectura de categorías y temas.
- La navegación visual hacia el tema activo queda más directa y compacta.
