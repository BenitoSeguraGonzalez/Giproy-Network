# TASK-0374 - Comunidad Topic Modal Workspace

Estado: COMPLETED

Tipo: Frontend + Documentation + QA

Prioridad: Alta

Área: Comunidad

Objetivo
Mover la lectura y publicación de un tema de `Comunidad` a un modal dedicado para despejar el índice principal y concentrar el contexto operativo del tema en una sola superficie.

Alcance
- Abrir un modal al pulsar un tema del índice.
- Mostrar dentro del modal el contexto del tema, sus publicaciones y respuestas.
- Reubicar en el modal la creación de nuevas publicaciones del tema.
- Mantener la lógica existente de replies, adjuntos, edición propia y moderación.

Restricciones
- Sin cambios backend.
- Sin duplicar la lógica de feed o moderación.
- El índice principal debe quedar enfocado en descubrir categorías y temas, no en leer el hilo completo.

Validación
- `npm run build`

Resultado
- El tema ya no se expande en el lienzo principal.
- El trabajo real sobre el tema ocurre dentro de un modal contextual.
- La navegación del índice queda más limpia y comprensible.
