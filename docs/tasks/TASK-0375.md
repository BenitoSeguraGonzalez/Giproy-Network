Objetivo
Optimizar el modal de tema de `Comunidad` para que entre con foco en lectura de publicaciones y reduzca el peso visual del bloque de contexto superior.

Alcance
- Compactar el bloque `Tema activo` dentro del modal.
- Priorizar visualmente el feed del tema antes del formulario de publicación.
- Mantener el compositor accesible dentro del mismo modal, pero sin competir con la lectura inicial.

Restricciones
- Sin cambios backend.
- Sin alterar permisos, moderación, respuestas ni adjuntos.

Validación
- `npm run build`

Resultado
- El modal ya no abre con una cabecera tan dominante.
- Las publicaciones pasan a ser la primera lectura útil.
- El formulario de publicación sigue disponible, pero en una posición más natural.
