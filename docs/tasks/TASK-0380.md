# TASK-0380 - Comunidad: banda de respuestas como toggle único

## Objetivo
Eliminar redundancia en la interacción de respuestas dentro del modal de tema de `Comunidad`, dejando una sola banda operativa para abrir/cerrar conversación y formulario de respuesta.

## Alcance
- Quitar botones redundantes `Ver/Ocultar respuestas` y `Responder`.
- Mantener la banda inferior de respuestas como único punto de interacción.
- Añadir icono de estado expandido/colapsado en la propia banda.
- Conservar el comportamiento reversible: si está cerrado abre, si está abierto cierra.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- La interacción de respuestas queda simplificada a una sola superficie clicable con icono de colapso visible.
