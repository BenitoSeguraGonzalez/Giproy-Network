# TASK-0381 - Comunidad: seguimiento de temas por usuario

## Objetivo
Añadir seguimiento personal de temas en `Comunidad` para que cada usuario pueda anclar sus temas preferidos al principio del índice sin romper el orden secundario por actividad reciente.

## Alcance
- Persistencia real por usuario para seguir/dejar de seguir temas.
- Icono de seguimiento en el listado de temas.
- Orden del índice por `seguidos primero` y, dentro de cada bloque, por `último post`.
- Compatibilidad con `Público` y `Mi empresa`.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Validaciones
- Migración Alembic para persistencia.
- `py_compile` backend.
- `npm run build` frontend.

## Resultado
- Cada usuario puede activar o desactivar seguimiento sobre temas concretos.
- Los temas seguidos suben al principio del índice para ese usuario, manteniendo como segundo criterio la actividad reciente.
