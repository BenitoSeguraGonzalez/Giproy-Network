# TASK-0382 - Comunidad: metadatos y acciones de post como iconos compactos

## Objetivo
Reducir la altura y el ruido visual de las tarjetas de publicación en `Comunidad`, moviendo metadatos y acciones a una banda de iconos compactos con hint contextual.

## Alcance
- Sustituir chips textuales de ámbito, estado, tema, sección y empresa por iconos compactos.
- Sustituir acciones de moderación/autor visibles por iconos compactos.
- Reubicar esa banda debajo de la descripción de la publicación.
- Mantener `showhint` mediante `title`.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- Las tarjetas de post consumen menos altura y concentran metadatos/acciones en una sola banda icónica debajo del contenido.
