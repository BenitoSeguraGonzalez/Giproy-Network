# TASK-0388 - Comunidad: fix de favoritos sin submit implícito

## Objetivo
Corregir el fallo de `Not Found` al pulsar la estrella de seguimiento en `Comunidad`, evitando que los controles de favoritos actúen como `submit` implícito dentro de superficies con formularios.

## Alcance
- Frontend: fijar `type="button"` en los controles de seguimiento de temas.
- QA: validar que el click de favoritos no navega ni dispara submit accidental.
- Documentación: registrar el bugfix operativo.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- La estrella de seguimiento ejecuta solo la acción de favorito.
- El click ya no deriva en `Not Found` por submit implícito.
