# TASK-0390 - Editor APU: fila única, acciones hover y % relativo responsivo

## Objetivo
Adecuar el creador de APUs para que las líneas de recursos mantengan lectura en una sola banda operativa, saquen las acciones fuera de una columna fija y oculten `% Rel.` cuando la densidad de pantalla no permita mostrarlo sin degradar la visión.

## Alcance
- Frontend: mover las acciones de línea a una bandeja inferior por `hover/focus`.
- Frontend: eliminar la columna fija `Acc.`.
- Frontend: ocultar `% Rel.` en rango compacto/intermedio.
- Frontend: compactar la línea para mantener todos los datos visibles en una sola fila, sin solapes.
- Documentación: actualizar libro de estilo, changelog y handoff.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- La línea del editor APU usa una sola banda de lectura.
- Las acciones aparecen solo al interactuar con la fila.
- `% Rel.` solo se muestra cuando el ancho efectivo lo permite.
