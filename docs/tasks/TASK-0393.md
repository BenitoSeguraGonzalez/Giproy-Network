# TASK-0393 - Dashboard principal: header y footer fijos con scroll solo en cards

## Objetivo
Evitar que el dashboard principal desplace conjuntamente cabecera, cards y pie. La navegación debe consumir el scroll solo en la banda de cards, manteniendo siempre visibles el header superior y el footer industrial.

## Alcance
- Frontend: separar header, zona de cards y footer dentro de un viewport fijo.
- Frontend: encapsular el scroll vertical solo en la banda de navegación.
- Documentación: registrar la regla en el libro de estilo y trazabilidad.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- El header no se pierde al desplazarse.
- El footer permanece visible.
- Solo las cards de navegación usan scroll vertical.
