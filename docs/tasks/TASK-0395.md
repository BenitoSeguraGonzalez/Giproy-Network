# TASK-0395 - Dashboard principal: indicadores reales de módulos en footer

## Objetivo
Convertir las barras decorativas del footer del dashboard principal en indicadores funcionales del módulo activo/visible y en accesos directos a cada card de navegación.

## Alcance
- Frontend: detectar el módulo visible/activo dentro de la banda de cards.
- Frontend: convertir las barras del footer en indicadores clicables.
- Documentación: registrar la semántica real del patrón.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- El footer refleja el módulo activo.
- Cada indicador permite saltar a su card correspondiente.
