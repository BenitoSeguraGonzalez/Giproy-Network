# TASK-0397 - APUs: OmniClass contextual y modal unificado de recurso

## Objetivo
Unificar la edición de recursos entre `Recursos` y `APUs`, y reducir la presión visual en la cabecera del creador/editor de APUs moviendo la asignación OmniClass a un icono contextual junto a `Unidad`.

## Alcance
- Frontend: extraer un modal compartido de recurso reutilizable desde `Recursos` y desde `APUs`.
- Frontend: alinear `Unidad de Medida` al mismo patrón del maestro de recursos.
- Frontend: formatear el precio del recurso con los decimales monetarios configurados.
- Frontend: compactar la cabecera del editor APU y convertir OmniClass en icono desplegable contextual.
- Documentación: registrar el patrón en libro de estilo, changelog y handoff.

## Agentes
- Arquitectura
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- `APUs` y `Recursos` usan el mismo modal de edición de recurso.
- `Unidad de Medida` mantiene el patrón `abreviatura - nombre completo`.
- El precio del recurso entra y se reabre con la precisión monetaria configurada.
- En el editor APU, OmniClass ya no ocupa una banda fija del header y se abre desde un icono compacto situado junto a `Unidad`.
