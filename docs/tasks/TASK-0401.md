# TASK-0401 - Subcategorías: columna única y orden persistente reutilizable

## Objetivo
Mantener el listado principal de `Subcategorías` en una sola columna y añadir reordenamiento persistente por drag-and-drop para que el mismo orden se refleje en todas las vistas consumidoras del catálogo.

## Alcance
- Backend: añadir `orden` persistente en `subcategorias_items`.
- Backend: exponer endpoint de reordenamiento entre hermanos.
- Frontend: renderizar el listado principal en columna única.
- Frontend: permitir drag-and-drop para reordenar dentro de la categoría activa y conservar el movimiento entre categorías.
- Documentación: registrar la regla de orden persistente compartido.
- QA: validar compilación frontend y consistencia de sintaxis backend.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Validaciones
- `python -m py_compile backend/app/api/endpoints/subcategorias_items.py backend/app/services/subcategoria.py backend/app/repositories/subcategoria_item.py`
- `npm run build`

## Resultado
- `Subcategorías` ya no vuelve a dos columnas en el listado principal.
- El orden de los ítems se puede cambiar por drag-and-drop dentro de la categoría activa.
- Ese orden queda persistido y pasa a ser el orden oficial consumido por `Recursos`, `APUs` y demás superficies que leen `subcategorias-items`.
