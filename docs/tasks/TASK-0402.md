# TASK-0402 - APUs: refresco inmediato de unidad al editar recurso

## Objetivo
Corregir el editor de `APUs` para que, al modificar la unidad de medida de un recurso desde el modal compartido, la línea del APU actualice inmediatamente la unidad visible sin requerir recarga completa de la pantalla.

## Alcance
- Frontend: reconstruir la unidad seleccionada en la línea y en el `item_obj` local tras guardar el recurso.
- QA: validar compilación de `frontend`.
- Documentación: registrar la corrección en changelog y handoff.

## Agentes
- Frontend
- QA
- Documentación

## Validaciones
- `npm run build`

## Resultado
- Cambiar la unidad de un recurso desde `APUs` actualiza de inmediato la unidad mostrada en la línea editada.
