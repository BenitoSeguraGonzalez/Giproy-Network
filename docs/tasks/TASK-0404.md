# TASK-0404 - Robustez de carga de logo de empresa en Login y Header

## Objetivo
Corregir la carga intermitente del logo de empresa en la ventana de login y en el header principal bajo conexiones donde el host efectivo no coincide con una URL API absoluta.

## Agentes
- Arquitectura
- Frontend
- QA
- Documentación

## Alcance
- Unificar la resolución de `logo_url` en frontend.
- Evitar dependencia de `VITE_API_URL` para rutas relativas de medios.
- Aplicar la misma política en `Login`, `AppLayout` y `Settings`.

## Implementación
- Se creó `frontend/src/utils/mediaUrl.js` con `resolveMediaUrl(...)`.
- La utilidad normaliza barras, respeta `data:`, `blob:` y URLs absolutas.
- Las rutas relativas de logo ahora se resuelven contra el mismo origen actual (`/uploads/...`) en vez de reconstruirse con un host API externo.
- Se sustituyó la lógica duplicada local en:
  - `frontend/src/pages/Login.jsx`
  - `frontend/src/layouts/AppLayout.jsx`
  - `frontend/src/pages/Settings.jsx`

## Impacto
- Mayor tolerancia a conexiones con distintos dominios, túneles o DNS dinámico.
- La empresa activa y las empresas del selector de login comparten la misma política de carga de logo.

## Validación
- `npm run build`

## Resultado
- Corregida la base técnica de resolución de logos para login y header.
