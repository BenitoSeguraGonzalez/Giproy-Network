# TASK-0405 - OmniClass contextual en modal compartido de Recursos

## Objetivo
Aplicar al modal compartido de creación/edición de recurso la misma estrategia de ocultamiento contextual de OmniClass usada en `APUs`.

## Agentes
- Arquitectura
- Frontend
- QA
- Documentación

## Alcance
- Mover OmniClass a una acción contextual junto a `Unidad de Medida`.
- Mantener el selector plegado por defecto.
- Reutilizar la misma solución visual para aperturas desde `Recursos` y desde `APUs`.

## Implementación
- Se actualizó `frontend/src/components/precios-unitarios/ResourceEditorModal.jsx`.
- `OmniClass` ahora se activa mediante icono contextual `LayoutGrid` junto a `Unidad`.
- El panel se despliega bajo demanda con `AnimatePresence`, resumen compacto y acción `Limpiar`.
- Se elimina la banda fija permanente de OmniClass dentro del modal.

## Validación
- `npm run build`

## Resultado
- La creación/edición de recursos mantiene más ancho útil para campos principales y alinea el patrón con `APUs`.
