# TASK-0407 - Normalización de logos legacy de empresa

## Objetivo
Corregir la carga de logos de empresa en `Login`, `Header` y vistas de empresa cuando el dato legado sigue almacenado como ruta relativa `/uploads/...`.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Implementación
- Se añadió resolución backend de `logo_url` legacy en `EmpresaService`.
- Las respuestas de `/empresas/*`, `/auth/accounts-by-email` y `/usuarios/me` ya entregan logos utilizables aunque el dato original siga siendo `/uploads/...`.
- La resolución convierte archivos locales existentes a `data:image/...;base64,...` para desacoplar la carga del host, puerto o proxy de entrada.

## Validación
- `python -m py_compile ...`
- `npm run build`

## Resultado
- Los logos heredados ya no dependen de que `/uploads` esté expuesto por el mismo origen del frontend.
