# TASK-0409 - Header: restaurar indicador visible de cuota de almacenamiento

## Objetivo
Restaurar en el header principal el indicador de espacio asignado/usado de la empresa, con visibilidad estable y lectura consistente en los modos actuales de shell.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Hallazgo actual
- El header todavía contiene el bloque visual de almacenamiento en `frontend/src/layouts/AppLayout.jsx`.
- Su visibilidad depende de `licenseInfo` y además hoy se oculta por completo en `Portable Workspace`.
- La métrica backend actual no es real: `LicenseService.calculate_storage_usage(...)` devuelve un placeholder fijo de `5 MB`.

## Alcance
- Backend: reemplazar la métrica placeholder de almacenamiento por un cálculo real por empresa.
- Frontend: restaurar la visualización del indicador en header con política clara para desktop y portable.
- QA: validar que el dato coincide con `Ajustes > Licencia y Cuotas`.

## Criterios de aceptación
- El header vuelve a mostrar `usado / asignado` de almacenamiento para la empresa activa.
- La métrica ya no depende de un valor fijo de ejemplo.
- El indicador sigue visible en las variantes de header permitidas por el libro de estilo.

## Dependencias
- Esta TASK prepara la base de `TASK-0410`, que incorporará adjuntos de `Comunidad > Empresa` en el cálculo.
