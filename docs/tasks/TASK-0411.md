# TASK-0411 - Header: indicador de mensajes directos no vistos con acceso directo

## Objetivo
Añadir en el header principal un indicador de mensajes directos no vistos y permitir navegación directa a `Comunidad > Mensajes directos` al pulsarlo.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Hallazgo actual
- `CommunityDmMessage` ya dispone de `read_at`.
- `CommunityDmThread` ya se serializa en backend, pero actualmente no expone un contador de no vistos.
- El frontend de `Comunidad` ya tiene la superficie `Mensajes directos`; falta la entrada resumida persistente en shell global.

## Alcance
- Backend: exponer un resumen de no leídos por hilo y/o total global para el usuario actual.
- Frontend: añadir un icono persistente en `AppLayout` con badge y acción de navegación directa a la sección correcta.
- UX: el indicador debe respetar contexto de empresa activa para no mezclar conversaciones de otra empresa.

## Criterios de aceptación
- El header muestra un badge con total de DMs no vistos del usuario actual.
- Al pulsar el indicador, el usuario entra directamente a `Comunidad` en la vista `Mensajes directos`.
- Al marcar lectura, el badge se actualiza sin quedar congelado con datos viejos.

## Dependencias
- Puede ejecutarse en paralelo con `TASK-0409`, pero comparte validación de shell/header.
