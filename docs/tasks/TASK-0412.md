# TASK-0412 - APUs: reactivar importación para estados revisados y legacy aprobados

## Objetivo
Corregir el bloqueo funcional del importador de `APUs` provocado por una incoherencia entre el estado que guarda el editor y el estado que exige el flujo de importación.

## Agentes
- Arquitectura
- Backend
- Frontend
- QA
- Documentación

## Hallazgo
- El editor de `APUs` persistía el estado aprobado como `Aprobado`.
- El flujo `import-from-base` y su listado frontend filtraban únicamente `Revisado`.
- Resultado: los APUs válidos quedaban fuera del importador y la función se percibía como desactivada.

## Implementación
- Frontend:
  - Los APUs ya se guardan como `Revisado` cuando no están `Por Validar`.
  - El listado de importación acepta también registros legacy con estado `Aprobado`.
- Backend:
  - El servicio de importación ahora considera elegibles los estados `Revisado` y `Aprobado`.

## Validación
- `python -m py_compile backend/app/services/apu.py`
- `npm run build`

## Resultado
- El importador de `APUs` vuelve a listar e importar registros revisados.
- Los APUs legacy `Aprobado` siguen siendo importables sin exigir migración previa de datos.
