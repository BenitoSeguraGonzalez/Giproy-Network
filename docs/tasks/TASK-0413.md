# TASK-0413 - APUs: apertura inmediata de modales de importación

## Objetivo
Corregir la percepción de importación desactivada en `APUs` haciendo que el modal abra de inmediato y relegando la carga de datos a un estado interno visible.

## Agentes
- Frontend
- QA
- Documentación

## Implementación
- `Base Ext.` ahora abre el modal inmediatamente y carga las bases disponibles dentro del propio modal.
- Se añadió estado interno `baseImportLoading` para bases origen y catálogo fuente.
- Los botones principales del toolbar de `APUs` quedaron explicitados como `type="button"` para eliminar ambigüedad de evento.

## Validación
- `npm run build`

## Resultado
- El usuario ya recibe feedback visual inmediato al pulsar importar.
- La importación desde otra base ya no parece desactivada mientras espera la carga de datos.
