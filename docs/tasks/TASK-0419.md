# TASK-0419 - Normalización de payload de stakeholder en EDO y EDT

## Objetivo
Corregir el error al asignar stakeholders en `EDO` y `EDT` normalizando el payload antes de enviarlo al backend.

## Agentes
- Frontend
- QA
- Documentación

## Hallazgo
- Los modales de asignación podían enviar `rol_id: ''` cuando no se escogía rol.
- Ese valor vacío no es compatible con los esquemas backend que esperan `Optional[int]`, generando error al guardar.

## Implementación
- Se añadió normalización de payload en `EDO` y `EDT`.
- `stakeholder_id` y `rol_id` ahora se envían como enteros reales o `null`.
- `actividades_claves` se normaliza a cadena vacía si no se informa.

## Validación
- `npm run build`

## Resultado
- La asignación de stakeholders en `EDO` y `EDT` ya no falla por `rol_id` vacío.
