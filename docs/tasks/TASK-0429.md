# TASK-0429 - Selección robusta de APU en Tanteo de Presupuesto

## Objetivo
Corregir la activación del `Simulador de Tanteo` cuando el usuario selecciona una línea de presupuesto, evitando fallos por comparación inconsistente de IDs o por contrato variable de respuesta del API de APU.

## Alcance
- Normalizar la resolución de línea seleccionada en `TanteoTab`.
- Normalizar la correspondencia entre `selectedApuId` y líneas del presupuesto.
- Soportar respuesta `response.data` o entidad directa al cargar APU.

## Agentes
- Arquitectura: valida robustez del flujo de selección.
- Frontend: corrige matching y carga defensiva del detalle APU.
- QA: verifica que seleccionar una línea abra y cargue tanteo.
- Documentación: registra el ajuste.
