# TASK-0430 - Presupuesto Tanteo Selection and Sidebar Exclusion Recovery

## Objetivo
Recuperar el flujo operativo de `Presupuesto` para que seleccionar una línea APU abra realmente `Tanteo`, y para que abrir el catálogo izquierdo vuelva a ocultar el panel de `Tanteo` en cualquier resolución.

## Alcance
- Forzar apertura explícita de `Tanteo` al seleccionar una línea presupuestaria APU.
- Endurecer la resolución de `apu_id` desde la línea seleccionada.
- Restituir la exclusión entre catálogo lateral izquierdo y `Tanteo` también fuera de viewport compacto.

## Validaciones
- Seleccionar una línea APU abre `Tanteo` con el rubro correcto.
- Si el catálogo izquierdo se despliega por click o hover, `Tanteo` se cierra.
- `npm run build` en frontend.
