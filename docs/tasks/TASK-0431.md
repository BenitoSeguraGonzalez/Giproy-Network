# TASK-0431 - Presupuesto Tanteo Side-by-Side and Editable-Field Exception

## Objetivo
Restituir el comportamiento operativo de `Tanteo` en `Presupuesto` para que el panel lateral siempre empuje el editor en vez de superponerse, y para que la apertura automática no se dispare al editar campos interactivos como `Cantidad`.

## Alcance
- Quitar el modo overlay del panel `Tanteo` en `Presupuesto`.
- Mantener apertura automática al seleccionar una línea presupuestaria.
- Excluir inputs editables de la activación automática.

## Validaciones
- Al seleccionar una línea APU, `Tanteo` se abre desplazando el editor.
- Al hacer foco o click en `Cantidad`, no se abre `Tanteo`.
- `npm run build` en frontend.
