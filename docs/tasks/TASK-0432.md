# TASK-0432 - Presupuesto Tant eo Root Cause Analysis and Structural-Line Filtering

## Objetivo
Cerrar el análisis completo del fallo de `Tanteo` en `Presupuesto` y corregir la causa raíz: las filas estructurales sincronizadas desde `EDT` se estaban renderizando y contabilizando como si fueran líneas APU reales.

## Hallazgo
- `activePresupuesto.detalle` mezcla:
  - filas estructurales (`apu_id = null`)
  - líneas presupuestarias reales (`apu_id != null`)
- El editor estaba mostrando ambas como si fueran partidas, por eso el usuario podía seleccionar una fila naranja sin APU enlazado y `Tanteo` quedaba vacío.

## Alcance
- Filtrar el render de líneas para mostrar solo partidas con `apu_id`.
- Calcular subtotales y contadores operativos sobre líneas APU reales.
- Blindar `Tanteo` para vaciarse de forma explícita si la línea seleccionada no tiene APU enlazado.

## Validaciones
- Las filas estructurales ya no se muestran como líneas APU.
- `APUs en presupuesto` ya cuenta solo líneas reales.
- Al seleccionar una línea visible, `Tanteo` puede resolver el APU asociado.
- `npm run build` en frontend.
