# TASK-0434 - Presupuesto Legacy Repair and Structural Detection Hardening

## Objetivo
Recuperar líneas operativas perdidas en presupuestos legacy y endurecer la lógica backend para que la sincronización `EDT -> Presupuesto` no vuelva a confundir partidas con filas estructurales.

## Hallazgos
- Había presupuestos con solo filas `CUENTA_PAQUETE` visibles aunque una revisión hermana del mismo `codigo_root` sí conservaba partidas operativas.

## Alcance
- Cambiar la detección estructural backend a `tipo = CUENTA_PAQUETE`.
- Añadir script de reparación para familias de proyecto con una revisión sin partidas y otra con partidas operativas.
- Reinyectar líneas operativas en la base local y reconstruir `apu_id` por match exacto de descripción cuando existe.

## Ejecución local
