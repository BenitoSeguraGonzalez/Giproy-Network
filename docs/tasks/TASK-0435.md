# TASK-0435 - Presupuesto Mutual Exclusion Fix Between Catalog and Tanteo

## Objetivo
Reparar la exclusión mutua entre el catálogo izquierdo y `Tanteo` en `Presupuesto`, evitando que `Tanteo` se reabra automáticamente al cerrarse por hover o expansión del catálogo.

## Hallazgo
- `PresupuestoDetail` mantenía un efecto que reabría `Tanteo` siempre que existiera `selectedLineId`.
- Al abrir el catálogo izquierdo, `Tanteo` se cerraba por un instante, pero el efecto lo volvía a mostrar inmediatamente.

## Alcance
- Eliminar el auto-reabridor global de `Tanteo`.
- Mantener la apertura en el punto de intención real: click de línea y navegación por teclado.
- Conservar la regla: si un panel se abre, el otro debe cerrarse, salvo fijación explícita futura.

## Validaciones
- Hover/click de apertura del catálogo cierra `Tanteo` y no rebota.
- Seleccionar una línea APU vuelve a abrir `Tanteo`.
- Navegación con flechas también puede reabrir `Tanteo`.
- `npm run build` en frontend.
