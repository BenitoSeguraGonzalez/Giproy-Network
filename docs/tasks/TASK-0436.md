# TASK-0436 - Presupuesto Quantity Editing UX and Keyboard Flow

## Objetivo
Dar protagonismo visual y operativo al campo `Cantidad` en el editor de `Presupuesto`.

## Alcance
- Selección completa del valor al enfocar `Cantidad`.
- Apariencia visual reforzada para dejar claro que `Cantidad` es editable.
- Navegación con `ArrowUp` y `ArrowDown` entre cantidades de líneas contiguas.
- Al navegar verticalmente, la nueva cantidad queda enfocada y completamente seleccionada.

## Validaciones
- Click o focus en `Cantidad` selecciona todo el contenido.
- `Cantidad` se distingue visualmente del `P. Unit.`.
- `ArrowUp` / `ArrowDown` sobre `Cantidad` cambia a la línea anterior/siguiente y mantiene edición.
- `npm run build` en frontend.
