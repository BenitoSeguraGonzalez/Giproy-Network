# TASK-0441 - Corrección definitiva de cursores en cantidad de presupuesto

## Objetivo
Corregir el bug real que seguía impidiendo la navegación con `ArrowUp` y `ArrowDown` en la edición de `Cantidad` dentro de `Presupuesto`.

## Causa raíz
- El callback `handleQuantityNavigation` seguía usando una variable obsoleta (`allLineDivs`) después de haber migrado la lógica a `quantityInputs`.
- Además, al navegar por cantidades se estaba forzando la apertura de `Tanteo`, lo cual no corresponde al flujo de edición de cantidad y podía interferir con el foco.

## Resultado
- La navegación vertical ya usa la colección correcta de inputs editables.
- El movimiento entre cantidades ya no intenta abrir `Tanteo`.
