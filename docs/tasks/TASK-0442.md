# TASK-0442 - Navegación con Enter en Tanteo

## Objetivo
Habilitar un flujo de edición continua en `Tanteo` para que `Enter` confirme el formato del rendimiento actual y mueva el foco al siguiente input, dejándolo seleccionado.

## Resultado
- `Enter` ya normaliza el rendimiento actual.
- El foco salta al siguiente rendimiento del panel.
- El siguiente valor queda completamente seleccionado para edición inmediata.
