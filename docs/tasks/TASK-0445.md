# TASK-0445 - Blindaje de navegación vertical en Cantidad

## Objetivo
Corregir la navegación con `ArrowUp` y `ArrowDown` en `Presupuesto > Cantidad` para que no produzca commits duplicados ni alteraciones en otras líneas.

## Causa raíz
- La navegación por teclado ya hacía `commit` explícito.
- Después, el `blur` del input saliente volvía a ejecutar otro `commit`.
- Esa doble secuencia generaba efectos extraños al subir, especialmente con refresco y cambio de foco entre líneas.

## Ajuste aplicado
- Se separó `onBlur` del flujo directo de commit.
- Se añadió un bypass controlado para ignorar el `blur` del input que ya fue comprometido por la navegación.
- `ArrowUp` y `ArrowDown` ahora usan el mismo patrón operativo: confirmar la línea actual una sola vez y mover el foco a la línea vecina editable.

## Validación
- `npm run build`
