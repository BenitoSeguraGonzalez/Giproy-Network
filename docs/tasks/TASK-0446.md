# TASK-0446 - Rehidratación local de cantidad confirmada

## Objetivo
Evitar que una línea de `Presupuesto > Cantidad` vuelva a un valor anterior al regresar con navegación vertical inmediatamente después de haber sido confirmada.

## Causa raíz
- El input se repoblaba en `focus` usando `linea.cantidad` del render actual.
- Ese dato podía seguir atrasado respecto al último valor ya confirmado por teclado.
- Al volver a la línea, el borrador se reconstruía con el valor viejo.

## Ajuste aplicado
- Se añadió una caché local de último valor confirmado por línea.
- El valor mostrado y el valor con el que se reabre la edición priorizan:
  1. borrador activo,
  2. último valor confirmado localmente,
  3. valor persistido recibido en props.

## Validación
- `npm run build`
