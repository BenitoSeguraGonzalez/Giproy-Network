# TASK-0448 - Handle exclusivo de arrastre en líneas de presupuesto

## Objetivo
Convertir `GripVertical` en el único punto de agarre válido para mover líneas de presupuesto entre cuentas EDT.

## Ajuste aplicado
- Se eliminó `draggable` de la fila completa.
- Se activó `dragstart` únicamente desde `GripVertical`.
- Se marcó el handle como zona interactiva para que no active paneo.

## Resultado esperado
- Click normal sobre la fila: selecciona / abre tanteo.
- Drag sobre `GripVertical`: mueve la línea.
- Drag sobre la superficie de fila: panea el listado.

## Validación
- `npm run build`
