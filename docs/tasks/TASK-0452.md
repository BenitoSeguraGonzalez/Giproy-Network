# TASK-0452 - Aviso no bloqueante al sumar líneas movidas en Presupuesto

## Objetivo
Informar al usuario, sin interrumpir el flujo, cuando una línea movida al presupuesto se fusiona por coincidencia de `apu_id` dentro del mismo `EDT`.

## Política
- Si el movimiento provoca suma de cantidades con una línea existente en el `EDT` destino, el backend devuelve una marca explícita de `merge`.
- El frontend muestra un aviso temporal no bloqueante indicando que los valores se sumaron porque el item ya existía en ese `EDT`.
- El aviso debe exponer detalle operativo completo:
  - `Cod APU - Descripción - Unidad : Cantidad Inicial + Cantidad movida = Cantidad total`
  - respetando siempre los decimales de cálculo del proyecto.
