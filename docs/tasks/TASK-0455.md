# TASK-0455 - Borrar línea de presupuesto no debe abrir Tanteo

## Objetivo
Corregir la propagación de eventos en el árbol de `Presupuesto` para que las acciones destructivas de línea no disparen la selección de fila ni la apertura de `Tanteo`.

## Ajuste
- El botón `Eliminar línea` debe detener la propagación del click antes de ejecutar el borrado, tanto en layout compacto como en layout ancho.
