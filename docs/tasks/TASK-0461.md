# TASK-0461 - Refinar shell y scroll en Stakeholders, Cronogramas, Desagregación y Fórmula

## Objetivo
Corregir la integración visual pendiente en módulos de proyecto que todavía no respetaban del todo el patrón de `EDO/EDT`, sin tocar comportamiento funcional.

## Alcance
- `Stakeholders`
- `Cronogramas`
- `Desagregación`
- `Fórmula Polinómica`

## Acciones
- Reforzar `Stakeholders` con `overflow-hidden`, buscador integrado dentro del cuerpo y scroll real sobre la lista.
- Compactar `Cronogramas` y `Desagregación` para que usen la misma shell vertical `h-full/min-h-0/flex-1` que `EDO/EDT`.
- Igualar la raíz de `Fórmula Polinómica` al mismo patrón de contenedor.

## Validación
- `npm run build`

## Resultado esperado
- `Stakeholders` vuelve a desplazarse correctamente.
- El buscador de stakeholders deja de romper la cabecera superior.
- `Cronogramas`, `Desagregación` y `Fórmula Polinómica` no se ven más abiertos que `EDO/EDT`.
