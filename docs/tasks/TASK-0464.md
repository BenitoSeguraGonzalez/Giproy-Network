# TASK-0464 - Configuración previa de reportes de Presupuesto con inclusión opcional de APUs

## Objetivo
Añadir una preconfiguración antes de la vista previa del reporte de `Presupuesto` para permitir generar el documento solo con presupuesto o con todos los APUs distintos asociados.

## Alcance
- modal previo en frontend
- preview de presupuesto con o sin APUs
- exportación Excel y PDF con variante `con APUs`

## Acciones
- insertar modal de selección `Sin APUs / Con APUs` antes del preview
- extender `reporting.preview_report` para anexar previews de APUs al presupuesto
- generar Excel combinado con hoja de presupuesto y una hoja por APU
- reutilizar el PDF común para emitir una página por item del preview

## Validación
- `py_compile` sobre `backend/app/services/reporting.py` y `backend/app/api/endpoints/reporting.py`
- `npm run build`

## Resultado esperado
- el usuario define la variante antes del visor
- `Con APUs` produce un único PDF con presupuesto + APUs en páginas separadas
- `Con APUs` produce un único Excel con presupuesto + una hoja por APU distinto
