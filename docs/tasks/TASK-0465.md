# TASK-0465 - Unificación de nombres de descarga para reportes visibles

## Objetivo
Aplicar una convención única y explícita de nombres de archivo para los reportes exportados por el frontend.

## Alcance
- `Presupuesto`
- `APUs`
- `EDT`
- `VAE`
- `Fórmula Polinómica`

## Política aplicada
- Formato visible obligatorio:
  - `Tipo de Reporte - Contexto - RevN.ext`

## Acciones
- crear helper frontend compartido para saneado y construcción del nombre
- reemplazar nombres históricos basados en `Reporte_*` o ids desnudos
- mantener intacto el contenido exportado; solo cambia el nombre de descarga

## Validación
- `npm run build`

## Evolución posterior
- la secuencia interna de emisiones (`E01`, `E02`, etc.) queda reservada como fase posterior con persistencia, auditoría y regla de reinicio por revisión
