# TASK-0466 - Diseño funcional del minimapa EDT en Presupuesto

## Objetivo
Definir un minimapa de navegación rápida para `Presupuesto` apoyado en la estructura `EDT`, sin mezclar edición ni operaciones de líneas.

## Alcance
- `Presupuesto`
- lateral izquierdo de herramientas
- navegación por capítulos `EDT`

## Decisiones
- el minimapa solo muestra nodos `CUENTA_PAQUETE`
- no muestra líneas APU operativas para evitar saturación
- la interacción principal es `click para navegar`
- no incorpora edición, drag & drop ni controles de árbol complejos

## Resultado esperado
- acceso rápido desde un icono lateral
- salto visual al capítulo `EDT` elegido
- coherencia visual con el minimapa usado en `EDT` gráfico
