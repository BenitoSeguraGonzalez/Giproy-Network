# TASK-0467 - Implementación frontend del minimapa de Presupuesto

## Objetivo
Integrar el icono, modal y navegación del minimapa `EDT` dentro de `Presupuesto`.

## Acciones
- añadir acción `Mapa` en la barra izquierda de herramientas
- abrir un modal compacto con el árbol `EDT`
- resaltar el nodo seleccionado
- cerrar el modal al navegar
- desplazar el listado central al capítulo elegido

## Restricciones
- no abrir `Tanteo`
- no modificar cantidades
- no interferir con drag & drop de líneas
