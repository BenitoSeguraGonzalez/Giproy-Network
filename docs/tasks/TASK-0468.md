# TASK-0468 - Sincronización y QA del minimapa de Presupuesto

## Objetivo
Garantizar que el minimapa navega sobre el editor real del presupuesto sin romper el flujo operativo.

## Validaciones
- click sobre un nodo del minimapa desplaza al capítulo correcto
- el nodo seleccionado queda resaltado
- la navegación limpia la selección de línea APU si corresponde
- no rompe catálogo lateral, `Tanteo`, edición de cantidades ni drag & drop
- `npm run build`
