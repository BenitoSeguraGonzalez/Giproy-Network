# TASK-0484: Editor de APUs Integrado en Presupuestos (Contextual)

## Contexto y Objetivo
El usuario requiere la capacidad de editar un APU directamente desde las líneas de un presupuesto activo. Esta acción debe ser contextual: no debe perderse el estado del presupuesto (incluyendo sesiones de "Tanteo" no guardadas o en memoria), y al cerrar el editor, toda la interfaz debe refrescar los impactos (tanto revisión, como tanteos y APUs anidados).

## Restricción Crítica
**No romper funcionalidades actuales**. El editor de APU actual (página `/apus`) es altamente complejo e integrado. 

## Solución Técnica
Implementar una vista **Embebida (Embedded Iframe)**.
1. La página de APUs (`APUs.jsx`) y el layout principal (`AppLayout.jsx`) se habilitarán para detectar un parámetro `?embedded=true`.
2. Si está embebido, se ocultará el navbar y el listado de APUs, forzando la apertura exclusiva del Editor de APU para el `apu_id` enviado.
3. Se integrará un botón "Editar APU" por cada línea (que sea tipo APU) dentro del `LineasPresupuestoTab.jsx`, al lado de "Notas".
4. Este botón usará `e.stopPropagation()` para **NO** activar la función de Tanteo que ocurre al hacer click en la línea.
5. `PresupuestoDetail.jsx` manejará un modal full-screen que dibujará el iframe hacia `/apus?apu_id=X&embedded=true`.
6. Al "Guardar" o pulsar "Cerrar" en el modo embebido, se emitirá un `window.parent.postMessage`.
7. `PresupuestoDetail` atrapará el mensaje, cerrará el modal y llamará a `refreshActivePresupuesto()` para recalcular de inmediato todo impacto en la UI.

## Scope y Tareas (Checklist)
- [x] **AppLayout & APUs**: Modificaciones de renderizado condicional si `embedded=true`.
- [x] **APUs**: Auto-seleccionar y abrir `handleEditApu(apu)` si se recibe `embedded=true` y un `apu_id` válido. Emitir postMessage en `handleCancelEdit`.
- [x] **LineasPresupuestoTab**: Añadir botón de "Editar APU" (usar ícono `Edit2`). `stopPropagation()`.
- [x] **PresupuestoDetail**: Modal Iframe y listener `message` global para la recarga via `refreshActivePresupuesto`.
- [x] **Validación**: Comprobar flujos integrales (sin afectar el routing de SPA ni memoria local).

## Criterios de Aceptación
1. El botón "Editar APU" no activa modo tanteo.
2. Hacer click abre un editor a pantalla completa sin los layouts del navbar global (embebido limpio).
3. Cerrar/Guardar el APU cierra el editor sin redireccionar en falso, y recarga la tabla de presupuesto mostrándose los nuevos totales.
