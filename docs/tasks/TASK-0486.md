# TASK-0486: Política de Indirectos — Referencial en APU, Funcional en Presupuesto

## Contexto y Regla de Negocio

| Módulo | Contexto | Naturaleza del Indirecto | Fuente del % |
|---|---|---|---|
| **APU / Catálogo** | Base Maestra o de Proyecto | **Referencial** — solo informativo para el analista | `base.porcentaje_indirectos` |
| **Presupuesto / Proyecto** | Líneas de presupuesto | **Funcional** — afecta `precio_unitario` real y todos los totales | `presupuesto.indirectos_porcentaje` |

> El APU siempre guarda su `costo_directo` como valor canónico. El indirecto referencial de la base es solo visual en el catálogo. Al pasar al presupuesto, el `precio_unitario` de la línea se calcula con el % propio del presupuesto.

## Problemas Identificados

1. **Bug visual:** La tarjeta de la línea APU en el presupuesto muestra `apu.precio_unitario_total` bajo la etiqueta "INDIRECTOS" cuando debería mostrar solo el costo del indirecto (`CD × %`).
2. **Bug funcional:** `refresh_presupuesto_prices` y `addApuToBudget` asignan `apu.costo_directo` como `precio_unitario` de la línea. Debe ser `CD × (1 + presupuesto.indirectos_porcentaje / 100)`.
3. **Bug acumulado:** Los subtotales de capítulo (EDT) son incorrectos porque el precio base no incluye el indirecto funcional.

## Scope y Tareas (Checklist)

### Fase 1: Backend
- [x] **`presupuesto.py` → `refresh_presupuesto_prices`**: Calcular `precio_unitario` = `apu.costo_directo × (1 + %ind_presupuesto)`.
- [x] **`presupuesto.py` → `add_line` o endpoint correspondiente**: Misma lógica al añadir un APU por primera vez.

### Fase 2: Frontend
- [x] **`PresupuestoContext.jsx` → `addApuToBudget`**: No enviar `apu.costo_directo`; usar `apu.precio_unitario_total` o dejar que el backend calcule.
- [x] **`LineasPresupuestoTab.jsx`**: Corregir desglose de tarjeta:
  - Fila 1: `COSTO DIRECTO` = `apu.costo_directo`
  - Fila 2: `INDIRECTOS (X%)` = `costo_directo × presupuesto.indirectos_porcentaje / 100`
  - Fila 3: `TOTAL DE PARTIDA` = suma
- [x] **`APUs.jsx`**: No modificar — el catálogo muestra el indirecto referencial de la base correctamente.

## Criterios de Aceptación

1. En el catálogo de APUs, la tarjeta muestra CD e indirecto referencial (sin cambios).
2. En el presupuesto, cada línea tiene `precio_unitario` = CD + Indirecto funcional del presupuesto.
3. Cambiar el % de indirectos del presupuesto y refrescar → todas las líneas se actualizan.
4. Subtotales de capítulos (EDT) coinciden con la suma de líneas con precio funcional correcto.
