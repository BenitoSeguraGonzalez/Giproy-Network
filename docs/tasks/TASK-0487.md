# Contexto
El sistema utiliza un indicador de propiedad para diferenciar entre activos propios y adquiridos vía Marketplace. Actualmente, este indicador colorea el texto del nombre de la base o proyecto activo, lo cual el usuario desea cambiar.

# Problema
El coloreado de las letras del nombre de la base/proyecto distrae y no es la estética deseada. Se prefiere un indicador minimalista.

# Alcance
- Modificar el header contextual en las páginas de catálogo (APUs, Recursos, Subcategorías) para incluir el círculo de color con tooltip y normalizar el color del texto del nombre.
- Modificar el header del detalle de proyecto para normalizar el color del texto del nombre.

# Tareas
1. [x] **Subcategorias.jsx**: Importar `MarketplaceOriginBadgeSet`, añadirlo al header en modo `tooltip` y quitar clase `activeBaseTone.textStrong`.
2. [x] **Recursos.jsx**: Importar `MarketplaceOriginBadgeSet`, añadirlo al header en modo `tooltip` y quitar clase `activeBaseTone.textStrong`.
3. [x] **APUs.jsx**: Localizar el header contextual, añadir `MarketplaceOriginBadgeSet` en modo `tooltip` y quitar clase `activeBaseTone.textStrong`.
4. [x] **Proyectos.jsx**: En el header del detalle, quitar las clases `selectedProjectTone.textStrong` y `selectedProjectTone.text` de los labels de nombre y código.

# Criterios de Aceptación
- El nombre de la base activa y del proyecto activo se muestra en color neutro (zinc-900 o similar).
- Un círculo de color (esmeralda para propio, ámbar para adquirido) aparece junto al nombre con un tooltip descriptivo.
