# Descripción
El intento de embeber `APUs.jsx` dentro de un iframe o un Drawer para editar análisis desde un Presupuesto ha resultado inestable y affects a la experiencia de usuario general (problemas de ruteo, renderizado del catálogo general, destellos y selectores de bases no deseados).
Por instrucción expresa del usuario, se dio marcha atrás a toda modificación de `APUs.jsx` relacionada con el modo embebido y se restauró como una página autónoma 100% operativa.
Se ha creado un componente clon nativo (`ApuBudgetEditor`) exclusivamente diseñado para vivir en `ApuEditorModal.jsx` y asistir al Presupuesto, operando con la base del proyecto/revisión correcta.
