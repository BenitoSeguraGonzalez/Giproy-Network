# Descripción
Añadir persistencia de origen y snapshot a `bases_trabajo` para que una `Base de Proyecto` deje de ser una copia sin trazabilidad.

# Objetivo
Que el sistema pueda responder:

- de qué base se clonó una base de proyecto;
- cuándo se clonó;
- con qué conteos nació;
- con qué política de sincronización debe tratarse.

# Dependencias
- ninguna

# Validación
- migración aplicada
- una base de proyecto nueva guarda `source_base_id`
- snapshot de conteos iniciales persistido
