# Descripción
Crear un comparador backend que clasifique diferencias entre la base origen y la base del proyecto.

# Objetivo
Obtener un reporte estructurado con:

- subcategorías faltantes
- recursos faltantes
- APUs faltantes
- APUs comunes con cabecera distinta
- APUs comunes con detalle distinto
- APUs vacíos en proyecto pero completos en origen

# Archivos afectados
- `backend/app/services/project_base_reconciliation.py`
- `backend/app/api/endpoints/proyectos.py` o endpoint admin específico
- schemas de respuesta diagnóstica
