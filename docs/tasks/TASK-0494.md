# Descripción
Reforzar el proceso de clonación al crear proyecto para dejar evidencia de completitud y evitar silencios operativos.

# Objetivo
Que una creación de proyecto falle de forma visible o deje auditoría suficiente si la base clonada no nace completa.

# Ajustes previstos
- verificación post-clonación de conteos
- log estructurado del clone result
- rollback o warning explícito si hay diferencias inesperadas en el mismo instante de creación
