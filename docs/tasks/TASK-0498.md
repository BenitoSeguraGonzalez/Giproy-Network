# Descripción
Exponer en las vistas generales de bases y APUs si el contenido es nativo, variante, heredado, local o divergente, sin depender solo del presupuesto.

# Objetivo
Que el usuario detecte la naturaleza del contenido derivado también en los módulos principales de bases y APUs.
