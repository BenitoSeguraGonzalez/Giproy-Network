# Descripción
Extender a las listas laterales hermanas el nuevo patrón visual de subcategorías ya probado en `APUs`, manteniendo una implementación reversible para poder validar la adopción transversal sin bloquear rollback.

# Objetivo
Unificar la presentación de listas operativas con:
- contador visible como `badge`
- descripción dominante y truncado elegante
- micro-línea contextual en la fila activa
- separación clara entre `badge` y `chevron`

# Solución aplicada
- Se integró el patrón de `badge técnico` en las sidebars operativas hermanas de `APUs`, `Recursos`, `Subcategorías` y `Catálogo APU`.
- Cada implementación quedó encapsulada detrás de un flag local para permitir rollback visual rápido sin reescribir lógica.
- La guía de estilo ahora fija este patrón como referencia obligatoria para sidebars homologables del sistema.

# Validación
- `npm run build` en `frontend`
- revisión visual preparada para contrastar rápidamente variante nueva vs layout previo mediante flags locales
