# TASK-0525

## Objetivo
Normalizar la familia de listados laterales homologables tomando la sidebar de `APUs` como referencia visual maestra.

## Alcance
- `Recursos`
- `Subcategorías`
- `Catálogo APU`
- navegación lateral de `ApuBudgetEditor`

## Diagnóstico
- Seguían conviviendo varias gramáticas visuales para el mismo tipo de lista: unas con activos saturados, otras con badges distintos y otras con jerarquía de texto diferente.
- El referente más equilibrado era la sidebar principal de `APUs`, pero `Recursos`, `Subcategorías` y `Catálogo APU` no convergían todavía del todo hacia ese patrón.

## Cambios aplicados
- `Recursos` abandonó el bloque activo naranja completo y adoptó activo sobrio con fondo neutro, borde definido y badge acentuado.
- `Subcategorías` dejó atrás el activo oscuro pesado y se alineó al mismo esquema de `APUs`.
- `CatalogoApuTab` ajustó sus cabeceras de subcategoría para reflejar el mismo lenguaje de badge, chevron y fondo activo sobrio.
- `ApuBudgetEditor` actualizó su navegación lateral para acercarla a la misma familia visual en categorías y grupos.
- El `STYLE_GUIDE` fijó explícitamente a `APUs` como referencia maestra de esta familia.

## Validación
- `npm run build` en `frontend`: correcto.

## Notas
- La normalización mantiene la idea reversible de variantes locales y no altera lógica de negocio ni estructura de datos.
