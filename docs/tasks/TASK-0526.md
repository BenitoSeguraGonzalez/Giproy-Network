# TASK-0526

## Objetivo
Cerrar los cabos sueltos de consistencia visual en la familia de listados PU y fijar una base técnica compartida para evitar nuevas divergencias.

## Alcance
- componente compartido de sidebar para catálogos operativos
- `APUs`
- `Recursos`
- `Subcategorías`
- `Catálogo APU`
- shell de `PreciosUnitarios`

## Cambios aplicados
- Se creó `CatalogSidebarCard` como pieza común para la gramática `código -> descripción -> badge -> contexto`.
- `APUs`, `Recursos`, `Subcategorías` y `CatalogoApuTab` pasaron a reutilizar esa pieza en sus variantes principales.
- `PreciosUnitarios` ajustó su landing para acercarse al mismo sistema visual: acentos contenidos, metadata secundaria clara y cierre sobrio con badge/indicador.
- Se reforzó el libro de estilo para exigir componente compartido cuando la gramática coincida.

## Validación
- `npm run build` en `frontend`: correcto.

## Notas
