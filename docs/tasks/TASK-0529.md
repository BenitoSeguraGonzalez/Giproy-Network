# TASK-0529

## Objetivo
Reubicar la descripción de las tarjetas que usan la representación compartida `CatalogSidebarCard` para evitar redundancia entre título y contexto inferior, aprovechando mejor el espacio de lectura.

## Alcance
- `CatalogSidebarCard` admite ocultar el título superior, personalizar el texto del tooltip y presentar el pie en modo descripción.
- `APUs`, `Recursos`, `Subcategorías` y `Catálogo APU` adoptan el mismo criterio: arriba queda la estructura técnica (`icono/código + badge + chevron`) y abajo el texto principal de lectura.

## Implementación
1. Extender `CatalogSidebarCard` con variantes mínimas para `displayTitle`, `tooltipText` y `footerVariant`.
2. Aplicar el mismo criterio a todos los consumidores actuales de `CatalogSidebarCard`.
3. En `Subcategorías`, usar el nombre oficial completo de la categoría como texto principal inferior.
4. En `APUs`, `Recursos` y `Catálogo APU`, reutilizar la descripción existente como texto principal de la franja inferior.
5. Actualizar guía de estilo y changelog.

## Validación
- Ningún consumidor actual de `CatalogSidebarCard` repite visualmente nombre y conteo.
- El `badge` sigue resolviendo el conteo.
- La franja inferior comunica el texto principal de lectura en toda la familia.
- En `Subcategorías` el texto inferior respeta el nombre oficial estándar de la categoría.
- `npm run build` en `frontend` compila sin errores.
