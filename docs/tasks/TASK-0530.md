# TASK-0530

## Objetivo
Normalizar la sidebar de categorías de `Fórmula Polinómica` para que use la misma gramática visual de la familia PU y reducir el sobredimensionamiento del contenedor izquierdo.

## Alcance
- `FormulaPolinomicaTab` adopta `CatalogSidebarCard` para la lista de categorías generales.
- La lista usa los mismos iconos, colores y estructura técnica que `Subcategorías`.
- El panel izquierdo se compacta para no quedar visualmente sobredimensionado frente al contenido real.

## Implementación
1. Importar `CatalogSidebarCard` en `FormulaPolinomicaTab`.
2. Definir colores de categoría coherentes con la familia principal.
3. Sustituir los botones naranjas actuales por tarjetas del patrón compartido.
4. Mantener arriba la estructura técnica (`Categoría X + badge + chevron`) y abajo el nombre completo de la categoría.
5. Reducir la altura de la zona de asignación y dejar el panel izquierdo en modo `self-start` para evitar una caja excesiva.

## Validación
- La sidebar izquierda de `Fórmula Polinómica` sigue el mismo patrón visual que `Subcategorías`.
- Iconos, colores, badges y jerarquía de lectura quedan homologados.
- El contenedor izquierdo ya no se percibe sobredimensionado.
- `npm run build` en `frontend` compila sin errores.
