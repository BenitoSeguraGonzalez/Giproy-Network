# TASK-0534

## Objetivo
Implementar el flujo seguro de edición de `APUs anidados` en ambos editores APU.

## Alcance
- `frontend/src/pages/APUs.jsx`
- `frontend/src/components/presupuestos/ApuBudgetEditor.jsx`
- `frontend/src/components/presupuestos/ApuEditorModal.jsx`
- `frontend/src/utils/nestedApuEditing.js`

## Implementación
1. Detectar líneas con `apu_hijo_id`.
2. Pedir confirmación explícita antes de editar el `APU anidado`.
3. Guardar el APU actual antes de abrir el hijo.
4. Cargar directamente el APU hijo desde el mismo sistema de edición.
5. Mantener una navegación mínima de retorno para no perder contexto.

## Validación
- El flujo es idéntico en `APUs` y `ApuBudgetEditor`.
- Si el guardado previo falla, no se abre el hijo.
- Si el guardado previo pasa, el hijo carga directamente.
- El retorno al padre conserva coherencia y no usa datos stale.
