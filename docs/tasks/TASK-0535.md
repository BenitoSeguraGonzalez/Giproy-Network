# TASK-0535

## Objetivo
Definir y ejecutar el grupo de pruebas de confirmación para la edición integrada de recursos y `APUs anidados`.

## Grupo de pruebas
1. Editar recurso normal desde `APUs`.
2. Editar recurso normal desde `ApuBudgetEditor`.
3. Editar `APU anidado` desde `APUs` con guardado previo.
4. Editar `APU anidado` desde `ApuBudgetEditor` con guardado previo.
5. Verificar propagación a APUs padres y presupuestos afectados.
6. Confirmar build del frontend sin regresiones.

## Validación automatizada
- `pytest backend/app/tests/test_nested_apu_integrity.py backend/app/tests/test_presupuesto_integrity_service.py`
- `npm run build` en `frontend`

## Criterios de cierre
- Pruebas backend en verde.
- Build frontend correcto.
- Los dos editores quedan alineados funcionalmente.
