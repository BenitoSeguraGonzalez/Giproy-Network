# TASK-0539

## Objetivo
Eliminar el sobresolapamiento visual entre la lista de categorías y la sección inferior de `Fórmula Polinómica`, manteniendo el patrón visual compartido de la familia PU.

## Alcance
- `frontend/src/components/projects/FormulaPolinomicaTab.jsx`
- `frontend/src/components/ui/CatalogSidebarCard.jsx`

## Implementación
1. Separar con más claridad el bloque superior de asignación y el bloque inferior de resultados.
2. Acotar la altura del panel superior para que la lista lateral no invada visualmente la sección inferior.
3. Dar scroll interno a la sidebar de categorías.
4. Añadir una variante compacta a `CatalogSidebarCard` para pantallas densas como `Fórmula Polinómica`.

## Validación
- La lista de categorías no se solapa con la zona inferior.
- La columna izquierda conserva el patrón homologado, pero en versión compacta.
- `npm run build` en `frontend` compila sin errores.
