# TASK-0543

## Objetivo
Homogeneizar los buscadores y filtros de la aplicación para que permitan limpiar rápidamente el texto tecleado mediante una acción `x` dentro del propio campo.

## Implementación
1. Crear un campo reutilizable de búsqueda con icono de búsqueda y acción de limpieza integrada.
2. Sustituir los buscadores y filtros principales que carecían de limpieza rápida.
3. Mantener la semántica y estilos de cada módulo, añadiendo solo el affordance de borrado dentro del contenedor.
4. Aplicar el mismo patrón tanto a filtros laterales como a buscadores globales y de modales.

## Validación
- Todos los buscadores/filtros intervenidos muestran una `x` cuando contienen texto.
- Pulsar la `x` limpia el valor sin efectos laterales.
- `npm run build` en `frontend` compila sin errores.
