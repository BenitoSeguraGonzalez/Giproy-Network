# TASK-0544

## Objetivo
Corregir la clasificación de recursos y subcategorías dentro de `ApuBudgetEditor` para que el editor asociado a presupuestos quede alineado con el editor maestro de `APUs`.

## Alcance
- `frontend/src/components/presupuestos/ApuBudgetEditor.jsx`

## Implementación
1. Resolver la categoría real de cada recurso usando `subcategoria_codigo`, catálogo de subcategorías y código del recurso, en vez de depender solo de `categoria_id`.
2. Enriquecer las líneas cargadas del APU con metadatos reales de subcategoría.
3. Rehacer la agrupación del árbol lateral para inicializar grupos desde las subcategorías reales de la base y no desde buckets improvisados.
4. Mantener esa misma resolución al agregar líneas nuevas y al editar un recurso desde el propio editor.

## Validación
- Las líneas del APU editado desde presupuesto aparecen bajo su categoría real.
- El árbol lateral muestra recursos agrupados por subcategorías correctas.
- La clasificación no colapsa todo en `Equipos y Herramientas`.
- `npm run build` en `frontend` compila sin errores.
