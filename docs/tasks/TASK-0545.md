# TASK-0545

## Objetivo
Gobernar la implantación completa de la capa BIM madura de GiProy Network usando `Three.js + That Open Engine`, garantizando alineación arquitectónica, control de licencias, consistencia multiempresa, paridad visual/funcional con GiProy y sincronización futura con `Proyecto`, `EDT`, `APUs` y `Presupuesto` sin interferir con `GiProy Clásico` durante la incubación.

## Alcance
- Arquitectura BIM transversal
- Dominio BIM en backend y base de datos
- Módulo BIM dentro de `Proyecto`
- Estrategia de convivencia paralela entre `GiProy Clásico` y `GiProy BIM`
- Vínculos BIM con negocio
- Validación funcional, simulación y smoke tests

## Criterio de cierre
La TASK madre solo puede cerrarse cuando toda la cadena BIM quede implantada, validada y documentada con la batería de pruebas definida.

Además, la TASK madre no puede cerrarse si:

- `GiProy Clásico` depende de BIM para operar
- la experiencia BIM rompe la identidad visual del producto
- la activación de BIM no puede controlarse por flags y rollback
