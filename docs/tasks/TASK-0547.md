# TASK-0547

## Objetivo
Diseñar e implantar el dominio backend y de base de datos necesario para modelos BIM, versiones, metadata, vistas y vínculos de negocio.

## Alcance
- Modelos SQLAlchemy BIM
- Schemas Pydantic BIM
- Migraciones Alembic
- Servicios backend BIM

## Implementación planificada
1. Crear entidades `bim_model`, `bim_model_version`, `bim_element`, `bim_storey`, `bim_view_state`.
2. Crear entidades de vínculo BIM con `EDT`, `APUs` y `Presupuesto`.
3. Diseñar endpoints de consulta, alta, activación de versión y vínculo.
4. Garantizar aislamiento multiempresa y trazabilidad.

## Validación
- Dominio BIM persistible y versionable.
- Relaciones claras con proyecto y negocio.
- Migraciones limpias y reversibles.
