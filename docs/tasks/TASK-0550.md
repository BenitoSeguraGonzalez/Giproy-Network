## Alcance

- enlace `Elemento BIM -> APU`

2. Añadir UX para crear, editar y eliminar vínculos.
3. Implementar navegación viewer -> negocio.
4. Implementar navegación negocio -> viewer.

## Validación
- Un vínculo creado desde cualquier lado persiste.
- La navegación en ambos sentidos funciona sin inconsistencias.
