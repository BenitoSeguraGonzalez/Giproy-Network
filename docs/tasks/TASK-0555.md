## Alcance
- shell BIM
- headers
- paneles laterales
- toolbars
- buscadores
- badges
- modales y estados vacíos

## Implementación planificada
1. Definir las reglas de paridad visual y funcional BIM.
2. Reutilizar tokens, componentes y shells actuales cuando aplique.
3. Diseñar la shell BIM como experiencia técnica, pero reconociblemente GiProy.
4. Definir criterios de excepción cuando BIM necesite mayor densidad o tooling especializado.

## Validación
- El módulo BIM se siente parte de GiProy.
- No se percibe como producto externo o ajeno.
- La futura integración visual con módulos clásicos queda preparada.
