# TASK-0556

## Objetivo
Implantar la estrategia de activación paralela y controlada de BIM mediante `feature flags`, garantizando independencia operativa de `GiProy Clásico` y cohesión futura progresiva.

## Alcance
- feature flags BIM
- activación por entorno/empresa/usuario
- rollback funcional
- puertas de integración futura

## Implementación planificada
1. Definir flags y política de activación.
2. Encapsular la entrada BIM dentro de `Proyecto`.
3. Proteger la UX clásica frente a cualquier dependencia BIM.
4. Preparar puntos de integración futura con `EDT`, `APUs` y `Presupuesto` sin exponerlos aún.

## Validación
- BIM puede activarse y desactivarse sin romper la experiencia clásica.
- La capa clásica no depende de BIM.
- La integración futura puede encenderse de forma gradual.
