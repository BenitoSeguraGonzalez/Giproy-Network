# TASK-0557

## Objetivo
Preparar un prompt maestro reutilizable para guiar la transición paralela entre `GiProy Clásico` y `GiProy BIM`, asegurando que futuras ejecuciones mantengan backend común, frontend BIM desacoplado, feature flags y ausencia de choques entre capas.

## Alcance
- Documento de prompt operativo
- Reglas de arquitectura y convivencia
- Mandatos de validación
- Criterios de no interferencia

## Implementación
1. Redactar un prompt maestro en lenguaje operativo para futuras ejecuciones.
2. Congelar reglas de backend común y frontend BIM desacoplado.
3. Fijar prohibiciones explícitas para evitar colisiones entre capas.
4. Incluir criterios de validación, rollback y trazabilidad.

## Validación
- Existe un prompt reutilizable y claro.
- El prompt cubre arquitectura, UX, flags, validación y no interferencia.
- El documento es suficiente para guiar futuras implementaciones del programa BIM paralelo.
