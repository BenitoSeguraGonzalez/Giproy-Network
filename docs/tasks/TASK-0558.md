# TASK-0558

## Objetivo
Preparar un prompt ejecutivo de activación para iniciar sesiones de trabajo en modo `GiProy Clásico`, `GiProy BIM` o `Integración Controlada`, asegurando que cada intervención se ejecute dentro del entorno correcto y sin choque entre capas.

## Alcance
- Prompt corto de activación de sesión
- Selección explícita de modo de trabajo
- Reglas operativas por modo

## Implementación
1. Redactar el prompt ejecutivo corto.
2. Definir reglas mínimas por modo.
3. Incluir principios obligatorios compartidos.
4. Dejarlo listo para reutilización en futuras sesiones.

## Validación
- Existe un prompt corto y operativo.
- Permite definir el entorno de trabajo de cada sesión.
- Mantiene la estrategia de no interferencia entre `GiProy Clásico` y `GiProy BIM`.
