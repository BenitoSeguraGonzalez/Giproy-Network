# TASK-0559

## Objetivo
Preparar plantillas físicas por modo de trabajo y un lanzador operativo que genere prompts de sesión y autocomplemente un estado runtime para acelerar el cambio entre `GiProy Clásico`, `GiProy BIM` e `Integración Controlada`.

## Alcance
- Plantillas físicas en `docs/plantillas`
- Estado runtime en `docs/runtime/WORK_MODE_STATE.json`
- Script Python lanzador
- Wrapper `.bat`

## Implementación
1. Crear plantillas físicas para modo clásico, BIM e integración.
2. Crear `WORK_MODE_STATE.json` para contexto autocompletado.
3. Implementar un lanzador Python que actualice el estado y genere el prompt adecuado.
4. Añadir un wrapper `.bat` para uso rápido desde consola.
5. Generar o reutilizar automáticamente una TASK activa de sesión.

## Validación
- Se puede invocar `clasico`, `bim` o `integracion`.
- El JSON runtime se autocompleta.
- El prompt final sale listo para copiar y pegar.
- La estrategia de no interferencia entre capas queda embebida en cada plantilla.
- La TASK activa se genera o reutiliza sin pedirla manualmente.
