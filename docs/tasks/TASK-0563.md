# TASK-0563.md

## Objetivo
Arrancar el primer slice ejecutable de `GiProy BIM` con activación controlada por feature flags y shell frontend desacoplada dentro de `Proyecto`.

## Modo
GIPROY BIM

## Estado
En ejecución durante la sesión `GIPROY BIM`.

## Fecha de creación
2026-03-26 20:21:18

## Alcance inicial
- Resolver feature flags BIM desde backend común sin contaminar contratos clásicos.
- Añadir cliente y hook frontend para consultar activación BIM por usuario/empresa.
- Insertar pestaña `BIM` en `Proyecto` solo cuando la flag esté habilitada.
- Mantener rollback limpio: con BIM apagado no debe aparecer ninguna UX nueva en GiProy Clásico.

## Validación
- `BIM_ENABLED=false`: la navegación clásica de `Proyecto` permanece intacta y la pestaña `BIM` no se renderiza.
- `BIM_ENABLED=true`: el endpoint BIM resuelve acceso y la pestaña `BIM` se muestra como shell desacoplada.
- Validación técnica mínima: compilación Python de los archivos BIM nuevos y build frontend sin ruptura.

- Frontend: nuevo cliente `bimApi`, hook `useBimFeatureAccess` y shell `BimTab/BimWorkspace`.
- Proyecto: la pestaña `BIM` solo entra cuando la activación lo permite y retrocede a `datos` si la flag se apaga.
