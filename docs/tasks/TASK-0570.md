# Descripción
La consola `Administración Global` no expone de forma visible el panel de gestión de superadministradores y mantiene una cabecera con metadatos documentales (`alcance`, `task madre`, `estado`) que no aporta valor operativo y confunde la lectura del módulo.

# Objetivo
Hacer que `Administración Global` conduzca claramente al panel de superadministradores y eliminar la cabecera documental residual para que la portada se comporte como consola de operación real.

# Alcance
- Añadir entrada explícita a la gestión de superadministradores desde `Administración Global`.
- Retirar la franja de metadatos documentales del header de la consola.
- Mantener el ajuste totalmente en frontend clásico.

# Implementación
- Se añadió una tarjeta `Superadministradores` dentro de `Administración Global` con navegación directa a `Ajuste SaaS` (`/settings?tab=superadmins`).
- Se retiraron del encabezado los bloques documentales `Alcance`, `Task madre` y `Estado`, que pertenecían a una shell interna y no a la operación normal del módulo.
- Se mantuvo intacta la restricción por rol: solo `superadministrador` puede entrar y operar esta consola.

# Validación
- `npm run build` en `frontend` completado correctamente.

# Resultado
`Administración Global` ya expone de forma explícita la entrada a la gestión de superadministradores y deja de mostrar metadatos internos que confundían la lectura UX del módulo.
