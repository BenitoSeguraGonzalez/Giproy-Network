# Descripción
La funcionalidad de categorías por alcance para `Sistema / Usuarios / Todos` ya quedó implementada, pero falta materializarla en la base local y dejar sembrado el catálogo inicial exclusivo de `Sistema` para `Licencias`, `Actualizaciones` y `Adicionales`.

# Objetivo
Ejecutar la migración Alembic pendiente y dejar un bootstrap reproducible e idempotente de las categorías iniciales del Marketplace clásico para `Sistema`.

# Alcance
- Ejecutar la migración `7c1e4d2b9f10_marketplace_category_scopes`.
- Crear un script de bootstrap para categorías iniciales de `Sistema`.
- Ejecutar el bootstrap sobre la base local.
- Verificar que las categorías resultantes quedan activas y con alcance correcto.
- Mantener el ajuste completamente desacoplado de BIM.

# Implementación ejecutada
- Se añadió el servicio idempotente `backend/app/services/marketplace_bootstrap.py` para materializar el catálogo inicial de categorías exclusivas de `Sistema`.
- Se añadió el script reproducible `backend/scripts/seed_marketplace_system_categories.py`.
- Se ejecutó Alembic de forma dirigida sobre la rama Marketplace:
  - `alembic -c alembic.ini upgrade 7c1e4d2b9f10`
- Se ejecutó el bootstrap local:
  - `python scripts/seed_marketplace_system_categories.py`

# Validación ejecutada
- `python -m py_compile app/services/marketplace_bootstrap.py scripts/seed_marketplace_system_categories.py alembic/versions/7c1e4d2b9f10_marketplace_category_scopes.py`
- Verificación de `alembic_version`:
  - `7c1e4d2b9f10`
  - `e2f3a4b5c6d7`
- Verificación de categorías materializadas en `marketplace_product_categories`:
  - `sistema-licencias`
  - `sistema-actualizaciones`
  - `sistema-adicionales`

# Resultado
- La migración de alcance de categorías Marketplace quedó aplicada en la base local real.
- El catálogo inicial exclusivo de `Sistema` quedó sembrado de forma reproducible e idempotente para `Licencias`, `Actualizaciones` y `Adicionales`.
- El ajuste se mantiene completamente en la capa clásica y no introduce ninguna dependencia con BIM.
