# Descripción
El Marketplace clásico ya permite crear, editar y activar/desactivar publicaciones, pero todavía no ofrece un ciclo de vida completo desde el panel vendedor. Faltan acciones operativas clave para administrar el catálogo sin salir a flujos manuales: clonar una publicación existente y retirarla definitivamente cuando ya no deba formar parte del catálogo.

# Objetivo
Completar el gestor clásico de publicaciones Marketplace añadiendo clonación y retiro definitivo desde el panel vendedor, manteniendo backend común y sin interferencia con BIM.

# Alcance
- Añadir clonación de productos marketplace desde el panel vendedor.
- Añadir retiro definitivo de publicaciones del vendedor.
- Mantener reglas de permisos y restricciones por rol.
- Reforzar la UX del `SellerDashboard` sin alterar la capa BIM.

# Implementación ejecutada
- `backend/app/services/marketplace.py`
  - Se añadió clonación de publicaciones del vendedor.
  - La clonación genera una nueva publicación manual, con título derivado y sin reutilizar el vínculo referenciado original.
  - Se añadió retiro definitivo de publicaciones del vendedor.
- `backend/app/api/endpoints/marketplace.py`
  - Se añadieron las rutas:
    - `POST /marketplace/seller/products/{product_id}/clone`
    - `DELETE /marketplace/seller/products/{product_id}`
- `frontend/src/api/marketplace.js`
  - Se añadieron los clientes `cloneSellerProduct` y `deleteSellerProduct`.
- `frontend/src/pages/SellerDashboard.jsx`
  - El panel vendedor incorpora acciones `Clonar` y `Retirar`.
  - Tras clonar, la nueva publicación pasa directamente a edición para continuar el trabajo.
  - Si se retira una publicación que estaba en edición, el formulario se limpia de forma controlada.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py backend/app/api/endpoints/marketplace.py`
- `npm run build`

# Resultado
- El panel vendedor clásico ya no se limita a editar o activar/desactivar: ahora permite clonar y retirar publicaciones.
- Marketplace queda más cerca de un gestor completo de items multi vendedor dentro de la capa clásica.
- No hubo interferencia con BIM.
