# Descripción
El Marketplace clásico ya permite operar productos y ventas, pero la lectura del catálogo en seller y administración global todavía es plana. Cuando crece el volumen, faltan filtros operativos para localizar productos por estado, tipo, categoría, actividad o propietario.

# Objetivo
Mejorar la navegabilidad del Marketplace clásico añadiendo filtros operativos ricos en `SellerDashboard` y `MarketplaceAdminDashboard`, sin introducir dependencias con BIM ni alterar contratos backend.

# Alcance
- Añadir filtros locales para catálogo vendedor.
- Añadir filtros locales para moderación admin.
- Mejorar la UX de lectura operativa y triage comercial.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Se añadieron filtros locales por texto, estado, tipo, categoría y actividad sobre el catálogo del panel vendedor.
  - Los filtros operan tanto en `Empresa` como en `Sistema`, reutilizando los datos ya cargados y sin backend nuevo.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadieron filtros locales por texto, estado, tipo y propietario en la superficie de moderación.
  - La moderación ahora puede triagear mejor productos sin depender de una lista plana.

# Validación ejecutada
- `npm run build`

# Resultado
- El Marketplace clásico gana lectura operativa real en seller y admin.
- La gestión ya no depende de listas planas cuando el catálogo crece.
- No hubo interferencia BIM.
