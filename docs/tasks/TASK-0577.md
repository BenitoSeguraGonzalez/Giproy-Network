# Descripción
El Marketplace clásico ya dispone de categorías exclusivas de `Sistema`, pero todavía no tiene productos reales publicados en el catálogo base. Para habilitar pruebas y operación inicial, hace falta sembrar un conjunto mínimo de productos de `Licencias`, `Actualizaciones` y `Adicionales`.

# Objetivo
Materializar un catálogo inicial reproducible e idempotente de productos `Sistema` dentro del Marketplace clásico.

# Alcance
- Crear bootstrap idempotente de productos iniciales de `Sistema`.
- Ejecutarlo sobre la base local con el `superadministrador` existente.
- Mantener el ajuste desacoplado de BIM.

# Implementación ejecutada
- Se añadió el servicio `backend/app/services/marketplace_catalog_bootstrap.py`.
- Se añadió el script reproducible `backend/scripts/seed_marketplace_system_catalog.py`.
- El bootstrap resuelve el `superadministrador` local disponible y materializa productos base de:
  - `Licencias`
  - `Actualizaciones`
  - `Adicionales`
- Los productos se crean como publicaciones manuales, activas y aprobadas, con propietario `Sistema`.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace_catalog_bootstrap.py backend/scripts/seed_marketplace_system_catalog.py`
- `python scripts/seed_marketplace_system_catalog.py`
- Reejecución idempotente del script sobre la misma base local sin duplicar productos.

# Resultado
- El Marketplace clásico ya cuenta con catálogo inicial real de `Sistema`.
- Quedaron sembrados:
  - `Licencia Profesional Plus`
  - `Pack de Actualización Marketplace`
  - `Servicio de Configuración Inicial`
- El ajuste quedó completamente dentro de la capa clásica y no introduce dependencias con BIM.
