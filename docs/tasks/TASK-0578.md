# Descripción
El Marketplace clásico ya tiene catálogo inicial de `Sistema`, pero la lectura visual en la portada y el detalle todavía trata esos productos como un item más del marketplace multi vendedor. Hace falta reforzar su presentación comercial para que el usuario entienda con claridad cuándo está frente a una oferta oficial de GiProy.

# Objetivo
Mejorar la jerarquía visual y la lectura comercial de los productos `Sistema` en la home de Tienda y en el detalle de producto.

# Alcance
- Destacar productos `Sistema` en la portada del Marketplace.
- Añadir señales comerciales más claras en el detalle de producto.
- Mantener el ajuste visual dentro de la capa clásica.

# Implementación ejecutada
- `frontend/src/pages/Marketplace.jsx`
  - La portada separa ahora el catálogo oficial de `Sistema` del resto del marketplace multi vendedor.
  - Los productos oficiales reciben una presentación destacada y una lectura comercial propia.
- `frontend/src/pages/MarketplaceProductDetail.jsx`
  - El detalle incorpora una banda explícita de `Oferta oficial` para productos del catálogo `Sistema`.
  - Se refuerza la lectura de propietario y la naturaleza comercial oficial del producto.

# Validación ejecutada
- `npm run build`

# Resultado
- Los productos `Sistema` ya no se perciben como un vendedor más dentro del grid general.
- Tienda gana una primera lectura comercial más clara entre catálogo oficial y publicaciones multi vendedor.
- No hubo interferencia BIM.
