# Descripción
El Marketplace clásico ya permite vender, comprar y moderar, pero las superficies de ventas en seller y administración siguen siendo demasiado planas. Falta una lectura operativa más útil de pedidos, fechas, tipos y contexto comercial para que el seguimiento sea realmente manejable.

# Objetivo
Mejorar la trazabilidad visual de ventas y pedidos en las superficies clásicas de seller y administración, sin abrir contratos backend nuevos ni tocar BIM.

# Alcance
- Añadir filtros locales y mejor contexto visual a las ventas del seller.
- Añadir filtros locales y mejor lectura de ventas globales en admin.
- Mantener el ajuste dentro del frontend clásico.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Se añadieron filtros por texto y tipo en las ventas del panel vendedor.
  - Cada venta ahora muestra referencia de pedido y fecha cuando están disponibles.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadieron filtros por texto, tipo y propietario en la lectura de ventas globales.
  - La superficie global ahora muestra mejor contexto operativo de pedido y trazabilidad temporal.

# Validación ejecutada
- `npm run build`

# Resultado
- Seller y admin ya pueden leer ventas y pedidos con más contexto operativo sin depender de backend nuevo.
- La operación comercial de Marketplace clásico gana seguimiento y triage real.
- No hubo interferencia BIM.
