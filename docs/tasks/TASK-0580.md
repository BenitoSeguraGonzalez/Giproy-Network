# Descripción
La administración global del Marketplace clásico ya permite moderar productos y leer ventas, pero todavía no ofrece una consola específica de pedidos. Falta una superficie operativa para revisar compradores, estados, totales y volumen por orden desde superadministración.

# Objetivo
Añadir una consola administrativa de pedidos globales en Marketplace clásico, con backend común, filtros UX y cero interferencia con BIM.

# Alcance
- Exponer pedidos globales de Marketplace para superadministración.
- Añadir filtros y lectura operativa de pedidos en el dashboard admin.
- Mantener el ajuste dentro de la capa clásica y el backend común.

# Implementación ejecutada
- `backend/app/schemas/marketplace.py`
  - Se añadió un resumen tipado de pedido administrativo para exponer comprador, estado, total y volumen por orden.
- `backend/app/services/marketplace.py`
  - Se añadió la lectura global de pedidos para superadministración con buyer, totales, estado, notas y cantidad de items.
- `backend/app/api/endpoints/marketplace.py`
  - Se expuso `GET /marketplace/admin/orders` dentro del backend común de Marketplace.
- `frontend/src/api/marketplace.js`
  - Se añadió el cliente `getAdminOrders` para consumir la nueva lectura administrativa.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadió una consola UX de pedidos globales con filtros por texto y estado.
  - La superficie admin ahora separa mejor moderación, pedidos y ventas para una lectura operativa más clara.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py backend/app/api/endpoints/marketplace.py backend/app/schemas/marketplace.py`
- `npm run build`

# Resultado
- La superadministración ya puede revisar pedidos globales de Marketplace clásico con mejor contexto operativo.
- El dashboard admin deja de depender solo de ventas unitarias y gana una vista de órdenes más útil para seguimiento comercial.
- No hubo interferencia BIM.
