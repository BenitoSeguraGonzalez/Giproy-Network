# Descripción
La consola global de pedidos ya permite triage operativo, pero todavía obliga a leer la orden de forma superficial. Falta una vista de detalle administrativo para inspeccionar items, distribución económica y contexto del comprador sin salir del dashboard.

# Objetivo
Añadir detalle administrativo expandible por pedido en la administración global del Marketplace clásico, reutilizando backend común y sin interferencia BIM.

# Alcance
- Exponer un detalle administrativo de pedido para superadministración.
- Incorporar expansión inline por pedido dentro del dashboard admin.
- Mantener el ajuste en la capa clásica.

# Implementación ejecutada
- `backend/app/schemas/marketplace.py`
  - Se añadieron los contratos de detalle administrativo de pedido e item para superadministración.
- `backend/app/services/marketplace.py`
  - Se añadió la lectura de detalle administrativo por pedido, con comprador, notas, distribución económica e items con vendedor.
- `backend/app/api/endpoints/marketplace.py`
  - Se expuso `GET /marketplace/admin/orders/{order_id}` dentro del backend común.
- `frontend/src/api/marketplace.js`
  - Se añadió `getAdminOrderById` para recuperar el detalle administrativo de la orden.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Cada pedido global ahora puede expandirse inline para ver su detalle sin salir del dashboard.
  - La experiencia administrativa gana una lectura más profunda de comprador, items, vendedor y distribución económica.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py backend/app/api/endpoints/marketplace.py backend/app/schemas/marketplace.py`
- `npm run build`

# Resultado
- La superadministración ya puede inspeccionar una orden concreta sin abandonar la consola global de Marketplace.
- El dashboard admin gana continuidad operativa al evitar navegación extra para revisar el contenido real de un pedido.
- No hubo interferencia BIM.
