# Descripción
La administración global del Marketplace clásico ya permite moderar productos y revisar pedidos, pero su cabecera sigue siendo demasiado básica. Faltan métricas operativas que ayuden a leer salud comercial, volumen reciente y base compradora sin depender de inspección manual.

# Objetivo
Añadir métricas operativas reales al dashboard admin de Marketplace clásico, reutilizando el backend común y manteniendo la UX orientada a operación.

# Alcance
- Extender el resumen administrativo de Marketplace con KPIs comerciales reales.
- Reforzar la portada admin con tarjetas y señales de actividad recientes.
- Mantener el ajuste acotado a la capa clásica.

# Implementación ejecutada
- `backend/app/services/marketplace.py`
  - Se amplió el resumen admin con compradores únicos, ticket medio, pedidos recientes, ventas recientes y fecha del último pedido.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - La portada admin ahora muestra métricas comerciales más ricas y un bloque de pulso reciente.
  - Se añadió una zona de señales operativas para leer actividad, recencia y cola de moderación sin inspección manual.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`

# Resultado
- La superadministración ya puede leer mejor la salud comercial del Marketplace clásico desde la propia cabecera del dashboard.
- El tablero gana contexto de compradores, ticket medio y actividad reciente sin abrir vistas adicionales.
- No hubo interferencia BIM.
