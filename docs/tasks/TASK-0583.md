# Descripción
La administración global del Marketplace clásico ya muestra métricas operativas, pero todavía falta una lectura más estratégica del negocio. No basta con saber cuántos pedidos hubo; también hace falta ver qué tipos lideran y qué compradores se están activando.

# Objetivo
Añadir insights comerciales ligeros al dashboard admin de Marketplace clásico para reforzar la lectura de mix de ventas y actividad compradora.

# Alcance
- Extender el resumen admin con rankings comerciales reales.
- Incorporar paneles visuales de mix por tipo y compradores activos.
- Mantener el ajuste dentro de la capa clásica.

# Implementación ejecutada
- `backend/app/services/marketplace.py`
  - Se amplió el resumen admin con ranking de tipos más vendidos y compradores más activos.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadieron paneles de `Mix comercial` y `Compradores más activos` dentro de la portada administrativa.
  - El dashboard ahora responde mejor qué se vende y quién compra sin depender de lectura manual de pedidos.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`

# Resultado
- La superadministración ya puede leer mejor el comportamiento comercial del Marketplace clásico.
- El dashboard admin gana una capa ligera de inteligencia comercial útil para seguimiento y priorización.
- No hubo interferencia BIM.
