# Descripción
El dashboard admin del Marketplace clásico ya muestra métricas e insights, pero todavía no ayuda a detectar excepciones. Falta una capa de alertas operativas que haga visible el backlog de moderación y la mezcla real entre ventas de `Sistema` y ventas de empresas usuarias.

# Objetivo
Añadir alertas operativas y lectura por canal comercial al dashboard admin del Marketplace clásico.

# Alcance
- Extender el resumen admin con señales de backlog y mezcla comercial.
- Añadir un panel UX de alertas operativas y distribución `Sistema / Empresas`.
- Mantener el ajuste confinado a la capa clásica.

# Implementación ejecutada
- `backend/app/services/marketplace.py`
  - Se añadieron señales de backlog envejecido y mezcla comercial entre `Sistema` y `Empresas`.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadió un panel de `Alertas operativas` para excepciones reales de moderación y actividad.
  - Se añadió una lectura visual del canal comercial `Sistema vs Empresas` basada en ventas completadas.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`

# Resultado
- La superadministración ya puede detectar mejor backlog, falta de actividad reciente y desbalance entre canales comerciales.
- El dashboard admin gana una capa más ejecutiva sin abandonar la base operativa ya construida.
- No hubo interferencia BIM.
