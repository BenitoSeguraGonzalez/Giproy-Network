# Descripción
El dashboard admin del Marketplace clásico ya avisa cuando hay backlog, pero todavía obliga a bajar a la lista completa de moderación para actuar. Falta una bandeja prioritaria que señale primero las publicaciones más antiguas pendientes y permita resolverlas rápidamente.

# Objetivo
Añadir una bandeja prioritaria de moderación al dashboard admin del Marketplace clásico, con foco en backlog envejecido y acción rápida.

# Alcance
- Priorizar publicaciones pendientes por antigüedad.
- Mostrar edad, propietario y categoría de las publicaciones más urgentes.
- Permitir aprobar o rechazar desde la propia bandeja.

# Implementación ejecutada
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadió una bandeja prioritaria de publicaciones pendientes ordenadas por antigüedad.
  - Cada publicación prioritaria muestra edad de moderación, propietario, tipo, categoría y fecha de creación.
  - La superadministración ahora puede aprobar o rechazar directamente desde la bandeja sin bajar a la lista general.

# Validación ejecutada
- `npm run build`

# Resultado
- La moderación del Marketplace clásico gana una cola prioritaria visible y accionable desde la portada admin.
- El backlog envejecido deja de quedar diluido dentro de la lista completa de publicaciones.
- No hubo interferencia BIM.
