# Descripción
La bandeja prioritaria ya permite actuar sobre publicaciones pendientes, pero todavía falta una lectura compacta de la cola de moderación. No es lo mismo tener backlog reciente que tener atasco envejecido, ni es igual una cola dominada por `Sistema` que por `Empresas`.

# Objetivo
Añadir un centro de mando de moderación al dashboard admin del Marketplace clásico para leer la cola por antigüedad y canal comercial.

# Alcance
- Resumir la cola pendiente por tramos de antigüedad.
- Separar el backlog entre publicaciones de `Sistema` y de `Empresas`.
- Mantener el ajuste dentro del frontend clásico, reutilizando los datos ya cargados.

# Implementación ejecutada
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadió un centro de mando de moderación con lectura de cola por tramos de antigüedad.
  - La cola pendiente ahora se separa entre publicaciones recientes, calientes y envejecidas.
  - También se añadió una lectura por canal pendiente `Sistema vs Empresas`, reutilizando los productos ya cargados en el dashboard.

# Validación ejecutada
- `npm run build`

# Resultado
- La superadministración ya puede leer mejor el estado real de la cola de moderación antes de actuar.
- El dashboard admin gana una vista compacta de atasco por antigüedad y por canal comercial.
- No hubo interferencia BIM.
