# Descripción
La moderación admin ya tiene prioridad, alertas y centro de mando, pero sigue faltando una revisión más informada antes de decidir. Hoy una publicación pendiente se lee sobre todo por título, tipo y propietario; todavía falta una vista previa administrativa con más contexto del contenido publicado.

# Objetivo
Añadir una vista previa administrativa expandible para publicaciones pendientes dentro del dashboard admin del Marketplace clásico.

# Alcance
- Permitir ampliar una publicación pendiente desde la bandeja prioritaria.
- Mostrar resumen, descripción, incluye/no incluye, etiquetas y vista previa técnica cuando existan.
- Mantener la decisión de aprobar/rechazar dentro del mismo flujo.

# Implementación ejecutada
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - Se añadió una vista previa administrativa expandible para publicaciones pendientes dentro de la bandeja prioritaria.
  - La ficha muestra resumen, descripción, incluye/no incluye, etiquetas, precio y vista previa técnica cuando existen.
  - La superadministración puede revisar mejor el contenido antes de aprobar o rechazar sin salir del dashboard.

# Validación ejecutada
- `npm run build`

# Resultado
- La moderación admin del Marketplace clásico gana una revisión más informada y menos superficial.
- El dashboard permite decidir mejor sin abrir otras pantallas ni perder el foco de la cola prioritaria.
- No hubo interferencia BIM.
