# Descripción
La moderación admin del Marketplace clásico ya tiene prioridad, alertas y vista previa, pero todavía no puede dejar contexto persistente sobre una decisión. Falta una forma real de guardar observaciones administrativas al aprobar o rechazar publicaciones.

# Objetivo
Añadir observaciones administrativas persistentes al flujo de moderación del Marketplace clásico.

# Alcance
- Añadir soporte backend común para notas administrativas en productos Marketplace.
- Permitir que aprobar o rechazar guarde observaciones.
- Mostrar esas observaciones dentro del dashboard admin.

# Implementación ejecutada
- `backend/app/models/marketplace.py`
  - Se añadió `admin_notes` al dominio de productos Marketplace.
- `backend/app/schemas/marketplace.py`
  - Se expuso `admin_notes` en la respuesta de producto y se añadió un payload específico para acciones de moderación.
- `backend/app/api/endpoints/marketplace.py`
  - Aprobar y rechazar productos admin ahora aceptan observaciones administrativas.
- `backend/app/services/marketplace.py`
  - La decisión de moderación ahora persiste `admin_notes` junto con el estado aprobado/rechazado.
- `backend/alembic/versions/a9b8c7d6e5f4_marketplace_admin_notes.py`
  - Se añadió la migración Alembic aditiva para materializar el nuevo campo en base de datos.
- `frontend/src/api/marketplace.js`
  - Se amplió el cliente admin para enviar payload en aprobar/rechazar.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx`
  - La vista previa administrativa ahora permite capturar y persistir observaciones al moderar una publicación.

# Validación ejecutada
- `python -m py_compile backend/app/models/marketplace.py backend/app/schemas/marketplace.py backend/app/api/endpoints/marketplace.py backend/app/services/marketplace.py backend/alembic/versions/a9b8c7d6e5f4_marketplace_admin_notes.py`
- `npm run build`

# Resultado
- La superadministración ya puede dejar contexto persistente en sus decisiones de moderación dentro del Marketplace clásico.
- Aprobar o rechazar deja de ser un acto mudo y gana trazabilidad operativa real.
- La migración Alembic se ejecutó posteriormente en `TASK-0590`.
- No hubo interferencia BIM.
