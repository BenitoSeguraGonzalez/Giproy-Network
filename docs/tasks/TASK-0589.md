# Descripción
La moderación admin ya puede guardar observaciones persistentes, pero el vendedor todavía no recibe ese contexto dentro de su panel. Falta cerrar el circuito para que las publicaciones muestren claramente la observación administrativa cuando exista.

# Objetivo
Hacer visibles las observaciones administrativas de moderación dentro del panel vendedor del Marketplace clásico.

# Alcance
- Mostrar `admin_notes` en las tarjetas de publicaciones cuando exista contexto administrativo.
- Dar mejor lectura de publicaciones `rejected` o aún `pending` con observación.
- Mantener el ajuste dentro del frontend clásico.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Las publicaciones del vendedor ahora muestran la observación administrativa cuando existe `admin_notes`.
  - La lectura visual diferencia mejor observaciones sobre publicaciones rechazadas y pendientes.
  - El vendedor ya puede entender el contexto administrativo sin salir de su panel comercial.

# Validación ejecutada
- `npm run build`

# Resultado
- El circuito de moderación clásica queda más completo al devolver contexto desde admin hacia seller.
- El vendedor deja de ver un rechazo o una revisión pendiente como un estado opaco sin explicación.
- No hubo interferencia BIM.
