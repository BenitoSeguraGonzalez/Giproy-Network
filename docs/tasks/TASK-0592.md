# Descripción
La bandeja seller ya permite detectar rápidamente publicaciones observadas o rechazadas, pero el siguiente paso natural es convertir esa bandeja en un flujo todavía más guiado de corrección y reenvío.

# Objetivo
Reducir la fricción entre observación administrativa y reenvío a moderación dentro del Marketplace clásico.

# Alcance
- Reenviar automáticamente a revisión las publicaciones rechazadas u observadas cuando el vendedor corrige contenido.
- Mostrar al vendedor que la edición reactivará el flujo de moderación.
- Mantener el trabajo dentro de la capa clásica y backend común sin interferencia BIM.

# Implementación ejecutada
- `backend/app/services/marketplace.py`
  - Las publicaciones con observaciones administrativas o estado `rejected` vuelven a `pending` cuando el vendedor corrige contenido material.
  - El backend reactiva el item para que la moderación pueda evaluarlo de nuevo sin pasos manuales extra.
- `backend/app/schemas/marketplace.py`
  - Se expone `fecha_actualizacion` en la respuesta del producto para mejorar lectura temporal del flujo.
- `frontend/src/pages/SellerDashboard.jsx`
  - El editor muestra una advertencia explícita cuando la publicación corregida será reenviada automáticamente a revisión.
  - La bandeja seller usa la marca temporal correcta del producto para priorizar el seguimiento.

# Validación ejecutada
- `python -m py_compile backend/app/schemas/marketplace.py backend/app/services/marketplace.py`
- `npm run build`

# Resultado
- Corregir una publicación observada deja de ser un gesto aislado y pasa a reactivar el circuito real de moderación.
- El vendedor entiende antes de guardar qué va a ocurrir con su publicación.
- No hubo interferencia BIM.
