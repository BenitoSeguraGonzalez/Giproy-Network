# Descripción
El vendedor ya puede detectar publicaciones observadas y corregirlas con reenvío automático a revisión, pero todavía falta una lectura específica de cuáles ya fueron corregidas y siguen pendientes de aprobación.

# Objetivo
Dar seguimiento claro dentro del panel vendedor a publicaciones reenviadas a moderación tras una corrección.

# Alcance
- Evaluar una bandeja o señalización específica para publicaciones corregidas que ya volvieron a `pending`.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Se añadió una bandeja específica para publicaciones ya corregidas y reenviadas a moderación.
  - La lectura separa lo que todavía requiere corrección de lo que ya está esperando nueva decisión administrativa.
  - Cada item reenviado conserva acceso directo al editor para revisar o ajustar nuevamente la publicación.

# Validación ejecutada
- `npm run build`

# Resultado
- El vendedor ya puede distinguir entre publicaciones observadas pendientes de corrección y publicaciones ya reenviadas a revisión.
- El panel seller gana una lectura de progreso real sobre el ciclo de moderación.
- No hubo interferencia BIM.
