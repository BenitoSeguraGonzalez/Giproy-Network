# Descripción
El workflow seller de moderación ya tiene resumen, bandejas de corrección y seguimiento, pero todavía falta conectar mejor esos estados con acciones comerciales del propio panel para que el usuario no quede solo en modo diagnóstico.

# Objetivo
Reforzar la recirculación desde estados de moderación hacia acciones útiles del workflow comercial seller.

# Alcance
- Evaluar accesos o puentes UX desde métricas y bandejas hacia acciones seller existentes.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - El resumen operativo seller ahora incorpora acciones directas hacia correcciones, seguimiento de reenviadas y creación de nuevos productos.
  - Las bandejas clave del workflow quedaron ancladas para navegación interna fluida desde la cabecera de moderación.
  - El panel deja de ser solo diagnóstico y pasa a recircular al usuario hacia acciones comerciales reales.

# Validación ejecutada
- `npm run build`

# Resultado
- El vendedor puede pasar de la lectura ejecutiva a la acción concreta sin buscar manualmente cada sección.
- El workflow seller gana continuidad y reduce fricción entre moderación y operación comercial.
- No hubo interferencia BIM.
