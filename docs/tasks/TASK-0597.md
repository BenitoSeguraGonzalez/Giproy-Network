# Descripción
El panel seller ya cubre moderación y catálogo aprobado, pero todavía falta una lectura más intencional de productos pausados o inactivos para facilitar reactivación y gobierno del catálogo.

# Objetivo
Mejorar la gestión seller de productos pausados dentro del Marketplace clásico.

# Alcance
- Evaluar una superficie o señalización específica para publicaciones inactivas.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Se añadió una bandeja específica para publicaciones pausadas o inactivas dentro del panel seller.
  - El vendedor ahora puede reactivar o revisar rápidamente productos fuera del catálogo visible.
  - El resumen operativo también incorpora la señal de productos pausados con acceso directo a esta superficie.

# Validación ejecutada
- `npm run build`

# Resultado
- El seller gana gobierno explícito sobre publicaciones pausadas sin depender del listado general.
- El catálogo activo y el catálogo pausado quedan equilibrados dentro del mismo flujo operativo.
- No hubo interferencia BIM.
