# Descripción
El panel seller ya cubre productos observados, reenviados, activos y pausados, pero todavía falta separar mejor los productos nuevos que quedaron pendientes de primera aprobación.

# Objetivo
Mejorar la lectura seller de publicaciones nuevas que están pendientes de revisión inicial en Marketplace clásico.

# Alcance
- Evaluar una superficie o señalización específica para pendientes nuevos.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- `frontend/src/pages/SellerDashboard.jsx`
  - Se añadió una bandeja específica para publicaciones nuevas en `pending` que aún esperan primera revisión.
  - El resumen operativo seller ahora diferencia también los pendientes nuevos del resto del pipeline.
  - La lectura separa claramente primera aprobación, observaciones, reenvíos, catálogo activo y catálogo pausado.

# Validación ejecutada
- `npm run build`

# Resultado
- El seller ya distingue mejor entre publicaciones nuevas a la espera de primera revisión y publicaciones observadas o reenviadas.
- El pipeline comercial del panel gana una lectura más limpia y menos ambigua.
- No hubo interferencia BIM.
