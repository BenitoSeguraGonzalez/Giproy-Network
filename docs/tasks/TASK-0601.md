# Descripción
La portada seller ya quedó bastante cohesionada como cockpit comercial, pero la experiencia buyer todavía puede reforzarse para mantener paridad de claridad en Tienda clásica.

# Objetivo
Reforzar la portada buyer de Marketplace clásico como una superficie comercial más cohesionada.

# Alcance
- Evaluar mejoras UX en la portada buyer manteniéndose dentro del frontend clásico.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- `frontend/src/pages/MarketplaceBuyerDashboard.jsx`
  - Se añadió una capa ejecutiva buyer con pulso comercial, foco siguiente y navegación interna.
  - La portada buyer ahora conecta mejor biblioteca, pedidos y regreso al catálogo desde una sola superficie.
  - También se reforzó la lectura comercial de pedidos con métricas compactas como ticket medio y último pedido.

# Validación ejecutada
- `npm run build`

# Resultado
- La experiencia buyer gana una lectura más cohesionada y comparable con la madurez ya alcanzada en seller.
- La tienda clásica queda mejor equilibrada entre compra, biblioteca y seguimiento de pedidos.
- No hubo interferencia BIM.
