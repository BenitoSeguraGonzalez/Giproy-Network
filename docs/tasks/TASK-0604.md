# Descripción
La tienda clásica ya tiene seller, buyer, portada y detalle de producto bastante cohesionados, pero la experiencia posterior a la compra todavía puede reforzarse mejor en el frente de pedidos.

# Objetivo
Mejorar la experiencia operativa de pedidos dentro del Marketplace clásico.

# Alcance
- Evaluar mejoras UX sobre las superficies de pedido existentes dentro del frontend clásico.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- Se reforzó `frontend/src/pages/MarketplaceOrderDetail.jsx` con una capa cockpit equivalente al resto de superficies Marketplace clásicas.
- Se añadió una lectura ejecutiva del pedido con pulso postcompra, distribución de items/activos/descargas y foco siguiente.
- Se incorporó navegación interna hacia resumen, activos, descargas y retorno a `Mis compras`.
- Se reforzó la jerarquía visual del detalle con tarjetas compactas de estado, items, factura y comisión.

# Validación ejecutada
- `npm run build`

# Resultado
- El detalle de pedido del Marketplace clásico ya no se presenta como una ficha plana y ahora funciona como superficie operativa postcompra cohesionada.
