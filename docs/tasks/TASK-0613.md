# Descripción
Tras reforzar también la portada pública, el siguiente paso natural es revisar si todavía quedan asimetrías menores entre superficies del Marketplace clásico.

# Objetivo
Detectar y cerrar las asimetrías residuales más pequeñas del Marketplace clásico.

# Alcance
- Revisar buyer, seller, admin, portada y detalle como una sola familia de superficies.
- Corregir huecos menores de coherencia si todavía persisten.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- Se revisaron las asimetrías residuales entre buyer, seller, admin y portada del Marketplace clásico.
- Se identificó un hueco visible en `frontend/src/pages/MarketplaceAdminDashboard.jsx`: varios estados vacíos seguían siendo demasiado planos frente al nivel ya alcanzado en otras superficies.
- Se reforzaron los vacíos de moderación prioritaria, moderación global, pedidos globales y ventas globales con mejor orientación contextual y limpieza rápida de filtros cuando aplica.

# Validación ejecutada
- `npm run build`

# Resultado
- La administración Marketplace clásica queda más alineada con buyer, seller y portada en calidad de orientación cuando no hay datos o cuando los filtros eliminan resultados.
