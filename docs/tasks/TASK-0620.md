# Descripción
Tras reforzar la señal principal del cockpit seller, el siguiente paso natural es seguir afinando micro-recuperaciones UX dentro del Marketplace clásico.

# Objetivo
Mantener la evolución incremental del Marketplace clásico con ajustes pequeños y accionables de continuidad.

# Alcance
- Priorizar micro-mejoras de navegación, foco y recuperación rápida.
- Evitar cambios estructurales o acoplamientos innecesarios.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- Se tomó un ajuste incremental sobre el detalle de pedido del Marketplace clásico.
- En `frontend/src/pages/MarketplaceOrderDetail.jsx` la tarjeta `Siguiente foco` dejó de ser solo descriptiva.
- Ahora esa señal guía también la recuperación directa hacia el frente más útil según el estado real del pedido:
  - descargas
  - activos entregados
  - resumen del pedido

# Validación ejecutada
- `npm run build`

# Resultado
- La superficie postcompra gana una salida directa más coherente con el foco operativo ya calculado por la ficha.
