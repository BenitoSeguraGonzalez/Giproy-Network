# Descripción
Tras reforzar la portada comercial, el siguiente paso natural es seguir afinando micro-mejoras incrementales de navegación y foco dentro del Marketplace clásico.

# Objetivo
Mantener la evolución incremental del Marketplace clásico con mejoras pequeñas, útiles y no estructurales.

# Alcance
- Priorizar micro-mejoras de navegación, recuperación rápida y accionabilidad contextual.
- Evitar cambios estructurales o acoplamientos innecesarios.
- Mantener el trabajo dentro de la capa clásica sin interferencia BIM.

# Implementación ejecutada
- Se tomó una micro-mejora incremental sobre el detalle de producto del Marketplace clásico.
- En `frontend/src/pages/MarketplaceProductDetail.jsx` la tarjeta de foco comercial dejó de ser solo descriptiva.
- Ahora esa señal conduce directamente al frente correcto según el estado real de la ficha:
  - compra
  - reseñas
  - descripción principal

# Validación ejecutada
- `npm run build`

# Resultado
- El detalle de producto gana una recuperación rápida más coherente con el foco comercial ya calculado por la propia ficha.
