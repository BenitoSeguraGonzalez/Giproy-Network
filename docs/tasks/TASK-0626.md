# Descripción
El creador/editor de APUs reiniciaba `RENDIMIENTO GLOBAL` como activado cada vez que se abría o recreaba el formulario, aunque el usuario lo hubiera guardado previamente desactivado.

# Objetivo
Hacer que el editor recuerde el último estado guardado de `RENDIMIENTO GLOBAL`, manteniendo `activado` como valor inicial de primer arranque de la aplicación.

# Alcance
- Persistir la preferencia del toggle `RENDIMIENTO GLOBAL` a nivel del editor clásico de APUs.
- Reutilizar esa preferencia al crear un nuevo APU o al abrir uno existente.
- Mantener el fallback inicial activado cuando todavía no exista preferencia guardada.

# Implementación ejecutada
- Se añadió una preferencia persistida en `localStorage` para el estado guardado de `RENDIMIENTO GLOBAL`.
- El formulario inicial del editor ahora toma esa preferencia en lugar de forzar siempre `true`.
- Al guardar un APU con éxito, el editor actualiza la preferencia persistida con el valor real del toggle.
- La misma preferencia se aplica tanto al crear un APU nuevo como al abrir uno existente para edición.

# Validación ejecutada
- Revisión del flujo de inicialización del editor.
- Revisión del flujo `crear nuevo`.
- Revisión del flujo `editar existente`.
- `npm run build` en frontend.

# Resultado
- `RENDIMIENTO GLOBAL` arranca activado si nunca se ha guardado una preferencia.
- Después del primer guardado, el editor conserva el último estado guardado por el usuario entre sesiones de edición.
