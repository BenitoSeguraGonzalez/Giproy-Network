# Descripción
Se aprueba la adecuación visual integral de Tienda para llevar Marketplace clásico a una lectura más actual, usable y comercial, inspirada en patrones de comercio modernos tipo WooCommerce, pero manteniendo la identidad visual propia de GiProy.

# Objetivo
Definir y ejecutar una remodelación visual integral de Marketplace clásico sin romper su estructura funcional ni introducir contaminación BIM.

# Alcance
- Portada pública de Tienda.
- Detalle de producto.
- Buyer dashboard y postcompra.
- Seller dashboard.
- Administración Marketplace.
- Gramática visual compartida específica de Tienda.
- Estados vacíos, navegación contextual, responsive y consistencia transversal.

# Principios de diseño aprobados
- Mantener identidad GiProy: naranja corporativo, azul técnico, negros/zinc y fondo claro.
- Evitar copiar WooCommerce literalmente; adoptar su claridad comercial, jerarquía y usabilidad.
- Unificar lenguaje de cards, badges, filtros, CTAs, bloques de confianza y navegación interna.
- Separar mejor la lectura pública de tienda frente a paneles operativos buyer/seller/admin.
- Reforzar experiencia comercial sin introducir una UX paralela ajena al sistema clásico.

# Plan integral de ejecución
1. Sistema visual compartido de Marketplace.
2. Remodelación de portada pública y detalle de producto.
3. Remodelación buyer y postcompra.
4. Remodelación seller y backoffice comercial.
5. Remodelación admin marketplace y gobierno comercial.
6. Pulido responsive, estados borde y consistencia final.
