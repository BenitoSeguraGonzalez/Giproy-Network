# Descripción
Slice reservado para aplicar la remodelación visual integral al panel seller de Marketplace clásico.

# Objetivo
Convertir `SellerDashboard` en un backoffice comercial más limpio, actual y mejor jerarquizado.

# Alcance
- Portada seller.
- Editor de producto.
- Flujo comercial y workflow de moderación.
- Catálogo vivo, pausados, pendientes y ventas.

# Implementación ejecutada
- Se aplicó la nueva shell visual de Marketplace al acceso restringido del panel seller.
- Se remodeló la capa superior de `SellerDashboard` con hero comercial, métricas principales y lectura más clara del frente activo.
- Se reforzó la selección de alcance `Empresa / Sistema` para superadministración con una gramática visual alineada a la nueva fase de Tienda.
- Se remodeló la navegación operativa superior del seller con accesos visuales más claros hacia creación, workflow y ventas.
- Se integraron estados vacíos y bloques introductorios del seller a la nueva gramática visual compartida de Marketplace.
- Se remodelaron las superficies internas de catálogo y ventas con headers, filtros y cards más cercanas a un backoffice comercial actual.
- Se reorganizó el formulario de producto por bloques de publicación, identidad comercial, configuración y origen referenciado para reducir lectura plana.
- Se mantuvo intacta la lógica operativa de publicación, moderación y ventas para evitar regresiones en este slice.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- El panel seller ya comparte la nueva capa visual superior de Tienda clásica y su navegación ejecutiva principal.
- El panel seller ya comparte la nueva gramática visual en shell, navegación, formulario, catálogo y ventas.
- Queda pendiente el remate visual fino de colas de moderación y el ajuste de continuidad con administración marketplace.

# Cierre
- La deuda remanente de seller fue absorbida por las tasks posteriores de buyer/seller funcionales y ya no requiere seguir abierta como slice histórico de rediseño.
