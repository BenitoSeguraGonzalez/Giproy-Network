# Descripción
Slice reservado para aplicar la remodelación visual integral a la administración global de Marketplace clásico.

# Objetivo
Rediseñar `MarketplaceAdminDashboard` como consola de gobierno comercial con mejor jerarquía visual.

# Alcance
- Resumen admin.
- Moderación prioritaria y global.
- Pedidos globales.
- Ventas globales.
- Señales operativas y lectura por canal.

# Resultado esperado
- Dashboard admin alineado con la nueva identidad visual de Tienda clásica y con mejor lectura ejecutiva.

# Implementación ejecutada
- Se aplicó la nueva shell visual de Marketplace al dashboard admin y a su acceso restringido.
- Se remodeló la capa superior con hero ejecutivo, métricas rápidas y lectura más comercial del gobierno marketplace.
- Se reforzaron actividad reciente, señales operativas y bandeja prioritaria con una navegación más accionable y visualmente coherente.
- Se alinearon moderación global, pedidos y ventas con headers, filtros y cards acordes a la nueva gramática visual de Tienda.
- Se mantuvo intacta la lógica de moderación, detalle de pedidos y lectura administrativa para evitar regresiones funcionales.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- `MarketplaceAdminDashboard` ya comparte la nueva identidad visual integral de Tienda clásica.
- La familia pública, buyer, seller y admin queda visualmente mucho más cohesionada dentro del mismo sistema.
