# Descripción
Slice incremental posterior a la remodelación integral, enfocado en endurecer la experiencia de carga de Tienda clásica.

# Objetivo
Sustituir esperas vacías o demasiado planas por superficies de carga coherentes con la nueva gramática visual de Marketplace clásico.

# Alcance
- Sistema visual compartido.
- Storefront.
- Buyer dashboard.
- Detalle de pedido.
- Administración marketplace.

# Implementación ejecutada
- Se añadió un estado de carga reutilizable al sistema visual compartido de Marketplace.
- Se sustituyó la espera plana de la portada pública por una superficie de carga comercial coherente.
- Se añadió una carga consistente al cockpit buyer antes de hidratar biblioteca y pedidos.
- Se sustituyó la espera textual del detalle de pedido por una carga postcompra alineada al sistema visual.
- Se añadió una carga inicial real a la consola admin mientras sincroniza estadísticas, moderación, pedidos y ventas.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Tienda clásica mejora continuidad y percepción de solidez durante la carga de datos.
- El marketplace mantiene una lectura visual coherente incluso antes de completar la hidratación de cada superficie.
