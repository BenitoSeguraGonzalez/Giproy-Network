# Descripción
Slice incremental enfocado en añadir una mesa comparativa ligera para reforzar la decisión de compra dentro de Tienda clásica.

# Objetivo
Permitir que el usuario contraste varios productos sin salir del storefront y mantenga continuidad comercial entre catálogo y ficha.

# Alcance
- Portada pública de Tienda.
- Detalle de producto.
- Sistema visual compartido para cards.
- Persistencia local por usuario dentro del frontend clásico.

# Implementación ejecutada
- Se añadió persistencia local por usuario para una lista corta de comparación con límite controlado.
- Se integró el toggle de comparación en las cards del catálogo.
- Se añadió una mesa comparativa rápida dentro de la portada pública de Tienda.
- Se añadió control de comparación y señal de estado en el detalle de producto.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Tienda clásica gana una función adicional real de evaluación comercial previa a la compra.
- El usuario puede contrastar varios productos sin romper el flujo clásico de descubrimiento y decisión.
