# Descripción
Plan integral de reorientación visual y funcional de Tienda clásica para que la portada pública se comporte como storefront comercial real, inspirada en la referencia tipo hardware store indicada por usuario.

# Objetivo
Reconvertir la home pública de Marketplace desde una lectura tipo dashboard/cockpit hacia una lectura claramente comercial: hero promocional, categorías, campañas, carriles de producto, beneficios de compra y continuidad comercial.

# Alcance
- Portada pública de Tienda.
- Detalle de producto alineado a storefront.
- Buyer como `Mi cuenta / Mis compras / Biblioteca`.
- Seller como backoffice comercial.
- Admin como consola de gobierno, no portada comercial.
- Mantener identidad visual GiProy y no contaminar BIM.

# Plan de implementación
1. `TASK-0638`: reorientar `Marketplace.jsx` hacia storefront tipo hardware store con hero promocional, categorías, beneficios y carriles comerciales.
2. `TASK-0639`: alinear `MarketplaceProductDetail.jsx` a una ficha más e-commerce y menos cockpit.
3. `TASK-0640`: ajustar buyer para que se lea como área de cuenta y postcompra dentro del mismo lenguaje comercial.
4. `TASK-0641`: reorganizar seller como backoffice comercial más limpio y jerárquico.
5. `TASK-0642`: reorganizar admin marketplace como consola de gobierno separada de la experiencia pública.
6. `TASK-0643`: pulido transversal final, responsive y consistencia visual entre todas las superficies de Tienda.

# Implementación ejecutada
- Se validó la necesidad de pivotar la portada pública hacia storefront comercial real según referencia explícita del usuario.
- Se reorganizó el trabajo en slices concretos para evitar seguir añadiendo funciones sobre una home con arquitectura visual incorrecta.

# Validación ejecutada
- Revisión de documentación base del proyecto y modo activo clásico.
- Confirmación de no interferencia BIM.

# Resultado esperado
- Tienda clásica pasará de “marketplace con capa dashboard” a “storefront comercial real” dentro de la identidad GiProy.
