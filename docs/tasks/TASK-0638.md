# Descripción
Primer slice real de la reorientación storefront: remodelación de la home pública de Tienda para que abra como una tienda comercial, no como un cockpit.

# Objetivo
Reordenar `Marketplace.jsx` con una lógica de portada comercial inspirada en hardware store: hero promocional, categorías, campañas, beneficios y carriles de producto.

# Alcance
- Portada pública de Tienda.
- Reutilización del sistema visual compartido ya existente.
- Mantener continuidad con favoritos, comparación y recientes como secundarios.

# Implementación ejecutada
- Se rehízo la jerarquía superior de `Marketplace.jsx` para priorizar storefront y no dashboard.
- Se añadieron campañas visibles, navegación por categorías comerciales y beneficios de compra.
- Se reordenaron las superficies de catálogo para que destaquen primero productos destacados, oficiales y multi vendedor.
- Se desplazaron favoritos, comparación y recientes a un rol secundario de continuidad comercial.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La home pública de Tienda queda reencuadrada como storefront comercial inicial, más cercana a la referencia tipo hardware store indicada por el usuario.
