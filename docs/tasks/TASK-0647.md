# Descripción
Plan y corrección de migración para devolver cada menú a su sitio funcional: `Administración Global` para SaaS/plataforma y `Tienda` para funciones comerciales exclusivas de `Sistema`.

# Objetivo
Restaurar la coherencia de navegación y evitar mezclar gobierno SaaS con control comercial del marketplace dentro de la misma shell.

# Plan de migración ejecutado
1. Restaurar `Administración Global` a su estructura funcional de plataforma/SaaS.
2. Retirar de `Administración Global` los accesos y agrupaciones añadidas para funciones de tienda.
3. Crear dentro de `Tienda` un menú visible solo para `superadministrador`.
4. Mover a ese menú las funciones comerciales exclusivas de `Sistema`.
5. Validar que la capa BIM no quede afectada y que la navegación clásica siga consistente.

# Implementación ejecutada
- Se restauró `Administración Global` a su estructura funcional previa centrada en SaaS y plataforma.
- Se retiró de esa shell el control comercial de `Sistema`.
- Se creó en la portada de `Tienda` un menú exclusivo de `superadministrador` para operaciones comerciales de `Sistema`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Cada menú vuelve a su lugar natural.
- `Administración Global` conserva funciones SaaS/plataforma.
- `Tienda` pasa a concentrar las funciones exclusivas de ventas y control comercial de `Sistema`.
