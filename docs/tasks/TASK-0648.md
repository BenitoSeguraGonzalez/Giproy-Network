# Descripción
Se reinicia el planteamiento visual del frontend de `Tienda` porque la remodelación anterior no quedó alineada a la referencia operativa aprobada por usuario. El nuevo enfoque parte de una storefront clásica tipo catálogo, manteniendo únicamente el header global de la aplicación y reconstruyendo el resto de la portada desde una lectura comercial más estricta.

# Objetivo
Reordenar el frontend de `Tienda` desde una base más controlada, empezando por la página inicial de ventas y dejando trazado un plan gradual para continuar el resto de superficies sin volver a mezclar decisiones no autorizadas.

# Alcance
- Documentar el inventario funcional actual del frontend de `Tienda`.
- Documentar el plan de saneamiento y migración storefront.
- Rehacer la página inicial de ventas (`Marketplace.jsx`) siguiendo la estructura de referencia aprobada.
- Mantener sin rediseñar todavía buyer, seller, admin ni detalle de producto, salvo compatibilidad mínima.
- Preservar el header global de GiProy y la separación funcional entre `Administración Global` y `Tienda`.

# Plan de implementación
1. Auditar y documentar funcionalidades activas del frontend de `Tienda`.
2. Abrir una nueva línea de saneamiento controlado para evitar seguir acumulando capas visuales incompatibles.
3. Rehacer la home pública como catálogo storefront con grid principal, orden, búsqueda, sidebar de categorías, precio y recientes.
4. Mantener el acceso exclusivo de `superadministrador` dentro de `Tienda`, pero sin romper la lectura comercial principal.
5. Validar build y dejar preparado el siguiente slice sobre detalle de producto y continuidad comercial.

# Validación prevista
- `npm run build` en frontend.
- Revisión de no interferencia BIM.
- Confirmación visual de que la home de `Tienda` deja de comportarse como dashboard y pasa a storefront.

# Resultado esperado
- `Tienda` queda reencauzada desde una portada coherente con la referencia.
- El trabajo futuro podrá continuar paso a paso sobre una base storefront más estable.

# Cierre
- El reset storefront se ejecutó y dejó una base estable.
- Las iteraciones posteriores de buyer/seller, recents y continuidad comercial ya ocurrieron sobre esa nueva base, por lo que esta task queda cerrada como slice histórico completado.
