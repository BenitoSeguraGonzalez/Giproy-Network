# Descripción
Primer slice real del saneamiento de `Tienda`: sustitución de la portada pública actual por una página inicial de ventas con estructura storefront clásica, grid principal de productos y sidebar comercial.

# Objetivo
Dejar `Marketplace.jsx` alineado con una lectura tipo tienda real, manteniendo el header global de GiProy y evitando dashboards o bloques inventados que no respondan a la referencia aprobada.

# Implementación ejecutada
- Se sustituyó la home pública anterior por una storefront basada en:
  - cabecera superior de resultados, orden y búsqueda,
  - grid principal de productos,
  - sidebar de categorías,
  - filtro por precio,
  - bloque de productos recientes.
- Se mantuvo el acceso exclusivo de `superadministrador` dentro de `Tienda`, en un bloque lateral no intrusivo.
- Se desacopló la portada pública del sistema visual anterior para evitar seguir arrastrando la gramática incorrecta.
- Se dejó documentado el inventario funcional actual de `Tienda` para análisis posterior.
- Se corrigió un desajuste con el endpoint clásico de productos: la storefront estaba solicitando `limit=200`, pero el backend solo acepta `limit <= 100`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La página inicial de ventas de `Tienda` ya responde a una arquitectura storefront controlada.
- El siguiente trabajo puede continuar sobre detalle de producto y siguientes funciones sin repetir el error de diseño anterior.
