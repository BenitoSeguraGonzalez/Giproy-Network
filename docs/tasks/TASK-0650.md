# Descripción
Se ajusta la nueva storefront inicial de `Tienda` para que funcione correctamente en escritorio real, especialmente en `1920x1080`, reduciendo tamaños excesivos de tipografía y contenedores que estaban consumiendo demasiado espacio útil.

# Objetivo
Hacer que la página inicial de ventas sea realmente usable en desktop y no solo visualmente cercana a la referencia, corrigiendo densidad, alturas y jerarquía tipográfica.

# Implementación ejecutada
- Se redujo la altura de las cards de producto y de sus portadas visuales.
- Se corrigió la escala tipográfica del grid principal, de la barra superior y de la sidebar.
- Se ajustaron gaps, paddings y dimensiones del sidebar para que el catálogo principal gane aire útil en escritorio.
- Se mantuvo intacta la estructura storefront ya aprobada, actuando solo sobre densidad y responsive real.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La página inicial de ventas ya se comporta con una densidad más razonable en escritorio amplio.
- Los productos se leen completos con mejor equilibrio entre imagen, texto y área útil.
