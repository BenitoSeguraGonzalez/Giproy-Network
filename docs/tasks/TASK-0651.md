# Descripción
La storefront inicial de `Tienda` incorpora ahora un header contextual del mismo lenguaje que los módulos principales de GiProy, sustituyendo el arranque neutro anterior por una entrada visual más coherente con el producto.

# Objetivo
Hacer que la portada pública de `Tienda` arranque con un header tipo aplicación, alineado a la gramática real de GiProy y no a una cabecera inventada.

# Implementación ejecutada
- Se añadió una franja superior contextual en `Marketplace.jsx` con:
  - acción de retorno,
  - título fuerte del módulo,
  - metadata secundaria,
  - acciones operativas a la derecha según contexto del usuario.
- El header se alineó al patrón visual ya usado en `Proyectos`, manteniendo la storefront debajo.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- `Tienda` abre con una cabecera más propia del sistema.
- La storefront conserva su estructura comercial, pero ya se siente integrada en el lenguaje de módulos GiProy.
