# Descripción
Se elimina de la storefront el bloque superior redundante de `Operacion exclusiva`, porque añadía ruido visual y duplicaba el acceso exclusivo de `superadministrador` dentro de `Tienda`.

# Objetivo
Limpiar la lectura principal de la página inicial de ventas dejando solo el catálogo y los accesos estrictamente necesarios.

# Implementación ejecutada
- Se retiró el bloque superior `Solo Sistema / Operacion exclusiva`.
- Se mantuvo el acceso exclusivo de `superadministrador` en la zona lateral de control comercial dentro de `Tienda`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront queda más limpia y centrada en la venta.
