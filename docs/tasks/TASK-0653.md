# Descripción
La nueva storefront de `Tienda` no estaba creando una superficie scrolleable propia dentro de `AppLayout`, por lo que la rueda del ratón no permitía recorrer el catálogo.

# Objetivo
Restaurar el desplazamiento natural con rueda central y scroll vertical dentro de la página inicial de ventas.

# Implementación ejecutada
- Se convirtió la raíz de `Marketplace.jsx` en una superficie scrolleable propia compatible con `AppLayout`.
- El catálogo vuelve a responder al desplazamiento natural del ratón y del trackpad.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront vuelve a ser navegable por scroll.
