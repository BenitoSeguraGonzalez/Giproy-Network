# Descripción
Se sustituye la paginación fija del storefront público de `Tienda` por un listado sin fin, manteniendo la API clásica y el scroll natural ya restaurado.

# Objetivo
Mostrar solo el tramo visual necesario del catálogo, ir liberando nuevos bloques al desplazarse y mantener una precache inmediata del siguiente conjunto de productos para que la navegación se sienta continua.

# Implementación ejecutada
- Se eliminó la paginación manual por páginas dentro de `Marketplace.jsx`.
- Se añadió una estrategia de carga progresiva basada en:
  - ventana visible inicial,
  - chunk incremental al acercarse al final,
  - precache del siguiente tramo de items.
- Se acopló la observación del final del grid al contenedor scrolleable real del storefront, respetando el layout clásico.
- Se mantuvo la carga inicial backend única sobre el slice clásico existente, sin abrir contratos nuevos.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La página inicial de ventas de `Tienda` ya funciona como listado continuo.
- El usuario puede desplazarse sin paginación y el grid va creciendo conforme hace falta, con siguiente tramo preparado en memoria.
