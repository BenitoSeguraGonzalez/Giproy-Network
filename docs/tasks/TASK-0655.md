# Descripción
Se ajusta la cabecera operativa del storefront de `Tienda` para que los accesos visibles respondan exactamente a la regla solicitada por rol y se dejan placeholders iniciales de las tres superficies que se definirán después.

# Objetivo
Mostrar en el storefront:
- `Mis Compras`
- `Mis Ventas`
- `Panel Administrador`

con estas reglas:
- usuario regular con permisos comerciales: solo `Mis Compras` y `Mis Ventas`,
- `Panel Administrador`: solo `superadministrador`,
- excepción temporal: `administrador` de la empresa `Santiago Bermeo` como beta tester.

# Implementación ejecutada
- Se sustituyeron las acciones superiores de Tienda por una banda controlada de accesos:
  - `Mis Compras`
  - `Mis Ventas`
  - `Panel Administrador`
- Se codificó la excepción temporal de beta testing para la empresa `Santiago Bermeo`.
- Se añadieron placeholders internos en la propia storefront para:
  - compras,
  - ventas,
  - panel administrador.
- Se dejó explícito en la lectura visual cuando el acceso administrativo es temporal por beta.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- El storefront ya tiene una banda de acceso alineada a la regla funcional pedida.
- Las tres futuras áreas quedan delimitadas en frontend sin adelantar todavía sus funciones reales.
