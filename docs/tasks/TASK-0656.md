# Descripción
Se corrige la escala de la banda superior de accesos del storefront para alinearla al tamaño real de los botones del sistema.

# Objetivo
Evitar que `Mis Compras`, `Mis Ventas` y `Panel Administrador` se lean como CTAs sobredimensionadas y dejarlos en el mismo nivel visual que otros botones de aplicación.

# Implementación ejecutada
- Se redujo altura, padding, tracking y escala tipográfica de los tres botones superiores del storefront.
- Se mantuvo intacta la regla de visibilidad por rol y la excepción beta temporal para `Santiago Bermeo`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La banda superior de `Tienda` queda alineada al lenguaje de botones del sistema y deja de dominar visualmente la cabecera.
