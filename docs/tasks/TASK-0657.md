# Descripción
Se ajusta la banda superior de accesos de `Tienda` para que use el mismo tamaño y escala visual que los selectores y campos de filtro del storefront.

# Objetivo
Hacer que `Mis Compras`, `Mis Ventas` y `Panel Administrador` se lean como controles del mismo sistema visual que `Orden predeterminado` y `Buscar productos`, evitando una jerarquía incoherente.

# Implementación ejecutada
- Se igualó la altura de los botones superiores al patrón `58px` de los filtros.
- Se ajustó tipografía, espaciado y borde para que la banda superior se comporte como controles de barra y no como botones sobredimensionados.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La navegación superior del storefront ya queda alineada al tamaño y presencia visual de los selectores de filtros.
