# Descripción
Se retiran del storefront público los paneles placeholder visibles de `Mis Compras`, `Mis Ventas` y `Panel Administrador`.

# Objetivo
Mantener la banda superior de acceso por rol, pero sin ocupar la home de Tienda con paneles provisionales que rompan la lectura del catálogo.

# Implementación ejecutada
- Se eliminaron los tres paneles placeholder visibles debajo del header de la storefront.
- Se conserva intacta la banda superior de accesos por rol.
- Se mantiene sin cambios la excepción beta temporal para `Santiago Bermeo`, pero ya sin panel visible dentro de la home.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La home de Tienda vuelve a quedar centrada en catálogo y navegación.
- Los accesos por rol permanecen disponibles sin introducir ruido visual adicional.
