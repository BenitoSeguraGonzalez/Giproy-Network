# Descripción
El catálogo de prueba de `Sistema` en Tienda seguía siendo demasiado corto para validar storefront, filtros y scroll continuo. Se amplía la semilla a un set de muestra de al menos `20` items.

# Objetivo
Disponer de un catálogo de muestra suficientemente amplio y variado para pruebas reales de la storefront pública de `Tienda`.

# Implementación ejecutada
- Se amplió `SYSTEM_MARKETPLACE_PRODUCTS` en `backend/app/services/marketplace_catalog_bootstrap.py`.
- El catálogo de `Sistema` pasa a incluir ejemplos de:
  - `Licencias`
  - `Actualizaciones`
  - `Adicionales`
- Se mantuvo el patrón idempotente por `slug` para permitir reejecución sin duplicados.

# Validación prevista
- `python -m py_compile backend/app/services/marketplace_catalog_bootstrap.py backend/scripts/seed_marketplace_system_catalog.py`
- `python scripts/seed_marketplace_system_catalog.py`
- Confirmación del conteo total sembrado en la base local.

# Resultado esperado
- La tienda debe quedar con al menos `20` items de muestra visibles del catálogo `Sistema`.
