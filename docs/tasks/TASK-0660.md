# Descripción
La storefront seguía demasiado pesada visualmente para escritorio real. Se ajusta la densidad general para permitir una lectura más elegante, profesional y con mayor capacidad de catálogo visible.

# Objetivo
Permitir que en escritorio amplio la tienda pueda mostrar al menos `4` items por fila y `3` filas útiles en pantalla, reduciendo además la sensación de tipografía sobredimensionada y bloques toscos.

# Implementación ejecutada
- Se redujo la altura visual de las cards de producto.
- Se rebajó la escala tipográfica de portada, card, sidebar y recientes.
- Se ajustó el grid principal para usar `4` columnas en escritorio amplio.
- Se estrechó ligeramente el sidebar para liberar espacio al catálogo.
- Se incrementó la capacidad del skeleton inicial para reflejar la nueva densidad de grid.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront gana una lectura más delicada y profesional.
- El catálogo puede mostrar `4` items por fila en escritorio amplio sin sensación de gigantismo.
