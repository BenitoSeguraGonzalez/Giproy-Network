# Descripción
La storefront necesitaba mantener contexto permanente durante el scroll del catálogo. Se fijan el header principal y el subheader de búsqueda/ordenación dentro de la superficie scrolleable de `Tienda`.

# Objetivo
Mantener siempre visibles:
- header de módulo,
- banda superior de accesos por rol,
- subheader de resultados, orden y búsqueda.

# Implementación ejecutada
- Se agrupó header + subheader en una cabecera sticky dentro del contenedor scrolleable de `Marketplace`.
- Se añadió fondo translúcido con `backdrop-blur` para preservar legibilidad sobre el catálogo.
- Se conservaron intactas las reglas de acceso por rol y la excepción temporal de `Santiago Bermeo`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront mantiene el contexto de navegación y filtros siempre visible durante el desplazamiento del catálogo.
