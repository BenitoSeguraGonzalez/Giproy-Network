# Descripción
Persistían rótulos visibles en inglés dentro de la storefront pública de `Tienda`. Se corrigen para alinear la experiencia al castellano del sistema.

# Objetivo
Eliminar etiquetas públicas en inglés dentro de la home de Tienda, empezando por sidebar y badge superior.

# Implementación ejecutada
- `Storefront` -> `Tienda`
- `Product categories` -> `Categorías`
- `Filter by price` -> `Precio`
- `Recent Products` -> `Recientes`

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront pública queda coherente con el idioma castellano del sistema en sus rótulos visibles principales.
