# Descripción
Se retira del lateral de la storefront el bloque `Tienda / Sistema - Control comercial`, por duplicar accesos ya presentes en la banda superior del módulo.

# Objetivo
Limpiar la home pública de `Tienda` y evitar redundancias visuales entre navegación superior y sidebar.

# Implementación ejecutada
- Se eliminó el bloque lateral de control comercial.
- Se mantuvieron los accesos superiores por rol sin cambios.
- Se retiró también el icono/import no necesario asociado al bloque.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront queda más limpia y centrada en catálogo, filtros y navegación superior.
