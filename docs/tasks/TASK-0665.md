# Descripción
Se incorpora a la storefront pública de `Tienda` un carrito de compras operativo en el header, con contador de items, modal de revisión del pedido, validación previa de datos de facturación y confirmación final antes del checkout real.

# Objetivo
Preparar el primer flujo de compra usable dentro de la página pública de ventas, sin abrir todavía el resto de superficies de postcompra.

# Implementación ejecutada
- Se añadió icono de carrito con contador visible en el header del storefront.
- Se añadió acción de añadir al carrito directamente desde las cards del catálogo.
- El carrito se persiste por usuario en `localStorage`.
- Se implementó modal de carrito con:
  - productos añadidos
  - cantidad
  - precio
  - total
  - retirada de items
  - botón `Pagar`
- Antes de pagar se valida en frontend la completitud de datos de facturación usando la empresa activa y el comprador actual.
- Si faltan datos, el flujo solicita completar la información en `Configuración`.
- Antes del checkout final se exige una confirmación explícita de la venta.
- El checkout usa el endpoint real ya existente de Marketplace y, tras compra exitosa, vacía el carrito y redirige a `Mis Compras`.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- La storefront ya dispone del primer circuito real de `carrito -> validación -> confirmación -> compra`, manteniéndose dentro de la capa clásica y sin introducir dependencias BIM.
