# Descripción
Se mejora el bloque `Precio` de la storefront pública para que el filtro resulte más claro y usable: mismo slider visual, pero ahora con rango mínimo y máximo sobre el mismo control, lectura visible de ambos extremos y reset directo.

# Objetivo
Hacer el filtrado por precio más intuitivo sin cambiar la arquitectura general del storefront.

# Implementación ejecutada
- Se sustituyó el slider único por un rango doble sobre la misma pista.
- Se añadió lectura visible de `Min` y `Max`.
- El filtro aplica ahora rango mínimo y máximo reales.
- Se añadió botón `Reset` para restaurar la selección completa.
- Se mantuvo el botón `Filtrar` como confirmación explícita del rango elegido.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- El bloque de `Precio` queda más claro, más profesional y más controlable para el usuario final.
