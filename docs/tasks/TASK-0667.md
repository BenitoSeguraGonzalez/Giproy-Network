# Descripción
Se adapta la estructura comercial de productos de Tienda para distinguir entre venta `unitaria` y venta `por paquete`, y se actualiza el carrito del storefront para comportarse por línea según esa regla.

# Objetivo
Permitir que ciertos productos aumenten cantidad sobre la misma línea del carrito, mientras otros sigan siendo de compra única, con advertencia no invasiva si el usuario intenta duplicar un producto unitario.

# Implementación ejecutada
- Se amplió el payload de checkout para aceptar `items` con `product_id` y `quantity`, manteniendo compatibilidad con `product_ids`.
- Se endureció el servicio de checkout para validar por producto:
  - compra unitaria
  - cantidad mínima
  - paso de incremento
  - cantidad máxima
- Se dejó preparada la estructura comercial futura mediante `sales_config` dentro de `vista_previa`, disponible ya en creación/actualización de producto aunque todavía no se exponga en la UI de ventas.
- Se actualizó el bootstrap del catálogo de `Sistema` para sembrar configuraciones variadas de ejemplo entre productos unitarios y productos vendibles por paquete.
- Se rehizo el carrito del storefront:
  - persistencia por línea
  - suma de cantidad en la misma línea para productos por paquete
  - bloqueo de duplicado para productos unitarios
  - aviso no invasivo cuando se intenta reañadir un producto unitario ya presente
  - control de cantidad por línea dentro del modal
  - total por línea y total global según cantidad real

# Validación ejecutada
- `python -m py_compile backend/app/schemas/marketplace.py backend/app/services/marketplace.py backend/app/services/marketplace_checkout.py backend/app/services/marketplace_catalog_bootstrap.py`
- `python scripts/seed_marketplace_system_catalog.py`
- `npm run build` en frontend
- Revisión de no interferencia BIM

# Resultado
- El carrito del storefront ya actúa con lógica real por línea.
- Los productos de prueba de `Sistema` ya tienen comportamiento mezclado entre unitario y paquete.
- La base queda preparada para que más adelante la estructura comercial se edite desde las opciones de ventas sin rehacer checkout ni carrito.
