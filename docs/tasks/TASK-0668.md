# Descripción
Se ajustan las cards de producto del storefront para que la franja inferior quede más profesional: precio y botón alineados, lectura más estable entre tarjetas y nota discreta de IVA incluido.

# Objetivo
Evitar desalineaciones visuales entre productos, reforzar la consistencia comercial de la rejilla y dejar explícito que el precio mostrado ya incluye IVA.

# Implementación ejecutada
- Se fijó una altura útil mínima para la zona inferior de la card.
- Se alinearon precio y botón de carrito sobre una misma base visual.
- Se dejó el botón del carrito con una caja de tamaño constante.
- Se añadió la leyenda `IVA incluido` bajo el precio.
- Se mantuvo el formateo del precio con dos decimales visibles.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Las cards del storefront quedan más delicadas, más consistentes y con mejor lectura comercial en filas densas.
