# Descripción
Se elimina el panel visible de estado del scroll progresivo y se ajusta la carga inicial del catálogo para que, cuando el volumen de resultados sea pequeño, la storefront muestre el conjunto completo en lugar de cortar el primer tramo a `9`.

# Objetivo
Evitar ruido visual innecesario y hacer que el catálogo actual de prueba se vea completo desde el primer render.

# Implementación ejecutada
- Se retiró el bloque visual que indicaba `Scroll continuo activo` y `Precache`.
- Se elevó la densidad base del primer tramo.
- Se añadió un umbral para renderizar de una sola vez catálogos pequeños.
- Se mantuvo la base de scroll progresivo para escenarios con más volumen.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Con la categoría `Todas`, el set actual de `20` items ya no se queda recortado a `9`.
- La storefront queda más limpia y menos explicativa.
