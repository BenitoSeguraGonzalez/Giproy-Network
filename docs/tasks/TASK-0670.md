# Descripción
Se reestructura la card del catálogo de Tienda para que su alineación dependa de zonas internas estables y no de la longitud del contenido textual.

# Objetivo
Conseguir una rejilla visualmente sólida, con títulos variables pero con precio y acción siempre alineados en la misma base entre productos.

# Implementación ejecutada
- Se definió una retícula interna fija para la parte inferior de la card.
- Se separaron tres zonas:
  - metadato superior
  - bloque de título
  - bloque de precio y acción
- Se mantuvo el truncado de título, pero ya no gobierna la alineación del pie comercial.
- Se conservó la indicación de `IVA incluido` dentro del bloque inferior fijo.

# Validación ejecutada
- `npm run build` en frontend.
- Revisión de no interferencia BIM.

# Resultado
- Las cards del storefront quedan alineadas por estructura, no por casualidad textual.
