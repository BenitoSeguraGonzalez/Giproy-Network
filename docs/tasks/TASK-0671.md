# Descripción
Se construye el primer bloque útil del nuevo `Panel Administrador` de Tienda: la gestión de categorías del catálogo.

# Objetivo
Permitir que superadministración gestione la estructura base de categorías mediante una entrada visual por paneles y una sección operativa para crear, editar y borrar categorías.

# Implementación ejecutada
- Se añadió una tarjeta de entrada `Categorías` dentro del `Panel Administrador`.
- Se creó la sección operativa interna para:
  - crear categorías
  - editar categorías
  - borrar categorías
- Se mantuvo la regla de acceso exclusiva para administración global del marketplace.
- Se completó backend con borrado de categorías.
- El borrado queda protegido cuando:
  - la categoría tiene productos asignados
  - la categoría tiene subcategorías asociadas

# Validación ejecutada
- `python -m py_compile backend/app/api/endpoints/marketplace.py backend/app/services/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El panel de administrador de Tienda deja de estar vacío y pasa a tener una primera función real, controlada y alineada al patrón visual por paneles que se pidió para esta zona.
