# Descripción
Se añade `Productos` como segundo bloque visible del `Panel Administrador` de Tienda, pero todavía como placeholder controlado.

# Objetivo
Delimitar la futura superficie administrativa de productos sin inventar lógica todavía, manteniendo el mismo patrón visual por paneles usado en categorías.

# Implementación ejecutada
- Se añadió la tarjeta de entrada `Productos` en la zona de paneles del administrador.
- Se creó una sección placeholder propia para `Productos`.
- Se dejó separada de `Categorías` para que la definición funcional posterior no quede mezclada.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El panel de administrador ya deja visibles los dos primeros bloques del catálogo:
  - `Categorías` como función real
  - `Productos` como siguiente frente preparado
