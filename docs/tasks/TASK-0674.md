# Descripción
Se extiende el bloque `Productos` del `Panel Administrador` para que deje de ser solo lectura y permita operar el catálogo global.

# Objetivo
Permitir que superadministración pueda, desde el listado global de productos:
- editar
- activar o desactivar
- borrar

# Implementación ejecutada
- Se añadieron endpoints administrativos para:
  - actualizar productos
  - borrar productos
- Se añadió el cliente frontend correspondiente.
- Se construyó un formulario de edición dentro del panel administrativo.
- El listado global de productos incorpora ahora acciones por fila para:
  - editar
  - activar/desactivar
  - borrar

# Validación ejecutada
- `python -m py_compile backend/app/api/endpoints/marketplace.py backend/app/services/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El bloque `Productos` del `Panel Administrador` pasa de lectura a gestión operativa inicial, sin reintroducir todavía otras funciones heredadas no definidas.
