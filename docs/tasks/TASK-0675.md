# Descripción
Se añade la creación de productos dentro del `Panel Administrador` de Tienda, obligando a seleccionar primero el tipo de producto.

# Objetivo
Permitir la creación de productos administrativos respetando la regla funcional de que cada tipo se comporta de forma diferente, por lo que el tipo debe quedar definido antes de entrar al formulario.

# Implementación ejecutada
- Se añadió soporte común para el nuevo tipo `portal_compras_publicas`.
- Se añadió selector previo obligatorio de tipo de producto.
- Tipos disponibles en la creación:
  - `Licencias`
  - `APUs`
  - `Bases Maestras`
  - `Proyectos`
  - `Portal de compras públicas`
- Tras seleccionar el tipo, se habilita el formulario de creación.
- El producto se crea desde el propio panel administrativo.

# Validación ejecutada
- `python -m py_compile backend/app/api/endpoints/marketplace.py backend/app/services/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- La zona `Productos` del `Panel Administrador` ya no solo lista y gestiona artículos existentes: también permite iniciar la creación de nuevos productos con un paso previo de selección de tipo.
