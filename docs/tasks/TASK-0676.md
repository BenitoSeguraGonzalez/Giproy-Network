# Descripción
Se sanea la carcasa visual del `Panel Administrador` de Tienda para que siga el patrón de `Ajuste SaaS`, reemplazando la estructura dispersa anterior por una navegación lateral simple y una única superficie principal de trabajo.

# Objetivo
Hacer que el panel administrativo de Tienda se lea como una consola coherente con el resto del sistema, manteniendo únicamente los dos bloques válidos definidos hasta ahora: `Categorías` y `Productos`.

# Implementación ejecutada
- Se sustituyó la entrada por bloques superiores por una navegación lateral compacta.
- Se dejó una única superficie principal, alineada al patrón visual de `Ajuste SaaS`.
- Se mantuvo el header de trabajo ya acordado para Tienda.
- Se conservaron intactas las funciones existentes de:
  - `Categorías`
  - `Productos`
- Se eliminaron dependencias de la carcasa anterior (`tiles`, `section headers`, refs de scroll interno) que ya no encajaban con el nuevo patrón visual.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El `Panel Administrador` de Tienda ya no aparece como una suma de bloques sueltos.
- La navegación y la lectura general quedan alineadas al estilo de `Ajuste SaaS`, pero acotadas a las funciones reales del panel de Tienda.
