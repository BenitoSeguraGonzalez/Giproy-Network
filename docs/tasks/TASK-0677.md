# Descripción
Se ajusta el `Panel Administrador` de Tienda para que sus opciones sigan el patrón visual real del `Ajuste SaaS`: tarjetas tipo submódulo, header fijo y navegación por opciones desplazable con rueda del ratón.

# Objetivo
Abandonar la navegación lateral compacta anterior y alinear esta superficie al patrón de paneles visuales que el usuario indicó expresamente como referencia válida.

# Implementación ejecutada
- Se sustituyó la navegación lateral por una banda de tarjetas tipo submódulo.
- Las opciones activas del panel quedaron como:
  - `Categorías`
  - `Productos`
- El header del `Panel Administrador` quedó fijo dentro de la superficie.
- La banda de opciones permite desplazamiento horizontal con rueda del ratón.
- Se mantuvo intacta la lógica funcional de `Categorías` y `Productos`.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El `Panel Administrador` ya usa una entrada visual coherente con la referencia de `Ajuste SaaS`.
- La cabecera permanece visible mientras el contenido operativo se desplaza por debajo.
