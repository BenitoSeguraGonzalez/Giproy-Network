# Descripción
Se define e implementa el creador/editor específico de `Portal de compras públicas` dentro del bloque `Productos` del `Panel Administrador` de Tienda.

# Objetivo
Separar este tipo de producto del formulario genérico y darle una superficie propia basada en modal, con:
- metadatos comunes del producto
- metadatos exclusivos del producto `Portal de compras públicas`
- estructura preparada para el importador posterior

# Implementación ejecutada
- Se amplió backend para aceptar y persistir:
  - `product_meta`
  - `portal_meta`
- Ambos metadatos quedan guardados dentro de `vista_previa`, junto con la estructura comercial ya existente.
- Se añadió autogeneración de `código` de producto en backend.
- Se añadió resolución automática de `creador`:
  - `Sistema` para superadministrador
  - nombre de empresa para vendedor de empresa
- Se validó en backend para `portal_compras_publicas`:
  - país obligatorio
  - provincia obligatoria
  - precio de licitación obligatorio
  - fecha de inicio obligatoria
  - fecha de fin obligatoria
- Se añadió modal específico en frontend para crear y editar este tipo de producto.
- Se reutilizó infraestructura real de:
  - `país`
  - `provincia`
  - `cantón`
- Se dejó un bloque visual de `Importador` como placeholder preparado para el siguiente slice.

# Metadatos implementados
## Meta común
- `Código`
- `Descripción corta`
- `Descripción larga`
- `Descripción completa`
- `Precio con IVA`
- `Fecha de publicación`
- `Fecha de retirada`
- `Descuento / Promoción`
- `Creador`

## Meta exclusivo de Portal de compras públicas
- `País`
- `Provincia`
- `Cantón`
- `Dirección`
- `Precio de licitación`
- `Fecha de inicio de licitación`
- `Fecha fin de licitación`

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py backend/app/schemas/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- `Portal de compras públicas` ya no depende del formulario genérico.
- El `Panel Administrador` dispone ahora de una superficie propia y preparada para seguir especializando este tipo de producto.
