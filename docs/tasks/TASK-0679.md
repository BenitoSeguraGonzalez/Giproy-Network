# Descripción
Se corrige el comportamiento del `Panel Administrador` de Tienda para que `Categorías` y `Productos` funcionen como submódulos reales, abriéndose en modal independiente desde sus lanzadores, en lugar de quedar incrustados en el panel principal.

# Objetivo
Alinear el panel al comportamiento esperado del patrón tipo `Ajuste SaaS`: cada lanzador abre su propia superficie de trabajo con scroll interno y cierre independiente.

# Implementación ejecutada
- Se dejó el panel principal solo como superficie de acceso.
- `Categorías` abre ahora su propio modal operativo.
- `Productos` abre ahora su propio modal operativo.
- Ambos modales usan:
  - cabecera propia
  - área de trabajo con scroll interno
  - cierre independiente
- Se mantuvo la banda superior de submódulos con desplazamiento horizontal por rueda del ratón.
- Se conservó intacta la lógica ya implementada dentro de cada submódulo.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- `Categorías` y `Productos` ya no contaminan el panel principal.
- El `Panel Administrador` pasa a comportarse como lanzador de submódulos, tal como se solicitó.
