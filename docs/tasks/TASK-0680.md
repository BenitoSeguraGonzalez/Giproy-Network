# Descripción
Se ajusta el `Panel Administrador` de Tienda para cerrar el comportamiento modal de `Categorías` y `Productos` según el patrón real de `Ajuste SaaS`.

# Objetivo
Evitar que el panel principal conserve lógica residual de sección y garantizar que cada lanzador abra exclusivamente su propio submódulo de trabajo.

# Implementación ejecutada
- Se eliminó el estado residual de panel interno que ya no aportaba valor al nuevo patrón.
- `Categorías` ahora cierra `Productos` antes de abrirse.
- `Productos` ahora cierra `Categorías` antes de abrirse.
- El panel principal queda consolidado solo como superficie lanzadora de submódulos.
- Se mantuvo el scroll interno dentro de cada modal para navegación con rueda del ratón.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El comportamiento del `Panel Administrador` queda más limpio y coherente.
- `Categorías` y `Productos` funcionan como submódulos independientes, sin contaminación cruzada en la superficie principal.
