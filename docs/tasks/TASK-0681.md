# Descripción
Se corrige la entrada visual del `Panel Administrador` de Tienda para que las tarjetas de `Categorías` y `Productos` se alineen realmente al patrón visual usado en `Ajuste SaaS`.

# Objetivo
Eliminar la lectura de carril horizontal sobredimensionado y sustituirla por una retícula de paneles con proporción, densidad y pie de acción compatibles con la referencia del sistema.

# Implementación ejecutada
- Se retiró la banda horizontal tipo rail para submódulos.
- `Categorías` y `Productos` ahora se presentan en retícula estable.
- Se ajustaron:
  - tamaño de panel
  - padding
  - escala de icono
  - jerarquía de tipografía
  - altura mínima de descripción
  - pie de acción
- Se mantuvo el header fijo y la apertura modal de cada submódulo.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El `Panel Administrador` se acerca visualmente al patrón real de `Ajuste SaaS`.
- Los lanzadores dejan de verse como un componente improvisado y pasan a funcionar como submódulos de entrada consistentes.
