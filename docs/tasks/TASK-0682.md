# Descripción
Se sustituye la superficie improvisada del submódulo `Productos` por un listado administrativo real, siguiendo patrones ya existentes en la aplicación.

# Objetivo
Convertir `Productos` en una consola de listado con creación desde lanzador compacto y acciones claras por fila.

# Implementación ejecutada
- Se eliminó la columna lateral improvisada de creación y edición.
- Se rehízo `Productos` como listado tabular.
- La creación de producto pasa a un icono `+` con menú desplegable de tipos.
- Cada fila del listado expone:
  - editar
  - activar / desactivar
  - borrar
- La edición de productos comunes pasa a modal propio.
- `Portal de compras públicas` mantiene su modal especializado.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- `Productos` deja de verse como una superficie improvisada.
- El submódulo queda alineado a una lectura de listado administrativo real dentro de Tienda.
