# Descripción
Se reduce la escala sobredimensionada de la entrada del `Panel Administrador` de Tienda para que las tarjetas de `Categorías` y `Productos` se lean con una proporción más cercana al patrón SaaS real del sistema.

# Objetivo
Eliminar gigantismo visual en header y tarjetas, compactando la superficie de entrada sin alterar el comportamiento modal ya corregido.

# Implementación ejecutada
- Se centró el ancho útil del panel.
- Se redujo la altura visual de las tarjetas.
- Se compactaron:
  - padding
  - tamaño de icono
  - tamaño de título
  - descripción
  - pie de acción
- Se rebajó también la escala del header para que no domine innecesariamente la pantalla.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- La entrada del `Panel Administrador` queda más contenida y profesional.
- `Categorías` y `Productos` se leen más cerca del patrón visual esperado.
