# Objetivo
Definir el modelo híbrido del producto `portal_compras_publicas` para soportar:
- exportación Excel
- entrega como artículo de Tienda
- creación posterior de proyecto adquirido

# Alcance
- ampliar `portal_meta`
- definir `delivery_mode`
- definir `import_source`
- definir `project_delivery_policy`
- reflejarlo en creador/editor admin

# Resultado esperado
El artículo queda formalmente preparado para comportamiento híbrido, sin depender aún del importador final.

# Cierre
- El modelado híbrido del producto quedó materializado por la evolución posterior del editor especializado y de la metadata persistida del `Portal de compras públicas`.
