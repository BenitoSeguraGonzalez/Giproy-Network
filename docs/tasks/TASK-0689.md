# Objetivo
Aplicar la primera política operativa al proyecto entregado por compra de `Portal de compras públicas`.

# Alcance
- proyecto sin base madre
- proyecto marcado como adquirido
- proyecto no enviable
- lectura visible del estado/política en UI

# Resultado esperado
El activo entregado queda diferenciado de un proyecto nativo y no puede enviarse mientras mantenga esta política.

# Cierre
- La política inicial del proyecto adquirido quedó absorbida por la entrega operativa y la metadata específica ya expuesta en el flujo postcompra.
