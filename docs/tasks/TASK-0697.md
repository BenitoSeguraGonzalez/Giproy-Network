# TASK-0697

## Objetivo
Endurecer el creador/editor administrativo de productos para que solo permita categorías fijas de Tienda y no arrastre categorías heredadas.

## Alcance
- Rechazar en backend cualquier categoría fuera del catálogo fijo.
- Limitar el selector frontend del editor a las categorías fijas visibles del panel.
- Limpiar categorías heredadas inválidas al abrir edición de productos antiguos.

## Validación
- El editor administrativo solo muestra categorías fijas.
- Un producto con categoría heredada inválida no la conserva en el formulario.
- Backend rechaza `category_id` fuera del catálogo fijo.
