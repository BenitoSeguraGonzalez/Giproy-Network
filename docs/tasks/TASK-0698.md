# Descripción
Se ajusta el creador/editor administrativo de `Portal de compras públicas` para retirar la tarjeta interna de `Producto activo` y sustituirla por un control tipo slider en el header del modal, junto a `Código` y `Creador`.

# Objetivo
Compactar la meta común del portal y llevar el estado de activación a una franja superior más operativa, sin alterar el contrato funcional actual del producto.

# Implementación ejecutada
- Se creó un control visual de activación tipo slider dentro del header del modal especializado.
- El nuevo control convive con:
  - `Código`
  - `Creador`
  - estado de visibilidad `Activo / Inactivo`
- Se retiró la tarjeta checkbox de `Producto activo` del bloque `Meta común del producto`.
- Se mantuvo intacto el payload `activo` que consume frontend y backend.
- No se alteraron:
  - reglas de ventana de publicación
  - validaciones de `Portal de compras públicas`
  - contratos backend de creación/edición

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El header del modal concentra ahora la lectura rápida de estado del producto.
- La sección `Meta común del producto` gana espacio útil.
- El ajuste queda acotado a `Tienda clásica` y no introduce dependencia hacia BIM.
