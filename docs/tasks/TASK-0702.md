# Descripción
Se refuerza la política de activación bloqueada de `Portal de compras públicas` para que, cuando el usuario intente activar un borrador incompleto, el modal lo lleve automáticamente al primer dato faltante.

# Objetivo
Reducir fricción operativa y evitar que el usuario tenga que buscar manualmente cuál es el siguiente descriptor obligatorio pendiente.

# Implementación ejecutada
- Se formalizó un mapa único de campos requeridos para activación.
- La evaluación de readiness ahora identifica también el primer campo faltante.
- El intento de activar un portal incompleto hace `scroll` y `focus` sobre el primer campo pendiente.
- El comportamiento cubre inputs, textareas, selects y bloques guiados del modal especializado.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- La activación sigue bloqueada hasta completar el producto.
- El bloqueo ahora es guiado y accionable, no solo informativo.
- El ajuste queda acotado a `Tienda clásica`.
