# Descripción
Se universaliza la política de borrador en el listado global de productos del panel administrador y se implementa el modo híbrido de estado: el artículo sigue mostrando `Inactivo`, pero con un microindicador ámbar y ayuda contextual cuando la causa real es un borrador incompleto.

# Objetivo
Mantener la fila en una sola línea, sin crear un nuevo estado visual dominante, pero haciendo visible por qué un producto permanece inactivo.

# Implementación ejecutada
- Se unificó en backend la lectura de `activation_readiness` para todos los tipos de producto.
- `Portal de compras públicas` conserva además sus requisitos específicos sobre la base común.
- El listado global usa ahora el estado principal `Inactivo` y añade un microindicador ámbar cuando el producto sigue incompleto.
- El microindicador muestra ayuda contextual del sistema con el mensaje `Inactivo por borrador incompleto`.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- La política de borrador deja de ser exclusiva del portal y pasa a tener una proyección universal.
- El listado sigue compacto y legible en una sola línea por fila.
- El ajuste queda acotado a `Tienda clásica`.
