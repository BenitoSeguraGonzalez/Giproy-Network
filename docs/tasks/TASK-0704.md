# Descripción
Se ajusta el listado global de productos del panel administrador para que `Borrador` sea un estado visible dentro de la misma columna `Estado`, y para que el filtro administrativo pueda segmentarlo explícitamente.

# Objetivo
Simplificar la lectura operativa del listado sin recargar la UI con indicadores secundarios dentro de la misma fila.

# Implementación ejecutada
- Se formalizó una lectura administrativa de estado:
  - `Activo`
  - `Inactivo`
  - `Borrador`
- El filtro de estado ahora incorpora la opción `Borradores`.
- La columna de estado pinta `Borrador` en ámbar cuando el producto permanece incompleto.
- Se mantiene intacta la política universal de `activation_readiness` ya introducida en backend.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El listado global gana una lectura más directa del pipeline real del producto.
- La presentación queda más limpia que el modo híbrido anterior para esta vista concreta.
- El ajuste queda acotado a `Tienda clásica`.
