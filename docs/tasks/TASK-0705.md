# Descripción
Se reajusta el listado global del panel administrador para que el estado visible del producto refleje la regla real de publicación del sistema.

# Objetivo
Alinear la lectura administrativa con la lógica efectiva del `StoreFront`, evitando que un producto aparezca como `Activo` en administración si todavía no puede verse públicamente.

# Regla aplicada
- `Activo`: producto completo, `approved`, activado y dentro de la ventana de publicación.
- `Borrador`: producto que todavía tiene campos obligatorios incompletos.
- `Inactivo`: producto completo que no está publicable por fecha, por desactivación manual o por estado interno distinto de `approved`.

# Implementación ejecutada
- Se ajustó la derivación de estado administrativo en `MarketplaceAdminDashboard`.
- `Borrador` mantiene prioridad semántica sobre cualquier otro estado visual.
- `Activo` deja de depender solo de `product.activo` y pasa a incluir ventana vigente y aprobación interna.
- `Inactivo` absorbe los casos completos no publicables.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El listado administrativo queda alineado con la regla real del `StoreFront`.
- La semántica visible del estado deja de inducir a error operativo.
- El ajuste queda acotado a `Tienda clásica`.
