# Descripción
Se endurece temporalmente la política interna de aprobación para que toda operación realizada por `superadministrador` deje el producto en `approved`.

# Objetivo
Conservar el campo interno `estado` para el workflow de moderación futuro, pero evitar que la etapa inicial del sistema quede condicionada por esa capa heredada.

# Implementación ejecutada
- Se verificó que la creación por `superadministrador` ya nacía en `approved`.
- Se reforzó `update_admin_product` para reafirmar `estado = approved` y registrar `approved_by_user_id` en cada edición administrativa hecha por `superadministrador`.
- No se eliminó el campo `estado`; solo se neutralizó su impacto operativo para la fase inicial.

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- Revisión de no interferencia BIM

# Resultado
- Toda operación actual de superadministración ya queda autoaprobada.
- El sistema conserva la estructura necesaria para reactivar moderación formal más adelante.
