# Descripción
Se corrige el modal especializado de `Portal de compras públicas` para impedir cierres abruptos que salten la confirmación de guardado.

# Objetivo
Garantizar que el editor nunca se cierre sin pasar por la decisión explícita del usuario sobre guardar y cerrar o cerrar sin guardar.

# Causa detectada
- El modal ya tenía `requestClosePortalModal`, pero varios caminos de cierre seguían conectados a `closePortalModal` directo.
- Eso afectaba al menos a:
  - clic sobre el backdrop
  - botón `X` del header
  - botón `Cancelar`

# Implementación ejecutada
- Se redirigieron todos esos caminos a `requestClosePortalModal`.
- Se mantiene `closePortalModal` solo como cierre interno final cuando ya hubo decisión explícita o guardado exitoso.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El modal ya no debe salir abruptamente por las vías de cierre principales.
- El flujo de confirmación de guardado queda realmente consistente.
