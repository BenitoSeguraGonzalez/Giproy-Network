# Descripción
Se corrige la lógica de cierre confirmado del editor de `Portal de compras públicas` para que el usuario pueda volver al editor sin salir del modal principal.

# Objetivo
Evitar que la `X` o el cierre de la ventana de confirmación se interpreten como salida sin guardar.

# Implementación ejecutada
- La confirmación de cierre del portal pasa a tener tres decisiones explícitas:
  - `Guardar y cerrar`
  - `Cerrar sin guardar`
  - `Volver al editor`
- La `X` de la ventana de confirmación queda alineada con `Volver al editor`, por lo que ya no expulsa del modal principal.
- Solo `Cerrar sin guardar` ejecuta realmente el cierre directo del editor.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El usuario puede retroceder desde la confirmación al editor sin perder el contexto.
- Se elimina la salida involuntaria que ocurría al cerrar la confirmación con `X`.
