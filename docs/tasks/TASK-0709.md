# Descripción
Se corrige la captura de `Precio de licitación` para aceptar correctamente montos pegados con separadores de miles y decimales, evitando deformaciones como `86,08388`.

# Objetivo
Hacer que el campo soporte pegado de formatos habituales como `86,083.88` o `86.083,88` y los convierta a una representación numérica estable.

# Implementación ejecutada
- Frontend:
  - el campo deja de usar `type="number"` y pasa a `type="text"` con `inputMode="decimal"`
  - se añade una normalización explícita de miles/decimales para el valor pegado o escrito
- Backend:
  - el parser del monto de licitación ahora interpreta correctamente formatos con `,` y `.`

# Validación ejecutada
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- Montos como `86,083.88` ya no se deforman al pegarse.
- Frontend y backend quedan alineados sobre la misma semántica numérica.
