# Descripción
Se añade un saneamiento transversal de pegado en los formularios del creador/editor de productos para que cualquier texto pegado entre ya recortado por ambos lados.

# Objetivo
Evitar que espacios, tabulaciones, saltos de línea u otros blancos Unicode residuales contaminen los campos al pegar contenido externo.

# Implementación ejecutada
- Se añadió un trim de pegado a nivel de formulario.
- El comportamiento cubre `input` y `textarea` editables.
- El recorte se aplica antes de insertar el texto en el campo.
- Se respetan el contenido interno y la selección actual del usuario.

# Validación ejecutada
- `npm run build`
- Revisión de no interferencia BIM

# Resultado
- El creador deja de arrastrar basura de pegado al inicio o final del valor.
- La mejora aplica tanto al editor genérico como al modal de `Portal de compras públicas`.
