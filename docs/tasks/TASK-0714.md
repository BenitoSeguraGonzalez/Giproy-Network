# TASK-0714.md

## Objetivo
Alinear las fechas del modal clásico de `Portal de compras públicas` para aceptar pegado de timestamps tipo `2026-03-26 16:30:00`, descartar la hora, persistir solo `YYYY-MM-DD` y compactar las etiquetas para evitar descuadres visuales.

## Contexto
- El portal usa `fecha_inicio_licitacion` y `fecha_fin_licitacion` como fechas simples.
- Los labels completos generaban descuadre visual en la cabecera del bloque de fechas.
- Se requiere permitir pegado de valores con hora sin migrar a datetime.

## Plan de adecuación
1. Renombrar y compactar los labels frontend de ambas fechas.
2. Añadir una normalización compartida en frontend para cambio manual y pegado.
3. Endurecer el parser backend para aceptar fecha simple o timestamp ISO-like y persistir solo fecha.
4. Validar que se conserve la lógica actual de rango y no haya interferencia BIM.

## Implementación
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` normaliza `YYYY-MM-DD HH:mm:ss` a `YYYY-MM-DD` en ambos campos de fecha del portal.
- Las etiquetas visibles quedan como `F. de publicación licitación` y `F. entrega propuesta`.
- `backend/app/services/marketplace.py` acepta esos mismos valores al normalizar `portal_meta`.
- No cambian nombres de claves ni estructura de `portal_meta`.

## Validación
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`

## No interferencia BIM
- El ajuste se limita al modal clásico de `MarketplaceAdminDashboard` y al servicio común de marketplace.
- No se activó ni modificó ninguna superficie BIM.
