# TASK-0715.md

## Objetivo
Refinar la semántica del estado en el listado administrativo de productos para que un producto completo dentro de su ventana de publicación, pero no activado, se muestre como `Borrador` y no como `Inactivo`.

## Contexto
- El panel admin ya distingue `Activo`, `Borrador` e `Inactivo`.
- La lógica vigente seguía enviando a `Inactivo` cualquier producto completo que no estuviera activo.
- La regla de negocio correcta ahora distingue entre vigencia temporal y activación efectiva.

## Implementación
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` ajusta `getProductAdminStatus`.
- `Activo`: requiere `activo=true`, aprobación interna y vigencia temporal.
- `Borrador`: cubre productos incompletos y también productos completos vigentes aún no activados.
- `Inactivo`: queda reservado para productos completos fuera de su ventana de publicación.

## Validación
- `npm run build`

## No interferencia BIM
- El ajuste se limita al dashboard clásico de administración de marketplace.
- No se activó ni modificó ninguna superficie BIM.
