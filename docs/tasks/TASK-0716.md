# TASK-0716.md

## Objetivo
Eliminar la duplicidad visible de `Código de licitación` dentro del editor de `Portal de compras públicas`, dejando una sola entrada técnica unificada y corrigiendo el comportamiento de pegado en ese identificador.

## Contexto
- El editor mostraba `Código de licitación` en el meta exclusivo y además mantenía `Referencia técnica / fuente` en el bloque del importador.
- Ambos datos terminaban representando el mismo identificador práctico del portal.
- Se observó una duplicación al pegar el código en el input visible, sin evidencia de concatenación en guardado o carga backend.

## Implementación
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` elimina el campo visible separado de `Código de licitación`.
- Se deja una única entrada `Código / referencia técnica` dentro del bloque técnico/importador.
- Esa entrada sincroniza `codigo_licitacion` e `import_source_reference` internamente para mantener compatibilidad con el backend actual.
- El campo usa pegado explícito y queda fuera del saneamiento global genérico para evitar duplicaciones en la inserción.
- `backend/app/services/marketplace.py` trata `codigo_licitacion` e `import_source.reference` como un mismo origen lógico y valida la referencia técnica unificada.

## Validación
- `python -m py_compile backend/app/services/marketplace.py`
- `npm run build`

## No interferencia BIM
- El ajuste se limita al dashboard clásico y al servicio común de marketplace.
- No se activó ni modificó ninguna superficie BIM.
