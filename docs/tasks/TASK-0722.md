# TASK-0722.md

## Objetivo
Diseñar el clasificador documental por evidencias para distinguir presupuesto, APUs, recursos, VAE y combinaciones mixtas sin depender de plantillas fijas.

## Implementacion
- `backend/app/services/public_procurement_portal_import.py` incorpora clasificación por evidencias a partir de texto detectable en `pdf`, `xls` y `xlsx`.
- Se emiten `document_kind`, `detected_sections`, `detected_section_labels`, `confidence` y `warnings` por archivo.
- El preview administrativo ahora recibe la clasificación por archivo y la muestra sin romper la UX previa de rubros, capítulos e importe.

## Validacion
- `python -m py_compile backend/app/services/public_procurement_portal_import.py`
- `npm run build`

## No interferencia BIM
- Slice de analisis clasico sin impacto BIM.
