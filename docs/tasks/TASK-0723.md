# TASK-0723.md

## Objetivo
Diseñar el `analysis_bundle` canonico y la fusion generica de fuentes para el portal clasico de compras publicas.

## Implementacion
- `backend/app/services/public_procurement_portal_import.py` devuelve ahora `analysis_bundle` junto con el análisis tradicional.
- El bundle incluye `document_sources`, `budget_items`, `apus`, `resources`, `apu_links`, `vae_entries`, `portal_metadata`, `origin_metadata`, `ownership_metadata`, `warnings` y `summary`.
- La fusión multiarchivo se hace ya sobre señales combinadas y conserva clasificación, cobertura y fuentes individuales.
- El bundle soporta ahora reimportación incremental: un `import_analysis` previo puede reutilizarse como base y fusionarse conservadoramente con nuevas fuentes sin perder la identidad del trabajo ya conciliado.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` muestra `Clasificación`, `Cobertura` y warnings sobre el bundle resultante.

## Validacion
- `python -m py_compile backend/app/services/public_procurement_portal_import.py`
- `npm run build`
