# TASK-0724.md

## Objetivo
Diseñar una estrategia de extraccion tolerante a variaciones para `pdf`, `xls` y `xlsx`, evitando reglas rigidas por plantilla.

## Implementacion
- `backend/app/services/public_procurement_portal_import.py` incorpora una extracción técnica inicial por bloques para detectar `APUs` y `recursos` a partir de líneas y encabezados reales, sin depender de posiciones fijas.
- Se detectan cabeceras `Análisis de Precios Unitarios`, junto con `Código`, `Descrip.` y `Unidad`.
- Se cuentan y muestrean recursos por sección (`Equipo`, `Materiales`, `Transporte`, `Mano de Obra`) usando heurísticas tolerantes al ruido del documento.
- El `analysis_bundle` ya devuelve `sample_apus`, `sample_resources`, `real_apus_count` y `resources_count`.
- Las firmas y claves de alineación incorporan además una normalización semántica ligera sobre descripciones para tolerar artículos, plurales, abreviaturas y signos sin depender de coincidencia literal.
- Esa normalización semántica pliega además acentos y variantes latinas (`desagregación/desagregacion`, `análisis/analisis`) antes de comparar, mejorando la tolerancia real sobre documentos hispanos.
- La lectura de `VAE / desagregación` captura ahora más detalle útil en formatos variables:
  - `section_header`
  - `detail`
  - `percentage`
  - `formulario`
  - `summary`
- El bundle expone además `vae_detail_count` y `vae_percentage_count` para distinguir volumen bruto de señales frente a detalle interpretable.
- Para `.xls`, si `xlrd` no está disponible en el entorno, el sistema cae a un `fallback` de señales textuales para no bloquear completamente la clasificación técnica.
- La fusión multiarchivo incorpora además conciliación conservadora por firmas para evitar duplicar rubros, APUs, recursos o señales VAE cuando varias fuentes se solapan.

## Validacion
- `python -m py_compile backend/app/services/public_procurement_portal_import.py`
- Prueba directa con los ejemplos PDF reales de `docs/adicionales`, verificando extracción de APUs/recursos y cobertura resultante.
- `npm run build`
