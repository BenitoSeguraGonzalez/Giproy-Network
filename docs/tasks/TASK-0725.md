# TASK-0725.md

## Objetivo
Diseñar la UX del bloque de importacion para trabajar con bundles documentales y correccion manual asistida.

## Implementacion
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` amplía el preview del portal para mostrar:
  - clasificación por archivo
  - cobertura del bundle
  - warnings
  - APUs detectados
  - recursos detectados
  - APUs bootstrap cuando el caso es `solo presupuesto`
- El editor y la vista previa muestran ahora además la conciliación incremental del bundle:
  - total de elementos conciliados
  - desglose por rubros, APUs base, APUs reales, recursos y VAE
- Se incorpora corrección manual asistida de rol por archivo:
  - `Auto`
  - `Presupuesto`
  - `APUs / recursos`
  - `Integrado`
  - `VAE / desagregación`
- `frontend/src/api/marketplace.js` y `backend/app/api/endpoints/marketplace.py` transportan `source_roles_json` para recalcular el bundle con esos overrides.
- El flujo de análisis del modal ya reutiliza el `import_analysis` existente como base cuando el usuario vuelve a analizar nuevas fuentes, convirtiendo el proceso en reimportación incremental en vez de reemplazo total.

## Validacion

- `python -m py_compile backend/app/api/endpoints/marketplace.py`
