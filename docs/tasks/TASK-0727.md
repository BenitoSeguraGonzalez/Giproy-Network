# TASK-0727.md

## Objetivo
Diseñar la generacion automatica de APUs en estado `Pendiente` cuando la entrada solo incluya presupuesto.

## Implementacion
- `backend/app/services/public_procurement_portal_import.py` genera `generated_apus` cuando la fuente queda clasificada como `presupuesto_only`.
- Se crea un APU base por cada linea de presupuesto distinta usando firma robusta de codigo/descripcion/unidad/capitulo.
- Cada APU nace sin recursos, con estado `Pendiente` y origen `generated_from_budget_only`.
- Cuando posteriormente llegan APUs reales compatibles, el bundle puede ahora promover esos APUs bootstrap a APUs enriquecidos, preservando su identidad técnica (`temp_id`) y dejando la traza de promoción.
- `build_excel_bytes` añade una hoja `APUs` cuando existan APUs bootstrap para mantener esa estructura visible en la salida técnica.
- El preview admin expone el bloque `APUs bootstrap` para que el superadministrador vea el resultado antes de guardar.

## Validacion
- `python -m py_compile backend/app/services/public_procurement_portal_import.py`
- `npm run build`

## No interferencia BIM
- Slice clasico de compras publicas sin impacto BIM.
