# TASK-0729.md

## Objetivo
Diseñar el mapeo de metadatos hacia salidas diferenciadas `GIPROY` y `Excel`.

## Implementacion ejecutada
- Se mapea `Código / referencia técnica` a `Proyecto > Datos de proyecto > Cod. Referencial` en la siembra del proyecto entregado por compra.
- La localización del portal (`país`, `provincia`, `cantón`, `dirección`) se proyecta a `Datos de proyecto` en el detalle sembrado.
- Se añade resolución automática conservadora de geolocalización para Ecuador por `provincia/cantón`, con fallback provincial cuando no existe coincidencia más fina.
- La vista previa clásica del editor muestra ya el bloque `Proyecto entregado al comprador` con:
  - `Cod. Referencial`
  - `Localización`
  - `Geolocalización propuesta`
- `Excel` mantiene solo datos genéricos de cabecera y no replica la estructura interna de `Datos de proyecto`.
