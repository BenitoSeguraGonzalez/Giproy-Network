# TASK-0730.md

## Objetivo
Diseñar el marcado estructural de procedencia para proyectos y bases de trabajo generados desde compras publicas.

## Implementacion ejecutada
- Se refuerza la procedencia comprada reutilizando `MarketplaceAssetOrigin` como marca persistente para los activos entregados.
- Los proyectos entregados por compra quedan marcados además dentro de `plantillas_config` con:
  - `marketplace_traceability`
  - `marketplace_flags.purchase_bound`
  - `marketplace_flags.requires_company_ownership`
- Cuando el activo entregado es un proyecto con base vinculada, la base también queda registrada como activo adquirido con su propia traza y referencia al proyecto enlazado.
- La metadata de procedencia incluye ya:
  - empresa propietaria
  - producto marketplace origen
  - pedido e ítem de pedido
  - tipo de producto
  - entidad entregada
  - marca de uso ligado a compra

## Validacion ejecutada
- `python -m py_compile backend/app/services/marketplace_asset_origin.py backend/app/services/marketplace_checkout.py`
- Revisión de flujo de checkout para confirmar registro de origen sobre proyecto y base vinculada cuando exista.
