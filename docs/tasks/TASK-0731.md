# TASK-0731.md

## Objetivo
Diseñar el enforcement obligatorio de propiedad empresarial para productos, proyectos y bases derivados de una compra.

## Implementacion ejecutada
- Se centraliza la validación de ownership en `MarketplaceAssetOriginService.validate_company_ownership(...)`.
- La política reutilizable inspecciona activos adquiridos desde marketplace y exige coincidencia entre:
  - empresa del contexto actual
  - empresa propietaria registrada en `purchase_scope.owner_company_id`
- Se aplica ya al abrir:
  - proyectos por ID
  - proyectos resueltos por base vinculada
  - base activa
  - base por ID
  - activación de base
- La generación de proyectos comprados queda ya naturalmente ligada al checkout, y el activo registrado conserva la empresa propietaria como parte de su contrato backend.

## Validacion ejecutada
- `python -m py_compile backend/app/services/marketplace_asset_origin.py backend/app/services/marketplace_checkout.py backend/app/api/endpoints/proyectos.py backend/app/api/endpoints/bases_trabajo.py`
- Revisión de cobertura backend sobre los puntos de apertura más sensibles del sistema clásico.
