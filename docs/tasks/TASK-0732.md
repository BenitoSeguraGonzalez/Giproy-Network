# TASK-0732.md

## Objetivo
Reorganizar visualmente el editor clásico del `Portal de compras públicas` separando con claridad `Configuración híbrida`, `Fuente documental` y `Resultado técnico`.

## Implementacion ejecutada
- Revisar la jerarquía actual del bloque híbrido del modal.
- Separar visual y semánticamente:
  - `Configuración híbrida`
  - `Fuente documental`
  - `Resultado técnico`
- Evitar que la carga documental quede mezclada con metadatos de modalidad, versión y referencia técnica.
- Mantener intactas las funciones actuales del importador clásico.
- `frontend/src/pages/MarketplaceAdminDashboard.jsx` reorganiza ya la columna técnica del modal en tres bloques reales, con títulos y subtítulos propios para cada zona.
- Se retiran del primer plano los indicadores y selectores derivados que no aportaban control real en esta fase, como `Versión de plantilla`, `Estado técnico` y `Origen técnico`.
- El bloque superior se compacta además dejando `Código / referencia técnica` y `Modalidad de entrega` en una sola fila y rebajando la densidad tipográfica del encabezado.
- Se afina la jerarquía visual del primer nivel: los campos editables pasan a `font-medium`, `Código / referencia técnica` recupera más ancho útil y `Modalidad de entrega` se estrecha todavía más para dejar claro su carácter transitorio.
- `Modalidad de entrega` deja de usar el desplegable nativo del navegador y pasa a un menú propio del modal, preservando la funcionalidad pero alineando caja y lista con el sistema visual clásico.
- Se rebaja además la densidad tipográfica del modal en escritorio amplio: labels, títulos de bloque y acciones del importador/final de modal dejan `font-black` y tracking agresivo para pasar a una jerarquía más sobria y respirable.

## Validacion
 - `npm run build` (la compilación genera los assets correctamente; el proceso Vite/Node cierra con una aserción residual de `UV_HANDLE_CLOSING` del entorno)

## Resultado
- El usuario entiende de inmediato qué parte configura el producto, qué parte carga archivos y qué parte muestra el resultado del análisis.
- La superficie deja de parecer un único bloque saturado y pasa a leerse como flujo operativo por zonas.

## No interferencia BIM
- Slice exclusivo de UX clásica sin impacto BIM.
