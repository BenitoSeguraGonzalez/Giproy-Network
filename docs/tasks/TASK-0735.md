# TASK-0735.md

## Objetivo
Separar la entrada documental del análisis profundo para que el `Resultado técnico` viva en un bloque propio, no incrustado en la misma superficie de carga.

## Implementacion ejecutada
- Mover el análisis técnico detallado a una zona claramente posterior a la carga.
- Dejar `Fuente documental` centrada en:
  - carga
  - estado inmediato
  - lista de archivos
  - acción de analizar
- Dejar `Resultado técnico` centrado en:
  - clasificación
  - cobertura
  - warnings
  - métricas del bundle
  - muestras técnicas
- El antiguo `Análisis integrado` queda ya relanzado como `Resultado técnico`, separado del bloque de carga y lectura documental.
- El bloque se compacta además con una jerarquía más ejecutiva:
  - resumen principal
  - `Lectura estructural`
  - `Calidad del bundle`
- La misma compactación visual se replica en la vista previa para mantener coherencia entre editor y confirmación.

## Validacion
- `npm run build`

## Resultado
- La pantalla deja de mezclar entrada y salida en el mismo bloque visual.
- El análisis técnico gana legibilidad porque ya no compite con los controles de carga.

## No interferencia BIM
- Slice exclusivo de UX clásica sin impacto BIM.
