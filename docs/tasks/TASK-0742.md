# TASK-0742 - Confirmación controlada al reemplazar fuentes ya analizadas

## Objetivo
Evitar reemplazos silenciosos de la fuente documental cuando el portal ya tiene análisis técnico asociado.

## Alcance
- Detectar recarga de archivos con `import_analysis` ya presente.
- Mostrar confirmación con el diálogo propio del sistema, sin usar el modal nativo del navegador.
- Si el usuario confirma, limpiar análisis y cola previos antes de cargar la nueva fuente.

## Estado
Completado - 2026-03-30

## Resultado
- El selector de archivos ya no pisa análisis previos sin aviso.
- El flujo usa `appConfirm` con copy específico de reemplazo de fuente documental.
- Al confirmar, el editor reinicia análisis, overrides y progreso para la nueva fuente.
