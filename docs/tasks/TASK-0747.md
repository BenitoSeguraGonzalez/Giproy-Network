# TASK-0747 - Normalización de meta común y meta exclusiva del producto público

## Objetivo
Definir una base común pública para todos los productos del marketplace clásico y separar de ella la meta exclusiva por tipo.

## Estado
Completado - 2026-03-30

## Resultado
- El storefront ya no depende del objeto bruto del backend para decidir qué mostrar.
- Se consolida la lectura de categoría, título, propietario, descripciones, precio, descuento e imagen como `meta común`.
- La zona común del editor genérico se homologa visualmente con el portal: `Título comercial`, `Descripción corta`, `Descripción larga`, `Descripción completa`, `Imagen relevante`, `Precio comercial`, `Descuento / promoción` y fechas de publicación quedan ordenadas bajo una misma semántica.
