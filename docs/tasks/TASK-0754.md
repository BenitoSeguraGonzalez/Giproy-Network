# TASK-0754 - Compatibilidad pública para productos legacy sin todos los campos comunes

## Objetivo
Evitar que el storefront clásico se rompa cuando un producto todavía no tenga todos los campos comunes enriquecidos.

## Estado
Completado - 2026-03-30

## Resultado
- El storefront conserva fallback de imagen, descripciones, descuento y meta exclusiva.
- Los productos antiguos siguen siendo renderizables sin romper la experiencia.
