# TASK-0756 - Gobierno de acceso a compra: solo administradores de empresa

## Objetivo
Restringir la compra del marketplace clásico a usuarios con rol de `administrador de empresa`, manteniendo el carrito persistente sin romper la lectura pública del catálogo.

## Alcance
- Validación frontend
- Enforcement backend
- Compatibilidad con carrito persistente
- Reglas de visibilidad de `Mis compras`
- Política de acceso por empresa

## Dependencias
- `TASK-0755`

## Criterio de cierre
- Solo los `administradores de empresa` pueden ejecutar compra.
- El backend bloquea cualquier intento no autorizado aunque el frontend falle.
- El carrito sigue siendo visible y persistente para el usuario, pero el checkout se restringe correctamente.
- `Mis compras` queda ligado a la empresa y a los roles autorizados.

## Estado
Completado - 2026-03-30

## Resultado
- La compra en marketplace queda restringida a `administrador` tanto en frontend como en backend.
- `superadministrador` conserva capacidades de venta y administración, pero deja de heredar compra por defecto.
- El mensaje de UX de compra no disponible ya explica que solo los administradores de empresa pueden comprar.
