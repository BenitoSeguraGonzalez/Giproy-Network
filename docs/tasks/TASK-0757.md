# TASK-0757 - Panel administrador Formas de pago con readiness y configuración

## Objetivo
Añadir al panel administrador clásico la sección `Formas de pago` para gestionar activación, configuración y readiness de métodos.

## Alcance
- Alta visual de la sección
- PayPhone
- PayPal
- Transferencia bancaria
- Activado/desactivado
- Sandbox/producción
- Estado de readiness
- Prioridad / orden visual
- Validación de configuración incompleta

## Dependencias
- `TASK-0755`

## Criterio de cierre
- El panel `Formas de pago` existe en administración.
- Cada método puede activarse o desactivarse sin tocar código.
- El sistema distingue `disabled`, `incomplete`, `sandbox_ready` y `production_ready`.
- Los métodos incompletos no se ofrecen como opciones reales de pago.

## Estado
Completado - 2026-03-31

## Resultado parcial
- Se añade el nuevo submódulo `Formas de pago` al panel administrador de Tienda.
- Backend incorpora ya el modelo `MarketplacePaymentMethod`, sus endpoints admin/públicos y la siembra automática de `PayPhone`, `PayPal` y `Transferencia bancaria`.
- El sistema calcula `readiness_status` según configuración mínima y bloquea la activación de métodos incompletos.
- El storefront solo recibe métodos activos y listos, sin exponer secretos de configuración.
- Los tres métodos iniciales ya consumen este readiness/configuración como fuente de verdad dentro del checkout clásico.
