# TASK-0760 - Integración PayPal con orden, captura, confirmación y reconciliación

## Objetivo
Integrar `PayPal` con creación de orden, captura backend y confirmación de compra segura.

## Alcance
- Configuración de credenciales
- Botón SDK
- Backend create/capture
- Webhook o reconciliación equivalente
- Activación de compra tras confirmación
- Idempotencia de orden y captura

## Dependencias
- `TASK-0755`
- `TASK-0757`
- `TASK-0758`

## Criterio de cierre
- `PayPal` puede operar en `sandbox` y quedar preparado para `producción`.
- El backend crea y captura la orden sin delegar la confirmación al frontend.
- Existe webhook o mecanismo equivalente de reconciliación.
- El activo solo se entrega tras confirmación/captura válida.

## Estado
Completado - 2026-03-31

## Avance actual
- Backend ya prepara el flujo `PayPal` desde `checkout_draft`.
- El storefront ya puede cargar el SDK oficial, crear orden y capturarla desde backend.
- La compra solo se activa después de `capture` completada y validada por backend.
- Buyer, detalle y `Ventas Sistema` ya leen la trazabilidad PayPal dentro del mismo circuito de conciliación del marketplace clásico.
