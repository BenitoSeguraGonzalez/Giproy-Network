# TASK-0761 - Transferencia bancaria con referencia, comprobante y validación manual

## Objetivo
Añadir `Transferencia bancaria` como método de pago pendiente de validación manual por `superadministrador`.

## Alcance
- Datos bancarios configurables
- Referencia obligatoria
- Comprobante recomendado
- Estado `pending`
- No entrega hasta validación
- Expiración y rechazo manual

## Dependencias
- `TASK-0755`
- `TASK-0757`
- `TASK-0758`

## Criterio de cierre
- La transferencia genera pedido sin entregar el activo.
- La compra queda en estado `pending` hasta validación manual.
- Se captura referencia bancaria obligatoria y datos mínimos de soporte.
- El backoffice puede aprobar, rechazar o expirar la operación.

## Estado
Completado - 2026-03-31

## Resultado parcial
- `Transferencia bancaria` ya funciona como primer método real del nuevo checkout.
- El carrito crea `checkout_draft`, exige referencia obligatoria y registra el pedido en estado `awaiting_manual_validation`.
- El backend crea/actualiza `payment_attempt` manual y deja trazabilidad inicial con `payment_event`.
- La compra no entrega activos ni incrementa ventas todavía; queda pendiente de validación manual.
- Los pedidos bancarios pendientes ya no quedan abiertos indefinidamente: si no se validan dentro del plazo operativo, pasan a `expired` y se audita el cambio.
- Buyer, detalle y `Ventas Sistema` ya distinguen correctamente validación pendiente, rechazo y expiración bancaria bajo una misma semántica visible.
