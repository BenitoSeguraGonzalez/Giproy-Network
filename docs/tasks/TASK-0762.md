# TASK-0762 - Mis compras para empresa compradora con estado de pago y acceso real

## Objetivo
Hacer funcional `Mis compras` para la empresa compradora dentro del marketplace clásico.

## Alcance
- Datos de empresa
- Historial de compras
- Estado de pedido y pago
- Método de pago
- Acceso a activos solo cuando la compra esté confirmada
- Continuidad con carrito persistente y postcompra

## Dependencias
- `TASK-0755`
- `TASK-0756`
- `TASK-0758`

## Criterio de cierre
- La empresa puede consultar sus compras confirmadas y pendientes.
- Se muestran estado de pedido, estado de pago, método, total y fecha.
- Los activos solo se habilitan cuando el pedido está confirmado/entregado.
- La vista no rompe la experiencia actual del área de empresa.

## Estado
Completado - 2026-03-31

## Avance 2026-03-31
- El detalle de `Mis compras` ya incorpora una cronología compacta del pago para que el comprador vea qué pasó sin depender de soporte manual.
- `Mis compras` ya usa el mismo lenguaje de método y estado de pago que detalle y backoffice, evitando lecturas distintas para la misma compra.
- El buyer ya puede ver también la resolución operativa del refund según el método de pago, sin quedarse en un `reembolsado` genérico.

## Avance 2026-03-30
- `Mis compras` ya distingue pedidos `completed`, `awaiting_manual_validation` y `payment_rejected`.
- El buyer dashboard ahora expone método de pago, estado de pago, referencia bancaria y fecha reportada cuando aplica.
- La factura sigue protegida y solo aparece para pedidos completados.
