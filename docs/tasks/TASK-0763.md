# TASK-0763 - Ventas Sistema para seguimiento operativo y validación manual de transferencias

## Objetivo
Crear la sección `Ventas Sistema` en el panel administrador clásico para seguimiento de compras y validación manual.

## Alcance
- Listado de ventas
- Filtros operativos
- Foco especial en transferencias pendientes
- Aprobar / rechazar
- Referencia y observación administrativa
- Reconciliación y trazabilidad básica

## Dependencias
- `TASK-0755`
- `TASK-0757`
- `TASK-0761`

## Criterio de cierre
- Existe la sección `Ventas Sistema` en administración.
- El backoffice permite localizar transferencias pendientes y validarlas.
- Se registran referencia, observación y usuario/fecha de validación.
- El diseño deja preparado el salto futuro a ventas multi-origen sin rehacer la consola.

## Estado
Completado - 2026-03-31

- `Ventas Sistema` ya muestra también la última señal relevante del pago, no solo el estado resultante.
- La conciliación administrativa gana más contexto porque backend resume la cronología de `payment_event` y expone el último hito visible por pedido.
- La consola ya expone un bloque explícito de `housekeeping` con drafts abiertos, transferencias fuera de plazo, pagos online en espera y pedidos todavía dentro de ventana automática de devolución.
