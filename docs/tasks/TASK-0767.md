# TASK-0767 - UX de Mis compras y Ventas Sistema para devoluciones y excepciones manuales

## Objetivo
Hacer visible y gobernable la política de devolución en `Mis compras` y `Ventas Sistema`, incluyendo la excepción manual por `superadministración`.

## Alcance
- Contador o estado de devolución disponible en `Mis compras`
- Estado de ventana activa / expirada
- Acciones administrativas de devolución manual en `Ventas Sistema`
- Observación y motivo de devolución
- No ruptura de la estética actual del marketplace clásico

## Dependencias
- `TASK-0762`
- `TASK-0763`
- `TASK-0765`
- `TASK-0766`

## Criterio de cierre
- `Mis compras` informa cuándo una compra puede devolverse y cuándo ya no.
- `Ventas Sistema` permite devolución manual excepcional por `superadministrador`.
- Las devoluciones manuales quedan auditadas con motivo, usuario y fecha.
- La UX sigue integrada con el lenguaje visual actual de postcompra y backoffice.

## Estado
Completado - 2026-03-31

## Avance 2026-03-31
- `Mis compras` ya informa si un pedido tiene devolución automática disponible, parcial o no aplicable.
- `Ventas Sistema` ya muestra el estado de esa ventana para que superadministración tenga contexto antes de una futura devolución manual.
- La UX ya diferencia entre ventana abierta, ventana expirada y pedido sin devolución automática.
- Buyer, detalle de pedido y `Ventas Sistema` ya muestran además el modo, motivo y fecha del reembolso cuando este ya fue ejecutado.
- La UX deja visible también la resolución operativa residual del refund por método de pago, mejorando soporte y conciliación.
