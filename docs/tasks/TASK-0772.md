# TASK-0772 - Rehabilitar persistencia inmediata del orden de líneas APU

## Objetivo
Recuperar la persistencia inmediata del reordenamiento drag-and-drop en el editor APU para líneas ya guardadas.

## Alcance
- Frontend `APUs.jsx`
- Reutilización de `apusApi.moveLinea`
- Reversión local si la persistencia falla

## Criterio de cierre
- Reordenar una línea en un APU existente actualiza también el orden persistido.
- Si la persistencia falla, la UI revierte el cambio y avisa claramente.
- Los APUs nuevos siguen pudiendo reordenarse localmente antes del primer guardado.

## Estado
Completado

## Resultado
- El `drag and drop` en APUs existentes vuelve a llamar al endpoint persistente de movimiento.
- La UI mantiene optimismo local, pero revierte si backend no confirma el cambio.
