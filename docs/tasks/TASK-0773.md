# TASK-0773 - Blindar backend del orden persistente de recursos APU

## Objetivo
Endurecer la normalización backend del orden de líneas APU para que conserve el orden técnico incluso cuando el payload de edición no incluya `recurso_codigo`.

## Alcance
- Backend `apu.py`
- Resolución de código de recurso desde `recurso_id`
- Conservación del criterio histórico de agrupación/orden por categoría técnica
- Confirmación de compatibilidad con consumidores y reportes

## Criterio de cierre
- La normalización backend resuelve la categoría correcta aunque el payload llegue sin `recurso_codigo`.
- Guardados y actualizaciones no rebarajan líneas de forma silenciosa.
- El orden persistido sigue siendo el mismo que consumen los reportes.

## Estado
Completado

## Resultado
- Backend ya infiere el código técnico de recurso desde `recurso_id` cuando falta metadata embebida.
- La normalización de `orden` vuelve a ser robusta ante payloads parciales del editor.
- El orden persistido queda de nuevo alineado con reportes y consumidores que leen por `orden`.
