# TASK-0806

## Título
Implementar housekeeping de expiración, gracia y activación siguiente

## Objetivo
Sincronizar expiraciones y activaciones futuras con lógica reusable por cron o ejecución manual.

## Estado
Completado.

## Resultado
- `LicenseService.run_license_housekeeping_for_company(...)` ya expira licencias vencidas, calcula gracia y activa la siguiente cuando corresponda.
- `LicenseService.run_license_housekeeping_for_all_companies(...)` ya permite ejecutar el barrido global sin depender de recorrer empresas desde fuera.
- `POST /api/v1/admin-licenses/housekeeping/run` ya ofrece ejecución manual segura para superadministración.
- `backend/scripts/license_housekeeping.py` deja listo el carril explícito de cron/ejecución programada.
- `AdminGlobalLicencias` ya puede disparar housekeeping desde la consola operativa y refrescar el resumen al terminar.
- El carril queda cubierto con pruebas de agregación y ejecución sin cambios.
