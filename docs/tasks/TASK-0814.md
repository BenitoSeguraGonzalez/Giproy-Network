# TASK-0814 - Sustituir licencias legacy del catálogo por licencias SaaS reales

## Estado
Completado

## Objetivo
Sustituir los productos de licencia legacy sembrados en el catálogo del sistema por la oferta comercial SaaS real (`Estándar`, `Profesional`, `Empresarial` en ciclo mensual/anual), manteniendo su compra visible para administradores de empresa y el gobierno editorial en `Panel Administrador`.

## Alcance
- Reemplazar el bootstrap de licencias del sistema por la oferta comercial real.
- Inyectar `license_offer` en `product_meta` para conectar catálogo y fulfillment.
- Desactivar las licencias legacy de prueba del catálogo del sistema.
- Añadir una entrada dedicada `Licencias SaaS` dentro de `Panel Administrador`, reutilizando el submódulo existente de productos.

## Resultado
- El catálogo del sistema deja de sembrar licencias de prueba y pasa a sembrar únicamente las licencias comerciales reales.
- Las licencias siguen visibles para administradores de empresa dentro de Tienda.
- Superadministración las gobierna desde una entrada dedicada del `Panel Administrador`.
