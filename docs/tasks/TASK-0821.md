# TASK-0821 - Recalcular precios vivos del presupuesto al leer el workbench

## Estado
Completado

## Objetivo
Evitar que el presupuesto muestre precios obsoletos cuando los APUs ya cambiaron en la base de proyecto.

## Resultado
- `GET /presupuestos/{id}` recalcula precios antes de responder.
- La lectura del presupuesto operativo por proyecto también fuerza recálculo antes de devolverlo.
