# TASK-0824 - Propagar sincronización de base a revisión operativa y presupuestos

## Estado
Completado

## Objetivo
Permitir que la sincronización se ejecute sobre una revisión concreta y refresque presupuestos operativos afectados.

## Resultado
- La UI ya permite elegir la revisión/base de proyecto objetivo cuando existen varias revisiones.
- La sincronización informa líneas de presupuesto afectables antes de confirmar.
- Tras sincronizar, se recalculan presupuestos de la revisión objetivo con precios vivos del APU actualizado.
