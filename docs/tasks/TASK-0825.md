# TASK-0825 - Añadir historial reversible de una sola sincronización

## Estado
Completado

## Objetivo
Permitir revertir solo la última sincronización de una base de proyecto desde su historial operativo.

## Resultado
- Cada sincronización guarda snapshot reversible del estado afectado.
- El historial muestra usuario, fecha/hora, modo y revisión de sincronización.
- Solo la última sincronización queda con `undo` disponible.
- La reversión restaura APUs, recursos, presupuestos y metadatos de la base al estado previo.
