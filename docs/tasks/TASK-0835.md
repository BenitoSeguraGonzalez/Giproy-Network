## Objetivo
Reducir la altura visual del modal de sincronización y mejorar el contraste del bloque `Impacto operativo` para que el flujo sea usable en viewport real.

- La lectura del flujo `tipo -> revisión -> impacto -> confirmación` se mantiene, pero con menos altura y mejor foco visual.
