# TASK-0841 - Exponer Capacidades Reales De Exportación MS Project Desde Backend

## Estado
Completado

## Objetivo
Hacer que el backend de `Cronograma de Trabajo` informe al frontend qué formatos de exportación están disponibles realmente en el entorno activo.

## Resultado
- `CronogramaTrabajoResponse` ya expone `export_capabilities`.
- El backend resuelve `preferred_format`, formatos disponibles y motivo cuando `.mpp` directo no está habilitado.
- El endpoint de exportación ya negocia `format=xml|mpp` y bloquea `.mpp` cuando el entorno no puede sostenerlo.
