Acercar el motor de `Cronograma de Trabajo` al análisis definido en `Análisis para Cronograma Trabajo.xlsx`, separando mejor `rendimiento unitario`, `trabajo útil` y `transporte` para que la duración no se apoye en una suma semánticamente incorrecta.

## Resultado

- Cada fila del cronograma expone además `trabajo_equipos`, `trabajo_mano_obra`, `trabajo_transporte`, `trabajo_total` y `recursos_calculados`.
