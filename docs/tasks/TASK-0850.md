# TASK-0850 - Virtualizar Y Aligerar El Render Del Árbol De Presupuesto

## Estado
Completado

## Objetivo
Evitar que el workbench de `Presupuesto` recomponga todo el árbol de líneas cuando el usuario añade, mueve o edita una sola línea.

## Resultado
- `LineasPresupuestoTab` ya no depende del render recursivo completo como ruta principal.
- El árbol se aplana en memoria y pasa por una virtualización progresiva por tramos, evitando render completo pero sin cortar visualmente el presupuesto.
- La navegación por teclado, selección, drag & drop, scroll y edición siguen operativos sobre la lista virtualizada.
- La primera aproximación por offsets fijos fue retirada porque podía dejar el presupuesto en blanco a mitad de EDT; la versión estable actual amplía filas según scroll, selección, minimapa y buffer real de contenedor.
- El slice queda preparado para presupuestos muy grandes con un coste de DOM mucho más contenido.
