# TASK-0853 - Migrar Exportación Directa .MPP A Pywin32 En Cronograma De Trabajo

## Estado
Completado

## Objetivo
Implementar la exportación directa `.mpp` de `Cronograma de Trabajo` usando `pywin32` y automatización COM de Microsoft Project en lugar del script embebido por PowerShell.

## Resultado
- `cronograma_trabajo.py` ahora detecta `pywin32/win32com` como condición real para habilitar `.mpp`.
- La exportación directa crea el `.mpp` usando `DispatchEx("MSProject.Application")`, apertura del XML interoperable y guardado final con Microsoft Project.
- El endpoint backend mantiene una negociación honesta entre `.mpp` y `XML`.
