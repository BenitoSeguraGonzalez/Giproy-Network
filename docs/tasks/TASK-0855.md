# TASK-0855 - Endurecer Validación De Predecesoras En Cronograma De Trabajo

## Estado
Completado

## Objetivo
Evitar que `Cronograma de Trabajo` permita guardar dependencias inválidas, inexistentes o incoherentes entre partidas del presupuesto operativo.

## Resultado
- El frontend valida predecesoras antes de guardar una línea.
- El backend vuelve a validar la misma regla antes de persistir `schedule_data`.
- Ya no se aceptan dependencias hacia la propia línea ni hacia partidas posteriores.
