# TASK-0856 - Alinear Secuencia Interna Del Cronograma Con El Orden Real Del Presupuesto

## Estado
Completado

## Objetivo
Hacer que el orden operativo del cronograma de trabajo dependa del orden real de las partidas calculables del presupuesto, para soportar validación y cálculo de fechas más consistentes.

## Resultado
- Cada fila calculada expone `sequence_index`.
- La validación de predecesoras usa ese orden real del presupuesto.
- El cálculo de fechas queda mejor protegido frente a secuencias incoherentes.
