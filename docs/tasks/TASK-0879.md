# TASK-0879 - Blindar create_revision y alta de líneas contra mezcla de bases

## Objetivo
Cerrar los flujos que podían reintroducir APUs de una base equivocada dentro de un presupuesto de proyecto.

## Estado
Completada

## Resultado
- `POST /presupuestos/{id}/lineas` ahora resuelve el APU contra la base activa del proyecto y rechaza conflictos sin equivalente.
- `create_presupuesto_service(...)` también valida/remapea `apu_id` de entrada.
- `ProyectoService.create_revision(...)` remapea `apu_id` al APU equivalente de la nueva base de revisión en lugar de copiar el id anterior.
- Se añadieron tests para:
  - saneamiento de líneas mezcladas
  - clonación de revisión sin arrastrar `apu_id` de otra base
