# TASK-0881 - Separar catálogos de unidades en el editor maestro de APUs

## Objetivo
Evitar que el modal de edición de recursos contamine la unidad del APU reutilizando la misma lista de unidades.

## Estado
Completada

## Resultado
- `frontend/src/pages/APUs.jsx` ahora separa `apuUnidades` y `resourceUnidades`.
- El selector de unidad del APU ya no depende de las unidades cargadas para el recurso editado.
- Cerrar o cancelar el modal de recurso limpia su contexto sin alterar el del APU.
