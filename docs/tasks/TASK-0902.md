# TASK-0902 - Blindar exportación `.mpp` para no devolver 500 genérico

## Objetivo
Evitar que la exportación de `Cronograma de Trabajo` a `MS Project` termine en `Error interno del servidor` cuando la automatización COM falle después de que la detección previa haya permitido intentar el carril `.mpp`.

## Alcance
- Convertir fallos operativos de `export_ms_project_mpp(...)` en respuestas HTTP controladas con detalle útil.
- Mantener el mensaje real para que frontend pueda mostrarlo al usuario.

## Cierre
- El endpoint captura `RuntimeError` de la automatización `.mpp` y responde `409` con `detail` explícito.
- El frontend ya no depende de un 500 genérico para surfacer el motivo real.
