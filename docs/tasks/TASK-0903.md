# TASK-0903 - Evitar timeouts 524 en exportación `.mpp` de Cronograma Trabajo

## Objetivo
Sacar la automatización COM de Microsoft Project fuera del proceso web y ponerle timeout duro para que una exportación `.mpp` fallida no bloquee el backend ni termine en `524`.

## Alcance
- Ejecutar la conversión XML -> MPP en un helper subprocess.
- Cortar la operación si Microsoft Project no responde dentro de una ventana razonable.
- Mantener el mensaje de error legible en frontend cuando el servidor/proxy devuelva HTML de timeout.

## Cierre
- El servicio usa un helper Python independiente para automatizar Project.
- La exportación `.mpp` falla rápido y con mensaje útil cuando la sesión COM no es operable.
- El parser de blobs del frontend convierte HTML/524 en un mensaje breve y entendible.
