# TASK-0905 - Instalar y autoarrancar Project Bridge una sola vez

## Objetivo
Permitir que el helper local quede instalado una sola vez y autoarranque al iniciar sesión en Windows.

## Cierre
- `install_bridge.ps1` registra la tarea programada `GiProy Project Bridge`.
- `uninstall_bridge.ps1` elimina el helper local.
