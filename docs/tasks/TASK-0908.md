# TASK-0908 - Añadir carril backend de exportación PDF desde Excel

## Objetivo
Permitir que los reportes se exporten como `PDF desde Excel`, reutilizando primero la plantilla `.xlsx` del reporte.

## Cierre
- `ReportExportRequest` acepta `pdf_excel`.
- el endpoint de reporting genera `.xlsx` y luego intenta convertirlo a PDF.
- la descarga conserva el naming estándar de reportes.
