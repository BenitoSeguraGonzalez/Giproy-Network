# TASK-0909 - Implementar helper aislado de conversión Excel a PDF

## Objetivo
Aislar la automatización de Microsoft Excel en un helper externo con timeout, para evitar cuelgues dentro del proceso web.

## Cierre
- nuevo helper `convert_excel_to_pdf.py`.
- usa Excel COM para `ExportAsFixedFormat`.
- el servicio `reporting` lo invoca mediante subprocess con timeout y errores operativos claros.
