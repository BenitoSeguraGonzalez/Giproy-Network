# TASK-0918 - Oficializar Vista Gantt De Cronogramas

## Modo
GIPROY CLASICO

## Objetivo
Promover la vista `Gantt` de `Proyecto > Cronogramas` desde estado experimental a vista funcional oficial, sin introducir dependencias BIM ni dependencias frontend nuevas.

## Alcance
- Renombrar el componente operativo de Gantt para retirar el contrato experimental.
- Mantener la vista como tercera pestaña oficial junto a `Cronograma Valorado` y `Cronograma de Trabajo`.
- Reutilizar el backend común de `cronogramas-trabajo`.
- Documentar que el acceso queda gobernado por los permisos del módulo `Cronogramas`.

## Cambios
- `CronogramaExperimentalGantt.jsx` pasa a `CronogramaGantt.jsx`.
- `Cronogramas.jsx` carga la vista oficial `CronogramaGantt`.
- La documentación del slice deja de prometer Syncfusion como dependencia obligatoria y formaliza la implementación propia actual.

## No Interferencia BIM
- No se modifica ninguna ruta, API, modelo ni componente BIM.
- La vista Gantt sigue consumiendo únicamente contratos clásicos de cronogramas.

## Validación
- `npm run build` en `frontend` ejecutado correctamente.
- `python -m json.tool` sobre `docs/project_state.json` y `docs/runtime/WORK_MODE_STATE.json` ejecutado correctamente.
- `eslint` enfocado sobre `Cronogramas.jsx` y `CronogramaGantt.jsx` ejecutado sin errores.
- No se modifican archivos, rutas, APIs ni componentes BIM.
