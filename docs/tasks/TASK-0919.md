# TASK-0919 - Recuperación De Chunks Lazy Tras Deploy

## Modo
GIPROY CLASICO

## Objetivo
Resolver el error `TypeError: Failed to fetch dynamically imported module` observado al cargar `PreciosUnitarios` desde assets versionados de Vite después de un despliegue.

## Diagnóstico
- El módulo `PreciosUnitarios` existe y compila correctamente.
- No se detectó Service Worker ni PWA activa en el frontend.
- El fallo corresponde a una referencia de chunk obsoleta en navegador o CDN: el cliente intenta cargar un archivo `assets/PreciosUnitarios-*.js` que ya no coincide con el build disponible.

## Cambios
- Se agregó `lazyImportRecovery.js` para encapsular los imports dinámicos de rutas.
- El helper reintenta una vez la importación y, si el fallo corresponde a chunk obsoleto, recarga la página una sola vez por URL para solicitar el `index` actualizado.
- `AppRouter.jsx` usa `lazyWithChunkRecovery` para las rutas lazy clásicas afectables, manteniendo rutas, permisos y layouts intactos.

## No Interferencia BIM
- No se modifica ninguna API, modelo, feature flag ni UX BIM.
- La ruta BIM preexistente conserva su `React.lazy` original para no alterar su comportamiento en este slice clásico.

## Validación
- `eslint` enfocado sobre `AppRouter.jsx` y `lazyImportRecovery.js` ejecutado sin errores.
- `npm run build` en `frontend` ejecutado correctamente.
