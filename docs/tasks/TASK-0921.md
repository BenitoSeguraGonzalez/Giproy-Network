# TASK-0921 - Contrato De Calendario Laboral Para Gantt

## Modo
GIPROY CLASICO

## Objetivo
Extender el contrato clásico de `cronogramas-trabajo` para aceptar `dias_laborables_semana` junto a `jornada_laboral_horas`, manteniendo compatibilidad con `dias_laborables_mes`.

## Plan
- Agregar `dias_laborables_semana` al schema `CronogramaTrabajoConfig`.
- Derivar `dias_laborables_mes` desde `dias_laborables_semana * dias_mes / 7` cuando el nuevo campo esté presente.
- Mantener lectura de cronogramas existentes que solo tienen `dias_laborables_mes`.
- Actualizar la exportación MS Project para calcular `MinutesPerWeek` con días laborables por semana.

## Cambios
- `CronogramaTrabajoConfig` añade `dias_laborables_semana`.
- `_resolve_config` normaliza configuraciones antiguas y nuevas.
- La exportación XML usa `jornada_laboral_horas * dias_laborables_semana`.

## No Interferencia BIM
- No se modifica ninguna ruta, API, modelo ni componente BIM.
- El cambio se limita al contrato clásico de `cronogramas-trabajo`.

## Validación
- `python -m py_compile` sobre schema y servicio de cronograma de trabajo ejecutado correctamente.
