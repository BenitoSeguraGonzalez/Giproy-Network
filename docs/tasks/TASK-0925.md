# TASK-0925 - Fijar Datos Base, Paneo Libre Y Buscador Incremental Del Gantt

## Modo
GIPROY CLASICO

## Objetivo
Mejorar la operativa de la vista oficial `Gantt` para que el desplazamiento horizontal no oculte los datos base de cada fila, el área gráfica permita paneo libre tipo lienzo y la búsqueda incremental siga el patrón ya usado en el creador de presupuesto.

## Plan De Adecuación
- Fijar las columnas base de fila (`Item`, `Descripción`, `Inicio`, `Dur.`, `% Av.`, `Cuad.`, `Predec. / Suc.`, `Guardar`) mediante un subgrid sticky.
- Mantener el desplazamiento horizontal visible sobre la zona gráfica del timeline sin arrastrar visualmente los datos base.
- Añadir paneo libre con arrastre sobre espacios vacíos del timeline.
- Añadir paneo con `Espacio + arrastre`, evitando capturar inputs, botones y barras.
- Reemplazar el filtro simple por un buscador incremental tipo `Presupuesto`, usando `ClearSearchField` y normalización compartida (`normalizeSearch`) para navegar por línea de presupuesto y EDT constitutiva sin ocultar filas.
- Añadir navegación incremental de coincidencias con contador y resaltado naranja institucional.

## Cambios
- `CronogramaGantt` separa visualmente datos base y zona gráfica usando constantes de grid y un bloque sticky.
- El layout de filas pasa a un carril `flex` con ancho explícito para que el bloque base completo permanezca visible durante el scroll horizontal, no solo la última columna.
- El bloque sticky de datos base usa fondos opacos y una capa superior para impedir que barras, guías o controles del timeline se vean por debajo al desplazar horizontalmente.
- La normalización de fechas ISO locales evita que el arrastre y soltado guarde la tarea en el día anterior por conversión UTC del navegador.
- El servicio común de `cronogramas-trabajo` aplica la `duration` manual guardada al reconstruir `dias_utiles` y `dias_calendario`, evitando que el Gantt vuelva visualmente a la duración calculada original tras guardar.
- La descripción truncada de cada fila muestra la descripción completa mediante el tooltip de la aplicación, y las columnas `Inicio` y `Dur.` ganan el ancho mínimo necesario para mostrar año y duraciones con decimales.
- La validación de predecesoras normaliza los identificadores de fila (`budget_line_id`, `presupuesto_linea_id`, `linea_id`) para que los enlaces creados entre barras del Gantt se guarden contra partidas reales y no disparen falsos `No existen en este presupuesto`.
- Los enlaces de predecesoras se vuelven seleccionables en el timeline: las líneas se muestran como flechas naranjas con sentido de relación y, al seleccionar una, se mantiene el naranja institucional y aparece una acción `X` también en naranja para romper la dependencia, limpiando la predecesora y guardando la fila afectada.
- Al mover una tarea predecesora o ajustar su fin, las sucesoras directas e indirectas se desplazan en sincronía mediante borradores locales, conservando el desfase existente y sin mover predecesoras hacia atrás desde una sucesora.
- Se integra el indicador `Suc.` dentro de `Predec.` como lectura derivada desde las predecesoras actuales y los borradores locales, sin duplicar persistencia ni ensanchar el bloque fijo; permite ver sucesoras, consultar tooltip con código/descripción y navegar al primer enlace sucesor.
- El bloque fijo vuelve a su ancho controlado para reparar el header de datos base y evitar que las barras o enlaces del timeline aparezcan por debajo de la información base.
- La relación `Dur.` / `Cuad.` se calcula como esfuerzo inverso: aumentar duración reduce cuadrilla y aumentar cuadrilla reduce duración, considerando días laborables y horas laborables configuradas como factor efectivo.
- Se añade acción `Restaurar` para descartar borradores locales, enlaces seleccionados, búsqueda, zoom, escala y configuración no guardada del Gantt, volviendo al estado cargado desde backend.
- El botón `Reporte` de `Cronogramas` queda enlazado y activo contra el reporte real de `Cronograma Valorado`, usando el carril común `reporting` con preview, Excel, PDF y PDF desde Excel.
- Al crear un enlace desde barra, si la sucesora empieza antes o el mismo día en que termina la predecesora, el Gantt la alinea automáticamente a una relación fin-a-inicio para evitar líneas que vuelvan visualmente hacia atrás.
- El render de enlaces descarta relaciones invertidas por secuencia visible para no dibujar dependencias gráficamente contradictorias.
- El viewport del Gantt permite paneo con cursor `grab/grabbing` sobre espacios vacíos y con la tecla `Espacio` mantenida.
- El buscador del Gantt reutiliza `ClearSearchField`, ignora acentos y valores nulos textuales, mantiene todas las filas visibles y permite saltar a la siguiente coincidencia con contador `x/y`, siguiendo el patrón del buscador de líneas de presupuesto.
- Las coincidencias se resaltan con naranja institucional `#F39200`.
