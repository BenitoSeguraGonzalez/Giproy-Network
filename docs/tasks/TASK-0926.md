# TASK-0926 - Saneamiento Visual De Conectores Y Escala Del Gantt

## Modo
GIPROY CLASICO

## Objetivo
Sanear la representación gráfica del Gantt oficial para que los conectores de predecesoras/sucesoras no pasen por encima de las barras, el bloque de datos base no muestre artefactos por transparencia y la posición temporal relativa se conserve al cambiar de escala.

## Plan De Adecuación
- Recalcular los conectores con puntos de salida y entrada exteriores a las barras.
- Sustituir el cálculo horizontal de conectores basado en DOM por cálculo desde la geometría matemática de barras.
- Añadir carril de escape cuando el enlace no tenga espacio horizontal suficiente, evitando que el trazado atraviese la barra destino.
- Reducir el tamaño de la punta de flecha y mantener el naranja institucional `#F39200` como color único de relación.
- Elevar y opacar completamente el bloque sticky de datos base y su header para que el timeline no se vea por debajo.
- Conservar una fecha ancla visible al cambiar escala o zoom para evitar saltos entre `Día`, `Semana`, `Mes`, `Semestre` y `Anual`.
- Revisar la anchura real de columnas base, especialmente `Guardar`, para que sus iconos no desborden hacia el timeline.
- Separar el canvas SVG de dependencias del canvas completo: las líneas deben vivir solo en la zona gráfica y no poder invadir `Item/Descripción/Inicio/Dur./% Av./Cuad./Predec./Guardar`.

## Cambios
- `CronogramaGantt` añade constantes de separación para conectores y carriles de escape.
- Las dependencias se dibujan desde fuera de la barra origen hacia fuera de la barra destino.
- La posición horizontal de cada conector se deriva de `buildBarGeometry` y `getBarVisualGeometry`, no de `getBoundingClientRect()` de las barras; el DOM se usa solo para la coordenada vertical de la fila.
- Si las barras quedan solapadas o sin espacio horizontal, el conector usa un carril vertical/horizontal externo para no cruzar la barra.
- Las flechas SVG pasan a un marcador más discreto y con trazo naranja institucional.
- La cabecera y el bloque de datos base usan capas más altas, fondo opaco e aislamiento del viewport para ocultar artefactos del timeline.
- El cambio de escala/zoom captura la fecha visible en el centro del área gráfica y restaura el scroll horizontal tras recalcular segmentos.
- El bloque base amplía la columna `Guardar` y actualiza el ancho total fijo para que los botones `Deshacer` y `Guardar` no salgan de su celda ni pisen el timeline.
- El SVG de dependencias queda anclado y recortado a partir del inicio real del timeline; sus coordenadas horizontales pasan a ser relativas al área gráfica.
- Las capas sticky de header y filas base suben de z-index y usan `overflow-hidden` para contener sus controles y tapar cualquier gráfico que pase por debajo durante el scroll horizontal.
