# TASK-0929 - UX De Dependencias Ricas En Gantt

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Permitir editar dependencias con tipo y desfase desde la vista Gantt, manteniendo la experiencia visual clásica.

## Alcance
- Panel de edición de dependencia seleccionada.
- Selector de tipo `Fin-Inicio`, `Inicio-Inicio`, `Fin-Fin`, `Inicio-Fin`.
- Campo de desfase/lag en días.
- Visualización de tipo y lag en tooltip del conector.
- Acción explícita para romper enlace.

## Criterio De Aceptación
- Crear enlace visual genera dependencia `FS + 0d` por defecto.
- Editar el enlace no rompe el guardado actual.
- El usuario puede ver y modificar tipo/lag sin tocar BIM.

## Implementación
- `CronogramaGantt` normaliza dependencias ricas desde `dependencies` y conserva compatibilidad con `predecessors`.
- El enlace visual entre barras crea `FS + 0d` por defecto y lo guarda junto a la lista legacy.
- El asistente de predecesoras, edición textual y ruptura de enlaces sincronizan `dependencies` para no perder metadatos de tipo/lag.
- El conector seleccionado abre un panel contextual con selector `Fin-Inicio`, `Inicio-Inicio`, `Fin-Fin`, `Inicio-Fin` y campo `Lag días`.
- El guardado de `Cronogramas` envía `dependencies` al backend común de `cronogramas-trabajo`.
