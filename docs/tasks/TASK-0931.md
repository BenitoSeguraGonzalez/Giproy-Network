# TASK-0931 - Calendarios Laborales Efectivos

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Formalizar el calendario laboral como base de cálculo para duración, lag y exportación MS Project.

## Alcance
- Consolidar días laborables por semana y horas laborables por día.
- Evaluar calendario por proyecto y posible override por tarea.
- Convertir duración/lag a días efectivos.
- Exportar calendario coherente hacia MS Project XML.

## Criterio De Aceptación
- Cambiar calendario afecta cálculos de duración y dependencia de forma predecible.
- La exportación XML conserva el calendario operativo.

## Implementación
- `CronogramaGantt` consolida helpers de calendario laboral efectivo:
  - normalización de días laborables por semana.
  - detección de días laborables `lunes -> n`.
  - desplazamiento de fechas por días laborables, no por días calendario lineales.
  - cálculo de fin inclusivo según duración efectiva.
- La cascada de dependencias `FS/SS/FF/SF` usa el calendario laboral configurado para:
  - duración de predecesoras.
  - lag positivo/negativo.
  - lag horario convertido por jornada laboral.
  - snap de inicio en días laborables.
- El drag/resize del Gantt usa el mismo calendario para preview y borradores.
- La exportación MS Project XML añade un calendario base `GiProy Calendario Laboral` con:
  - `MinutesPerDay`.
  - `MinutesPerWeek`.
  - `DaysPerMonth`.
  - días laborables por semana.
  - tramo horario continuo desde `08:00` según jornada configurada.
  - `CalendarUID` aplicado a tareas.
