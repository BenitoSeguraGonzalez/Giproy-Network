# TASK-0932 - Ruta Critica, Holguras E Hitos

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Añadir capacidades de planificación profesional al Gantt clásico.

## Alcance
- Calcular ruta crítica.
- Calcular holgura total y libre.
- Soportar hitos con duración cero o marca específica.
- Diferenciar visualmente tareas críticas e hitos.

## Criterio De Aceptación
- El Gantt identifica tareas críticas sin cambiar backend BIM.
- Los hitos se renderizan de forma distinta y exportan a MS Project XML.

## Implementación
- `CronogramaGantt` calcula una red local de planificación desde filas calculables, borradores y dependencias normalizadas `FS/SS/FF/SF`.
- La red calcula holgura total y holgura libre por tarea, usando días laborables efectivos de la configuración vigente.
- Las tareas con holgura total `0` se marcan como críticas con badge y realce naranja institucional.
- Las tareas con duración `0` se interpretan como hitos y se renderizan como rombo naranja, conservando capacidad de enlace.
- El backend común de `cronogramas-trabajo` acepta duración manual `0` y el XML MS Project exporta `Milestone = 1` para tareas no resumen de duración cero.
