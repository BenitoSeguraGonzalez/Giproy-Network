# TASK-0933 - Linea Base Y Comparativo Gantt

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Permitir guardar una línea base y comparar el plan actual contra el plan aprobado.

## Alcance
- Guardar baseline de fechas/duraciones.
- Mostrar desviación visual en Gantt.
- Reportar diferencias principales.
- Evitar sobrescritura accidental de baseline.

## Criterio De Aceptación
- El usuario puede crear/restaurar/ver baseline.
- El Gantt muestra diferencias sin modificar el cronograma actual.

## Implementación
- Se expone `metadata` en las filas computadas de `cronogramas-trabajo` para reutilizar el JSON existente sin migración.
- El Gantt clásico guarda una línea base por partida en `metadata.gantt_baseline_v1`.
- La línea base captura inicio, fin, duración, progreso, cuadrilla y dependencias formales.
- Se añade panel `Línea base` para crear/actualizar, mostrar/ocultar comparación y restaurar como borrador local.
- La comparación visual se pinta como barra/rombo fantasma naranja institucional y badge `LB` con desviación.
- La restauración no sobrescribe el cronograma automáticamente; deja borradores para revisión y guardado explícito.
