## Objetivo
Completar interoperabilidad con Microsoft Project mediante XML rico e integración asistida con Project Bridge.

## Alcance
- Exportar dependencias ricas `FS/SS/FF/SF + lag`.
- Exportar calendarios, recursos y assignments.
- Importar XML MS Project para actualizar cronograma con validación.
- Consolidar mensajes de límite para `.mpp`.

## Criterio De Aceptación
- XML abre en Microsoft Project con dependencias y calendario coherentes.
- GiProy puede reimportar XML controlado sin perder presupuesto/APU.

## Implementación Slice 1
- Se enriquece el XML MSPDI de `Cronograma de Trabajo` con:
  - `LinkLag` y `LagFormat` para dependencias `FS/SS/FF/SF + lag`.
  - `Resources` derivados de recursos reales del APU.
  - `Assignments` por tarea/recurso con `Units` y `Work`.
- Se mantiene el calendario laboral `GiProy Calendario Laboral` ya existente.
- No se modifica la UX ni el Project Bridge en este slice.
- No se añade importación todavía: queda como Slice 2 para incorporar mapeo controlado, validación y UI de carga sin riesgo de romper presupuesto/APU.

## Implementación Slice 2
- Se añade identificador estable `Text1 = line-{presupuesto_linea_id}` al XML MSPDI exportado para poder reimportar sin depender solo del texto visible.
- Se incorpora importación XML controlada en backend común:
  - Lee tareas no resumen del XML MSPDI.
  - Mapea contra líneas calculables del presupuesto por `Text1`, `Text2`, `OutlineNumber` o fallback de notas `line-{id}`.
  - Actualiza únicamente `start_date`, `end_date`, `duration`, `progress_pct`, `predecessors`, `dependencies` y metadata de importación.
  - No modifica presupuesto, EDT, APUs, recursos ni assignments.
  - Convierte `PredecessorLink` de Microsoft Project a dependencias GiProy `FS/SS/FF/SF + lag_days`.
- Se expone `POST /cronogramas-trabajo/{presupuesto_id}/import/ms-project` con permisos de edición, licencia comercial y auditoría.
- Se añade botón `Importar XML` en `Proyecto > Cronogramas > Cronograma de Trabajo`, con confirmación previa y subida segura de `.xml`.
- El Project Bridge no cambia en este slice: se mantiene para apertura local/exportación asistida.
