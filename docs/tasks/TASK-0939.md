# TASK-0939 - Contrato de media para Datos de Proyecto

## Modo

GIPROY CLASICO

## Objetivo

Corregir de forma estructural la carga de la imagen referencial en `Proyecto > Datos de Proyecto`.

## Diagnóstico

La imagen referencial se guardaba como `/uploads/proyectos/...`, pero el frontend la resolvía contra `/api/v1/proyecto-detalles/image-proxy`. Esa ruta podía colisionar con el endpoint dinámico `/{codigo_root}`.

## Implementación

- Se añade `/api/v1/proyecto-detalles/media/image-proxy`.
- Se conserva la ruta anterior como compatibilidad.
- El resolvedor frontend `resolveMediaUrl` usa la nueva ruta estable.
- El backend resuelve uploads tanto desde repo raíz como desde `backend`.

## No interferencia BIM

No se toca BIM, rutas BIM, flags BIM ni UX BIM.

Completada.
