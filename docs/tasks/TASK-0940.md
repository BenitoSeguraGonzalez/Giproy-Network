# TASK-0940 - Media visual en reportes de Datos de Proyecto

## Modo

GIPROY CLASICO

## Objetivo

Garantizar que los reportes de datos del proyecto incluyan imagen referencial y georreferenciación.

## Diagnóstico

El reporte `acta_constitucion` ya tenía placeholders para `#IMAGENPROYECTO` y `#GEOREFERENCIACION`, pero el mapa dependía de un proveedor externo de imagen estática. Si esa llamada fallaba, el bloque visual quedaba vacío.

## Implementación

- La imagen referencial se obtiene desde el upload local o desde URL remota si aplica.
- La georreferenciación intenta usar el mapa estático remoto y, si falla, genera una captura técnica local PNG con marcador y grilla.
- El preview usa una URL `data:image/png;base64` para que la georreferenciación no dependa de autenticación ni de proxy externo.
- La exportación Excel inserta la imagen referencial y la georreferenciación con los placeholders existentes.

## No interferencia BIM

No se toca BIM, rutas BIM, flags BIM ni UX BIM.
