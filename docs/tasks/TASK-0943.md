# TASK-0943 - Saneamiento PDF desde Excel de Stakeholders

## Estado
Completada - 2026-04-07

## Modo
GIPROY CLASICO

## Objetivo
Corregir la perdida visual de datos en el reporte `Equipo del Proyecto (Stakeholders)` cuando se exporta como `PDF desde Excel`.

## Diagnostico
El flujo de frontend usa correctamente `report_type = stakeholders` y `format = pdf_excel`.

La causa esta en la preparacion del Excel para conversion: la plantilla de Stakeholders usa columnas densas y filas con wrapping, pero el generador dejaba alturas de fila fijas. El conversor `PDF desde Excel` respeta esas alturas y recortaba datos largos como profesion/institucion, direccion, correo o rol.

## Cambios
- El reporte de Stakeholders ya prepara explicitamente su hoja antes de guardar:
  - orientacion horizontal;
  - area de impresion estable `A:L`;
  - filas de datos con altura calculada segun contenido;
  - wrapping vertical superior;
  - recorte de filas vacias posteriores para evitar paginas en blanco.
- Se conserva `profesion + institucion` cuando ambos datos existen.
- `ciudad` y `canton` se combinan cuando hay ambos.
- Los stakeholders sin rol muestran `Sin rol` en el reporte.

## Impacto GiProy Clasico
Afecta solo al reporte clasico de `Proyecto > Stakeholders`.

## No Interferencia BIM
No se tocan rutas BIM, UX BIM, feature flags BIM ni modelos BIM.

## Validacion

- Compilacion Python de reporting.
