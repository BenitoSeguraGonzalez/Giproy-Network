# TASK-0948 - Migración visible de Cronograma de Trabajo a Gantt operativo

Estado: Completada

Fecha: 2026-04-07

Modo: GIPROY CLASICO

## Objetivo

Eliminar la redundancia visual en `Proyecto > Cronogramas` para que la sección quede solo con `Cronograma Valorado` y `Cronograma Gantt`.

## Alcance

- Quitar la opción visible `Cronograma de Trabajo` del selector principal.
- Redirigir cualquier estado residual `trabajo` hacia `gantt`.
- Integrar en `CronogramaGantt` el resumen operativo que antes vivía en la vista intermedia.
- Integrar en `CronogramaGantt` los botones `MS Project`, `Importar XML` y `XML Project`.
- Mantener el backend común `cronogramas-trabajo` como motor interno para no romper persistencia ni MS Project.

## Resultado

- El selector de cronogramas expone solo `Valorado` y `Gantt`.
- El Gantt queda como superficie operativa única para el cronograma de trabajo.
- La exportación local usa nombres visibles `Cronograma_Gantt_*`.
- No se cambia el contrato backend ni se toca BIM.

## Validación prevista

- ESLint enfocado en `Cronogramas.jsx` y `CronogramaGantt.jsx`.
- Build frontend.
- JSON de estado.
- Búsqueda de no interferencia BIM.
