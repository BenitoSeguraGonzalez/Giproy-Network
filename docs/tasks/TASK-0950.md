# TASK-0950 - Contrato Integral Gantt, Valorado Y Caja

## Modo
GIPROY CLASICO

## Estado
Completada - Planificación

## Objetivo
Fijar el contrato funcional aprobado para que `Gantt`, `Cronograma Valorado` y `Flujo de Caja` queden interconectados sin crear ciclos de actualización ni dependencias BIM.

## Decisión
El flujo dominante queda:

```text
Presupuesto / APU -> Gantt operativo -> Cronograma Valorado -> Flujo de Caja
```

La sincronización queda:

```text
Gantt <-> Cronograma Valorado <-> Flujo de Caja
```

## Reglas
- `Gantt` es fuente temporal: fechas, dependencias, hitos, calendario y recursos/asignaciones.
- `Cronograma Valorado` deriva cantidades y costos por periodo desde el Gantt.
- `Flujo de Caja` deriva costos por periodo y acumulados desde el valorado y las asignaciones.
- Cambios desde `Valorado` hacia `Gantt` se tratan como override o propuesta de reprogramación.
- Cambios desde `Caja` hacia `Valorado/Gantt` se tratan como restricción financiera y requieren reconciliación explícita.
- La relación `duración <-> cuadrilla <-> rendimiento` deja de ser motor dominante y queda como cálculo auxiliar de recursos/APU.

- No se modifican rutas, componentes, feature flags ni UX BIM.
- La integración queda en GiProy Clásico y backend común.
