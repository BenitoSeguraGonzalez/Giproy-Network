# TASK-0951 - Motor De Periodización Gantt A Cronograma Valorado

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Implementar el motor que derive `Cronograma Valorado` desde el `Gantt` usando solape temporal de tareas contra periodos.

## Alcance
- Calcular periodos desde la configuración de cronograma valorado.
- Para cada tarea/línea Gantt, calcular solape efectivo con cada periodo.
- Distribuir cantidad y costo por periodo según solape temporal.
- Recalcular totales por EDT/padres mediante rollup.
- Mantener compatibilidad con distribuciones manuales existentes mediante overrides trazables.

## Implementación Slice 1
- Se añade `distribution_mode = "gantt"` al contrato de `Cronograma Valorado`.
- El backend calcula la distribución de cada línea por solape de fechas del Gantt contra los periodos valorados.
- Si una tarea no solapa ningún periodo, se asigna al periodo contenedor o al extremo más cercano.
- Si una tarea es hito o duración cero, se asigna al periodo que contiene su fecha.
- Los overrides manuales por línea se respetan y siguen teniendo prioridad sobre la derivación desde Gantt.
- El frontend añade la opción `% Ejecución global = Desde Gantt` sin eliminar los modos `Homogéneo` ni `Definido por usuario`.
- El modo queda opt-in para no cambiar cronogramas existentes en silencio.

## Criterios De Aceptación
- Cambiar fechas o duración en Gantt puede regenerar la distribución valorada al aplicar modo `Desde Gantt`.
- El valorado conserva totales contra presupuesto.
- El usuario puede distinguir distribución derivada de override manual.
- No se rompe el guardado optimista actual de porcentajes.
