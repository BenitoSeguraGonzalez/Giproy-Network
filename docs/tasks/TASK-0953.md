# TASK-0953 - UX De Sincronización, Overrides Y Reconciliación

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Crear la experiencia visible para sincronizar `Gantt <-> Valorado <-> Caja` sin cambios silenciosos ni pérdida de control del usuario.

## Alcance
- Indicador de estado: sincronizado, pendiente de recalculo, override manual o conflicto.
- Acción `Recalcular desde Gantt` en Cronograma Valorado.
- Acción `Recalcular Caja` desde Valorado/Gantt.
- Vista de diferencias antes de aplicar reconciliación.
- Confirmación explícita cuando un ajuste inverso proponga mover fechas del Gantt.

## Implementación Slice 1
- `Cronograma Valorado` muestra estado visible de sincronización:
  - `Sincronizado desde Gantt`.
  - `Override manual`.
  - `Pendiente de aplicar`.
  - `Modo valorado`.
- Se añade acción `Recalcular desde Gantt` con confirmación explícita.
- Esta acción cambia a modo `gantt`, limpia overrides manuales y recalcula Valorado/Caja desde fechas Gantt sin mover el Gantt.
- Se añade acción `Recalcular Caja`, que refresca la lectura desde el Valorado vigente sin mutar fechas ni dependencias.
- Se mantiene bloqueada la bidireccionalidad inversa automática `Caja -> Valorado/Gantt`.

## Criterios De Aceptación
- Ningún cambio inverso pisa el Gantt sin confirmación.
- Los overrides quedan visibles y trazables.
- La UI evita duplicar controles o reintroducir `Cronograma de Trabajo` como vista separada.
