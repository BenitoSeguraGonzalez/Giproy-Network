# TASK-0958 - Diagnóstico De Restricción Financiera En Caja

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Avanzar la bidireccionalidad controlada `Gantt <-> Cronograma Valorado <-> Flujo de Caja` mostrando una lectura financiera de Caja sin permitir mutaciones inversas automáticas sobre Gantt o Valorado.

## Alcance
- Calcular una desviación de referencia en `Flujo caja`.
- Usar una curva lineal acumulada como baseline financiera simple.
- Mostrar el periodo con mayor desviación, dirección e impacto estimado.
- Mantener el resultado como diagnóstico, no como edición inversa.

## Implementación Slice 1
- La pestaña `Flujo caja` incorpora una banda `Lectura de restricción financiera`.
- La UI identifica si la caja está adelantada, retrasada o alineada frente a una referencia lineal acumulada.
- Se muestra el impacto estimado asociado a la mayor desviación.
- Se deja explícito que el diagnóstico no reprograma `Gantt` ni redistribuye `Cronograma Valorado` sin propuesta y confirmación futura.

## Criterios De Aceptación
- El usuario puede detectar concentraciones financieras relevantes sin editar datos.
- No hay cambios silenciosos en fechas, dependencias, recursos, Valorado o Caja.
- La funcionalidad prepara la futura reconciliación inversa `Caja -> Valorado/Gantt`.
