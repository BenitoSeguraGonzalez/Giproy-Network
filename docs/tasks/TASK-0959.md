# TASK-0959 - Propuesta Inversa Controlada Desde Caja

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Convertir el diagnóstico financiero de `Flujo de Caja` en una propuesta explícita de ajuste inverso, sin aplicar cambios automáticos sobre `Cronograma Valorado` ni `Gantt`.

## Alcance
- Mostrar una acción visible `Ver propuesta` desde la lectura de restricción financiera.
- Explicar la mayor desviación de caja, impacto estimado y sentido de la recomendación.
- Mantener el flujo como lectura/propuesta, no como mutación.

## Implementación Slice 1
- `Flujo caja` añade una acción `Ver propuesta`.
- La propuesta se muestra en un diálogo de la aplicación con:
  - periodo de mayor desviación;
  - dirección financiera (`adelantada`, `retrasada` o `alineada`);
  - impacto estimado;
  - recomendación conceptual para una futura reconciliación.
- La acción no llama backend, no guarda, no mueve fechas, no cambia distribuciones y no toca recursos.

## Criterios De Aceptación
- El usuario puede entender qué debería evaluarse si desea ajustar Caja contra Valorado/Gantt.
- La aplicación no aplica cambios silenciosos desde Caja.
- El flujo prepara la futura fase de diff/aplicación confirmada.
