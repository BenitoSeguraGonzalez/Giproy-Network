# TASK-0960 - Diff De Propuesta Financiera Desde Caja

## Modo
GIPROY CLASICO

## Estado

## Objetivo
Hacer más operativa la propuesta inversa desde `Flujo de Caja`, mostrando un diff de periodos antes de cualquier fase futura de aplicación controlada.

## Alcance
- Calcular los periodos con mayor desviación frente a la referencia financiera lineal.
- Mostrar el acumulado real, acumulado esperado, dirección de desviación e impacto estimado.
- Mantener la propuesta como lectura segura, sin mutar `Gantt`, `Cronograma Valorado` ni `Flujo de Caja`.

## Implementación Slice 1
- `Ver propuesta` ahora incluye un bloque `Diff de propuesta`.
- El diff lista hasta tres periodos con mayor desviación.
- Para cada periodo se muestra:
  - porcentaje real acumulado;
  - porcentaje de referencia acumulado;
  - dirección y magnitud de desviación;
  - impacto financiero estimado.
- La acción no llama backend ni aplica cambios.

## Criterios De Aceptación
- El usuario puede ver qué periodos explican la presión financiera.
- El diff prepara una futura confirmación aplicable sin introducir cambios silenciosos.
- No se modifica el contrato de API ni se toca backend.
