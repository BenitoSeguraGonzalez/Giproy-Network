# TASK-0961 - Borrador Aplicable De Propuesta Financiera

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Convertir la lectura financiera de `Flujo de Caja` en un primer borrador aplicable y controlado sobre `Cronograma Valorado`, sin mutar `Gantt` ni guardar cambios silenciosos.

## Alcance
- Añadir una acción explícita para preparar un borrador desde la restricción financiera.
- Usar una distribución lineal de referencia como primera propuesta segura.
- Cambiar solo el estado visible de configuración a `Definido por usuario`.
- Exigir que el usuario revise y pulse `Aplicar configuración` para persistir.

## Implementación Slice 1
- Se añade `Preparar borrador` junto a `Ver propuesta` en la pestaña `Flujo caja`.
- La acción exige confirmación previa.
- Si hay cambio de tipo de periodo pendiente, bloquea la preparación.
- Si la caja está alineada, informa y no genera borrador.
- El borrador no llama backend, no guarda y no mueve fechas del Gantt.
- El borrador carga una distribución lineal balanceada en `globalDistribution` y cambia la configuración visible a `usuario`.

## Criterios De Aceptación
- El usuario puede pasar de diagnóstico financiero a borrador revisable.
- El sistema evita cambios automáticos en `Gantt`, `Cronograma Valorado` y `Flujo de Caja`.
- La persistencia sigue dependiendo de `Aplicar configuración`.
