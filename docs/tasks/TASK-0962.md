# TASK-0962 - Diff Previo De Borrador Financiero

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Endurecer el paso `Caja -> Valorado` mostrando el impacto del borrador antes de cargarlo en configuración visible.

## Alcance
- Calcular la distribución actual de Caja por periodo.
- Compararla contra la distribución lineal de referencia que usará el borrador.
- Mostrar los principales periodos afectados antes de preparar el borrador.
- Mantener la acción sin guardado automático y sin modificar `Gantt`.

## Implementación Slice 1
- `Preparar borrador` muestra ahora un diff `actual -> propuesta`.
- El diff incluye hasta tres periodos con mayor cambio.
- Para cada periodo indica si se debe `incrementar` o `reducir`, porcentaje actual, porcentaje objetivo e impacto estimado.
- La acción sigue cargando solo un borrador local en `Definido por usuario`.
- La persistencia sigue dependiendo de `Aplicar configuración`.

## Criterios De Aceptación
- El usuario ve el impacto del borrador antes de cargarlo.
- El borrador no se guarda ni reprograma Gantt automáticamente.
- No se introduce contrato nuevo de API.
