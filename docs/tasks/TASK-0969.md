# TASK-0969 - Contrato De Gobierno Gantt A Presupuesto APU

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Formalizar la política funcional entre programación Gantt y lógica productiva del Presupuesto/APU.

## Política Aprobada
- Cambio de fecha/momento = solo programación.
- Cambio de duración = solo mediante editor de recursos/rendimientos.
- Reconciliación con Presupuesto/APU operativo = solo con aprobación explícita del usuario.
- Persistencia definitiva del cronograma = solo con aprobación explícita del usuario.
- Debe existir `undo` al último cronograma confirmado.
- Si Presupuesto cambia cantidades o rendimientos, Gantt debe reflejarlo automáticamente, salvo conflicto con borrador abierto.

## Implementación Slice 1
- Se integra esta política al plan maestro del Gantt.
- Se fija como contrato rector para slices posteriores de frontend, backend y QA.

## No Interferencia BIM
