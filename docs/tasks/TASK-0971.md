# TASK-0971 - Restricción Frontend De Duración Y Guía A Editor De Recursos

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 2

## Objetivo
Llevar al frontend del Gantt la política obligatoria de que la duración no se edita directamente, sino mediante recursos/rendimientos.

## Implementación Slice 1
- Bloquear edición directa del campo `Dur.` en la vista Gantt.
- Desactivar resize de barras que altere duración.
- Mantener permitido mover tareas, dependencias y secuencia temporal.
- Añadir guía visible hacia el editor de recursos/APU operativo como siguiente paso funcional.

## Implementación Slice 2
- Bloquear también la edición directa de `Cuad.`/recursos asumidos como control libre en la fila Gantt.
- Mostrar el valor solo como lectura derivada y guiar al usuario al futuro editor de recursos/rendimientos.
- Añadir estados visuales de gobierno por fila:
  - `Sincronizado`
  - `Programación ajustada`
  - `Pendiente APU`
  - `En tanteo`

## Criterios De Aceptación
- El usuario ya no puede cambiar duración editando `Dur.` ni redimensionando barras.
- El usuario ya no puede alterar recursos asumidos desde el input directo de fila.
- El sistema explica que la duración deriva del rendimiento operativo.
- Cada fila calculable deja visible su estado de gobierno sin tocar todavía la persistencia aprobada.
- No se rompe el guardado de programación temporal existente.

## No Interferencia BIM
- Sin cambios en rutas, modelos, flags, componentes ni UX BIM.
