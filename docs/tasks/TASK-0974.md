# TASK-0974 - Sincronización Automática Presupuesto A Gantt

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Reflejar automáticamente en Gantt los cambios de cantidad o rendimiento realizados en Presupuesto/APU operativo.

## Alcance
- Recalcular duración derivada.
- Ajustar fin previsto.
- Propagar a Valorado y Caja.
- Detectar conflicto si existe borrador Gantt abierto.

## No Interferencia BIM
- Sin cambios en rutas, modelos, flags, componentes ni UX BIM.

## Implementado
- Evento frontend `Presupuesto/APU -> Gantt` cuando se guardan cambios productivos en el editor APU de presupuesto.
- Recarga automática de `Presupuesto detalle`, `Cronograma Valorado` y `Cronograma Gantt` cuando no hay tanteo abierto.
- Guardarraíl de conflicto: si el usuario tiene borradores o aprobaciones pendientes en Gantt, no se pisa el estado local y se muestra aviso explícito.
- Acción manual `Recalcular desde presupuesto` para resolver el conflicto sin tocar BIM ni crear backend nuevo.
