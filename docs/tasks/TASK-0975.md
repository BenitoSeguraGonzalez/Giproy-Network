# TASK-0975 - Resolución De Conflictos Entre Borrador Gantt Y Cambios De Presupuesto

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Resolver explícitamente el conflicto cuando Presupuesto cambie la duración derivada mientras existe un borrador Gantt pendiente, y añadir comparación previa antes de aprobar el cronograma.

## Alcance
- Comparar cambios.
- Permitir recalcular desde presupuesto.
- Permitir mantener borrador y revisar.
- Evitar pisado silencioso.
- Mostrar diff previo antes de confirmar el cronograma actual.

## No Interferencia BIM
- Sin cambios en rutas, modelos, flags, componentes ni UX BIM.

## Implementado
- Comparativa previa antes de `Confirmar cronograma`, contra el último snapshot confirmado disponible por línea.
- Comparativa explícita de conflicto `Presupuesto -> Gantt` antes de `Recalcular desde presupuesto`.
- Resumen visible por partidas afectadas, variación de duración, recursos y dependencias.
- Confirmación ya no ciega: el usuario revisa el diff y luego decide si confirma o si mantiene el tanteo.
