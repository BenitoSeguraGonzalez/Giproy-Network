# TASK-0985 - UI Del Editor Ligero De Rendimientos

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 3

## Objetivo
Crear la UI ligera de recursos/rendimientos desde Gantt, sin reutilizar el editor completo del APU.

## Alcance
- Modal propio del Gantt.
- Solo recursos/rendimiento operativo.
- Métricas visibles de cantidad, trabajo útil, duración y jornada.

## Implementación Slice 1
- Se añade `GanttResourceEditorModal` dentro del Gantt clásico.
- El modal expone solo información operativa mínima y el ajuste de `recursos operativos`.
- La apertura reemplaza el alert genérico al intentar cambiar duración.

## Implementación Slice 2
- El modal se remaqueta para operación rápida:
  - menos texto explicativo;
  - menor peso tipográfico;
  - edición de recursos y resultado visible en el mismo primer pliegue;
  - preview de impacto `Valorado / Caja` sin obligar a scroll largo.
- El panel pasa a priorizar:
  - recurso editable;
  - duración resultante;
  - rendimiento operativo;
  - jornada;
  - acciones.

## Implementación Slice 3
- El modal se simplifica de forma más agresiva para dejarlo realmente operativo:
  - se eliminan bloques narrativos de `gobierno`, `persistencia` y `estado de trabajo`;
  - `Cantidad`, `Trabajo útil`, `Recursos`, `Duración`, `Rendimiento` y `Jornada` quedan en el primer foco visual;
  - `Valorado / Caja` pasa a un bloque colapsable secundario;
  - el desglose técnico y las acciones quedan compactos, sin competir con la edición principal.

## No Interferencia BIM
- Sin cambios en rutas, modelos, flags, componentes ni UX BIM.
