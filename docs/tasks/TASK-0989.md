# TASK-0989 - QA Del Editor Ligero De Rendimientos

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Validar que el editor ligero solo gobierna rendimiento operativo, no el APU maestro, y que recalcula el Gantt en tiempo real sin romper otras funciones.

## Implementación
- El editor ligero explicita en UI que:
  - no modifica el APU maestro;
  - trabaja sobre borrador operativo;
  - la aprobación final sigue pendiente.
- El guardado de borrador devuelve feedback de éxito y mantiene la fila marcada como `Pendiente APU`.
- Se refuerza el guardarraíl de uso para evitar lecturas ambiguas entre catálogo maestro y cronograma operativo.

## No Interferencia BIM
