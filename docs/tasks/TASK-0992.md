# TASK-0992 - Historial De Versiones Confirmadas Del Cronograma

## Modo
GIPROY CLASICO

## Estado
Completada - Slice 1

## Objetivo
Conservar más de un cronograma confirmado, con trazabilidad de usuario, fecha e impacto resumido.

## Implementación
- Cada confirmación del Gantt ahora añade un snapshot al historial persistido por línea en metadata.
- Las confirmaciones por lote comparten sello temporal para poder agruparse como versión operativa visible.
- El header del Gantt añade botón `Historial`.
- El panel de historial resume versiones confirmadas visibles con:
  - fecha;
  - hora;
  - cantidad de partidas;
  - duración agregada;
  - origen `Confirmado` o `Restaurado`.
- No se reabre backend ni se altera el flujo de aprobación ya estabilizado.
