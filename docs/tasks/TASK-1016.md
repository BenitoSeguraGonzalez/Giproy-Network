# TASK-1016 - Retirar Project Bridge Y Consolidar Fallback XML En Cronogramas Clásicos

## Estado

## Objetivo
Retirar el carril `Project Bridge` del módulo clásico de cronogramas y dejar como contrato operativo únicamente `.mpp` directo cuando el entorno lo soporte, o `XML` cuando no sea posible, incluyendo sistemas no Windows.

## Alcance
- Eliminar referencias activas a `Project Bridge` del frontend clásico de cronogramas.
- Retirar el endpoint backend accesorio del bridge.
- Alinear mensajes y fallback hacia `XML Project` en entornos no Windows o sin soporte `.mpp`.

## Criterios De Cumplimiento
- No quedan flujos activos de `Project Bridge` en `Cronogramas` ni `CronogramaGantt`.
- En sistemas no Windows el usuario ve y usa `XML Project` como fallback explícito.
- El CTA `MS Project` no intenta instalación, descarga ni apertura por bridge.
- No se toca BIM.

## No Interferencia BIM
- Sin cambios en rutas, flags, componentes ni UX BIM.

## Plan De Ajuste
1. Localizar referencias activas del bridge en frontend y backend clásico.

3. Reforzar mensajes de fallback hacia XML, especialmente en no Windows.
4. Validar que el frente clásico siga exportando `.mpp` o XML según capacidades reales.
