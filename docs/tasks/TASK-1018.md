# TASK-1018 - Rehacer Exportación Project Sin Dependencia De Microsoft Project

## Modo
GIPROY CLASICO

## Estado
Activa

## Objetivo
Restaurar una exportación estable hacia Microsoft Project desde el cronograma clásico sin depender de Microsoft Project desktop, COM, bridge local ni generación `.mpp` directa.

## Alcance
- Convertir el carril `MS Project` a exportación XML compatible generada completamente por GiProy.
- Eliminar la dependencia operativa con automatización de Microsoft Project para exportar.
- Alinear backend y frontend para que el botón `MS Project` descargue XML interoperable.
- Mantener `XML Project` como salida explícita del mismo carril interoperable.

## Criterios De Cumplimiento
- Exportar a `MS Project` no requiere Microsoft Project instalado.
- El backend no intenta crear `.mpp` mediante COM ni helpers externos.
- El archivo descargado es XML compatible con Microsoft Project.
- No se tocan rutas, flags, componentes ni UX BIM.

## No Interferencia BIM
- Sin cambios en BIM, feature flags BIM, rutas BIM, modelos BIM ni UX BIM.

## Plan De Ajuste
1. Auditar el carril actual de exportación y detectar dependencias vivas con `.mpp`.
2. Reforzar el backend para exportar solo XML compatible generado por GiProy.
3. Alinear el contrato frontend del botón `MS Project` al nuevo carril interoperable.
4. Validar el roundtrip XML ya cubierto por pruebas del servicio.
5. Documentar el cambio y su no interferencia BIM.
