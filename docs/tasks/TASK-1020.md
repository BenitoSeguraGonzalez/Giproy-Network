# TASK-1020 - Implementar Runner Java Privado Para Exportacion MPP

## Modo
GIPROY CLASICO

## Estado
Completada

## Objetivo
Implementar el runner Java interno que use `Aspose.Tasks for Java` para generar el `.mpp` del cronograma clasico a partir de configuracion privada del servidor y una plantilla `.mpp` semilla valida.

## Alcance
- Crear el conversor Java interno.
- Cargar licencia privada desde configuracion segura del servidor.
- Cargar plantilla `.mpp` semilla valida.
- Aceptar un payload intermedio del cronograma clasico.

## Criterios De Cumplimiento
- El runner Java puede ejecutarse sin Microsoft Project.
- La licencia no se expone al cliente.
- El `.mpp` se genera usando la licencia Java validada.
- El fallo del runner devuelve diagnostico util al backend comun.

## No Interferencia BIM
- Sin cambios en BIM, rutas BIM, modelos BIM ni UX BIM.

## Plan De Ajuste
1. Definir contrato de entrada para el runner Java.
2. Activar licencia y plantilla semilla desde configuracion privada.
3. Escribir el `.mpp` de salida y propagar errores controlados.
4. Validar que no exista dependencia con COM ni Project Bridge.
5. Documentar configuracion tecnica minima.

## Seguimiento De Sesion 2026-04-10

- El runner activa `Aspose.Tasks for Java` con licencia privada, carga una plantilla `.mpp` semilla, limpia tareas/recursos/asignaciones previas y reconstruye el proyecto desde el XML MSPDI generado por GiProy.
