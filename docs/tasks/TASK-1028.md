# TASK-1028 - Incorporar Valor Ganado Y Capa De Control Del Proyecto

## Modo
GIPROY CLASICO

## Estado
Open

## Objetivo
Incorporar metodologia de valor ganado al cronograma clasico para que el proyecto pueda controlarse en plazo y costo desde el mismo modelo operativo.

## Alcance
- Calcular `PV`, `EV`, `AC`, `SPI`, `CPI`, `EAC`.
- Soportar fecha de estado y avance real por actividad.
- Generar curva S integrada al cronograma.
- Marcar actividades criticas retrasadas con alerta reforzada.

## Criterios De Cumplimiento
- El sistema calcula indicadores EVM desde cronograma + presupuesto.
- Curva S disponible cuando existan datos de avance.
- Los indicadores son coherentes con el modelo CPM y el APU.
- La visualizacion se mantiene en la capa clasica.

## No Interferencia BIM
- Sin cambios en BIM, rutas BIM, feature flags BIM, modelos BIM ni UX BIM.

## Plan De Ajuste
1. Definir modelo de fecha de estado y avance real.
2. Distribuir PV temporalmente desde el cronograma.
3. Calcular EV y AC por actividad y agregados del proyecto.
4. Exponer KPIs y alertas en el modulo clasico.
5. Validar con escenarios controlados.
