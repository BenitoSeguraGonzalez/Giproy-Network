# TASK-1029 - Adecuar UX Gantt/PDM Clasica A La Logica De Programacion De Obras

## Modo
GIPROY CLASICO

## Estado
Open

## Objetivo
Rehacer la experiencia del modulo Gantt clasico para que represente con claridad ruta critica, holguras, restricciones, recursos y estructura PDM/AON sin introducir UX BIM.

## Alcance
- Coloreo normativo de barras, hitos, holguras y alertas.
- Zona sombreada de holgura en barras no criticas.
- Vista PDM/AON sincronizada con Gantt.
- Tooltip y paneles con `ES`, `EF`, `LS`, `LF`, `HT`, `HL`, recursos y restricciones.
- Histograma de recursos y panel de control visibles en la capa clasica.

## Criterios De Cumplimiento
- El usuario puede distinguir de inmediato critica, no critica y holgura negativa.
- PDM y Gantt no muestran estados inconsistentes.
- El histograma y alertas son visibles y operativos.
- La interfaz sigue coherente con el sistema clasico actual.

## No Interferencia BIM
- Sin cambios en BIM, rutas BIM, feature flags BIM, modelos BIM ni UX BIM.

## Plan De Ajuste
1. Simplificar la UI para consumir datos autoritativos del backend.
2. Aplicar nuevo lenguaje visual de programacion de obra.
3. Añadir vista PDM y sincronizacion bidireccional.
4. Incorporar histograma, panel de alertas y tooltips tecnicos.
5. Ejecutar QA visual y responsive.
