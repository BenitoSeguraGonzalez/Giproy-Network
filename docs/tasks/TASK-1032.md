# TASK-1032 - Nivelacion Asistida Controlada Del Gantt Clasico

## Modo
GIPROY CLASICO

## Estado
Open

## Objetivo
Abrir la siguiente fase del modulo `Proyectos > Cronogramas > Gantt` para evolucionar desde la asistencia de conflicto hacia una nivelacion asistida controlada, sin automatizar aun el recálculo completo ni romper la operacion clasica vigente.

## Alcance
- Gestionar tanteos locales de alivio como una sesion operativa coherente.
- Exponer trazabilidad de las maniobras adoptadas durante la sesion.
- Preparar el terreno para una futura nivelacion mas estructurada.

## Criterios De Cumplimiento
- El usuario puede identificar todas las maniobras locales de alivio adoptadas en la sesion.
- La UI distingue claramente entre recomendacion, tanteo adoptado y conflicto aun pendiente.
- No se activa nivelacion automatica ni recálculo masivo.

## No Interferencia BIM
- Sin cambios en BIM, rutas BIM, feature flags BIM, modelos BIM ni UX BIM.

## Plan De Ajuste
1. Crear bandeja operativa de tanteos de alivio.
2. Consolidar trazabilidad de maniobras de sesion.
3. Preparar acciones futuras de revision y limpieza controlada.
4. Mantener backend comun sin introducir automatismos prematuros.
