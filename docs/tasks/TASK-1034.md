## Objetivo
Gobernar la alineacion integral del criterio de `recurso gobernante` del APU con la fuente de verdad `docs/adicionales/Recurso_Gobernante_APU_v1.docx`, sin introducir dependencia BIM ni contaminar la UX BIM.

## Alcance
- Crear el carril documental de control y sus subtasks.
- Alinear contrato de datos clasico para clasificacion gobernante de recursos.
- Alinear motor backend para seleccionar un recurso gobernante individual con trazabilidad.
- Alinear el modal/Gantt clasico para consumir la nueva semantica.
- Cerrar con QA y documentacion.

## Criterios De Cumplimiento
- Solo existe un recurso gobernante por APU calculable.
- El desempate sigue la cascada documental: `rendimiento -> jerarquia -> costo/hora`.
- `Materiales` y `Transporte` no ganan gobernanza temporal principal.
- El backend publica trazabilidad suficiente para explicar por que gano el recurso.
- La capa clasica no depende de BIM.

## No Interferencia BIM
- Sin cambios en rutas BIM, feature flags BIM, modelos BIM, servicios BIM ni UX BIM.

## Incidencia Operativa Resuelta 2026-04-11
- Tras el cierre funcional se detecto un `500` real en el modal embebido de recursos.
- Analisis completo:
  - el frontend ya enviaba correctamente el payload,
  - pero la base activa no tenia aplicadas las columnas `equipment_ownership_kind` y `governing_resource_kind` en `recursos`,
  - lo que provocaba `psycopg2.errors.UndefinedColumn` durante cargas de `Recursos` y `APUs`.
- Accion ejecutada:
  - se aplica la rama Alembic especifica hasta `fa0b1c2d3e4f` sin forzar `upgrade heads`, porque otra rama ajena (`system_bim_settings`) ya existia fisicamente y bloqueaba el upgrade global.
- Verificacion ejecutada:
  - inspeccion de `information_schema.columns` confirma ambas columnas en `recursos`,
  - `apu_repo.get_by_id(...)` carga APUs reales,
  - `recurso_service.update_recurso(...)` actualiza un recurso real con smoke test usando valores estables.
- Resultado:
  - el `500` del modal queda reparado por alinear definitivamente la rama clasica de `recursos` con la base activa.
