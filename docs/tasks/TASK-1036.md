# TASK-1036 - Motor Backend De Recurso Gobernante Y Trazabilidad

## Modo
GIPROY CLASICO

## Estado
Closed

## Objetivo
Sustituir la gobernanza agregada por categoria por una seleccion backend de `recurso gobernante` individual, trazable y alineada con la cascada documental.

## Alcance
- Servicio `cronograma_trabajo`.
- Contrato `CronogramaTrabajoComputedRow`.
- Metadata de duracion y trazabilidad.
- Casos de prueba unitarios.

## Criterios De Cumplimiento
- El backend devuelve un unico recurso gobernante.
- El criterio aplicado queda visible.
- Los empates siguen `rendimiento -> jerarquia -> costo_hora`.

## Implementacion 2026-04-11
- `cronograma_trabajo` ya recoge candidatos de recursos gobernantes a traves del APU y sus APUs anidados.
- El selector backend aplica la cascada oficial:
  - mayor `trabajo_horas`,
  - luego jerarquia hardcodeada,
  - luego `costo_hora`,
  - y por ultimo orden estable solo si persiste empate total.
- `CronogramaTrabajoComputedRow` y `duration_model` ya publican:
  - recurso gobernante,
  - clasificacion fina,
  - criterio aplicado,
  - y costo hora del ganador.
- Se añaden pruebas unitarias especificas para los criterios `1-rendimiento`, `2-jerarquia` y `3-costo`.
