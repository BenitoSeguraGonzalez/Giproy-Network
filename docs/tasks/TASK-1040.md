# TASK-1040 - Backend De Configuracion Temporal Del Gantt Clasico

## Modo
GIPROY CLASICO

## Estado
Closed

## Objetivo
Endurecer el backend del cronograma de trabajo para que la configuración temporal del Gantt clásico tenga contrato consistente, soporte fecha de inicio del proyecto configurable y no falle por datetimes mixtos.

## Alcance
- Normalización de fechas `naive/aware`.
- Semana laboral entera.
- Fecha de inicio configurable.
- Reanclaje de overrides.
- Fecha de inicio/fin resueltas en la respuesta.

## No Interferencia BIM
- Backend común sin dependencias nuevas hacia BIM.

## Resultado
- Se normalizan fechas mixtas `naive/aware`.
- Se publica `fecha_inicio_proyecto` en el contrato clásico.
- Se reanclan overrides de fechas al cambiar el inicio del proyecto.
- Se publican `fecha_inicio` y `fecha_fin` resueltas en la respuesta.
