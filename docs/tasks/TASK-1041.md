# TASK-1041 - Frontend De Configuracion De Proyecto Del Gantt Clasico

## Modo
GIPROY CLASICO

## Estado
Closed

## Objetivo
Convertir el popup actual de configuración del Gantt en una `Configuración de Proyecto` clara y operable dentro del Gantt clásico.

## Alcance
- Renombrar el panel.
- Cierre explícito y estable.
- `Días laborables / semana` entero.
- `Fecha de inicio del proyecto` editable.
- `Fecha de finalización` referencial no editable.
- Aplicación de cambios sin dejar el panel bloqueado.

## No Interferencia BIM
- Solo UX clásica del Gantt.

## Resultado
- El popup se renombra a `Configuración de Proyecto`.
- `Días laborables / semana` queda entero.
- Se añade edición de `Fecha inicio proyecto`.
- `Fecha finalización` pasa a mostrarse solo como referencia.
- El panel ya puede cerrarse con `Cancelar` o con botón de cierre.
