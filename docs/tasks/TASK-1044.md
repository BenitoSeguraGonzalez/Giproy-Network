# TASK-1044 - Modelo De Datos Calendario Oficial Gantt

## Modo
GIPROY CLASICO

## Estado
Done

## Objetivo
Crear el modelo base `maestro + snapshot + overrides` para festivos del Gantt clásico.

## Implementacion
- Tablas nuevas para fuentes, festivos maestros, snapshots y overrides por proyecto.
- Base pensada para Ecuador y extensible a otros países.
- Registro oficial local ampliado para `Quito`, `Cuenca`, `Guayaquil`, `Manta`, `Paute`, `Daule`, `Ambato` y `Santo Domingo`.
- Cada festivo local queda asociado a una fuente municipal verificable dentro del catálogo maestro.

## Validacion
- Migración Alembic creada.
- Modelos SQLAlchemy registrados.
- Reseed maestro `2025-2028` ejecutado sobre la base activa con `9` fuentes oficiales y `78` festivos maestros persistidos.
