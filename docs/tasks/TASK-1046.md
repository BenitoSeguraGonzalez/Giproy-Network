# TASK-1046 - UI Clasica Calendario De Festivos Del Proyecto

## Modo
GIPROY CLASICO

## Estado
Done

## Objetivo
Exponer en `Configuración de Proyecto` el calendario de festivos que afecta al Gantt clásico.

## Implementacion
- Sustitución del listado por un calendario visual mensual.
- Navegación de un solo mes visible a la vez, comenzando por el primer mes de la fecha de inicio operativa del proyecto.
- Resaltado de días laborables, no laborables, festivos oficiales y festivos manuales.
- Tooltip contextual sobre cada fecha festiva usando el patrón ya existente del módulo.
- Panel contextual para el día seleccionado con acciones de baja por fecha.
- Acciones `Recargar oficiales` y `Resetear`.
- Alta manual de festivo.
- Desactivación por proyecto de una fecha festiva cargada.
- Retiro de la tarjeta agregada `Verificación CPM` para devolver espacio útil al cronograma y dejar solo señales contextuales por tarea.

## Validacion
- `npm run build` en `frontend`
