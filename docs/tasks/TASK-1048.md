# TASK-1048 - Override Manual de Recurso Gobernante en Empate Técnico

## Modo
GIPROY CLASICO

## Estado
Done

## Objetivo
Permitir que el editor ligero de rendimientos del Gantt clásico deje seleccionar manualmente el recurso gobernante cuando existan varios candidatos empatados en trabajo gobernante, sin alterar el APU maestro ni introducir lógica BIM.

## Alcance
- Selector manual solo dentro del modal `Rendimientos operativos`.
- Activación exclusiva ante empate técnico real entre candidatos gobernantes.
- Persistencia como borrador del Gantt clásico.
- Posibilidad de volver al modo automático.
- Sin cambios en BIM.

## Criterios De Cumplimiento
- Si existe un único gobernante, el card sigue mostrando solo el resultado automático.
- Si existe empate técnico entre varios candidatos, el card `Gobierna` permite desplegar los empatados.
- El usuario puede elegir manualmente uno de los candidatos empatados o volver a `Automático`.
- La selección manual no modifica el APU maestro; solo vive en el draft operativo del Gantt.
- Si desaparece el empate, prevalece otra vez la lógica automática.

## No Interferencia BIM
- Sin rutas BIM, sin UX BIM, sin feature flags BIM y sin contratos BIM nuevos.

## Implementacion Ejecutada
- Se introduce una clave de metadata local para override manual del recurso gobernante dentro del borrador del Gantt clásico.
- El modal detecta candidatos empatados a partir del mismo motor que ya resuelve la gobernanza automática.
- El card `Gobierna` pasa a comportarse como disparador contextual cuando hay empate técnico.
- La selección manual ya no mezcla categorías: primero se respeta la categoría gobernante efectiva y solo después se listan los candidatos válidos dentro de esa categoría.
- Si la categoría gobernante efectiva es `Mano de obra`, el selector no debe ofrecer recursos de `Equipos y Herramientas`.
- El despliegue permite elegir entre `Automático`, los recursos manualmente elegibles de la categoría dominante y la opción final de categoría gobernante.
- El reset del editor de recursos limpia también el override manual de gobernanza.
- Se corrige el contrato de cálculo del Gantt clásico para que el gobernante se resuelva por `mayor rendimiento h/unidad` y no por `cantidad de cuadrilla x rendimiento`.
- La duración visible del modal vuelve a derivarse desde `cantidad presupuestada x rendimiento gobernante / jornada`.
- El card `Rendimiento` deja de mostrar productividad (`unidad/día`) y pasa a mostrar el rendimiento gobernante real en `h/unidad`.
- El bloque `Recursos del APU` del modal se reorganiza para seguir el patrón visual del editor de APUs: prioridad a `Recurso / Descripción`, luego `Unidad`, `Cantidad`, `P. unitario`, `Rend.`, `P. total` y `Tiempo`.
- Se añade un cierre económico inferior con `Costo Directo`, `Costo Indirecto`, `Precio Total APU` y `Precio en Presupuesto`.
- Se compacta la altura de filas, cabeceras e inputs para acercar la densidad visual del modal de Gantt al editor clásico de APUs.
