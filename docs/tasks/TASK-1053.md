- El usuario puede reajustar horizontalmente la separación entre grid y timeline.
- El doble click sobre una barra abre un popover ligero, no un modal tosco.
- Desde ese popover se puede abrir ajuste fino, contexto y acciones de dependencias.
- Las dependencias visibles y editables usan `Item` como referencia humana, sin romper los IDs técnicos.
