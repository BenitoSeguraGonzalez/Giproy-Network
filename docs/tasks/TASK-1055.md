# TASK-1055 - Splitter Reajustable Grid Timeline En Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Permitir que el usuario reajuste horizontalmente el ancho relativo entre grid de datos y timeline del Gantt clásico sin desalinear cabeceras ni filas.

## Implementacion
- Separador draggable discreto.
- Mínimos y máximos seguros.
- Reflujo en vivo de grid y timeline.
- El viewport izquierdo conserva cabeceras, filas y timeline alineados al reajustar.

## Validacion
- `npm run build` OK en `frontend`.
- Sin interferencia con la capa BIM.
