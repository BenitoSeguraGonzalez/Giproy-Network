# TASK-1056 - Menú Contextual Ligero Y Dependencias Operativas En Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Sustituir el doble click modal del Gantt clásico por un menú contextual ligero con acciones de inicio, contexto y creación/gestión de dependencias.

## Implementacion
- Popover contextual anclado a la barra.
- Acción `Ajustar inicio`.
- Acción `Contexto de área`.
- Acción `Gestionar dependencias`.
- Acción `Añadir sucesora` en modo pick directo sobre otra barra.
- Etiquetado de dependencias usando `Item` como referencia visible.

## Validacion
- `npm run build` OK en `frontend`.
- Se mantiene el flujo clásico sin introducir UX BIM.
