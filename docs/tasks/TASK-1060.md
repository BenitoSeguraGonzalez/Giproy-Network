# TASK-1060 - Propagación Operativa Del Nuevo Item Visible En Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Alinear las referencias visibles del Gantt clásico para que cualquier flujo que use `Item` consuma la nueva numeración jerárquica basada en `EDT + líneas`, sin romper el uso separado de `Cod EDT`.

## Alcance
- Etiquetas visibles `Item`.
- Referencias humanas en acciones rápidas y dependencias.
- Resolución por item visible cuando aplique.
- Tooltips o resúmenes donde el `Item` sea parte del contexto.

## Criterios De Cumplimiento
- El usuario ve el mismo `Item` en grid, menús y flujos de dependencias.
- `Cod EDT` sigue siendo una referencia independiente.
- No se generan ambigüedades entre `Item` visible y `codigo_item`.
- No se introduce lógica paralela fuera de `CronogramaGantt`.

## Validación Prevista
- Smoke técnico de referencias visibles.
- Comprobación manual de coherencia entre columna, modal y menús.

## No Interferencia BIM
- Sin cambios fuera del carril clásico.

## Resultado
- Las referencias humanas del Gantt clásico siguen leyendo `Item` desde el mismo mapa visible actualizado.
- La resolución por item para dependencias se mantiene acotada a tareas calculables, evitando contaminación funcional desde filas `EDT`.
