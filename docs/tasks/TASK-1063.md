# TASK-1063 - Separación Visible De Item Y Cod EDT En Cronograma Valorado

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Aplicar en `Cronograma Valorado` el contrato visual clásico que separa `Item` y `Cod EDT`, evitando que una sola columna mezcle la referencia de línea con la referencia estructural.

## Alcance
- `frontend/src/components/projects/Cronogramas.jsx`
- Construcción de filas visibles EDT + líneas.
- Render del grid base del `Cronograma Valorado`.
- Sin tocar persistencia ni backend.

## Criterios De Cumplimiento
- Las filas EDT muestran `Cod EDT` como referencia estructural.
- Las líneas calculables muestran `Item` como referencia de línea y `Cod EDT` como referencia de capítulo.
- `codigo_item` no cambia en backend ni en payloads.
- El cambio queda acotado a la UI clásica del valorado.

## Implementacion
- El grid base del `Cronograma Valorado` añade una columna visible `Cod EDT` junto a `Item`.
- Las filas visibles separan `item_visible` y `edt_code_visible` sin alterar `codigo_item`.
- Para líneas calculables, `Item` sigue leyendo `codigo_item` y `Cod EDT` se resuelve desde su rama EDT.
- Para filas estructurales, `Item` queda vacío y `Cod EDT` muestra la referencia jerárquica del nodo.

## Validacion
- Revisión técnica del render de filas EDT + líneas.
- Verificación explícita de no interferencia BIM a nivel de alcance tocado.

## No Interferencia BIM
- Sin cambios en rutas, módulos, flags ni UX BIM.
