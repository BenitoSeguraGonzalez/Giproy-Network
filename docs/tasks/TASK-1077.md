# TASK-1077 - Tipo De Duración Individual En Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Permitir que el selector `Tipo dur.` del `Gantt` clásico opere por fila y deje de cambiar en bloque la magnitud visual de duración para todo el cronograma.

## Alcance
- `Proyecto > Cronogramas > Gantt`
- Solo UX clásica
- Sin tocar BIM
- Sin cambiar el backend común

## Implementación
- `frontend/src/components/projects/CronogramaGantt.jsx` deja de tratar `Tipo dur.` como preferencia global exclusiva de la vista.
- La preferencia de magnitud visible pasa a guardarse por fila dentro de `metadata.gantt_duration_display_unit`, reutilizando el contrato de guardado existente de cada línea.
- La columna `Dur.` ya renderiza usando la preferencia individual de la propia fila.
- La columna `Tipo dur.` cambia solo la fila activa y deja intactas las demás.
- Se mantiene un fallback global de visualización para filas sin preferencia individual, evitando ruptura funcional en paneles y comparativas existentes.

## Validación
- `npm run build` en `frontend` OK.

## No Interferencia BIM
- Sin BIM.
