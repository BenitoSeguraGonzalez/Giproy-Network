# TASK-1086 - Derivación Frontend Correcta De Tramos Iniciales Valorado

## Modo
GIPROY CLASICO

## Estado
IN_PROGRESS

## Objetivo
Corregir la derivación fallback de subbarras en frontend para que, cuando una línea no tenga `gantt_subbars` persistidas, nazca desde los periodos no nulos del `Cronograma Valorado` y no desde la intersección con la ventana residual de una barra antigua.

## Dependencia
- `TASK-1085`
- `TASK-1082`

## Criterios De Cumplimiento
- `Replanteo y nivelación` con 7 periodos no nulos debe producir 7 tramos iniciales base.
- La derivación manual sí puede recortarse por ventana operativa.
- La derivación automática desde valorado no se recorta por la duración residual vieja de la tarea.
- `parent_initial_id` sigue el contrato `valuado-initial-{linea}-{periodo}`.

## Progreso
- Se extrae un helper puro `cronogramasGanttSubbars.js` para la derivación base y la geometría del timeline.
- La derivación fallback deja de intersectar automáticamente el `Valorado` con `row.start/end` cuando el origen es el tramo inicial valorado.
- La derivación manual mantiene clipping por ventana operativa, preservando el caso `manual_window_period_seed`.
