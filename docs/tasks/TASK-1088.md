## Estado

## Objetivo
Congelar con smoke tests y QA técnica que el `Gantt` segmentado responde al contrato valorado y que la geometría base no vuelve a colapsar a pastillas mínimas.

## Dependencia
- `TASK-1085`
- `TASK-1086`
- `TASK-1087`

## Criterios De Cumplimiento
- Existe smoke test para derivación de 7 tramos iniciales desde distribución valorada.
- Existe smoke test para envelope y anchuras mínimas no colapsadas.
- `npm run build` queda en verde.

## Progreso
- Se añade `frontend/scripts/smoke-cronogramas-gantt-subbars.mjs` con validación de derivación de 7 tramos, clipping manual y envelope temporal.
- `frontend/scripts/smoke-cronogramas-gantt-bootstrap.mjs` se mantiene en verde junto al nuevo smoke test, y `npm run build` valida la integración completa del cambio.
- Se cierra además el contrato visible de sincronización con `Cronograma Valorado`: `Valorado -> Gantt` mantiene la derivación desde distribución vigente, y `Gantt -> Valorado` deja de depender solo de acciones manuales al resincronizar automáticamente el valorado cuando el modo activo es `gantt` y se guarda una línea del timeline.
