# TASK-1093 - Control De Reingeniería Del Zoom Del Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
IN_PROGRESS

## Objetivo
Rehacer el zoom del `Gantt` clásico para que sea operativo y fluido, desacoplando el zoom visual inmediato del recálculo pesado de layout, sin romper ninguna funcionalidad ya estable de barras, subbarras, selección, dependencias o sincronización.

## Documento Rector
- `docs/architecture/CRONOGRAMA_VALORADO_GANTT_SYNCHRONIZATION_FUNCTIONAL_SPEC.md`

## Subtasks
- `TASK-1094` - Zoom visual diferido con commit estructural anclado al viewport.
- `TASK-1095` - Contención del coste de render en timeline durante interacción de zoom.
- `TASK-1096` - Smoke tests, validación de build y guardarraíles de no regresión del zoom.

## Criterios De Cumplimiento
- El control de zoom responde de forma inmediata al gesto del usuario.
- El recalculo pesado del timeline no se dispara en cada tick del slider.
- El timeline conserva el ancla visual del viewport al confirmar el zoom.
- No se rompe selección de subbarras, menús rápidos, enlaces ni panel lateral.
- `npm run build` queda en verde.
- Existen pruebas reproducibles del nuevo carril de zoom.

## Progreso
- Se abre este frente como slice aislado de rendimiento/UI para no contaminar la lógica funcional del Gantt.
- La estrategia elegida es `zoom visual inmediato + commit estructural diferido`, manteniendo la escala temporal y la geometría pesada fuera del carril de interacción continua.
- La optimización ya no es solo de zoom: el Gantt clásico queda encaminado a un carril virtualizado horizontal + verticalmente, con scroll lógico para filas desmontadas.
