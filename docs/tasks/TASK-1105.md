# TASK-1105 - Reset Integral De Cronogramas Clásicos

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Restaurar `Cronograma Valorado` y `Cronograma Gantt` al estado equivalente de creación inicial para un presupuesto operativo, eliminando modificaciones manuales posteriores y reaplicando las políticas vigentes de creación, sin tocar BIM.

## Dependencia
- `TASK-0950`
- `TASK-0955`
- `TASK-1101`

## Subtasks
- `TASK-1106` - Gobierno y contrato de reset integral.
- `TASK-1107` - Implementación backend/frontend del reset integral clásico.
- `TASK-1108` - Validación técnica, pruebas y documentación.

## Criterios De Cumplimiento
- El reset limpia overrides manuales del `Cronograma Valorado`.
- El reset elimina persistencia operativa del `Gantt` para que se reconstruya con políticas vigentes.
- El reset limpia overrides manuales del calendario festivo del proyecto para no dejar residuos operativos ocultos.
- La respuesta devuelve el nuevo estado `Valorado + Trabajo` ya reconstruido.
- La UX clásica expone la acción con confirmación fuerte.
- No se toca BIM ni se crean dependencias nuevas hacia BIM.

## Progreso
- Se confirma que el repositorio solo tenía reset fino por línea valorada y reset aislado de festivos.
- Se abre el frente de reset integral clásico para permitir pruebas limpias de creación y ejecución real del contrato actual.
- Se implementa endpoint integral de reset por presupuesto sobre backend común, con respuesta combinada `Valorado + Trabajo`.
- La UI clásica expone `Reset integral` con confirmación fuerte y actualización atómica del estado local.
- Validación completada con `pytest`, smokes técnicos del Gantt, `eslint` focalizado del API y `npm run build`.
