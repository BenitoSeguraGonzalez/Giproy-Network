# TASK-1106 - Gobierno Del Reset Integral Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Definir un contrato explícito de reset integral por presupuesto para `Cronograma Valorado`, `Gantt` y calendario festivo del proyecto, asegurando no interferencia con BIM y backend común.

## Criterios De Cumplimiento
- El reset es atómico a nivel de presupuesto.
- El reset reaplica defaults vigentes del `Valorado`.
- El reset deja `schedule_data` vacío para que el `Gantt` se regenere con políticas actuales.
- El reset del calendario solo afecta overrides manuales del proyecto.
- La trazabilidad queda documentada.

## Resultado
- Se fija el contrato de reset integral clásico: `period_type=mensual`, `distribution_mode=homogeneo`, `global_distribution=[]`, `line_distribution_overrides={}`, `schedule_data={}` y limpieza de overrides manuales del calendario del proyecto.
- El contrato se mantiene invisible para BIM y no introduce dependencias nuevas hacia su carril.
