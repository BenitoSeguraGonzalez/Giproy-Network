# TASK-1111 - Optimización Visible Del Gantt Clásico

## Modo
GIPROY CLASICO

## Estado
DONE

## Objetivo
Reducir la presión de render en el Gantt clásico durante drag, zoom y navegación visible, manteniendo el contrato funcional actual.

## Criterios De Cumplimiento
- `dragPreview` deja de comprometer una actualización React por cada `pointermove`.
- El slider de zoom deja de comprometer una actualización React por cada tick crudo del input.
- El comportamiento visible del Gantt se mantiene estable.

## Resultado
- El carril de `dragPreview` se bufferiza con `requestAnimationFrame` y se limpia explícitamente al finalizar la interacción.
- El slider principal de zoom bufferiza `zoomTargetLevel` con `requestAnimationFrame` y fuerza flush antes del commit final.
- Los listeners globales de drag dejan de depender del cierre React de cada render y pasan a leer el runtime vigente desde refs estables.
- El drag horizontal queda ahora acotado al primer día permitido y, al volver casi al borde izquierdo, imanta la barra al origen operativo en vez de dejarla parcialmente recortada.
- Se conserva el comportamiento funcional de drag, zoom y navegación del Gantt clásico.
