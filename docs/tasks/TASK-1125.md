## Descripción
Cerrar la lógica operativa del modal de división del Gantt clásico para que porcentaje y duración queden enlazados, las filas inferiores se redistribuyan automáticamente y nunca puedan guardarse huecos porcentuales.

## Resultado
- Cada fila muestra porcentaje y duración operativa equivalente dentro del padre y ambos campos editan la misma distribución.
- Al editar una fila, las filas inferiores se rebalancean homogéneamente sobre el remanente sin tocar las superiores ya definidas.
- La validación bloquea guardado si existe cualquier parte a cero o si la suma no cuadra exactamente con el porcentaje del padre.
- La validación quedó verificada con `npm run build` y smokes técnicos del Gantt clásico.
