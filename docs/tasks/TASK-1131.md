# TASK-1131 - Evitar Apertura Automatica Del Contexto Tras Operaciones De Subbarras

## Descripción
Eliminar la regresión donde el contexto de área/tarea volvía a abrirse automáticamente al dividir o reagrupar tramos del Gantt clásico, aunque el usuario no lo hubiera solicitado explícitamente desde el menú.

- `docs/tasks/TASK-1131.md`

## Resultado
- Las operaciones estructurales sobre subbarras siguen seleccionando el tramo resultante, pero ya no abren el contexto.
- El contexto vuelve a quedar restringido a la acción explícita del menú.
- No se activó UX BIM ni se alteraron contratos BIM.
