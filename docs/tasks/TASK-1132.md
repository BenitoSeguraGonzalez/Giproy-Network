## Descripción
Eliminar la persistencia indebida del tooltip informativo durante la pulsación y el arrastre de tramos/subtramos del Gantt clásico, y añadir una guía temporal punteada que muestre la distancia de tiempo respecto a tramos adyacentes mientras se mueve un subtramo.

- El tooltip de datos solo aparece en hover real, sin botones pulsados.
- El indicador superior de posición durante el movimiento se mantiene.
- Durante el arrastre de un subtramo aparece una guía punteada con la distancia temporal respecto a tramos anterior y siguiente si existen.
