# TASK-1135 - Proteger Salida De Gantt Con Cambios Pendientes Y Gobernar Boton De Confirmacion

## Estado

## Tipo

## Prioridad

## Descripción
Evitar que el usuario salga del Gantt clásico hacia otra sección sin una advertencia cuando existan cambios locales pendientes, y hacer que el botón superior de confirmación solo se active y se pinte en naranja cuando realmente haya cambios por guardar o confirmar.

## Resultado
- El Gantt informa al contenedor padre si existen cambios pendientes reales.
- Al cambiar desde Gantt a otra sección solo aparece advertencia si hay cambios locales sin guardar.
- El mensaje avisa expresamente que los cambios se perderán si se sale sin guardar.
- El botón superior de confirmación queda desactivado y con estilo neutro si no hay cambios.
- El botón recupera el naranja corporativo únicamente cuando existen cambios pendientes confirmables.
- No se activó UX BIM ni se alteraron contratos BIM.
