# TASK-1137 - Limpieza operativa del contexto de tarea en Gantt clásico

## Objetivo
Reducir el panel `Contexto tarea` del Gantt clásico para que muestre solo información útil al usuario, con lectura centrada en la tarea y en el tramo activo, eliminando metadatos técnicos, diagnósticos internos y bloques globales que contaminaban la visual.

## Alcance autorizado
- Capa clásica de `Cronogramas / Gantt`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM
- Sin tocar backend

## Implementación
- Se mantiene la cabecera operativa de la tarea.
- Se conservan tarjetas básicas de `Inicio`, `Fin`, `Duración` y `Monto / % tramo`.
- Se simplifica la lectura del tramo seleccionado para dejar solo:
  - posición del tramo
  - inicio
  - fin
  - duración
  - porcentaje asignado
  - monto
- Se deja una alerta compacta cuando el tramo activo excede el cupo del periodo valorado.
- Se mantienen alertas accionables por tarea cuando aplican:
  - conflicto visible de capacidad
  - recomendación operativa de alivio
- Se limpia el bloque de dependencias para dejar solo:
  - predecesoras
  - sucesoras
  - holgura total

## Eliminado del contexto
- Origen técnico del tramo
- Estado técnico detallado
- IDs y referencias internas
- Resúmenes globales por periodos/tramos
- Lecturas de presión de recursos de carácter técnico
- Histogramas globales y rankings globales
- Sesiones técnicas de alivio
- Bloques APU/CPM/costo-tiempo de carácter experto

## Validación
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`

## Resultado
El contexto queda definido por tarea y por tramo activo, con lectura operativa y sin ruido técnico o global.
