# TASK-1140 - Control de integración segura de ruta crítica en Gantt clásico

## Objetivo
Cerrar el contrato de implementación segura de la ruta crítica en el Gantt clásico para que la inteligencia CPM autoritativa se integre sin romper la estructura visual actual ni las funciones operativas ya estabilizadas.

## Alcance autorizado
- Backend común de `cronogramas-trabajo`
- Frontend clásico de `Cronogramas / Gantt`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Control funcional
- El motor CPM backend sigue siendo la única autoridad matemática.
- La ruta crítica se expone en la capa clásica mediante metadata estable y segura.
- La lectura visible no sustituye el color base operativo del Gantt ni rompe subtramos, drag, división, aprobación o sincronización actual.
- Las tareas pueden distinguir:
  - crítica
  - no crítica
  - holgura negativa
  - restricciones activas
  - múltiples rutas críticas
- El contexto de tarea debe mostrar esta información por tarea/tramo, no como resumen global contaminante.

## Resultado esperado
El Gantt clásico gana una lectura de ruta crítica más completa y útil, manteniendo intacto el carril visual y funcional actual.
