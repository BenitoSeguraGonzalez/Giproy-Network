# TASK-1143 - Ejecución de navegación CPM compacta en Gantt clásico

## Objetivo
Implementar la navegación compacta de ruta crítica en el Gantt clásico para recorrer tareas críticas, con holgura negativa y con restricciones activas sin romper la búsqueda ni la experiencia consolidada del header.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1142.md`
- `docs/tasks/TASK-1143.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Implementación prevista
- Añadir un navegador CPM compacto junto a la búsqueda del Gantt clásico.
- Permitir activar foco por:
  - críticas
  - holgura negativa
  - restricciones
- Añadir contador, navegación secuencial y resaltado coherente de filas.
- Mantener intacta la búsqueda textual existente y la geometría del lienzo.

## Implementación ejecutada
- Se añade un navegador CPM compacto dentro del header operativo del Gantt clásico, junto al buscador existente.
- El usuario puede activar foco por:
  - `Críticas`
  - `Holgura negativa`
  - `Restricciones`
- Cada foco muestra:
  - contador de coincidencias
  - navegación secuencial `Sgte`
  - posicionamiento automático sobre la primera coincidencia
  - selección automática de la tarea navegada
- Las filas afectadas quedan resaltadas con señal azul sutil reutilizando el lenguaje visual actual del clásico, sin recolorear barras ni contaminar BIM.
- La restauración local del Gantt limpia también este estado auxiliar para no dejar navegación residual.
