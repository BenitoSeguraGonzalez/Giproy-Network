# TASK-1144 - Control de acciones guiadas CPM seguras en Gantt clásico

## Objetivo
Definir el contrato seguro para convertir el diagnóstico CPM en una acción guiada sobre la tarea seleccionada dentro del Gantt clásico, evitando incoherencias con subtramos, ventanas manuales o cambios pendientes incompatibles.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- Documentación TASK + CHANGELOG + estado de trabajo
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Control funcional
- La acción CPM debe ser explícita, local a una tarea y reversible.
- Debe exigir confirmación previa del usuario.
- No debe ejecutarse si la tarea tiene:
  - subbarras operativas persistidas
  - ventana temporal manual operativa
  - bloqueos previos del contrato CPM ya existente
- El resultado debe quedar como tanteo local pendiente de aprobación, no como aprobación final.

## Resultado esperado
La ruta crítica del Gantt clásico no solo diagnostica, sino que permite aplicar una recomendación CPM segura y trazable sobre una tarea concreta.
