# TASK-1145 - Ejecución de adopción CPM guiada en tarea seleccionada

## Objetivo
Implementar una acción compacta para adoptar la recomendación CPM backend sobre la tarea seleccionada del Gantt clásico, con confirmación previa, bloqueo en casos incompatibles y reversión local visible.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1144.md`
- `docs/tasks/TASK-1145.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Implementación prevista
- Exponer una acción `Aplicar tanteo CPM` en el bloque contextual de ruta crítica.
- Mostrar delta visible entre programación actual y recomendación CPM.
- Pedir confirmación previa.
- Bloquear la acción cuando existan subbarras o ventana manual operativa.
- Permitir revertir el tanteo local CPM mientras siga en borrador.

## Implementación ejecutada
- Se añade una acción compacta `Aplicar tanteo CPM` dentro del bloque contextual `Ruta crítica` de la tarea seleccionada.
- El bloque muestra ahora:
  - delta visible de inicio, fin y duración frente al CPM backend
  - ventana recomendada por CPM
  - duración recomendada
- La acción exige confirmación previa antes de generar el borrador local.
- La acción queda bloqueada con motivo visible cuando la tarea tiene:
  - subtramos operativos
  - ventana temporal manual operativa
- Si ya existe una adopción CPM local, se expone también la acción `Quitar tanteo CPM`, igualmente confirmada.
- Todo queda como borrador local pendiente de aprobación reutilizando el contrato clásico ya existente.
