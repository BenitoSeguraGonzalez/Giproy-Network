# TASK-1146 - Control de compatibilidad CPM con subtramos en Gantt clásico

## Objetivo
Cerrar el contrato seguro para que una recomendación CPM pueda aplicarse también sobre tareas con subtramos o ventana manual en el Gantt clásico sin destruir la microprogramación interna ya existente.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- Documentación TASK + CHANGELOG + estado de trabajo
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Control funcional
- Si la tarea tiene subtramos, la adopción CPM no debe rehacerlos.
- La acción debe desplazar la envolvente completa preservando:
  - duraciones internas
  - separaciones relativas
  - orden de subtramos
- Si la tarea usa ventana manual operativa, la adopción CPM debe trasladar también esa ventana.
- Todo debe seguir siendo borrador local pendiente de aprobación.

## Resultado esperado
La capa clásica gana compatibilidad CPM real con tareas segmentadas sin romper el contrato operativo del Gantt.
