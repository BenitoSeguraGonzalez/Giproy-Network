# TASK-1148 - Control de trazabilidad CPM en Gantt clásico

## Objetivo
Cerrar la trazabilidad operativa de las decisiones CPM dentro del Gantt clásico usando la infraestructura de metadata e historial ya existente, sin introducir un subsistema nuevo ni tocar BIM.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- Documentación TASK + CHANGELOG + estado de trabajo
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Control funcional
- Toda adopción o reversión CPM debe dejar traza local por línea.
- La traza debe conservar:
  - cuándo ocurrió
  - qué acción fue
  - sobre qué modo actuó
  - quién la ejecutó si el contexto clásico ya dispone de esa identidad
- La confirmación del cronograma debe resumir cuántos tanteos CPM se están consolidando.
- El historial visible del Gantt debe dejar lectura de cuántas líneas CPM entraron en una confirmación.

## Resultado esperado
La ruta crítica clásica deja de ser una acción opaca y pasa a quedar trazada de forma útil dentro del propio Gantt.
