# TASK-1149 - Ejecución de trazabilidad CPM y cierre conservador del frente clásico

## Objetivo
Implementar la trazabilidad CPM del Gantt clásico y cerrar el frente actual con validación conservadora, priorizando no romper la operativa estabilizada.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1148.md`
- `docs/tasks/TASK-1149.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM

## Implementación ejecutada
- Se añade traza CPM por línea en metadata clásica (`adopt` / `revert`).
- Cada evento registra:
  - fecha/hora
  - acción
  - modo (`línea`, `envolvente de subtramos`, `ventana manual`)
  - actor si el `AuthContext` clásico lo aporta
  - recomendación aplicada
- El contexto de tarea muestra ya una lectura compacta de la traza CPM más reciente.
- El modal de confirmación del cronograma resume también cuántos tanteos CPM están entrando en la aprobación.
- El historial confirmado del Gantt añade lectura de cuántas líneas CPM participaron en cada lote confirmado.

## Validación ejecutada
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-zoom.mjs`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`

## Resultado
La ruta crítica del Gantt clásico queda trazable, visible y operativamente gobernable sin alterar la geometría ni la lógica ya estabilizada del sistema.
