# TASK-1150 - Control de endurecimiento operativo CPM en Gantt clásico

## Objetivo
Cerrar el siguiente paquete de mejoras CPM del Gantt clásico sin abrir superficie innecesaria: foco por acciones CPM, guardarraíles frente a edición manual fina, smoke específico y lectura histórica más compacta.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `frontend/src/components/projects/cronogramasGanttCpm.js`
- `frontend/scripts/smoke-cronogramas-gantt-cpm.mjs`
- Documentación TASK + CHANGELOG + estado de trabajo
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM
- Sin tocar backend común

## Control funcional
- Debe existir un foco visible para localizar tareas con acción CPM.
- La fila debe exponer una señal CPM discreta y no invasiva.
- Las aperturas de edición manual fina sobre tareas con trabajo CPM deben advertir al usuario antes de continuar.
- El historial confirmado debe resumir CPM de forma compacta.
- Debe existir smoke específico para el helper CPM nuevo.
- Cualquier preparación futura para reporting común debe quedar solo como contrato/documentación, no activada.

## Resultado esperado
El frente CPM del Gantt clásico queda más operable, más auditable y mejor protegido frente a sobrescrituras manuales accidentales, sin tocar BIM ni el backend compartido.
