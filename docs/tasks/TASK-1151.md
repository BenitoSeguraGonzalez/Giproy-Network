# TASK-1151 - Ejecución de endurecimiento operativo CPM en Gantt clásico

## Objetivo
Implementar el paquete conservador de mejoras CPM del Gantt clásico, reforzando navegación, trazabilidad compacta, guardarraíles de edición manual y QA específica sin romper el código funcional ya estabilizado.

- `docs/CHANGELOG.md`
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM
- Sin tocar backend común

## Implementación prevista
- Añadir helper CPM puro reutilizable para:
  - lectura de estado CPM por fila
  - guardarraíl previo a edición manual fina
  - formato compacto de histórico CPM
- Extender el navegador CPM con foco por `Acción CPM`.
- Añadir badge discreto `CPM+` en filas con tanteo o traza CPM.
- Advertir antes de abrir edición manual de inicio o ajuste fino de subtramo sobre tareas con trabajo CPM.
- Compactar historial confirmado a lectura `n tanteo(s) CPM`.
- Añadir smoke específico para el helper CPM.
- Dejar documentado el contrato futuro hacia reporting sin activarlo todavía.

## Implementación ejecutada
- Se crea `cronogramasGanttCpm.js` como helper puro del frente clásico para centralizar:
  - estado CPM por fila
  - guardarraíl de edición manual fina
  - etiqueta compacta del histórico CPM
- El navegador CPM añade el foco `Acción CPM` para recorrer tareas con tanteo o traza CPM.
- Las filas calculables incorporan badge discreto `CPM+` cuando existe acción CPM relevante.
- Abrir `Ajuste fino` de subtramo o edición manual de inicio sobre tareas con lectura CPM ya exige confirmación previa.
- El historial confirmado compacta su lectura a `n tanteo(s) CPM`.
- Se añade smoke específico `smoke-cronogramas-gantt-cpm.mjs`.
- El contrato futuro hacia reporting queda solo preparado a nivel de helper/documentación; no se activa ninguna UX ni integración nueva.
