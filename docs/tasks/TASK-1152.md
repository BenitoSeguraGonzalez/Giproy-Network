# TASK-1152 - Control del contrato CPM hacia reporting común y QA funcional

## Objetivo
Preparar el cierre seguro del frente CPM clásico dejando definido un contrato puro y reusable hacia reporting común, junto con una guía QA funcional real, sin activar aún esa integración en pantallas ni backend compartido.

## Alcance autorizado
- `frontend/src/components/projects/cronogramasGanttCpmReportingContract.js`
- `frontend/scripts/smoke-cronogramas-gantt-cpm-reporting.mjs`
- Documentación TASK + CHANGELOG + estado de trabajo
- Sin activar ni mostrar UX BIM
- Sin introducir acoplamientos hacia BIM
- Sin tocar backend común ni reporting productivo actual

## Control funcional
- El contrato debe ser puro, serializable y estable.
- Debe resumir lo necesario para reporting futuro:
  - criticidad
  - holguras
  - restricciones
  - deriva contra CPM
  - tanteo/traza CPM
- La guía QA debe cubrir casos reales de decisión operativa y no solo humo técnico.
- Nada de esto debe alterar la UI ni el comportamiento actual del Gantt clásico.

## Resultado esperado
El sistema queda listo para conectar CPM con reporting común en un siguiente slice, sin abrir riesgo ahora mismo sobre la capa clásica visible.
