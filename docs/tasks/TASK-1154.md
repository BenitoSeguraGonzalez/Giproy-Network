# TASK-1154 - Control de compactación y modernización del shell común de diálogos clásicos

## Objetivo
Redefinir el shell común de alertas, confirmaciones y prompts del carril clásico para hacerlo más compacto, moderno y coherente con la UX de Gantt, sin alterar la semántica funcional ni abrir dependencias hacia BIM.

## Alcance autorizado
- `frontend/src/components/ui/AppDialogProvider.jsx`
- `docs/tasks/TASK-1154.md`
- `docs/tasks/TASK-1155.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin modificar contratos funcionales de confirmación ya integrados

## Control funcional
- El cambio debe aplicarse desde el módulo común para impactar alertas, confirmaciones y prompts.
- Los diálogos deben reducir huella visual, padding, footer y tamaño de botones.
- La nueva piel visual debe mantener accesibilidad básica, estados de foco y acciones existentes.
- No se debe romper ninguna interacción funcional de Gantt clásico ni del resto del frontend clásico.

## Resultado esperado
El sistema clásico gana un shell de diálogo más limpio y profesional, con comportamiento intacto y sin contaminación BIM.
