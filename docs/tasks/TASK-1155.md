# TASK-1155 - Ejecución del shell neumórfico compacto para diálogos clásicos

## Objetivo
Implementar la nueva presentación compacta de los diálogos comunes del carril clásico, inspirada en la plantilla propuesta por negocio, preservando todas las acciones existentes.

## Alcance autorizado
- `frontend/src/components/ui/AppDialogProvider.jsx`
- `docs/tasks/TASK-1154.md`
- `docs/tasks/TASK-1155.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin alterar el contrato visible de Gantt clásico más allá del shell común de diálogo

## Implementación prevista
- Compactar header, body y footer del proveedor común de diálogos.
- Sustituir la piel actual por una variante más ligera inspirada en neumorfismo suave.
- Reducir tamaño y peso visual de iconos, botones y overlays.
- Mantener `alert`, `confirm` y `prompt` sobre el mismo contrato funcional existente.

## Validación prevista
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`
- `node frontend/scripts/smoke-cronogramas-gantt-cpm.mjs`

## Implementación ejecutada
- Se adapta `AppDialogProvider.jsx` como shell común del frontend clásico para que todo el sistema herede un diálogo más compacto y moderno desde un único punto.
- Se introduce una superficie visual inspirada en la plantilla propuesta, con relieve suave, campos inset y botones más pequeños.
- Se reducen anchuras, paddings, alturas de footer y tamaño de CTAs para eliminar el efecto de modal tosco.
- Se retira la dependencia visual del botón líquido en este shell común y se mantiene la semántica funcional de confirmación, cancelación y prompt.

## Validación ejecutada
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`
- `node frontend/scripts/smoke-cronogramas-gantt-cpm.mjs`

## Resultado esperado
Los diálogos del carril clásico quedan más compactos, coherentes y reutilizables, sin romper flujos existentes ni introducir interferencia con BIM.
