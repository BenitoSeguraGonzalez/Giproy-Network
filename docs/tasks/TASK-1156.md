# TASK-1156 - Control de variante visual experimental para rail de controles del Gantt clásico

## Objetivo
Preparar una variante visual experimental del panel operativo derecho del header del Gantt clásico usando una rail oscura reutilizable, sin perder la implementación actual y sin tocar la lógica funcional.

## Alcance autorizado
- `frontend/src/components/ui/ControlRail.jsx`
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1156.md`
- `docs/tasks/TASK-1157.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM

## Control funcional
- La variante nueva debe ser reversible.
- El rail debe quedar desacoplado como componente genérico reutilizable.
- La lógica actual de zoom, escala, herramientas y confirmación no debe alterarse.
- La implementación clásica previa debe permanecer disponible como fallback.

## Resultado esperado
El Gantt clásico dispone de una prueba visual controlada para su panel operativo superior, lista para evaluar impacto sin comprometer el comportamiento existente.
