# TASK-1159 - Ejecución de simplificación del header Gantt y reubicación de exportación MS Project

## Objetivo
Implementar en el carril clásico la retirada del panel-resumen superior del Gantt y mover la exportación `.mpp` al menú superior de `Reportes`, sin romper la funcionalidad vigente.

## Implementación prevista

- Mantener el input oculto de importación XML para no romper interoperabilidad.
- Reubicar `MS Project` como opción del botón superior `Reportes` cuando la pestaña activa sea `Gantt`.
- Mantener el comportamiento actual del reporte estándar en `Cronograma Valorado`.

## Validación prevista
- `npm run build`

## Implementación ejecutada
- Se retira por completo la barra resumen superior del componente `CronogramaGantt`, preservando el input oculto para importación XML.
- El header de `Cronogramas` pasa a mostrar un menú de `Reportes` específico para la vista `Gantt`, con acceso a la vista previa del reporte y a la exportación `MS Project`.
- La vista `Cronograma Valorado` conserva su botón estándar de reporte sin alteraciones.

## Validación ejecutada
