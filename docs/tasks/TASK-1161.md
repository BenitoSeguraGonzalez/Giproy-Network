# TASK-1161 - Ejecución de shortcode de dependencias y modal de sucesoras con subtramos en Gantt clásico

## Objetivo
Implementar el contrato visual y funcional de dependencias cortas del Gantt clásico, añadiendo una columna editable de sucesoras y actualizando el modal `Añadir sucesora` para soportar subtramos y lag normalizado.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1160.md`
- `docs/tasks/TASK-1161.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM

## Implementación prevista
- Añadir normalización `FC/CC/FF/CF` para el shortcode visible del grid.
- Soportar lag en `d / h / min`.
- Rehacer el modal `Añadir sucesora` con preview superior, selector de subtarea origen/destino y lag con unidad.
- Añadir una nueva columna izquierda `Suc.` editable con persistencia en lote.
- Estabilizar el guardado del enlace para evitar bloqueos con subtramos.

## Validación prevista
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`

## Implementación ejecutada
- `CronogramaGantt` amplía el contrato de dependencias para normalizar shortcode `FC/CC/FF/CF`, soportar lag en `día/hora/minuto` y persistir metadata de subtramos de origen/destino.
- El modal `Añadir sucesora` incorpora preview superior del shortcode, selector de subtarea origen/destino y lag con unidad explícita.
- El grid izquierdo añade la nueva columna `Suc.` con edición directa de shortcode y persistencia en lote contra las tareas destino afectadas.
- La columna `Suc.` se compacta como editor explícito en reposo/edición para que el usuario pueda crear el shortcode desde la propia tabla sin depender del modal de sucesoras.
- Se endurece el flujo de `Guardar enlace` con captura de error explícita para evitar el estado de espera silenciosa al trabajar con subtramos.
- Se unifica la barra superior del Gantt clásico en tres carriles oscuros diferenciados (`búsqueda`, `ruta crítica`, `escala/zoom`) para alinear toda la cabecera con el nuevo tema operativo sin tocar BIM ni backend.
- El bloque de `ruta crítica` compacta chips, contador y resumen `partidas calculables · críticas`, evitando duplicidades visuales con la navegación de búsqueda.
- El selector de escala temporal refuerza ancho y legibilidad del desplegable dentro del rail oscuro y el slider de zoom mantiene la guía clara sobre fondo oscuro.

## Validación ejecutada
- `npm run build`
- `node frontend/scripts/smoke-cronogramas-gantt-subbars.mjs`

## Resultado esperado
El Gantt clásico expone dependencias editables y persistentes con semántica compacta, sin romper el comportamiento vigente del módulo.
