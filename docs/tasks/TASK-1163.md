# TASK-1163 - Modernización de headers del grid Gantt clásico y ayuda operativa para shortcuts de sucesoras

## Objetivo
Modernizar visualmente los headers del grid izquierdo del `Cronograma Gantt` clásico para alinearlos mejor con el lenguaje reciente del `Cronograma Valorado`, y volver realmente instructiva la ayuda de la columna `Suc.` para la creación de shortcuts de dependencias.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1163.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin introducir acoplamientos hacia BIM

## Implementación prevista
- Rehacer el header del grid izquierdo con una piel más moderna y compacta.
- Unificar el header entre `split layout` y fallback clásico.
- Mejorar el tooltip de `Suc.` para explicar el formato del shortcode, el tipo de vínculo, el código destino y el lag opcional.
- Mantener intacta la lógica de dependencias y persistencia ya vigente.

## Validación prevista
- `npm run build`

## Implementación ejecutada
- El grid izquierdo del `Gantt` clásico sustituye los títulos planos por celdas de header más actuales, con microetiqueta, badge y tonos suaves por tipo de dato, acercándose al lenguaje visual del `Cronograma Valorado`.
- El nuevo header se encapsula en un bloque reutilizable y se aplica tanto al `split layout` como al fallback clásico, evitando divergencias visuales entre ambos carriles.
- La columna `Suc.` pasa a mostrar un tooltip estructurado y pedagógico con el contrato real del shortcut: tipo `FC/CC/FF/CF`, código de tarea sucesora y lag opcional en `d`, `h` o `min`.
- Los `title` del editor inline de `Suc.` y de su botón de edición también se vuelven más útiles, reforzando el mismo formato sin cambiar persistencia ni semántica.
- No se modifica backend, no se activa UX BIM y la capa BIM permanece aislada del ajuste.

## Validación ejecutada
- `npm run build`

## Resultado esperado
El `Gantt` clásico mejora la lectura de su grid izquierdo y la columna `Suc.` deja de ser críptica para el usuario operativo, sin introducir interferencias con BIM ni alterar el contrato funcional existente.
