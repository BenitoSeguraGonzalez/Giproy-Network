# TASK-1166 - Regresión clásica en enlaces del Gantt no anclados a barras visibles

## Objetivo
Corregir una regresión visual del `Cronograma Gantt` clásico en la que las dependencias quedan dibujadas hacia posiciones que no coinciden con la barra o subtramo visible de destino.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1166.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin introducir acoplamientos hacia BIM

## Implementación ejecutada
- La capa de dependencias deja de depender solo de geometría inferida por fila y ahora prioriza la geometría DOM real del bar visible.
- Cuando la dependencia apunta a un subtramo, el anclaje intenta resolver también la geometría DOM real del `subbar` visible antes de usar el fallback calculado.
- El cálculo de rutas usa el `centerY` del anclaje real resuelto, evitando desfases verticales que dejaban flechas “en el vacío”.
- El ajuste queda encapsulado en la capa clásica del Gantt y no altera BIM ni el backend común.

## Validación ejecutada
- `npm run build`

## Resultado esperado
Los enlaces del Gantt vuelven a terminar sobre la barra o subtramo visible correspondiente, sin desplazamientos aparentes entre origen/destino y geometría dibujada.
