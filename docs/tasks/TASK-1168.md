# TASK-1168 - Implementación de corrección total de representación de dependencias del Gantt clásico

## Objetivo
Corregir de forma definitiva la representación de enlaces del `Cronograma Gantt` clásico para que toda dependencia quede anclada exactamente al elemento visual correcto antes de avanzar con cambios de simbología.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1168.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin introducir acoplamientos hacia BIM

## Alcance funcional previsto
- Revisar anclaje sobre barra principal, subbarra y hito.
- Resolver desfases por scroll, virtualización, zoom y geometría sticky.
- Blindar el cálculo de rutas para que no apunte a filas vacías ni a targets visuales inexistentes.
- Dejar criterio de aceptación visual verificable para enlaces `FC`, `CC`, `FF` y `CF`.

## Validación prevista
- `npm run build`
- Revisión visual sobre casos reales del Gantt clásico

## Estado
- TASK completada.

## Implementación ejecutada
- La ruta SVG de dependencias deja de asumir siempre un comportamiento tipo `FC`.
- El punto de salida del enlace ahora depende del tipo real de relación:
  - `FC / FF`: salida por el fin del origen.
  - `CC / CF`: salida por el comienzo del origen.
- El punto de llegada del enlace ahora depende del tipo real de relación:
  - `FC / CC`: llegada al comienzo del destino.
  - `FF / CF`: llegada al fin del destino.
- El cálculo de corredores y aproximación final se adapta al lado real de anclaje, evitando que enlaces `CC`, `FF` o `CF` se dibujen como si fueran `FC`.

## Validación ejecutada
- `npm run build`
