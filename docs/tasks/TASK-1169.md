# TASK-1169 - Implementación de simbología documental de secuenciamiento en el Gantt clásico

## Objetivo
Adaptar la UX del `Cronograma Gantt` clásico a la simbología documental definida en `docs/adicionales/Condiciones de secuenciamiento actividades cronogramas.docx`, exponiendo de forma consistente `FC`, `CC`, `FF` y `CF`.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `docs/tasks/TASK-1169.md`
- `docs/runtime/WORK_MODE_STATE.json`
- `docs/CHANGELOG.md`
- Sin tocar backend común
- Sin activar UX BIM
- Sin introducir acoplamientos hacia BIM

## Alcance funcional previsto
- Unificar labels, tooltips, ayudas y ejemplos visibles a `FC / CC / FF / CF`.
- Mantener compatibilidad interna con el modelo técnico actual si todavía usa `FS / SS / FF / SF`.
- Centralizar el mapeo entre simbología visible e identificadores internos.
- Alinear shortcuts, editor rápido, panel de enlace y ayudas contextuales con el documento fuente.

## Precondición obligatoria
- `TASK-1168` debe quedar cerrada satisfactoriamente antes de ejecutar esta TASK.

## Validación prevista
- `npm run build`
- Revisión funcional sobre shortcuts, selector de tipo y tooltips

## Estado
- TASK completada.

## Implementación ejecutada
- La UX visible deja de hablar en términos `Fin-Inicio / Inicio-Inicio / Inicio-Fin` y pasa a usar la terminología documental `Fin-Comienzo / Comienzo-Comienzo / Fin-Fin / Comienzo-Fin`.
- Se centraliza una función de presentación para que selectores, labels derivados y lectura de dependencias expongan el mismo formato visible `FC / CC / FF / CF`.
- El editor de dependencia y el creador rápido de sucesoras muestran la misma simbología canónica que ya utilizan los shortcodes.
- La normalización de tipos acepta tanto códigos visibles (`FC / CC / FF / CF`) como identificadores internos (`FS / SS / FF / SF`) y aliases heredados, cerrando la simetría entre parseo, edición y persistencia.
- La ayuda contextual del grid y de los editores explica ya la semántica documental exacta de `FC`, `CC`, `FF` y `CF`, evitando lecturas ambiguas del tipo de relación.
