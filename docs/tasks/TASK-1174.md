# TASK-1174 - Representación, QA e interoperabilidad de dependencias MSP-compatibles del Gantt clásico

## Objetivo
Cerrar la adecuación integral asegurando que la representación gráfica, la validación funcional y la interoperabilidad de dependencias del Gantt clásico queden alineadas con la lógica de Microsoft Project.

## Alcance autorizado
- `frontend/src/components/projects/CronogramaGantt.jsx`
- QA y documentación vinculadas al módulo
- Sin activar UX BIM
- Sin romper backend común

## Alcance funcional previsto
- Alinear el dibujo de enlaces con los tipos internos `FS/SS/FF/SF`.
- Verificar que la representación visible sea coherente con `FC/CC/FF/CF`.
- Validar múltiples dependencias en una sola celda.
- Validar `lag/lead` en tiempo absoluto y porcentaje.
- Verificar estabilidad con scroll, zoom y virtualización, asegurando además que la existencia de subbarras no introduzca endpoints de dependencia a nivel de tramo.
- Revisar la alineación del modelo con import/export MSP/XML cuando corresponda en el frente.

## Criterio de aceptación
- Ningún enlace puede quedar desanclado visualmente.
- El texto de `Predecesoras` y la geometría del gráfico deben expresar exactamente la misma relación.
- El módulo debe quedar listo para interoperabilidad MSP sin traducciones semánticas improvisadas.
