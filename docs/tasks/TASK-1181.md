# TASK-1181 - Guardarraíles anti-regresión de serialización Gantt clásico

## Objetivo
Añadir pruebas y validaciones que impidan volver a una lógica donde `Predecesoras` se guarde como metadata, pero no gobierne realmente la programación temporal de la tarea destino.

## Validaciones obligatorias
1. Smoke real sobre `Santiago Bermeo` con dependencias persistidas.
2. Validación de que las fechas computadas cumplen todas las relaciones activas.
3. Validación específica de `FS/FC` y `FF` con datos reales.
4. Smoke frontend consolidado del Gantt clásico.
5. Build frontend.

## Criterios de aceptación
- El smoke falla si una fila con dependencia queda antes de su restricción efectiva.
- La validación no depende de inspección visual manual.
- La capa BIM permanece no contaminada.

## Implementación
- El smoke real `smoke_test_cronogramas_gantt_real.py` valida que todas las dependencias activas cumplan `FC/CC/FF/CF` sobre fechas computadas.
- Se añaden pruebas unitarias de calendario laboral y autoridad temporal para impedir que vuelvan a mandar fechas manuales obsoletas sobre relaciones activas.
- La validación frontend consolidada mantiene el smoke de dependencias, ruta crítica y no contaminación BIM.
- El build frontend valida que la resolución visual local del grafo queda integrada sin romper virtualización, búsqueda ni render del Gantt clásico.

## Validación
- `python -m pytest app/tests/test_cronograma_trabajo_cpm_metadata.py app/tests/test_cronograma_trabajo_ms_project.py -q`
- `python scripts/smoke_test_cronogramas_gantt_real.py --max-schedule-seconds 20 --max-valuado-seconds 20 --max-reset-seconds 20`
- `npm run smoke:gantt-classic`
- `npm run build`
