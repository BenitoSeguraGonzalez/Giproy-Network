# TASK-1188 - Geometría de barras Gantt basada en fecha real de fin

Estado
DONE

Tipo
visual-functional-bug

Prioridad
high

Descripción
Corregir la representación de barras del Gantt clásico para que el ancho visual se calcule con la posición real de `fin - inicio` en el timeline, y no como `duración * ancho de columna`.

Alcance
- Solo capa clásica.
- Solo geometría visual de barras Gantt.
- Sin cambios en backend, serialización de predecesoras ni BIM.

Motivo
En escalas no horarias, especialmente vistas semanales, la barra podía dibujarse con una longitud proporcional a columnas completas en lugar del calendario real. Esto hacía que relaciones como `6FF` parecieran no igualar el fin aunque la fecha calculada fuese correcta.

Resultado
- La barra toma `start_date`, calcula su `finish` con calendario laboral y pinta `width = posición(fin) - posición(inicio)`.
- `FF` puede alinear visualmente el borde derecho de destino con el borde derecho de origen.
- Se conserva ancho mínimo para hitos o duraciones visualmente muy pequeñas.
- Sin interferencia con GiProy BIM.

Validación ejecutada
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `node scripts/smoke-cronogramas-gantt-subbars.mjs`
- `npm run build`
