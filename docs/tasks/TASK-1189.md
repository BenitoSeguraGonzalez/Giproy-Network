# TASK-1189 - Escala temporal manual aplica zoom base

Estado
DONE

Tipo
ux-bug

Prioridad
high

Descripción
Corregir la sensación de que la escala temporal del Gantt clásico no actúa cuando el usuario cambia entre Hora/Día/Semana/Mes/etc. El cambio manual de escala debe ser evidente y no quedar neutralizado por un zoom anterior o por el modo "Todo".

Alcance
- Solo capa clásica.
- Solo selector de escala temporal y zoom asociado.
- Sin cambios en backend, fechas, predecesoras ni BIM.

Resultado
- Al seleccionar una escala temporal manual, la escala se fija y el zoom vuelve a `100%`.
- El viewport conserva el ancla temporal central para no perder contexto.
- El zoom puede ajustarse después de elegir la escala, pero ya no neutraliza el cambio inicial.
- Sin interferencia con GiProy BIM.

Validación ejecutada
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `node scripts/smoke-cronogramas-gantt-subbars.mjs`
- `npm run build`
