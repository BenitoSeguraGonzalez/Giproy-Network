# TASK-1192 - Configurar representación visual de tareas menores a un día

## Estado
DONE

## Modo
GIPROY CLASICO

## Objetivo
Hacer opcional la regla visual del Gantt clásico que representa tareas de duración menor a un día como un día completo.

## Alcance
- Capa clásica de Cronograma Gantt.
- Sin cambios en cálculo temporal real ni backend obligatorio.
- Sin activación ni exposición de UX BIM.

## Cambios
- Se añade la opción `Tareas cortas = 1 día visual` al panel de configuración del Gantt.
- El valor por defecto queda activado para conservar el comportamiento histórico.
- Al desactivar la opción, las barras y subtramos menores a un día se pintan con su duración visual real.
- La opción se conserva dentro de `configDraft` y viaja en la configuración guardada del cronograma.

## Validación
- `node scripts/smoke-cronogramas-gantt-subbars.mjs`
- `npm run build`

## No interferencia BIM
Sin cambios en rutas, componentes, APIs ni documentación operativa BIM.
