# TASK-1194 - Compactar informacion de descripcion Gantt por preferencia visual

## Estado
DONE

## Modo
GIPROY CLASICO

## Objetivo
Hacer opcional la informacion extendida mostrada bajo la descripcion de cada tarea del Gantt, manteniendo siempre visible la informacion obligatoria: estado principal y shortcode de secuenciacion dominante.

## Alcance
- Capa clasica de Cronograma Gantt.
- Preferencia visual por usuario, proyecto y revision.
- Sin cambios en backend, calculo de predecesoras, Cronograma Valorado ni BIM.

## Cambios
- Se anade el check `Informacion extendida en descripcion` en la configuracion del Gantt.
- La preferencia se guarda junto a las preferencias visuales locales por usuario/proyecto/revision.
- Con la opcion apagada, la descripcion mantiene solo el estado principal (`Pendiente aprobar`, `Sincronizado`, etc.) y el shortcode dominante (`6FF`, `3FC`, etc.).
- Con la opcion activa, vuelven a mostrarse diagnosticos auxiliares como ruta critica, CPM, recursos, conflictos, tramos y conteo de relaciones.

## Validacion
- `node scripts/smoke-cronogramas-gantt-subbars.mjs`
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `npm run build`

## No interferencia BIM
Sin cambios en rutas, componentes, APIs ni documentacion operativa BIM.
