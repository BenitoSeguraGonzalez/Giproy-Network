# TASK-1195 - Selector De Columnas En Grids Clásicos De Cronogramas

## Contexto
El usuario solicita aprovechar la barra de búsqueda de los grids de `Cronograma Gantt` y `Cronograma Valorado` para añadir un control de columnas que permita ordenar y mostrar/ocultar campos sin perder las columnas fijas `Item` y `Cod EDT`.

## Alcance
- Capa clásica únicamente.
- Sin dependencias ni UX BIM.
- Backend común sin cambios.
- `Item` y `Cod EDT` permanecen visibles y ancladas.
- Preferencias visuales persistidas por usuario, proyecto/presupuesto y revisión.
- `Cronograma Valorado` incorpora columna `Fin` cuando existe ventana real derivada del Gantt.

## Implementación
- Se crea `GridColumnManager` como control reutilizable de columnas para grids clásicos.
- El buscador de `Cronograma Gantt` incorpora el botón `Columnas del Gantt`.
- El buscador de `Cronograma Valorado` incorpora el botón `Columnas del valorado`.
- El grid base del valorado puede ocultar/reordenar columnas no obligatorias y muestra `Fin` desde la fecha final efectiva del Gantt cuando está disponible.

## Validación
- `npm run build`.
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`.
- `node scripts/smoke-cronogramas-gantt-subbars.mjs`.

## No interferencia BIM
No se modifican rutas, componentes, APIs ni documentación BIM. El cambio queda limitado a componentes clásicos de cronogramas y documentación de tarea.
