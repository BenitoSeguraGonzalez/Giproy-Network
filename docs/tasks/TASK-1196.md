# TASK-1196 - Preferencias Visuales Del Gantt Visibles En Configuración

## Contexto
El usuario no localiza las opciones `Tareas cortas = 1 día visual` e `Información extendida en descripción` dentro del panel de configuración del Gantt clásico.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin BIM.
- Corrección visual de accesibilidad/descubribilidad.

## Implementación
- La rama compacta del panel `Configuración de Proyecto` del Gantt incorpora al inicio un bloque `Preferencias visuales`.
- Las dos opciones quedan visibles antes de fechas y horario laboral.
- Se reutiliza la misma lógica persistente ya existente por usuario/proyecto/revisión.

## Validación
- `npm run build`.

## No interferencia BIM
No se modifican rutas, componentes ni APIs BIM.
