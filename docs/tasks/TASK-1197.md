# TASK-1197 - Calendario De Festivos Visible En Configuración Compacta Del Gantt

## Contexto
El usuario no localiza la opción de calendario donde se gestionan días festivos dentro del panel compacto de configuración del `Cronograma Gantt`.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin UX BIM.
- Reutilizar handlers existentes del calendario laboral.

## Implementación
- La configuración compacta del Gantt muestra ahora `Calendario de festivos`.
- Se puede recargar calendario oficial, resetear, añadir festivo manual y revisar/quitar festivos existentes por fecha.
- La lógica usa el calendario ya existente de `CronogramaTrabajo`, sin crear un contrato nuevo.

## Validación
- `npm run build`.

## No interferencia BIM
No se modifican rutas, componentes ni APIs BIM.
