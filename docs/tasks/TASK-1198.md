# TASK-1198 - Snap Visual De Líneas De Secuenciación En Zoom

## Contexto
Al variar el zoom del Gantt clásico, algunas líneas de secuenciación podían quedar ligeramente desalineadas respecto al marcador/ancla de la tarea destino.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin UX BIM.
- Sin cambios en cálculo temporal ni política de predecesoras.

## Implementación
- Se añade cuantización de coordenadas SVG a medio píxel para rutas de dependencias.
- `buildDependencyRoute` normaliza puntos, control de selección y rutas casi verticales con el mismo criterio.
- La llegada de la línea conserva el ancla gobernada (`inicio`/`fin`) pero evita decimales arbitrarios generados por mediciones DOM bajo zoom.

## Validación
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`.
- `npm run build`.

## No interferencia BIM
No se modifican rutas, componentes, APIs ni feature flags BIM.
