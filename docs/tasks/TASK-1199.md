# TASK-1199 - Gantt Restaura La Ventana Original Al Limpiar Relaciones

## Contexto
Al quitar predecesoras en el Gantt clásico, la línea podía quedarse con fechas desplazadas por la secuenciación previa aunque ya no existiera ninguna relación activa.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin UX BIM.
- Sin cambios en Cronograma Valorado.

## Implementación
- Se introduce un snapshot de ventana independiente (`gantt_unconstrained_schedule_v1`) para preservar la fecha base de la tarea antes de que quede gobernada por predecesoras.
- Cuando una línea pasa a tener relaciones, el guardado conserva esa ventana independiente en metadata.
- Cuando la línea vuelve a quedar sin relaciones, el guardado restaura el inicio original desde ese snapshot y limpia la marca temporal de secuenciación.
- Como red de seguridad, si no existe snapshot independiente pero sí snapshot confirmado previo, se reutiliza este último para evitar dejar la tarea desplazada tras limpiar relaciones no confirmadas.

## Validación
- `npm run build`

No se modifican rutas, componentes, APIs ni feature flags BIM.
