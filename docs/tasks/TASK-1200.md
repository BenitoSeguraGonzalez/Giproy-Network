# TASK-1200 - Gantt Alinea Secuenciación Al Borde Temporal Real

## Contexto
En zoom fino, especialmente en escala hora, la secuenciación del Gantt clásico podía aparentar lags inexistentes porque la línea se anclaba a un punto interior decorativo y, en casos cercanos, colapsaba la ruta a una vertical falsa.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin cambios en cálculo temporal.
- Sin UX BIM.

## Implementación
- Las rutas de dependencia dejan de usar un inset interno para inicio/fin gobernado y pasan a cerrar en el borde temporal real visible de la barra.
- Se elimina la simplificación que colapsaba diferencias horizontales pequeñas a una vertical artificial sobre la `x` del destino.
- El triángulo naranja del gobernado se recoloca para coincidir visualmente con el mismo borde temporal.
- Se actualiza el smoke test para exigir anclaje estricto en FC, CC, FF y CF.

## Validación
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `npm run build`

## No interferencia BIM
No se modifican rutas, componentes, APIs ni feature flags BIM.
