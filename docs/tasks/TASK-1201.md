# TASK-1201 - Gantt Reescribe El Motor De Líneas De Secuenciación

## Contexto
La interpretación visual de secuenciación del Gantt clásico seguía introduciendo codos y recorridos innecesarios, además de mantener una falsa ayuda visual de tareas cortas incluso desactivada.

## Alcance
- Capa clásica únicamente.
- Sin backend.
- Sin BIM.
- Sin cambiar la lógica temporal del cálculo de secuenciación.

## Implementación
- Se sustituye el router heurístico de dependencias por un router ortogonal determinista:
  - vertical pura si origen y destino comparten `x` temporal,
  - horizontal + vertical simple cuando existe separación real,
  - desvío exterior solo para relaciones con geometría hacia atrás.
- Las barras normales dejan de usar anchura mínima artificial cuando tienen duración positiva.
- La preferencia `Tareas cortas = 1 día visual` vuelve a gobernar la geometría real de barra: apagada ya no aproxima duraciones menores de un día a un ancho tipo día completo.

## Validación
- `node scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `npm run build`

## No interferencia BIM
No se modifican rutas, APIs ni componentes BIM.
