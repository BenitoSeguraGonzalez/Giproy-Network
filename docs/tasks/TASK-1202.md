# TASK-1202 - Estabilizar refresco visual del viewport Gantt al cambiar zoom

## Contexto
- Modo activo: `GIPROY CLASICO`
- Frente: `Gantt clásico`
- Motivación: al cambiar el zoom, la zona visible del timeline podía quedar desfasada respecto al scroll real y a la ventana virtual renderizada.

## Objetivo
- Forzar que el snapshot lógico del viewport del Gantt se resincronice inmediatamente tras cada cambio de zoom o reajuste anclado.
- Evitar que la virtualización deje segmentos visibles sin refresco correcto después de cambiar escala.

## Alcance
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `frontend/scripts/smoke-cronogramas-gantt-dependencies.mjs`

## Implementación
- Se endurece la actualización del snapshot horizontal y vertical del viewport para no tolerar diferencias amplias tras zoom.
- Se fuerza el commit del snapshot cuando el zoom reancla el `scrollLeft` del timeline.
- Se fuerza también la resincronización desde el `ResizeObserver` del viewport del timeline.
- Se alinean las expectativas del smoke de dependencias al router ortogonal actualmente activo.

## Validación
- `node frontend/scripts/smoke-cronogramas-gantt-dependencies.mjs`
- `npm run build`
