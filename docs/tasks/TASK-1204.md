# TASK-1204 - Hacer estrictas las anclas temporales de secuenciación en Gantt

## Contexto
- Modo activo: `GIPROY CLASICO`
- Frente: `Gantt clásico`
- Motivación: las líneas de secuenciación podían usar la geometría visual de barras muy cortas o aproximadas, creando lag visual falso y recorridos ortogonales incorrectos.

## Objetivo
- Separar la geometría temporal exacta de la geometría visual decorativa.
- Hacer que las dependencias `FC/CC/FF/CF` se anclen siempre al `inicio/fin` real calculado, aunque la barra visible sea más ancha por representación.

## Alcance
- `frontend/src/components/projects/CronogramaGantt.jsx`

## Implementación
- El layout de dependencias pasa a construir una `anchorGeometry` con `X` temporal exacta y `Y` visual de la fila.
- La ruta usa esa ancla exacta para origen y destino.
- La banda de obstáculos sigue tomando la geometría visual para evitar cruces sobre barras visibles.
- Con ello, una relación sin lag deja de interpretarse como geometría “hacia atrás” por culpa del ancho visual mínimo de barras cortas.

- `npm run build`
