# TASK-1205 - Forzar redraw del grid izquierdo al reordenar columnas en Gantt

## Contexto
- Modo activo: `GIPROY CLASICO`
- Frente: `Gantt clásico`
- Motivación: al mover columnas del grid izquierdo, el layout podía no redibujarse de forma consistente cuando cambiaba el orden pero no variaba suficientemente el ancho total.

## Objetivo
- Forzar una resincronización fiable del grid izquierdo cuando cambia el orden o el ancho visible de columnas.
- Evitar estados intermedios donde cabecera, filas y alturas queden con métricas antiguas.

## Alcance
- `frontend/src/components/projects/CronogramaGantt.jsx`

## Implementación
- Se introduce una firma de layout basada en `visibleColumnIds + visibleWidths`.
- La resincronización de alturas del grid pasa a depender también de esa firma.
- Las cabeceras y superficies duplicadas del grid usan la firma para invalidar mejor el render cuando cambia el orden de columnas.

## Validación
- `npm run build`

- Sin cambios en backend.
