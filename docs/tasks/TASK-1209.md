# TASK-1209 - Estabilizar grid izquierdo al navegar tareas críticas

## Contexto
- Modo activo: `GIPROY CLASICO`
- Frente: `Gantt clásico`
- Motivación: al usar la navegación de ruta crítica, el grid izquierdo podía deformarse o desincronizarse respecto al timeline.

## Objetivo
- Mantener alineados grid izquierdo y timeline al enfocar una tarea crítica.
- Evitar desplazamientos unilaterales del grid izquierdo.

## Alcance
- `frontend/src/components/projects/CronogramaGantt.jsx`

## Implementación
- La navegación a filas deja de depender de `scrollIntoView` unilateral sobre el grid izquierdo.
- El scroll vertical se resuelve por offset compartido y se aplica a ambos paneles.
- La resincronización de alturas escucha explícitamente el estado activo del navegador crítico.

## Validación
- `npm run build`
