# TASK-1211 - Corregir ReferenceError de navegador crítico en Cronograma Gantt

## Contexto
- `CronogramaGantt` lanzaba `ReferenceError: Cannot access 'activeCpmNavigatorMatchId' before initialization`.
- La regresión rompía la carga del módulo en `Proyectos > Cronogramas > Gantt`.

## Causa raíz
- El valor derivado `activeCpmNavigatorMatchId` se utilizaba en efectos de sincronización visual antes de declararse en el cuerpo del componente.
- Al estar definido con `const`, JavaScript aplicaba la `TDZ` y el componente fallaba en runtime.

## Implementación
- Se reordena el bloque de efectos de resincronización de filas para ejecutarse después de derivar:
  - `cpmNavigatorMatches`
  - `cpmNavigatorMatchIds`
  - `activeCpmNavigatorMatchId`
- No se modifica la lógica funcional del navegador crítico ni del grid.

## Validación
- `npm run build`
  - Resultado: OK

## No interferencia BIM
- Sin cambios en BIM.
- Sin cambios en backend.
