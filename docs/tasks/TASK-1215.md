# TASK-1215 - Estabilizar drag'n drop del Gantt y rollback ante persistencia fallida

## Objetivo
Corregir las regresiones del `drag'n drop` en Gantt clásico cuando una operación falla al guardar, evitando deformaciones del layout, ghost mal anclado y estado visual inconsistente.

## Problemas atacados
- El drag aplicaba un estado optimista en pantalla antes de persistir.
- Si backend rechazaba el movimiento, el Gantt quedaba visualmente alterado porque no existía rollback.
- La altura del workspace podía recalcularse durante el arrastre y generar sensación de cambio de tamaño.
- La burbuja informativa del drag se mostraba centrada en la fila y no sobre el preview real de la barra/subtramo.
- Cuando el backend detectaba una línea ya no válida para el presupuesto activo, el frente no se autocuraba.

## Decisiones aplicadas
- Congelar la altura del workspace durante una interacción de drag.
- Esperar la persistencia real del movimiento y restaurar el snapshot previo de borradores si falla.
- Si el backend devuelve `La línea X no pertenece a una partida calculable...`, recargar cronograma desde presupuesto para resincronizar la capa clásica.
- Reanclar la burbuja del drag al centro geométrico real del preview visible.
