# TASK-1218 - UX de Configuración de Gantt y calendario anual completo

## Objetivo
Evolucionar el modal `Configuración de Gantt` para incorporar un acceso a calendario anual completo con look & feel oscuro alineado al rail y popovers actuales del Gantt clásico.

## Alcance
- Renombrado visible consolidado a `Configuración de Gantt`.
- Apertura de un calendario anual completo desde el modal.
- Vista oscura técnica, coherente con la interfaz actual del Gantt.
- Visualización de:
  - laborables
  - no laborables
  - festivos
  - excepciones manuales
  - presencia de franjas horarias

## Requisitos funcionales
- Debe existir un botón claro para abrir el calendario anual.
- El calendario anual debe permitir revisar y editar el estado laborable de cada fecha.
- Debe diferenciar patrón base y override por fecha.
- Debe seguir siendo usable sin romper la configuración simple existente.

## Requisitos UX
- Una sola jerarquía visual clara.
- Modo oscuro técnico, no modal blanco heredado.
- Sin introducir wrappers o shells visuales ajenos al lenguaje actual del Gantt clásico.

## Validación esperada
- QA visual en distintas resoluciones.
- QA de apertura/cierre sin overlays, bandas negras ni tooltips congelados.
- QA de no regresión sobre el modal actual.

## Impacto BIM
- Ninguno.

## Implementación 2026-04-23
- `Configuración de Gantt` incorpora el bloque oscuro `Calendario avanzado`.
- El usuario puede activar/desactivar el calendario avanzado sin tocar la configuración simple.
- Se añade edición de patrón semanal con:
  - día laborable/no laborable
  - múltiples franjas por día
  - hora inicio
  - hora fin
  - descripción de franja
- Se añade listado de excepciones por fecha, usando la fecha seleccionada del calendario/festivos como origen operativo.
- La UI queda dentro del panel clásico existente, sin wrappers nuevos ni UX BIM.

## Validación 2026-04-23
- `npm run build`

## Impacto BIM
- Ninguno. No se modifican rutas, flags ni componentes BIM.
