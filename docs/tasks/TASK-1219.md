# TASK-1219 - Grid de franjas horarias múltiples por día en Gantt clásico

## Objetivo
Añadir al calendario del `Gantt` clásico la capacidad de definir múltiples horarios de trabajo por día mediante un grid técnico editable.

## Alcance
- Grid por día con columnas:
  - `Hora inicio`
  - `Hora fin`
  - `Descripción`
- Soporte para múltiples franjas por día.
- Soporte para huecos libres entre franjas.
- Edición tanto sobre patrón semanal como sobre excepciones por fecha.

## Requisitos funcionales
- Un día puede tener `n` franjas horarias.
- Las franjas no pueden solaparse.
- `Hora fin` siempre debe ser mayor que `Hora inicio`.
- El orden debe ser consistente y visible.
- Debe permitirse un día sin franjas, tratándolo como no laborable.

## Regla de convivencia
- La ausencia de franjas explícitas no debe romper la lógica simple actual.
- El grid debe convivir con la configuración laboral heredada hasta cierre aprobado del frente.

## Validación esperada
- QA de alta, edición, eliminación y ordenación de franjas.
- QA de días con una franja, dos franjas, varias franjas y sin franjas.
- QA de validaciones de solapamiento y huecos libres.

## Impacto BIM
- Ninguno.

## Implementación 2026-04-23
- Se implementa grid semanal de franjas horarias múltiples dentro de `Configuración de Gantt`.
- Cada día soporta `Hora inicio`, `Hora fin` y `Descripción`.
- Se pueden añadir y eliminar franjas por día.
- Un día sin franjas queda tratado como no laborable para el calendario avanzado.
- La normalización frontend mantiene horarios en `HH:MM` y descarta franjas inválidas con `fin <= inicio`.
- Backend valida y rechaza solapes para impedir persistencia ambigua.
