# TASK-1220 - Adaptador de motor temporal avanzado en backend común para Gantt

## Objetivo
Implantar una nueva capa de cálculo temporal en el backend común capaz de operar con franjas horarias múltiples por día, manteniendo como fallback el motor simple actual.

## Alcance
- Resolver siguiente instante laborable.
- Resolver fin a partir de inicio + duración sobre tiempo efectivo.
- Resolver inicio a partir de fin - duración sobre tiempo efectivo.
- Aplicar festivos y excepciones por fecha.
- Soportar desplazamientos y lag sobre tiempo laborable real.

## Requisitos funcionales
- El motor avanzado debe ser invocable sin desactivar todavía el motor simple.
- Debe existir un adaptador que seleccione:
  - motor simple
  - motor avanzado
  según la configuración activa del cronograma.
- La aritmética de duración no puede seguir tratándose como un bloque plano de `jornada_laboral_horas` cuando el calendario avanzado esté activo.

## Requisitos de no regresión
- Las operaciones actuales del backend deben conservar resultado idéntico en modo simple.
- No romper exportes ni snapshots del cronograma.
- No romper dependencias `FC/CC/FF/CF`.

## Validación esperada
- Tests unitarios y de integración para:
  - suma de duración atravesando varias franjas
  - saltos de huecos libres
  - saltos de festivos
  - overrides por fecha
  - lag positivo y negativo

## Impacto BIM
- Ninguno.

## Implementación 2026-04-23
- Se implanta adaptador temporal avanzado en backend común con fallback automático al motor simple.
- El adaptador se activa únicamente cuando `advanced_calendar.enabled === true` y `mode === "advanced"`.
- Soporta:
  - siguiente instante laborable
  - suma de duración cruzando franjas y huecos
  - resta de duración desde fecha fin
  - festivos avanzados y festivos externos del calendario de proyecto
  - excepciones por fecha
  - lag positivo/negativo usado por relaciones `FS/SS/FF/SF`
- El motor simple permanece en el mismo flujo para configuraciones legacy.
