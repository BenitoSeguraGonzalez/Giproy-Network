# TASK-1223 - Saneado visual del modo tareas cortas = 1 día visual en Gantt clásico

## Objetivo
Corregir las regresiones visuales del modo `Tareas cortas = 1 día visual` en el `Gantt` clásico, eliminando etiquetas heredadas dentro de la barra y recuperando una lectura coherente de las secuencias sin tocar el cálculo temporal real.

## Problemas atacados
- En tareas/subtramos cortos aproximados a `1 día visual` seguía apareciendo una etiqueta heredada tipo `T01-S01` dentro de la barra.
- La representación visual de tareas cortas aproximadas no enseñaba el núcleo temporal exacto, lo que hacía que las dependencias parecieran incorrectas o con lag visual falso.
- La geometría visual aproximada y la geometría temporal exacta no estaban expresadas de forma clara para lectura del usuario.

## Decisiones aplicadas
- Retirar el texto inline heredado de subtramos dentro de las barras del Gantt.
- Mantener el contenedor visual ampliado a `1 día`, pero dibujar dentro un núcleo exacto que represente la duración real cuando la tarea es menor a un día.
- Dejar la línea de dependencia anclada al tiempo exacto y hacer visible ese anclaje mediante el núcleo interno, en lugar de aparentar que la línea entra o sale de una barra plana incorrecta.
- Ajustar el router de dependencias para que el punto de salida/llegada use el anclaje real de la tarea y no el borde superior/inferior ni la caja visual ampliada.
- Añadir un codo mínimo de legibilidad cuando dos anclajes reales quedan en la misma coordenada X pero pertenecen a filas distintas, evitando columnas verticales ambiguas en zoom día sin mover el origen ni el destino real.
