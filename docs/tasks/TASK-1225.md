# TASK-1225 - Corrección de codos inventados en líneas de secuenciación del Gantt clásico

## Objetivo
Evitar que el router visual de dependencias cree codos horizontales cuando los anclajes de origen y destino ya están temporalmente alineados o avanzan de forma local.

## Causa
El ajuste de legibilidad para escalas gruesas introdujo un codo mínimo cuando los anclajes quedaban casi en la misma coordenada `X`. En escala `HORA`, esa regla era incorrecta porque convertía relaciones estrictas sin lag en recorridos con separación visual falsa.

## Corrección
- Se elimina el codo mínimo forzado como regla general.
- Si los anclajes están prácticamente alineados, la línea cae sobre el mismo eje temporal.
- Si el destino está localmente hacia delante, se usa una ruta directa al anclaje destino.
- El carril exterior queda reservado para relaciones que realmente vuelven hacia atrás o requieren evitar barras.
