# TASK-1226 - Corregir reordenamiento real del grid izquierdo del Gantt clásico

## Modo
GIPROY CLASICO

## Objetivo
Eliminar la desalineación de filas cuando el usuario reordena columnas del grid izquierdo del Gantt, especialmente al mover `Predecesoras` antes de `Inicio`.

## Causa raíz
El grid renderizaba las celdas en orden DOM histórico y las recolocaba con `gridColumn`. En CSS Grid, si el orden visual no coincide con el orden de auto-placement, el navegador puede crear huecos o filas implícitas en escenarios de reordenamiento. Esto hacía que una celda como `Predecesoras` pareciera pertenecer a otra fila.

## Implementación
- El helper común `getCellGridStyle` ahora fija `order` según el índice visible de columna.
- El helper mantiene `gridRow: 1 / 2` y añade `minWidth: 0` para que todas las celdas se comporten como una única fila lógica.
- Las filas del Gantt activan `gridAutoFlow: dense` como defensa adicional ante huecos de auto-placement.

## Alcance
- Frontend clásico: `CronogramaGantt` y `GridColumnManager`.
- Sin cambios en backend.
- Sin cambios en Cronograma Valorado.
- Sin cambios en BIM ni dependencias hacia BIM.

## Validación
- `npm run build` completado correctamente.
