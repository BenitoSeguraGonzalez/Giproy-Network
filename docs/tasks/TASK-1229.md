# TASK-1229 - Barra resumen EDT en Gantt clasico

## Modo
GIPROY CLASICO

## Objetivo
Mostrar en las filas EDT del Gantt una barra resumen tipo Project que acote graficamente el inicio minimo y fin maximo de sus tareas calculables descendientes.

## Alcance
- Capa visual del Gantt clasico.
- Sin cambios de calculo temporal, dependencias, guardado ni cronograma valorado.
- Sin activar ni modificar UX BIM.

## Implementacion
- Se calcula una envolvente por fila EDT usando solamente descendientes calculables.
- El inicio de la barra EDT toma el inicio mas temprano de sus tareas hijas.
- El fin de la barra EDT toma el fin mas tardio de sus tareas hijas.
- La representacion se dibuja como linea fina con remates verticales, pasiva y sin afectar interacciones de tareas.

## Validacion
- `npm run build` completado correctamente.
- Verificacion de no contaminacion BIM: cambios limitados a `CronogramaGantt.jsx`, TASK y CHANGELOG.

## No interferencia BIM
- No se modifican rutas ni componentes BIM.
- No se introduce dependencia hacia BIM.
