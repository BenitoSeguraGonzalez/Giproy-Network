# TASK-1232 - Calendario visual del proyecto y usabilidad del panel de configuración Gantt

## Modo
GIPROY CLASICO

## Objetivo
Mejorar la experiencia de `Configuración de Gantt` con header siempre visible, renombrado a `Calendario laboral personalizado`, acción iconográfica, un modal visual del calendario laboral del proyecto basado en la ventana operativa real y una fecha fin objetivo editable para medir retraso/adelanto de obra.

## Alcance
- Frontend clásico del Gantt.
- Ajuste mínimo de backend para persistir `fecha_fin_objetivo_proyecto` dentro del contrato existente de configuración del cronograma.
- Reutilización del contrato existente `holiday_calendar`.
- Reutilización del calendario simple y del calendario personalizado existentes.
- Sin cambios de licencias ni UX BIM.

## Implementación
- El header del panel `Configuración de Gantt` pasa a comportamiento sticky para mantener siempre visible la acción de cierre.
- La denominación visible `Calendario laboral ampliado` pasa a `Calendario laboral personalizado`.
- La acción para alternar el calendario personalizado se compacta a botón iconográfico contextual (`CalendarRange` / `RotateCcw`).
- `Calendario de festivos` añade un acceso iconográfico para abrir un modal dedicado del calendario laboral del proyecto.
- El modal visual muestra la franja operativa real del proyecto y representa todos los meses del rango en una vista cómoda.
- El coloreado distingue días laborables, no laborables semanales, festivos oficiales y festivos manuales.
- El modal marca además `Inicio`, `Fin`, `Hoy` y el índice de día dentro de la franja del proyecto.
- La ventana visual del calendario se recalcula desde el rango operativo efectivo del proyecto (`fecha_inicio_proyecto` + fin real de referencia) en lugar de depender solo del rango devuelto por `holiday_calendar`.
- La configuración añade `fecha_fin_objetivo_proyecto` como fecha editable persistida del cronograma para comparar el fin calculado contra la meta del proyecto.
- `Fecha finalización` deja de ser una referencia estática y pasa a mostrarse como `Fecha finalización objetivo`, acompañada por el `Fin calculado` y la lectura de `Retraso obra` o `Adelanto obra`.
- El modal del calendario amplía su ventana hasta la fecha más tardía entre fin calculado, fin objetivo y rango de festivos, para no perder visibilidad cuando existe desviación.
- El lateral del modal permite revisar el estado del día seleccionado y retirar festivos manuales existentes sin salir del flujo.
- La grilla mensual del modal reduce densidad visual: los meses pasan a una sola columna hasta resoluciones muy amplias, se elimina el ruido repetitivo `Dxx` dentro de cada celda y los estados se compactan en chips más cortos para evitar solapes.
- La celda diaria del calendario se simplifica aún más: abandona etiquetas textuales largas dentro del grid y pasa a una lectura por número, marcadores mínimos y punto de estado, dejando el detalle semántico completo al panel lateral del día seleccionado.
- La tarjeta resumen del modal renombra `Oficiales` a `Festivos` para mantener consistencia verbal con el resto del módulo.
