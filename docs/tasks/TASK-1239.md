## Modo
GIPROY CLASICO

## Tipo
Implementación frontend

## Objetivo
Permitir que los hitos manuales participen en la red visual de dependencias del Gantt clásico como marcadores de planificación de duración cero.

## Relación
- Frente padre: `TASK-1230`.
- Control asociado: `TASK-1237`.

## Implementación
- Se habilitan ids sintéticos `manual-milestone:<id>` para relaciones visuales frontend.
- Los hitos manuales pueden ser origen o destino de dependencia.
- Las relaciones que involucran hitos manuales se guardan dentro de `config.manual_milestones`.
- Si un hito manual depende de una tarea, su fecha se alinea con la relación creada.
- Si una tarea depende de un hito manual, se alinea el inicio visible de la tarea sin enviar ids sintéticos al backend.
- El payload backend de líneas reales filtra dependencias de origen manual para mantener el contrato numérico vigente.
- Los conectores visuales del Gantt incluyen hitos manuales visibles y mantienen la edición/remoción de relación desde la capa de dependencias.
