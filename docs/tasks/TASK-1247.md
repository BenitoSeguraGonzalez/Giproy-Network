# TASK-1247 - Implementación visual del editor de dependencias clampado al viewport

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / frontend

## Prioridad
high

## Objetivo
Mover el editor gráfico de dependencias a una capa portal fija y calcular una posición visible que no quede cortada por el workspace del Gantt.

## Implementación aplicada
- `CronogramaGantt.jsx` renderiza el editor de dependencias vía `createPortal(..., document.body)`.
- El panel usa posicionamiento `fixed` con `left/top` recalculados desde el anclaje real de la dependencia seleccionada.
- El cálculo descuenta `scrollLeft/scrollTop` del viewport timeline para mantener el anclaje correcto durante scroll.
- El panel se clampa al rectángulo visible del módulo Gantt y al viewport global.
- Se habilita `max-height` con `overflow-y-auto` para evitar recorte vertical residual.
