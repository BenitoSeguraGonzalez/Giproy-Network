# TASK-1252 - Control rector de secuenciación gráfica con origen fijado y destino por click

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
feature / ui / control

## Prioridad
high

## Objetivo
Permitir secuenciar tareas lejanas del Gantt clásico fijando visualmente una tarea origen y completando la relación con click sobre la tarea destino tras navegar libremente por el timeline.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener el arrastre gráfico existente como alternativa.

## Criterios de aceptación
- El botón hover de secuenciación permite armar un origen con click.
- El usuario puede hacer scroll libre tras fijar el origen.
- El click sobre otra tarea calculable crea la dependencia por defecto.
- El mismo botón permite cancelar la selección de origen si se vuelve a pulsar.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Alto en usabilidad para relaciones largas como `7 -> 2059`.
- No elimina la secuenciación por arrastre ya existente.

## No interferencia BIM
- Sin interferencia.
