# TASK-1258 - Control rector del dismiss externo del editor de dependencias

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / ui / control

## Prioridad
high

## Objetivo
Hacer que la selección de una dependencia se cierre si el usuario pulsa fuera del diálogo y fuera de la propia línea seleccionada.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener el editor y el carril de dependencias existentes.

## Criterios de aceptación
- Si la dependencia está seleccionada y el usuario pulsa fuera del diálogo y fuera de esa línea, el estado se limpia.
- Si el click ocurre dentro del diálogo o sobre la propia dependencia, no se cierra.
- `Escape` también cierra la selección.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Mejora consistencia y limpieza visual del editor de dependencias.

## No interferencia BIM
- Sin interferencia.
