# TASK-1259 - Implementación del dismiss externo del estado de dependencia seleccionada

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / frontend

## Prioridad
high

## Objetivo
Cerrar automáticamente la selección de dependencia cuando el usuario interactúa fuera del editor y fuera del propio enlace seleccionado.

## Implementación aplicada
- `CronogramaGantt.jsx` añade un listener global de `pointerdown` y `Escape` mientras exista `selectedDependencyKey`.
- El editor portal mantiene su selección si el click ocurre dentro de `dependencyEditorRef`.
- El carril seleccionado se marca con `data-dependency-key` para preservar la selección al interactuar sobre la propia línea o su botón `X`.
- Cualquier click fuera de esas dos zonas limpia `selectedDependencyKey`.

## Impacto de licencias
- Ninguno.

## Impacto UI
- El botón `X` y el editor dejan de quedarse abiertos si la atención ya salió de esa dependencia.
