# TASK-1264 - Control rector del carril de dependencias para relaciones ascendentes

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / ui / control

## Prioridad
high

## Objetivo
Eliminar la limitación del Gantt clásico que impedía dibujar secuenciaciones cuando la predecesora quedaba por debajo de la tarea destino en el orden visible.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener el contrato existente de `Predecesoras` y el editor gráfico ya implantado.

## Criterios de aceptación
- Si la tarea destino referencia una predecesora situada más abajo en la grilla visible, la dependencia debe dibujarse.
- El carril debe seguir funcionando para relaciones descendentes y en misma fila.
- El botón `X` de ruptura debe seguir usando el anclaje medio real del path visible.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Corrige una inconsistencia visual del carril y evita que relaciones válidas parezcan ausentes.
