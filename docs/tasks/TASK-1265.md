# TASK-1265 - Implementación del carril bidireccional de dependencias visibles

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / frontend

## Prioridad
high

## Objetivo
Permitir que el generador de `dependencyPaths` dibuje relaciones tanto descendentes como ascendentes y exponga el anclaje medio real del path en el estado visible.

## Implementación aplicada
- `frontend/src/components/projects/CronogramaGantt.jsx` retira el guardarraíl que descartaba cualquier relación con `sourceOrder >= targetOrder`.
- El cálculo del tramo observado entre origen y destino usa ahora `min/max` del orden visible para construir `bandGeometries`, `bandLayouts` y `obstacleBand` en ambos sentidos.
- `hasIntermediateRows` pasa a calcularse con distancia absoluta entre origen y destino.
- El estado `dependencyPaths` empieza a conservar también `actionX/actionY`, de modo que el botón `X` puede apoyarse en el punto medio real expuesto por el helper geométrico.
