# TASK-1270 - Control rector de selección y borrado de dependencias desde el grid Gantt

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / ui / control

## Prioridad
high

## Objetivo
Corregir dos anomalías del Gantt clásico: el desplazamiento involuntario del viewport al hacer click en el grid y la inconsistencia entre romper dependencias desde el carril gráfico y quitarlas desde `Predecesoras` en el grid izquierdo.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener intacta la selección por barra/hito y la lógica autoritativa de ruptura ya implantada.

## Criterios de aceptación
- Hacer click en el grid izquierdo no debe seleccionar la tarea ni desplazar el campo de visión.
- La selección de línea debe entrar solo desde la representación gráfica del Gantt.
- Quitar una predecesora desde el grid izquierdo debe ejecutar la misma lógica completa de `removeDependencyLink(...)`.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Evita saltos inesperados de viewport y unifica el comportamiento de ruptura de dependencias entre grid y carril gráfico.

## No interferencia BIM
- Sin interferencia.

- `TASK-1272` - QA técnica y no regresión del hotfix.
