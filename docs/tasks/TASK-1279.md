# TASK-1279 - Control rector del hotfix de recentrado automático en acciones Gantt

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / ux / control

## Prioridad
high

## Objetivo
Eliminar el recentrado automático del viewport cuando el usuario ejecuta acciones normales sobre tareas o subbarras del Gantt clásico, manteniendo ese centrado solo para navegación explícita como búsqueda o CPM.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener la navegación explícita y la semántica de selección actuales.

## Criterios de aceptación
- Abrir acciones normales de una tarea no debe centrar la fila en el viewport.
- Seleccionar subbarras o lanzar operaciones sobre ellas no debe recentrar horizontalmente el timeline si ya están visibles.
- La búsqueda y el navegador CPM pueden conservar su política de centrado explícito.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Corrige un comportamiento molesto de foco de visión que se confundía con el error de movimiento del Gantt.

## No interferencia BIM
- Sin interferencia.

- `TASK-1281` - QA técnica y trazabilidad del ajuste.
