# TASK-1280 - Implementación del scroll nearest para acciones normales y revelado mínimo de subbarras

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / frontend

## Prioridad
high

## Objetivo
Evitar que las acciones normales del Gantt recentren fila o timeline al seleccionar/operar sobre una tarea o subbarra.

## Implementación aplicada
- `frontend/src/components/projects/CronogramaGantt.jsx` amplía `scrollRowIntoViewById(...)` con política `align`, diferenciando `center` de `nearest`.
- La política por defecto del módulo pasa a `nearest`; el centrado se reserva solo para búsqueda, navegador CPM, Pareto y acciones explícitas de centrado.
- Las rutas normales de acción sobre una tarea (`inicio fino`, `gestor de dependencias`, `preparar sucesora`) pasan a usar `nearest` en vez de centrar.
- Se elimina el `scrollIntoView(...)` automático sobre la barra/subbarra seleccionada para evitar recentrados encubiertos en renders posteriores.
- El efecto que revelaba la subbarra seleccionada deja de centrarla horizontalmente; ahora solo hace scroll mínimo si queda fuera del viewport.
