# TASK-1282 - Control rector de la corrección estructural del viewport vertical del Gantt

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / arquitectura frontend / control

## Prioridad
high

## Objetivo
Eliminar la sincronización vertical inducida por render dentro del Gantt clásico para que el viewport no se reposicione al cambiar selección, drafts o estado visual de una fila.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- Mantener la sincronización vertical solo en eventos reales de scroll del usuario.

## Criterios de aceptación
- Cambios de selección, guardado o re-render ya no deben forzar `scrollTop` entre grid y timeline.
- La sincronización vertical debe seguir funcionando durante scroll real del usuario.
- El workspace no debe depender de `useLayoutEffect` para alinear `scrollTop` tras cada render.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Corrige de raíz el desplazamiento espurio del área visible al operar sobre una tarea del Gantt.

## No interferencia BIM
- Sin interferencia.
