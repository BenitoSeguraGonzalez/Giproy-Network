# TASK-1285 - Control rector de la estabilización transaccional del viewport horizontal del Gantt

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
hotfix / arquitectura frontend / control

## Prioridad
critical

## Objetivo
Eliminar el salto horizontal del área visible al soltar una barra del Gantt clásico, blindando el viewport durante toda la transacción de drag y guardado.

## Alcance rector
- Frontend clásico del Gantt.
- Sin cambios en backend, licencias, multiempresa ni BIM.
- El bloqueo del viewport debe cubrir tanto el gesto de drag como el commit posterior del movimiento.

## Criterios de aceptación
- Soltar una barra no debe enviar `scrollLeft` al final del timeline.
- Los efectos de auto-reveal o anclaje no deben poder reescribir `scrollLeft` durante un drag o su commit.
- La navegación explícita del usuario debe seguir funcionando fuera del contexto de drag.

## Impacto de licencias
- Ninguno.

## Impacto UI
- Corrige de raíz el salto horizontal del viewport al mover una tarea del Gantt.

## No interferencia BIM
