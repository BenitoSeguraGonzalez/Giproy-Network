# TASK-1301 - Implementación del nuevo landing ejecutivo para ProjectManager

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
frontend

## Prioridad
high

## Objetivo
Introducir un landing más ejecutivo para gestión de proyectos y equipos, reutilizando la lógica viva del `ProjectManager` actual.

## Implementación
- Se añade una rama `PROJECT_MANAGER_ENABLE_NEW_LANDING` para activar el nuevo landing sin borrar el modelo anterior.
- El modelo legacy queda preservado en `renderLegacyLanding()` como standby reversible.
- El nuevo landing incorpora:
  - hero ejecutivo
  - KPIs
  - toolbar de búsqueda y cambio de vista
  - superficie principal de registros con tabla enriquecida
  - acciones directas por fila reutilizando handlers actuales
- Se mantienen intactos:
  - `handleOpenAssign(...)`
  - `handleOpenDashboard(...)`
  - modales de asignación
  - dashboard de equipo
  - EDT, módulos y alcance global/revisión
