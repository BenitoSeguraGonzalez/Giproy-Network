# TASK-1410 - Homologacion global de scrollbars

## Modo
GIPROY CLASICO

## Estado
DONE

## Tipo
frontend

## Prioridad
media

## Objetivo
Extender la nueva familia visual de controles de movimiento al resto de superficies desplazables de la aplicacion, homogeneizando `scrollbars` claras y oscuras con la misma direccion grafica aplicada a los sliders.

## Alcance autorizado
- Actualizar `custom-scrollbar`.
- Actualizar `gantt-native-scroll`.
- Actualizar `gantt-dark-scrollbar`.
- Mantener logica funcional de scroll.
- Donde se use indicador visual propio, garantizar interaccion completa: click en rail, arrastre del thumb, rueda y teclado basico.
- No tocar backend, licencias ni BIM.

## Impacto licencias
- Sin impacto funcional.

## Impacto UI
- Global sobre la mayor parte de superficies desplazables del frontend clasico.
- El lenguaje visual abandona el naranja dominante y adopta rail gris, pieza circular clara y punto naranja corporativo puntual.

## No interferencia BIM
- Confirmada.

## Porcentaje de terminacion
- Avance inicial: 0%.
- Avance intermedio: 70%.
- Avance final: 100%.

## Validacion
- `npm run build` en `frontend/`.

## Resultado
- Todas las familias principales de scrollbar pasan a una estetica mas limpia y moderna.
- Las tracks quedan grises/neutras y los thumbs pasan a una pieza movil gris con punto naranja central, alineada con la conceptualizacion de sliders.
- Correccion posterior: la pista deja de ser una barra coloreada y pasa a una linea guia gris orientada segun scrollbar vertical u horizontal; el thumb se representa visualmente como circulo, no como bloque alargado.
- Ajuste final: la geometria visible replica la referencia aprobada de linea gris fina + circulo claro desplazable + pequeno punto naranja central, evitando barras azules/naranjas dominantes.
- Hotfix especifico: `Datos de Proyecto` usa un indicador visual propio sobre el scroll real para que la referencia aprobada se vea de forma efectiva, ya que la scrollbar nativa no permite representar un thumb circular puro de forma consistente.
- Hotfix funcional: el indicador propio de `Datos de Proyecto` deja de ser informativo y acepta click en rail, drag del circulo, rueda de raton y teclado (`ArrowUp`, `ArrowDown`, `PageUp`, `PageDown`, `Home`, `End`).
- El naranja deja de dominar los controles de desplazamiento y queda reservado como acento puntual de marca.
