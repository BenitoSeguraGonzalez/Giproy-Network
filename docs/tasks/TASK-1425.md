## Implementación realizada
- Se introduce un sentinel interno para representar hitos manuales anclados antes de la primera fila visible, evitando que el movimiento vertical hacia arriba termine recalculándose como inserción al final.
- El cálculo de `resolveManualMilestoneVerticalDrop(...)` deja de usar una sola semántica `after` y pasa a resolver inserciones `before/after` según el sentido del movimiento.
- El `drag'n'drop` vertical de hitos manuales y el menú `Subir línea / Bajar línea` comparten ya el mismo criterio real de destino y persistencia.
- La resolución geométrica de fila destino del timeline pasa a devolver también la intención `before/after`, evitando bloqueos falsos al soltar en la mitad superior de una fila.
- El cierre de secuenciación por `pointerup` deja de depender exclusivamente de acertar sobre elementos visibles pequeños y reutiliza la misma resolución geométrica de destino para completar la dependencia `hito <-> tarea`.

- La secuenciación `hito <-> tarea` recupera el commit real usando la misma geometría de resolución que el drop vertical.
