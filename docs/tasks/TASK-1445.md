- Presupuesto validado: presupuesto `13`.
- El backend CPM devuelve `30` nodos criticos calculables y `29` arcos criticos en `metadata.cpm_network.critical_paths`.

## Implementacion aplicada
- `cronogramasGanttCriticalPath.js` normaliza `metadata.cpm_network.critical_paths` y reconstruye pertenencia critica por nodo: arcos entrantes, arcos salientes, indices de ruta y total de rutas.
- `CronogramaGantt.jsx` enriquece el nodo CPM backend con esa pertenencia antes de alimentar `displayPlanningMap`.
- `isPlanningNodeCriticalPathMember(...)` acepta tambien `criticalPathIndexes` para que nodos terminales de una ruta critica cuenten en semaforos y barras.
- Las subbarras/barras criticas usan tono rojo solo cuando la fila ya es miembro real de ruta critica; las barras no criticas conservan su familia azul existente.
- El drag vertical de hitos manuales usa una referencia viva de `resolveManualMilestoneVerticalDrop`, evitando que el listener global de `pointerup` trabaje con un snapshot anterior que no conoce un hito recien creado.
