## Contexto
Se requiere asignar un mismo Codigo CPC a varios recursos desde `Precios Unitarios > Recursos`, aprovechando la seleccion multiple existente y manteniendo el dato persistente para su consumo posterior en `Desagregacion`.

## Implementacion backend
- Se agregan `RecursoBulkCpcRequest` y `RecursoBulkCpcResponse`.
- Se agrega `PUT /recursos/bulk-cpc`.
- `recurso_service.bulk_assign_cpc(...)`:
  - deduplica ids de recursos,
  - valida que el CPC exista,
  - valida que todos los recursos pertenecen a la empresa activa,
  - actualiza solo recursos cuyo CPC cambia realmente,
  - marca recursos heredados como divergentes cuando la base de trabajo tiene origen maestro,
  - persiste en `recursos.cod_cpc_id`.

## Implementacion frontend
- `recursosApi.bulkAssignCpc(...)` consume el endpoint masivo.
- `Recursos.jsx` agrega accion contextual con icono `Tags` en el area derecha de acciones cuando hay varios recursos seleccionados.
- La accion abre un modal visualmente alineado con el modulo, con buscador CPC existente, lista de resultados y confirmacion previa.
- Tras asignar, se recarga la lista de recursos para mostrar el CPC persistido.

## Interaccion con Desagregacion
`Desagregacion` consume recursos a traves del detalle APU. Al cambiar `recursos.cod_cpc_id`, el APU devuelve el CPC actualizado sin duplicar datos ni mantener una copia independiente en la linea APU.
