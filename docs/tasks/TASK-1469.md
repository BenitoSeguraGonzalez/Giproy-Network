# TASK-1469 - Slider vertical redimensionable en Formula Polinomica

## Estado
Completada al 100%.

## Objetivo
Incorporar en `Formula Polinomica` un separador vertical entre el grid de recursos y el grid de coeficientes/indices para redimensionar ambos paneles, siguiendo el patron funcional usado en Gantt.

## Alcance
- GiProy Clasico.
- Frontend `FormulaPolinomicaTab.jsx`.
- Sin cambios backend.
- Sin cambios de calculo de formula.
- Sin impacto en licencias.
- Sin activar ni acoplar BIM.

## Implementacion
- Se sustituyo el layout fijo de dos paneles por un grid controlado por `gridTemplateColumns`.
- Se agrego estado local para el ancho del panel izquierdo.
- Se agrego separador vertical con `role="separator"` y `aria-orientation="vertical"`.
- El drag horizontal actualiza el ancho del panel izquierdo y conserva ancho minimo del panel derecho.
- En viewports no anchos se conserva el comportamiento responsive apilado existente.

## Validacion

- `node scripts/validate-formula-responsive-dom.mjs` OK a `1920x1080`.
- `npm run build` OK.
- Validacion visual real del usuario: scrollbars y slider vertical entre grids de Formula Polinomica cumplen el cometido.

## Impacto
- Impacto UI: si, Formula Polinomica permite redimensionar los dos grids.
- Impacto licencias: no aplica.
- Impacto backend/calculos: no aplica.
- No interferencia BIM: confirmada; solo se modifica UI clasica de Formula Polinomica.
