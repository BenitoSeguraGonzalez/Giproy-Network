## Estado

## Objetivo
Retirar el letrero tecnico `Guardando linea ...` del rail oscuro del Gantt y reforzar el flujo de aprobacion para que no ejecute resincronizaciones economicas por cada linea confirmada.

## Alcance
- `frontend/src/components/projects/CronogramaGantt.jsx`
- `frontend/src/components/projects/Cronogramas.jsx`

## Implementacion
- Se elimina el render del aviso intrusivo asociado a `trabajoSaving || savingId`.
- `handleSaveTrabajoLine(...)` y `handleSaveTrabajoDraftBatch(...)` aceptan `skipValoradoSync` para persistir Gantt sin disparar sincronizacion economica inmediata.
- `executeApproveCurrentGantt(...)` confirma las lineas con `skipValoradoSync: true` y ejecuta `onSyncValoradoFromGantt(...)` una sola vez al final del lote.
- El estado `savingId` se mantiene internamente para bloquear/mostrar estados de fila cuando aplica, pero ya no desplaza la botonera ni aparece como mensaje tecnico.
