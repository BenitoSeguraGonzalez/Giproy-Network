## Objetivo
Optimizar la opcion `Aceptar` del Gantt para persistir las lineas confirmadas mediante un unico lote cuando el contrato batch esta disponible, limpiando drafts locales y permitiendo que las etiquetas visibles se actualicen desde el estado autoritativo.

## Implementacion
- Se incorpora `persistConfirmedRowsBatch(...)` en `CronogramaGantt.jsx`.
- La aprobacion construye un `schedule_data` confirmado por linea usando `buildLineSavePayload(...)` con `approvalMode: confirmed`.
- El guardado usa `onSaveTrabajoDraftBatch(...)` si esta disponible y conserva fallback linea a linea para compatibilidad.
- El lote se guarda con `skipValoradoSync: true`; `onSyncValoradoFromGantt(...)` se ejecuta una sola vez al final.
- Tras persistir, se limpian drafts/historial de las lineas confirmadas y se cierran selectores/editores abiertos para evitar etiquetas o focos obsoletos.
- La restauracion al confirmado reutiliza el mismo camino batch con drafts generados desde el snapshot confirmado.
