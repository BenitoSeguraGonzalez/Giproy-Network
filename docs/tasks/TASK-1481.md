## Objetivo
Hacer que el drag horizontal de hitos manuales propague sus dependencias a las tareas sucesoras, evitando lineas diagonales incoherentes y fechas antiguas en la ruta dependiente.

## Implementacion
- En `CronogramaGantt.jsx`, el flujo de `pointerup` para hito manual ahora crea un snapshot con la nueva fecha del hito.
- Se llama a `buildDependentScheduleDrafts(...)` usando el hito como origen.
- Si existen sucesores recalculados, se persisten mediante `persistDraftPatches(...)` con `source: gantt_manual_milestone_move` y `deferValoradoSync: true`.
- Se mantiene la persistencia previa del hito en `manual_milestones`, sin cambiar el contrato backend.
- Se refuerza `smoke-cronogramas-gantt-manual-milestone-drag.mjs` para congelar que el movimiento horizontal de un hito manual recalcula y persiste sucesores.
