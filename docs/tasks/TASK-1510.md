## Objetivo

Corregir la divergencia visual donde, al arrastrar un hito manual en `Proyectos > Cronogramas > Gantt`, la ruta de dependencia del preview podia conectarse contra la geometria anterior de las sucesoras en vez de contra la cascada temporal calculada.

## Cambios

- `frontend/src/components/projects/CronogramaGantt.jsx`
  - Durante `dragPreview` de tipo `move`, las filas sucesoras que reciben `activeMovePreviewDrafts` ya no fuerzan la ruta SVG a leer la caja DOM previa o en transicion.
  - Para esas sucesoras se prefiere la geometria calculada desde el draft temporal, manteniendo la geometria DOM solo para la barra activa que sigue el puntero.
  - El router de dependencias no cambia; solo cambia la fuente de geometria usada durante el preview.
  - El `pointerup` de hitos manuales clasifica el gesto con `lastHorizontalDeltaPx` real, no con `lastDeltaDays * pixelsPerDay`, porque el delta laboral puede ser fraccional o caer en `0` aunque el puntero se haya desplazado.
  - El helper de drag muestra `Moviendo hito` y toma la fecha real desde `activePreview.currentDraft.start_date`, evitando presentar el movimiento como tarea de duracion cero.

- `frontend/scripts/smoke-cronogramas-gantt-manual-milestone-drag.mjs`
  - Se agrega proteccion estatica para que el preview de hito manual use geometria calculada de sucesores movidos y no la caja DOM anterior/en transicion.
  - Se agrega proteccion para que el commit de hitos manuales use delta horizontal real y para que el helper lea la fecha real del draft del hito.
