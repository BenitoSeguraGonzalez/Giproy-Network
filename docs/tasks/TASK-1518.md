# TASK-1518 - Control de fluidez visual post-commit en Gantt

Estado: En validacion del usuario
Fecha: 2026-05-06
Modo: GIPROY CLASICO
Tipo: Control

## Objetivo

Gobernar el saneamiento visual del Gantt clasico al soltar movimientos de tareas, hitos y subtramos, evitando saltos de pintado sin modificar formulas de preview, commit, dependencias ni calendario laboral.

## Ley de alcance

- No tocar calculo temporal.
- No cambiar `previewCommitContract`.
- No modificar `buildDependentScheduleDrafts(...)`.
- No cambiar reglas `FS/SS/FF/SF`.
- No cambiar persistencia backend.
- No usar DOM como fuente de calculo.
- No activar UX BIM ni acoplamientos BIM.

## Causa controlada

Al soltar un movimiento, el `dragPreview` podia limpiarse antes de que el commit asincrono rehidratase el estado canonico. Durante ese intervalo, el render podia volver un frame a geometria base anterior y despues saltar al estado persistido. El calculo no era el problema en este slice; el hueco estaba en la transicion visual entre preview y commit.

## TASK de implementacion

- `TASK-1519`: puente visual de commit para conservar la ultima geometria validada hasta que el estado canonico se estabilice.

- Smoke focal de hito manual intacto.
- Smoke clasico completo OK.
- `smoke-classic-no-bim-contamination` OK.
- Build OK.
