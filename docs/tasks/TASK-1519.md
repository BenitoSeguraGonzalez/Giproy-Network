# TASK-1519 - Implementacion de puente visual post-commit en Gantt

Estado: En validacion del usuario
Fecha: 2026-05-06
Modo: GIPROY CLASICO
Control: TASK-1518

## Objetivo

Eliminar el rebote visual al soltar movimientos en el Gantt clasico manteniendo una imagen visual efimera del ultimo preview mientras termina el commit y el render canonico se estabiliza.

## Alcance

- `frontend/src/components/projects/CronogramaGantt.jsx`
- `frontend/scripts/smoke-cronogramas-gantt-manual-milestone-drag.mjs`
- Documentacion de sesion.

## Resultado aplicado

- Se incorpora `visualCommitPreview` como estado visual efimero.
- Cada movimiento guarda `interaction.lastVisualPreview` con el mismo payload de preview ya calculado.
- En `pointerup`, antes de apagar `dragPreview`, se copia esa ultima imagen a `visualCommitPreview` con marca `isCommitVisual`.
- `activeMovePreviewDrafts` y el ruteo de dependencias aceptan `dragPreview` durante arrastre o `visualCommitPreview` durante commit, reutilizando la misma geometria/drafts mostrados.
- La burbuja `Moviendo...` y la guia auxiliar no se muestran durante `isCommitVisual`; solo se conserva la geometria para evitar salto.
- La liberacion del puente visual espera dos `requestAnimationFrame` y tiene fallback de `180 ms`, dando tiempo a que el estado persistido sustituya al preview sin volver al origen.
- En cancelaciones o errores se limpia el puente visual de inmediato para no dejar una imagen falsa.
- Refuerzo posterior: al cerrar el puente visual se fuerza un refresco de layout/rutas en dos frames mediante `dependencyLayoutRefreshTick`, para que `dependencyPaths` vuelva a medir barras y filas sin depender de que el usuario mueva el viewport.
- Refuerzo posterior: durante la fase de commit visual se prioriza `visualCommitPreview` sobre `dragPreview`, evitando que quede visible el helper `Moviendo...` si React conserva un preview anterior durante un frame.
- Refuerzo posterior: el hito manual no suma `translationPx` durante `isCommitVisual`; en esa fase el estado optimista ya ha colocado el hito en la fecha de commit y volver a sumar el desplazamiento producia un salto visual hacia adelante antes de volver a su sitio.
