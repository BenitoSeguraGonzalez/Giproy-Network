# TASK-1522 - Control zoom fluido Gantt clasico

Estado: En validacion del usuario
Fecha: 2026-05-06
Modo: GIPROY CLASICO

## Objetivo

Controlar el saneamiento visual del zoom del Gantt clasico para recuperar fluidez, mantener foco temporal y evitar rutas mal medidas hasta que el usuario desplaza el viewport.

## Alcance autorizado

- Solo capa visual/interaccion del Gantt clasico.
- Mantener foco de zoom en el inicio de la tarea o hito seleccionado.
- Si no hay seleccion, conservar el ancla visual actual del viewport.
- Refrescar rutas de dependencias solo despues de estabilizar layout, scroll y virtualizacion.
- No tocar calculo de fechas, dependencias, calendario laboral, commit ni backend.

## Criterios de aceptacion

- Zoom con tarea seleccionada conserva visible el inicio temporal de esa tarea.
- Zoom con hito seleccionado conserva visible el inicio temporal del hito.
- Si la pieza visual seleccionada supera el viewport despues del zoom, el inicio visual queda centrado para conservar el foco operativo.
- Las rutas hito -> tarea sin lag no generan rodeos visuales ni capas interactivas que bloqueen el rombo durante zoom/scroll.
- Zoom sin seleccion conserva el centro visible actual.
- Las rutas no quedan en interpretacion intermedia hasta hacer scroll.
- El zoom por rueda y slider se percibe fluido, sin saltos por medicion a medio render.
- `smoke:gantt-classic`, build y no contaminacion BIM pasan.

## Riesgos controlados

- No crear un segundo motor de calculo temporal.
- No modificar `buildDependentScheduleDrafts(...)`.
- No modificar `previewCommitContract`.
- No modificar reglas `FS/SS/FF/SF`.
- No modificar backend ni datos persistidos.

## Cierre

No cerrar hasta confirmacion expresa del usuario en UI real.
