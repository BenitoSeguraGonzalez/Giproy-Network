# TASK-1523 - Implementacion foco y refresco estable de zoom Gantt

Estado: En validacion del usuario
Fecha: 2026-05-06
Modo: GIPROY CLASICO
Control: TASK-1522

## Objetivo

Implementar el carril visual de zoom estable del Gantt clasico: ancla temporal por seleccion, estabilizacion de viewport y refresco diferido de rutas de dependencias tras el layout definitivo.

## Causa

El zoom cambia `segmentColumnWidth`, ancho de timeline y ventana virtual en el mismo ciclo en que `dependencyPaths` mide DOM. El `scrollLeft` de anclaje se corrige despues mediante `requestAnimationFrame`, de modo que las rutas pueden quedar medidas contra una mezcla de zoom nuevo, viewport antiguo y filas virtualizadas previas. Al desplazar manualmente el viewport, el snapshot se actualiza y la ruta se corrige.

## Plan de implementacion

- Resolver un ancla temporal de zoom priorizando tarea/hito seleccionado.
- Para tramos/subbarras seleccionados, usar el inicio del tramo visual real como ancla, no solo la fecha de la fila.
- Centrar el inicio visual seleccionado durante el zoom para que una barra mayor que el viewport conserve su punto de entrada bajo atencion.
- Aplicar zoom con esa ancla antes de medir dependencias.
- Forzar snapshot de viewport despues de escribir `scrollLeft`.
- Refrescar rutas en doble frame tras estabilizar scroll y virtualizacion.
- Mantener el fallback actual de centro visible si no existe seleccion.
- Desactivar la capa interactiva de dependencias durante scroll/zoom reducido y elevar el hito sobre el SVG para evitar que la ruta capture el drag.
- Simplificar visualmente rutas hito -> tarea sin lag para evitar rodeos antiguos cuando el hito es origen.
- Centrar el rombo del hito sobre su fecha real: la fecha no puede quedar en el borde izquierdo del elemento visual en escala hora.
