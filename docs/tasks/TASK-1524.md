# TASK-1524 - Control guia visual inicio fin proyecto Gantt clasico

Estado: En validacion del usuario
Fecha: 2026-05-07
Modo: GIPROY CLASICO

## Objetivo

Controlar la incorporacion de una guia visual sutil de inicio y fin de proyecto en el Gantt clasico, con atenuacion de las zonas temporales fuera del rango del proyecto.

## Alcance autorizado

- Solo capa visual del Gantt clasico.
- Mostrar una linea vertical sutil para el inicio del proyecto.
- Mostrar una linea vertical sutil para el fin del proyecto.
- Atenuar la zona anterior al inicio y posterior al fin del proyecto.
- No modificar calculo de fechas, dependencias, commit, preview, calendario laboral ni backend.
- No bloquear drag, zoom, scroll, seleccion ni rutas de dependencias.

## Criterios de aceptacion

- Las lineas son finas y discretas, sin trazo grueso.
- Las zonas fuera de proyecto se perciben atenuadas sin ocultar el Gantt.
- El overlay no captura eventos de puntero.
- El movimiento de hitos y tareas conserva el comportamiento existente.
- El zoom y las rutas siguen validando con los smokes clasicos.
- No hay activacion ni contaminacion BIM.

## Cierre

No cerrar hasta confirmacion expresa del usuario en UI real.
