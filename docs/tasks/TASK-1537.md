# TASK-1537 - Implementacion de selector explicito de reportes de cronogramas

Estado: En validacion del usuario
Fecha: 2026-05-07
Modo: GIPROY CLASICO
Control: TASK-1536

## Objetivo

Corregir las incongruencias de uso de los reportes de cronogramas clasicos, dejando accesibles las variantes documentales actuales desde la UI.

## Implementacion

- El boton `Reporte` de Gantt abre un menu explicito con:
  - `Reporte Gantt`
  - `Reporte integrado`
  - `MS Project`
- El boton `Reporte` de Cronograma Valorado abre un menu explicito con:
  - `Cronograma valorado`
  - `Flujo de caja`
  - `Reporte integrado`
- `handleOpenCronogramaValoradoReport(...)` acepta una variante explicita para no depender solo de la pestaña activa.
- El modal de generacion usa la variante real del preview cuando existe, evitando mensajes desalineados durante exportacion.

## No cambios funcionales

- No se modifica backend.
- No se modifica `reporting_service`.
- No se modifica `cash_flow`, `footer`, periodizacion, reconciliacion, Gantt, Presupuesto/APU ni persistencia.
- No se modifica la generacion Excel/PDF/PDF desde Excel.
