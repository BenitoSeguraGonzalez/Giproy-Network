# TASK-1538 - Control de alineacion de botones del rail de proyecto clasico

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Revisar la alineacion de los botones verticales del rail de secciones de proyecto con el patron visual clasico, manteniendo el senalamiento oscuro del modulo activo.

## Alcance autorizado

- Frontend clasico de `Proyectos`.
- Capa visual y composicion de botones del rail lateral.
- Sin backend, sin persistencia y sin UX BIM.

## Criterios

- Mantener el activo oscuro como senalamiento operativo.
- Dar mayor relevancia al borde de los botones sin cambiar el patron anterior del rail.
- Reducir la altura visual del boton colapsado para que el borde no se perciba como una zona gruesa.
- Mantener el punto de color del modulo activo tambien cuando el rail esta colapsado, centrado verticalmente sobre el borde derecho.
- Probar una animacion modular de reveal del label al expandir el rail, sin tocar la animacion de cambio de modulo.
- Suavizar la apertura/cierre del panel contenedor de opciones para evitar el salto brusco de ancho.
- Eliminar el salto horizontal interno de los botones manteniendo una caja estable durante la transicion del panel.
- No modificar permisos, rutas, activacion de modulos ni reglas BIM.

## Validacion

- `npm run build` OK.
- `npm run smoke:gantt-classic` OK, incluyendo `smoke-classic-no-bim-contamination`.
