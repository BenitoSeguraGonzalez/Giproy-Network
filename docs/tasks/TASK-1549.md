# TASK-1549 - Reporting compone mapa real desde teselas OSM

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Resultado

El backend de reporting ahora genera la imagen de georreferenciacion de Datos de Proyecto componiendo teselas reales de OpenStreetMap con el zoom guardado por el usuario.

## Cambios

- `backend/app/services/reporting.py`
  - Añade conversión `lat/lng/zoom` a pixel global Web Mercator.
  - Descarga teselas OSM `https://tile.openstreetmap.org/{z}/{x}/{y}.png` con `User-Agent` propio.
  - Compone un PNG del tamaño solicitado con `PIL`, centrado en la coordenada del proyecto.
  - Dibuja marcador operativo sobre el centro del mapa.
  - Cachea teselas e imagen final para reducir llamadas repetidas.
  - Cambia el orden de resolución: teselas OSM reales primero, static map externo después, snapshot sintético solo como último fallback.

## No cambios

- Sin cambios en modelo de datos, APIs públicas, frontend, plantillas, permisos ni persistencia.
- Sin cambios en BIM, UX BIM, rutas BIM ni acoplamientos nuevos.

## Validacion

- `python -m py_compile backend/app/services/reporting.py` OK.
- Prueba focal con red: `_build_project_osm_tile_map_bytes(...)` genera PNG real de `85606` bytes para coordenada/zoom de ejemplo.
- `npm run smoke:gantt-classic` OK, incluyendo `smoke-classic-no-bim-contamination`.
