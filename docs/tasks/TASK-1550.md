# TASK-1550 - Control de cache universal de georreferenciacion por proyecto

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Consolidar la georreferenciacion de reportes de Datos de Proyecto como una referencia unica por proyecto, compartida por todos los usuarios y sin versionado por revision.

## Criterios

- La imagen georreferenciada pertenece al proyecto, no al usuario.
- El zoom y coordenadas aceptadas en Datos de Proyecto definen la firma vigente.
- Al guardar/aceptar cambios de georreferenciacion se intenta crear la imagen cacheada.
- Si el servicio de mapas no esta disponible, el proyecto queda marcado como `pending`.
- Las lecturas y reportes reintentan actualizar cuando la referencia esta pendiente o desfasada.
- Las revisiones no crean copias: existe una sola georreferencia universal por proyecto.

## Alcance protegido

- Solo Datos de Proyecto clasico y reporting comun.
- Sin UX BIM, rutas BIM, modelos BIM ni acoplamiento hacia BIM.
- Sin cambio de proveedor de mapas; se deja ese caso como evolucion futura.
