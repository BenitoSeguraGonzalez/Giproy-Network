# TASK-1556 - Control de geocodificacion asistida en Datos de Proyecto

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Recuperar la localizacion asistida por direccion de Datos de Proyecto y evitar dependencia directa del navegador contra proveedores externos.

## Diagnostico

La accion `Localizar` seguia consultando `nominatim.openstreetmap.org` directamente desde el frontend. Esa ruta era fragil por CORS, red del cliente, politicas de identificacion del proveedor y rate-limit, y no quedaba alineada con el backend comun ni con la cache georreferenciada por proyecto.

## Criterios

- La consulta de geocodificacion debe pasar por el backend comun.
- El frontend no debe llamar directamente al proveedor externo.
- El backend debe enviar identificacion HTTP propia de GiProy.
- La respuesta debe conservar latitud, longitud, zoom sugerido y mensaje de precision.
- El cambio debe mantener la edicion georreferenciada en pantalla completa.
- No debe tocar BIM ni introducir dependencia hacia BIM.
