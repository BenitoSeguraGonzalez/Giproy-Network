# TASK-1560 - Control de compatibilidad ante backend sin reinicio

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Evitar que la localizacion asistida falle con `Method Not Allowed` cuando el backend activo de Windows aun no ha cargado el endpoint nuevo `geocode-address`.

## Diagnostico

El codigo del endpoint `POST /proyecto-detalles/geocode-address` esta correcto, pero el servicio activo en `localhost:3001` no lo tenia en OpenAPI y respondia 405 contra la ruta dinamica heredada. La sesion no pudo detener el servicio por permisos del sistema.

## Criterios

- Mantener la via preferente por backend comun.
- Activar fallback solo si el backend devuelve 404/405.
- Reutilizar las variantes de direccion ecuatoriana en el fallback.
- No cambiar el modelo ni la persistencia.
- No tocar BIM ni introducir dependencia hacia BIM.
