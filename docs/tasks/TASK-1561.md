Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Resultado

La accion `Localizar` mantiene como primera opcion el backend comun, pero si el backend activo responde `404` o `405` por no estar actualizado, usa un fallback de navegador con las mismas variantes de direccion ecuatoriana.

## Cambios

- `frontend/src/components/projects/DatosProyecto.jsx`
  - Agrega helpers modulares de fallback para construir candidatos de geocodificacion.
  - Replica el patron ecuatoriano de interseccion: `y`, `con`, `&`, `/`, `entre`, `interseccion`, `cruce`, `esquina`.
  - Mantiene la llamada principal a `proyectoDetalleApi.geocodeAddress`.
  - Solo activa `geocodeAddressFromBrowserFallback` si el backend devuelve `404` o `405`.
  - Conserva actualizacion de latitud, longitud, zoom y cache `pending`.
