# TASK-1562 - Control de busqueda editable en georreferenciacion

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Asegurar que la accion `Localizar` de Datos de Proyecto tenga sentido operativo: el usuario debe poder abrir el modal de georreferenciacion, redefinir la busqueda en el mismo contexto y buscar direcciones ecuatorianas con o sin acentos.

## Alcance autorizado

- Datos de Proyecto clasico.
- Modal de georreferenciacion.
- Geocodificacion de direccion por backend comun y fallback temporal de navegador.

## Criterios

- El boton junto al campo `Direccion Exacta` debe abrir el mapa completo y ejecutar la localizacion sin exigir un segundo clic.
- El modal debe incluir un campo editable junto a `Localizar`.
- `Enter` en el campo debe disparar la busqueda.
- La busqueda debe generar variantes con y sin acentos.
- El cambio debe mantener la cache georreferenciada como `pending` cuando cambian coordenadas o zoom.

## No interferencia BIM

No se permite tocar UX BIM, rutas BIM, modelos BIM ni introducir dependencias hacia BIM.
