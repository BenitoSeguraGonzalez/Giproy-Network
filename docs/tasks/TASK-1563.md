# TASK-1563 - Datos Proyecto permite redefinir busqueda georreferenciada

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Resultado

Datos de Proyecto ahora permite redefinir la busqueda de georreferenciacion desde el modal y localiza usando variantes con y sin acentos.

## Cambios

- `frontend/src/components/projects/DatosProyecto.jsx`
  - Agrega estado `geoSearchQuery` para separar la busqueda editable del campo persistente `direccion`.
  - El boton de mapa junto a `Direccion Exacta` abre el modal y ejecuta la localizacion inmediatamente.
  - El modal incorpora un `Input` junto a `Localizar`.
  - `Enter` dentro del input ejecuta la busqueda.
  - El fallback de navegador expande candidatos con variantes sin diacriticos y aliases acentuados.
  - Se cubren aliases comunes como `Simon`/`Simón` y `Bolivar`/`Bolívar`.
- `backend/app/api/endpoints/proyecto_detalles.py`
  - El backend comun tambien expande candidatos con variantes con y sin acentos.
