# TASK-1564 - Control de precision en intersecciones georreferenciadas

Fecha: 2026-05-07

Modo: GIPROY CLASICO

## Objetivo

Evitar que Datos de Proyecto acepte como localizacion correcta una posicion generica o parcial cuando el usuario busca una interseccion ecuatoriana concreta.

## Caso observado

La busqueda `Miguel Velez y Rafael Maria Arizaga` en Cuenca puede caer en una referencia parcial de calle si solo se usa Nominatim. La interseccion existe en OSM, pero Nominatim no siempre la devuelve como punto de cruce.

## Criterios

- La cabecera del modal no debe duplicar coordenadas.
- El titulo `Geo-referenciacion` debe tener mayor jerarquia visual.
- Una busqueda de interseccion debe priorizar geometria real de calles.
- Si la respuesta textual no contiene ambas calles, no debe aceptarse como exito exacto.
- No se debe caer a ciudad/canton como resultado valido para una interseccion concreta.

## No interferencia BIM

Sin UX BIM, rutas BIM, modelos BIM ni acoplamientos nuevos hacia BIM.
