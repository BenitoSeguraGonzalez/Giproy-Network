# TASK-1568 - Control de formato PDF en reportes clasicos

Fecha: 2026-05-07

## Objetivo

Controlar la diferencia funcional entre los dos flujos de salida PDF de reportes clasicos:

- PDF desde Excel: puede ser apaisado cuando la hoja lo requiere, pero no debe dejar informacion fuera del documento.
- PDF directo: debe generarse como documento formal A4 vertical, no como salida apaisada.

## Alcance

- Backend comun `reporting_service`.
- Renderizado PDF directo y conversion propia Excel a PDF.
- Sin cambios en plantillas, contratos API, frontend, PostgreSQL ni BIM.

## Criterios

- El PDF directo usa A4 vertical.
- Las tablas del PDF directo se ajustan al ancho disponible del documento vertical.
- Los bloques formales principales no se cortan innecesariamente entre paginas.
- Excel a PDF mantiene orientacion apaisada cuando la hoja lo pide o por ancho, pero refuerza ajuste de texto para evitar recortes.

## Validacion esperada

- `python -m py_compile backend/app/services/reporting.py`
- `python -m pytest app/tests/test_reporting_stakeholders_excel_pdf.py -q`

## No interferencia BIM

No se modifica UX BIM, rutas BIM, modelos BIM ni dependencias BIM.
