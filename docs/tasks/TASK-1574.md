# TASK-1574 - Control de cortes de seccion en PDF desde Excel

Fecha: 2026-05-07

## Objetivo

Evitar que el conversor PDF desde Excel parta secciones formales del Acta de Constitucion en mitad de su bloque, especialmente `ESPECIFICACIONES TECNICAS Y CONTRACTUALES`.

## Alcance

- Backend comun de reporting.
- Conversion propia Excel a PDF.
- Sin cambios en plantillas, datos, frontend, contratos API ni BIM.

## Criterios

- Detectar cabeceras oscuras de seccion.
- Mantener cada seccion junto si cabe en una pagina.
- Si no cabe tras el bloque anterior, saltarla completa a la pagina siguiente.
- Versionar cache de exportacion para no servir cortes antiguos.

## No interferencia BIM

No se modifica UX BIM, rutas BIM, modelos BIM ni dependencias BIM.
