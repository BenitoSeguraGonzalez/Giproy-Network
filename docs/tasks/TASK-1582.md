# TASK-1582 - Hotfix de carga del modulo Proyectos

## Estado
Implementada y validada.

## Contexto
El entorno publicado mostro:

`TypeError: Failed to fetch dynamically imported module: .../assets/Proyectos-Cri-8C2T.js`

El asset existia en `frontend/dist` y el host publicado respondia `200`, por lo que el fallo encaja con una ventana de despliegue/caché de chunk dinamico en la ruta principal de Proyectos.

## Cambios
- `frontend/src/routes/AppRouter.jsx`
  - `Proyectos` vuelve a import directo desde `../pages/Proyectos`.
  - Se elimina solo el lazy chunk de la ruta `/proyectos`.
  - Se mantienen lazy imports internos de las secciones pesadas del workspace de proyecto.

## Impacto
- Reduce el riesgo de caida por chunk dinamico en la entrada principal de Proyectos.
- Aumenta el bundle principal, pero evita el punto exacto de fallo del asset `Proyectos-*.js`.
- No cambia permisos, rutas, layout, backend, persistencia ni funcionalidad de proyecto.

## Validacion
- `npm run build` OK desde `frontend/`.
- El build nuevo ya no genera `assets/Proyectos-*.js`.
- `node scripts/smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.

## No interferencia BIM
Sin UX BIM, rutas BIM, modelos BIM, dependencias BIM ni acoplamientos nuevos.
