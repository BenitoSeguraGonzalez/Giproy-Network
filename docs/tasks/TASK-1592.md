# TASK-1592 - Cierre visual de modales de reportes

## Modo
GIPROY CLASICO.

## Objetivo
Alinear el boton de cierre del visor comun de reportes con el boton soft circular usado en Datos de Proyecto, conservando el comportamiento real de cierre.

## Alcance
- Frontend clasico.
- `CommonReportPreviewModal`.
- `AppModalHeader` como soporte opcional para clases de cierre especificas.

## Cambios
- `AppModalHeader` acepta `closeButtonClassName` y `closeIconClassName` sin cambiar el default existente.
- El visor comun de reportes usa el patron visual de `ProjectSectionReportButton`: 40px, radio `0.95rem`, superficie soft, sombra clara, hover con acento azul y estado activo inset.
- El `onClose` sigue conectado al mismo handler recibido por el modal.

## No alcance
- Sin backend.
- Sin reportes generados, plantillas ni datos.
- Sin EDO/EDT.
- Sin BIM, UX BIM, rutas BIM ni acoplamientos nuevos.

## Validacion
- `npm run build` OK.
- `node scripts/smoke-classic-no-bim-contamination.mjs` OK.
