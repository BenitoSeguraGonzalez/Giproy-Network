# TASK-1595 - EDO modales visuales

## Modo
GIPROY CLASICO.

## Objetivo
Llevar los modales de EDO al patron visual usado en `Stakeholders`: header negro, cuerpo claro, secciones internas limpias y footer sobrio.

## Alcance
- Modal de hito.
- Modal de stakeholder/asignacion.
- Modal de mover seleccion.
- Boton X blanco/soft.
- Footer con acciones claras `Cancelar` / `Guardar` o equivalente.

## No alcance
- Sin cambios de validaciones funcionales.
- Sin cambios de payload.
- Sin cambios backend.
- Sin BIM.

## Criterios
- Header oscuro solo dentro del modal.
- Cuerpo claro con grupos compactos.
- Inputs/selects con densidad consistente.
- No introducir gestion paralela de roles.

## Validacion prevista
- Build frontend.
- Smoke no contaminacion BIM.
- Prueba focal de apertura/cierre/guardar/cancelar en cada modal.

## Implementacion
- `HitoModal`, `StakeholderModal` y `MoveSelectionModal` adoptan header negro, cuerpo claro y footer plano.
- Boton de cierre X usa el boton circular blanco/soft usado en `Stakeholders` y `Datos de Proyecto`.
- El contenido interno se agrupa en secciones claras con borde y sombra soft.
- Footer conserva `Cancelar` y accion principal sin cambiar handlers ni payloads.

## Validacion ejecutada
- `npm run build` OK desde `frontend/`.
- `node scripts/smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.

## Estado
Implementada y validada.
