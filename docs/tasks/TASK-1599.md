# TASK-1599 - Stakeholders reporta roles sincronizados en exportaciones

Fecha: 2026-05-08  
Modo: GIPROY CLASICO  
Estado: Implementada y validada

## Objetivo
Corregir la reportería de `Stakeholders` para que Excel, PDF nativo y PDF desde Excel reflejen los roles sincronizados desde `EDO` / `EDT`, igual que ya ocurre en la vista previa/resumen.

## Alcance
- Backend común de reporting.
- Caché de exportación de reportes de `stakeholders`.
- Test focal de sincronización rol -> clave de exportación.
- Sin cambios visuales, sin cambios BIM, sin rutas BIM.

## Implementación
- Se añade una firma específica para exportaciones `stakeholders` en `ReportingService`.
- La clave de caché ahora incluye:
  - proyecto raíz,
  - stakeholders del proyecto,
  - asignaciones `proyecto_stakeholders`,
  - `rol_id`, nombre y marca temporal del rol.
- Se incrementa `REPORT_EXPORT_RENDER_VERSION` para invalidar exportaciones previas.
- Se añade test que verifica que la clave de exportación cambia al sincronizar un rol desde EDO.

## Validación
- `python -m py_compile backend/app/services/reporting.py` OK.
- `python -m pytest app/tests/test_stakeholder_role_sync.py -q` OK desde `backend/`, 5 passed.

## No interferencia BIM
No se modifican componentes, rutas, endpoints ni UX BIM. El cambio queda limitado a reportería clásica/backend común y al test focal existente de stakeholders.
