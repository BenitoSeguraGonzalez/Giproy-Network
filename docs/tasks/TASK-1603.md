# TASK-1603 - Contrato del motor de laminas graficas clasicas

Fecha: 2026-05-09  
Modo: GIPROY CLASICO  
Estado: Implementada como contrato base

## Objetivo
Definir el contrato operativo para un motor comun de impresion grafica clasica, reutilizable en `EDO`, `EDT`, `Cronogramas > Valorado > Curva S` y `Gantt`, con salida en tamanos `A0` a `A4` y orientacion horizontal/vertical.

## Reglas rectoras
- La salida es una `lamina grafica`, separada del reporte documental Excel/PDF existente.
- No se imprimen controles de interfaz: botones, buscadores, tabs, filtros, toggles, scrollbars, handles, menus ni acciones de edicion.
- Siempre se imprime una version extendida con todos los datos disponibles para la superficie.
- `EDO` y `EDT` imprimen la jerarquia completa expandida.
- `Cronograma Valorado > Curva S` imprime todos los periodos acumulados disponibles.
- `Gantt` imprime grid izquierdo y timeline completos reconstruidos desde datos, sin depender del viewport virtualizado.
- El boton visible sigue anclado al patron `Reporte`, pero distingue `Reporte documental` y `Lamina grafica`.

## Alcance tecnico aprobado
- Frontend clasico solamente.
- Sin backend nuevo en este primer corte.
- Generacion mediante ventana tecnica HTML/CSS con `@page`, compatible con guardado PDF desde el dialogo nativo del navegador.
- Preparado para evolucionar despues a render headless backend si se requiere generacion PDF server-side directa.

## No interferencia BIM
Sin rutas BIM, UX BIM, modelos BIM, APIs BIM ni dependencias BIM. El contrato aplica solo a superficies clasicas.
