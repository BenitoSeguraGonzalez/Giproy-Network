# TASK-1604 - Motor inicial de laminas graficas clasicas

Fecha: 2026-05-09  
Modo: GIPROY CLASICO  
Estado: Implementada y ajustada a descarga PDF directa

## Objetivo
Implementar el primer motor funcional de laminas graficas clasicas para testear y pulir impresion de `EDO`, `EDT`, `Cronogramas > Valorado > Curva S` y `Gantt`.

## Implementacion
- Se agrega `ClassicPrintOptionsModal` como selector comun de impresion:
  - tamanos `A0`, `A1`, `A2`, `A3`, `A4`;
  - orientacion `Horizontal` o `Vertical`;
  - resumen de preflight por superficie;
  - confirmacion `Generar PDF`.
- Se agrega `classicPrintEngine.js` como motor comun de PDF directo:
  - scaffold de lamina tecnica con titulo, proyecto, revision, papel y fecha;
  - salida sin controles interactivos;
  - calculo interno de pagina `A0` a `A4` y orientacion;
  - generacion de `Blob application/pdf` y descarga directa desde el boton `Generar PDF`.
- Ajuste de calidad grafica para `EDO` / `EDT`:
  - la lamina deja de dibujar los nodos como rejilla tabular;
  - se proyecta el arbol estructural igual que la vista grafica: tarjetas, conectores jerarquicos, chips y responsable embebido;
  - se elimina el mojibake `þÿ` sustituyendo la escritura UTF-16 defectuosa por texto PDF limpio compatible con fuentes base.
- Ajuste de calidad grafica para `Gantt`:
  - se retira la franja naranja artificial al inicio de cada barra porque podia leerse como avance/progreso sin estar respaldada por datos;
  - el naranja queda reservado para hitos/acento visual, no para segmentos de tarea sin semantica.
  - se agregan lineas de relacion predecesora al timeline PDF usando solo `dependencies` explicitas, sin inferir rutas desde campos secundarios;
  - se respetan anclajes `FS`, `SS`, `FF`, `SF` con codos y flecha hacia la sucesora;
  - se retiran de la lamina PDF los rotulos flotantes `FS`/`FF`/etc. del timeline porque no aportan lectura real;
  - el grid izquierdo de la lamina Gantt incorpora `Pred.` con los shortcuts de predecesoras por fila;
  - se evita que la lamina convierta tareas de duracion/ancho pequeno en hitos: solo se dibuja hito cuando la fila lo declara explicitamente;
  - el grid izquierdo de la lamina Gantt incorpora `Inicio`, `Fin` y `Dur.` por tarea.
- `EDO` integra el boton `Reporte` como menu:
  - `Reporte documental`;
  - `Lamina grafica`.
- `EDT` integra el mismo menu y usa la jerarquia valorada cuando existe presupuesto operativo.
- `Cronogramas` agrega:
  - `Lamina Gantt completo` dentro del menu de reporte Gantt;
  - `Lamina Curva S` dentro del menu de reporte del Valorado.
- `Gantt` se reconstruye desde datos, con grid izquierdo completo y timeline completo, sin depender del DOM visible ni de la virtualizacion.

## Frontera de pulido
- La primera entrega prioriza funcionalidad completa y testeo real.
- El usuario puede pulir densidad, escala, nomenclatura, paginacion multipagina o fidelidad visual exacta por superficie en slices posteriores.
- La ruta backend headless queda preparada conceptualmente, pero no se introduce en este corte para evitar dependencias nuevas.
- El flujo antiguo de ventana tecnica/dialogo de impresion queda sustituido para evitar ventanas independientes del navegador.
- El primer PDF directo generaba una rejilla de nodos y errores tipograficos; queda corregido hacia una salida grafica jerarquica testeable.
