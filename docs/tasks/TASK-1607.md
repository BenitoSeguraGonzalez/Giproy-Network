# TASK-1607 - Control de fuente unica para PDF Gantt clasico

Fecha: 2026-05-12  
Modo: GIPROY CLASICO  
Estado: Control arquitectonico abierto y aplicado al slice inicial

## Objetivo
Fijar la regla de gobierno para la lamina PDF de `Gantt completo`: el PDF no debe interpretar dependencias ni rutas por su cuenta cuando existe una escena visual resuelta por el Gantt de la aplicacion.

## Decision
- El Gantt operativo es la fuente de verdad visual y funcional.
- El motor PDF debe consumir una escena visual del Gantt, no recalcular secuenciacion.
- El PDF solo puede adaptar salida: escala, pagina, margenes, grosor, color de impresion, tipografia y metadatos.
- Queda prohibido que el PDF decida carriles, anclajes, hitos o rutas desde datos crudos si la escena de aplicacion esta disponible.

## Frontera
No se toca el motor operativo del Gantt. La integracion se hace exponiendo una escena de impresion desde la presentacion existente.

## No interferencia BIM
Sin cambios BIM, sin imports BIM, sin rutas BIM, sin feature flags BIM y sin acoplamientos nuevos.
