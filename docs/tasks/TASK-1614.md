# TASK-1614 - Control visual global de botones y menus de reporte

## Modo
GIPROY CLASICO

## Tipo
Control / Norma visual

## Objetivo
Fijar como regla global que todo boton principal de `Reporte` y todo desplegable de opciones de reporte use el patron visual vigente de `Cronogramas > Gantt`.

## Norma
- Todo boton principal de `Reporte` debe usar `ProjectSectionReportButton`.
- Todo menu de reporte con opciones debe usar `ProjectReportMenu`.
- Toda opcion de menu debe usar `ProjectReportMenuItem`.
- El patron visual obligatorio es el de Gantt: boton soft/neumorfico, icono centrado, estado activo naranja suave; menu blanco con capsulas soft, sombra/relieve, texto en mayusculas e icono a la derecha.
- No se deben crear clases locales ad-hoc para reportes en EDO, EDT, Cronogramas u otros modulos clasicos.

## Impacto en GiProy Clasico
Regla visual transversal para reportes clasicos. No cambia datos, backend, persistencia ni contratos de exportacion.

## No interferencia BIM
No activa UX BIM, rutas BIM, modelos BIM ni dependencias BIM. Cualquier futuro boton BIM queda fuera de esta TASK salvo autorizacion explicita.

## Validacion requerida
- Verificar que `EDO`, `EDT` y `Cronogramas` usen componentes comunes para botones/menus de reporte.
- Ejecutar build frontend.
- Ejecutar smoke de no contaminacion BIM.
