# TASK-1616 - Copy institucional en laminas tecnicas clasicas

## Modo
GIPROY CLASICO

## Objetivo
Actualizar el encabezado comun de las laminas graficas clasicas para que deje de mostrar `GiProy Clasico - Lamina tecnica` y use el texto institucional solicitado: `Lámina Técnica Generada por GIPROY®`.

## Analisis de alcance
Las laminas tecnicas clasicas activas usan el mismo encabezado de `classicPrintEngine.js`:
- `EDO > Reporte > Lamina grafica`.
- `EDT > Reporte > Lamina grafica`.
- `Cronogramas > Valorado > Lamina Curva S`.
- `Cronogramas > Gantt > Lamina Gantt completo`.

## Implementacion
- Se actualiza el literal del encabezado PDF comun en `drawSheetHeader`.
- Se ajusta la escritura de strings PDF para conservar caracteres WinAnsi seguros como `á`, `é` y `®`, evitando que el nuevo texto pierda acentos o marca registrada al renderizar.
- Hotfix posterior: las fuentes base del PDF declaran explicitamente `/Encoding /WinAnsiEncoding`. Sin esa declaracion, algunos visores interpretaban los bytes con `StandardEncoding` y mostraban `á`, `é` y `®` como caracteres incorrectos.
- Segundo hotfix: el motor deja de depender solo del alias `/WinAnsiEncoding` y define una codificacion PDF propia con `Differences` para glifos espanoles frecuentes y marca registrada (`/aacute`, `/eacute`, `/registered`, etc.), evitando que visores mantengan la lectura legacy `á -> Æ`, `é -> Ø`, `® -> fi`.

## Impacto en GiProy Clasico
Cambio de copy visual en PDFs de laminas graficas clasicas. No modifica datos, calculos, reportes documentales, preview, Excel/PDF Excel, menus, backend ni persistencia.

## No interferencia BIM
Sin rutas BIM, UX BIM, modelos BIM, imports BIM ni dependencias BIM.

## Validacion
- Validacion focal: el motor declara una codificacion con `Differences`, mapea `á`, `é` y `®` a codigos propios y mantiene el literal `Lámina Técnica Generada por GIPROY®`.
- `npm run build` OK desde `frontend/`.
- `node scripts/smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.
- Parseo JSON de `docs/project_state.json` y `docs/runtime/WORK_MODE_STATE.json` OK.
