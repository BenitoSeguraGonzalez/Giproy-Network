# TASK-1617 - PDF documental A4 para reportes EDO y EDT

## Modo
GIPROY CLASICO

## Objetivo
Reactivar el boton `PDF` directo en los reportes de `EDO` y `EDT`, pero usando un formato documental A4 vertical pensado para incorporarse a un informe, no una tabla tipo Excel.

## Implementacion
- `CommonReportPreviewModal` vuelve a mostrar el boton `PDF` cuando existe `onExportPdf`, incluyendo EDO y EDT.
- Hotfix posterior: en EDO/EDT el CTA se rotula `PDF Documento` y usa variante de acento para distinguirlo claramente de `PDF Excel`.
- Ajuste posterior TASK-1618: el footer comun de reportes reemplaza esa etiqueta temporal por el contrato global `PDF` -> `Excel` -> `Excel -> PDF`, manteniendo los handlers existentes.
- Se agrega `frontend/scripts/smoke-edo-edt-pdf-document-button.mjs` para bloquear regresiones donde el visor vuelva a ocultar el PDF directo de EDO/EDT.
- Ajuste posterior de maquetacion documental:
  - `EDO`: columnas `Item` y `Rol Asignado` quedan centradas en el previo y en el workbook usado por Excel/PDF Excel.
  - `EDT listado`: columnas `Item` y `Cod. EDT` se compactan, y `Descripcion Cuenta / Paquete de Trabajo` gana ancho.
  - `EDT diccionario/valorada`: `Cod. EDT` se compacta y la columna de descripcion gana ancho.
- `REPORT_EXPORT_RENDER_VERSION` sube a `2026-05-13-edo-edt-document-report-v3` para invalidar exportes cacheados con anchos anteriores.
- `ReportingService.generate_preview_pdf(...)` enruta `edo` y `edt` a un nuevo renderer documental A4 vertical.
- Se agrega `_build_hierarchy_document_pdf(...)` como base reutilizable para reportes jerarquicos documentales.
- El PDF documental incluye:
  - cabecera de seccion `EDO` / `EDT`;
  - metadatos de proyecto, revision, codigo referencial, ciudad y fecha;
  - resumen ejecutivo con tarjetas compactas;
  - proposito de la seccion;
  - detalle documental en fichas jerarquicas, no tabla Excel;
  - bloque de control documental;
  - pie de pagina con codigo de proyecto y numeracion.
- `Excel` y `PDF Excel` mantienen las plantillas existentes sin cambios.
- `REPORT_EXPORT_RENDER_VERSION` sube a `2026-05-13-edo-edt-document-report-v2` para invalidar exportes cacheados.

## Impacto en GiProy Clasico
Backend comun de reporting y frontend clasico del visor de reportes. No cambia arbol EDO/EDT, persistencia, plantillas Excel, PDF desde Excel ni UX de laminas graficas.
