# TASK-1618 - Contrato comun de botones de exportacion de reportes

## Modo
GIPROY CLASICO

## Objetivo
Homologar los botones inferiores del visor comun de reportes para que toda la aplicacion clasica use el mismo orden, etiqueta, jerarquia visual y comportamiento.

## Implementacion
- `CommonReportPreviewModal` define el contrato visible comun:
  - `PDF`
  - `Excel`
  - `Excel -> PDF`
- El orden queda fijado como `PDF` primero, `Excel` segundo y `Excel -> PDF` tercero.
- `PDF` queda como accion secundaria documental directa.
- `Excel` conserva la variante de acento como accion primaria de descarga editable.
- `Excel -> PDF` queda como accion secundaria para la conversion desde plantilla Excel.
- Se eliminan variantes visibles anteriores como `PDF Documento`, `PDF Excel`, `Exportar PDF directo` y `Exportar PDF documental A4`.
- El smoke `frontend/scripts/smoke-edo-edt-pdf-document-button.mjs` pasa a validar el contrato global de orden, etiquetas y ausencia de variantes antiguas.

## Impacto en GiProy Clasico
Solo cambia el footer grafico del visor comun de reportes clasicos. Mantiene handlers existentes y no cambia la generacion backend de PDF, Excel ni Excel -> PDF.

## No interferencia BIM
Sin rutas BIM, UX BIM, modelos BIM, imports BIM ni dependencias BIM.

## Validacion
