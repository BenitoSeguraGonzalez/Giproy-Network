# TASK-1620 - Ajuste de columnas EDO en reporte documental

## Modo
GIPROY CLASICO

## Objetivo
Precisar el layout tabular del reporte documental EDO: centrar las dos primeras columnas, reducir bastante `Item`, reducir solo un poco `Rol Asignado` y trasladar el espacio ganado a `Actividades clave`.

## Implementacion
- `REPORT_EXPORT_RENDER_VERSION` sube a `2026-05-13-edo-document-columns-v4` para invalidar exportes cacheados con anchos anteriores.
- `_normalize_edo_document_columns(...)` fija:
  - columna `A / Item`: ancho `5`;
  - columna `B / Rol Asignado`: ancho `12.5`;
  - columna `C / Nombre del Responsable`: minimo `26`;
  - columna `D / Actividades clave`: minimo `38`.
- Se conserva centrado horizontal para `Item` y `Rol Asignado` desde la fila de cabecera hasta el final.
- `CommonReportPreviewModal` alinea el previo EDO con el mismo criterio proporcional:
  - `Item`: `5%`;
  - `Rol Asignado`: `16%`;
  - `Nombre del Responsable`: `24%`;
  - `Actividades clave`: `39%`.
