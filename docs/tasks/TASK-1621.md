# TASK-1621 - Ajuste de columnas EDT en reporte documental

## Modo
GIPROY CLASICO

## Objetivo
Aplicar al reporte documental EDT listado el mismo criterio de lectura: reducir la primera y segunda columna y trasladar el espacio ganado a `Descripcion Cuenta / Paquete de Trabajo`.

## Implementacion
- `REPORT_EXPORT_RENDER_VERSION` sube a `2026-05-13-edo-edt-document-columns-v5` para invalidar exportes cacheados.
- `_normalize_edt_document_columns(...)` para variante `listado` fija:
  - columna `A / Item`: ancho `5`;
  - columna `B / Cod. EDT`: ancho `8`;
  - columna `C / Descripcion Cuenta / Paquete de Trabajo`: ancho `56`.
- Se mantiene centrado horizontal para `Item` y `Cod. EDT`.
- `CommonReportPreviewModal` alinea el previo EDT con proporciones:
  - `Item`: `5%`;
  - `Cod. EDT`: `8%`;
  - `Descripcion Cuenta / Paquete de Trabajo`: `63%`.

## Impacto en GiProy Clasico
Solo modifica presentacion del reporte documental EDT listado en preview y workbook usado por Excel / Excel -> PDF. No cambia datos, arbol EDT, calculos, persistencia ni BIM.

## No interferencia BIM
Sin rutas BIM, UX BIM, modelos BIM, imports BIM ni dependencias BIM.
