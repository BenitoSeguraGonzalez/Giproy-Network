# TASK-1622 - Control de ampliacion de laminas graficas clasicas

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Definir el control de alcance para ampliar las laminas graficas clasicas con una salida paginada reutilizable en EDO, EDT y Presentacion Gantt, excluyendo expresamente Curva S.

## Alcance autorizado

- Frontend clasico de `EDO`, `EDT` y `Cronogramas > Gantt`.
- Motor comun `classicPrintEngine`.
- Modal comun de opciones de lamina grafica.
- Documentacion de TASK, CHANGELOG, project_state y runtime.

## Regla tecnica

- No crear calculos nuevos de Gantt, EDO o EDT.
- Usar el arbol/snapshot actual ya emitido por cada modulo.
- Mantener la salida completa actual como modo base.
- Agregar paginacion como modo opcional de impresion para estructuras extensas.
- Curva S queda fuera de esta ampliacion.

## No interferencia BIM

- Sin rutas BIM.
- Sin componentes BIM.
- Sin imports BIM.
- Sin feature flags BIM.
- Sin cambios en modelos, APIs o persistencia BIM.

## Criterios de aceptacion

- EDO y EDT permiten elegir salida completa o paginada.
- Gantt permite elegir salida completa o paginada.
- Curva S conserva solo opciones de papel/orientacion.
- La paginacion reutiliza datos actuales y no reconstruye calculos de dominio.
- Existe smoke que bloquee regresiones de alcance y exclusion de Curva S.
