# TASK-1623 - Ejecucion de paginacion reutilizable en laminas clasicas

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Implementar la opcion paginada para laminas graficas clasicas de EDO, EDT y Presentacion Gantt, manteniendo la salida completa existente y usando el mismo motor PDF directo.

## Implementacion

- `ClassicPrintOptionsModal` incorpora modo de salida `Completa / Paginada` y selector de elementos por pagina cuando el consumidor lo habilita.
- `Edo.jsx` y `Edt.jsx` pasan `printMode` y `rowsPerPage` al motor comun de jerarquias.
- `Cronogramas.jsx` habilita paginacion solo para `Presentacion Gantt`; Curva S queda excluida.
- `classicPrintEngine.js` divide jerarquias por grupos de raices y Gantt por filas del snapshot ya resuelto.
- La salida paginada agrega numeracion de pagina en el subtitulo y conserva papel/orientacion seleccionados.

## Validacion esperada

- Smoke especifico de paginacion clasica.
- Smoke existente de dependencias Gantt.
- Build frontend.
- Smoke de no contaminacion BIM.
- Parseo JSON documental.

## Impacto

Frontend clasico y motor comun de laminas graficas. Sin backend, sin persistencia y sin BIM.
