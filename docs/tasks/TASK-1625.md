# TASK-1625 - Menu desplegable de reportes en Presupuesto clasico

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Reemplazar el modal intermedio de configuracion de reportes en `Presupuesto` por un desplegable alineado con el patron visual vigente de reportes clasicos usado en Gantt, EDO y EDT.

## Alcance autorizado

- Frontend clasico de `Presupuesto`.
- Entrada visual del boton `Reporte`.
- Reutilizacion de `ProjectSectionReportButton`, `ProjectReportMenu` y `ProjectReportMenuItem`.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- El boton de reporte de Presupuesto abre un menu desplegable comun.
- El menu ofrece:
  - `Presupuesto`;
  - `Presupuesto + APUs`.
- Cada opcion llama directamente al preview existente con `variant=without_apus` o `variant=with_apus`.
- Se elimina el modal local `Configuracion de Reporte` de este flujo.
- Se conserva el preview comun y los handlers de exportacion existentes.
