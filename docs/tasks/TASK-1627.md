# TASK-1627 - Reporte de indirectos activos del presupuesto

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Agregar al menu de reportes de `Presupuesto` un reporte especifico de indirectos activos por proyecto/revision/presupuesto, mostrando cada porcentaje aplicado sobre el total sin indirectos y el costo monetario resultante.

## Alcance autorizado

- Backend comun de reporting clasico.
- Frontend clasico de `Presupuesto`.
- Plantilla Excel editable `001 - Porcentajes de Indirectos.xlsx`.
- Visor comun de reportes clasicos.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- Se agrega la variante `report_type = presupuesto` + `variant = indirectos`.
- El preview muestra `Reporte de Indirectos del Presupuesto`.
- El menu desplegable de Presupuesto incorpora la opcion `Indirectos` junto a `Presupuesto` y `Presupuesto + APUs`.
- El motor lee `Presupuesto.indirectos` y filtra conceptos con porcentaje distinto de cero como indirectos activos.
- Cada cuenta calcula:
  - base de calculo = `presupuesto.subtotal`;
  - costo aplicado = `presupuesto.subtotal * porcentaje / 100`.
- El reporte agrupa por categoria, agrega subtotal por categoria y resumen final.
- El Excel usa la plantilla editable `docs/reportes/001 - Porcentajes de Indirectos.xlsx`, con placeholders para cabecera, tabla, base, porcentaje, costo aplicado, IVA y total.
- La cache de exportacion se invalida mediante `REPORT_EXPORT_RENDER_VERSION = 2026-05-13-budget-indirects-report-v1`.
