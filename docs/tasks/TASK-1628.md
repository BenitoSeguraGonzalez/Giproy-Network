# TASK-1628 - Reporte de indirectos configurados por categoria

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Ajustar el reporte clasico de `Indirectos` en `Presupuesto` para que muestre el listado de indirectos configurados para el proyecto/revision/presupuesto, incluyendo cuentas con porcentaje `0.00%`, y preserve el subtotal porcentual y monetario por categoria.

## Alcance autorizado

- Backend comun de reporting clasico.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- El generador de filas de indirectos deja de filtrar por `porcentaje != 0`.
- El reporte conserva todas las cuentas configuradas de `Presupuesto.indirectos`.
- Cada fila mantiene:
  - categoria;
  - codigo;
  - concepto;
  - tipo;
  - porcentaje aplicado;
  - base de calculo = `presupuesto.subtotal`;
  - costo aplicado = `presupuesto.subtotal * porcentaje / 100`.
- Las filas de subtotal por categoria siguen acumulando porcentaje y costo aplicado.
- El contador `#TOTAL_CUENTAS` pasa a contar cuentas configuradas, no solo activas.
- La cache de exportacion se invalida mediante `REPORT_EXPORT_RENDER_VERSION = 2026-05-13-budget-indirects-report-v2`.
