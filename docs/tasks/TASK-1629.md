# TASK-1629 - Cabecera tecnica para reporte de indirectos

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Ajustar la presentacion del reporte clasico de `Indirectos` para que el previo mantenga sus indicadores en una sola linea y la plantilla Excel editable tenga una cabecera tecnica, ordenada y localizable desde configuracion.

## Alcance autorizado

- Backend comun de reporting clasico.
- Frontend clasico del visor comun de reportes y `Presupuesto`.
- Plantilla editable `docs/reportes/001 - Porcentajes de Indirectos.xlsx`.
- Configuracion visible de plantillas.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- El preview de `Indirectos` declara `summary_layout = single_line`.
- `CommonReportPreviewModal` respeta ese layout para cuatro indicadores en una sola fila y reduce ligeramente la densidad del encabezado.
- `PresupuestoDetail` resuelve la plantilla de la variante `indirectos` desde `plantillas_config.indirectos`, separandola de `plantillas_config.presupuestos`.
- `PLANTILLAS_OPCIONES.indirectos` queda visible como `Indirectos del Presupuesto` en el menu de configuracion.
- La plantilla `001 - Porcentajes de Indirectos.xlsx` se remaqueta con bloques tecnicos:
  - identificacion del proyecto/revision;
  - resumen economico;
  - listado de indirectos configurados por categoria;
  - resumen final.
- La cache de exportacion se invalida mediante `REPORT_EXPORT_RENDER_VERSION = 2026-05-13-budget-indirects-report-v3`.
