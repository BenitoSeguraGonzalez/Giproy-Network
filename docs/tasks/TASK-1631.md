# TASK-1631 - Forzar una sola linea en paneles del previo de indirectos

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Corregir el previo clasico del reporte `Indirectos` para que los cuatro paneles informativos ocupen una sola linea real, incluso si el payload servido por backend/cache aun no trae `summary_layout = single_line`.

## Alcance autorizado

- Frontend clasico del visor comun de reportes.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- `CommonReportPreviewModal` detecta reportes de indirectos con cuatro paneles y fuerza el layout `grid-cols-4` aunque falte `summary_layout`.
- El encabezado del reporte usa una grilla compacta con columna derecha reservada para los cuatro paneles.
- Los paneles compactos reducen padding, fuente de etiqueta y fuente de valor para evitar salto a segunda linea.
- Los valores monetarios quedan en `nowrap` para no partir cifras.
