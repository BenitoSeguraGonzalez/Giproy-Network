# TASK-1633 - Compactar datos tecnicos del previo de indirectos

Fecha: 2026-05-13

Modo: GIPROY CLASICO

## Objetivo

Reducir la altura excesiva del bloque de datos tecnicos en el previo clasico del reporte `Indirectos`, manteniendo la estructura visual comun de reportes y sin cambiar el contrato de datos.

## Alcance autorizado

- Frontend clasico del visor comun de reportes.
- Documentacion TASK, CHANGELOG, project_state y runtime.

## Implementacion

- `CommonReportPreviewModal` mantiene el layout normal de campos para reportes generales.
- En previos compactos, como `Indirectos`, `item.fields` pasa de filas completas a una grilla de fichas tecnicas pequenas.
- Cada ficha muestra etiqueta y valor en altura reducida, con truncado y `title` para valores largos.
- El cambio conserva los datos existentes: codigo de proyecto, revision, codigo referencial, IVA, base con indirectos e IVA calculado.
