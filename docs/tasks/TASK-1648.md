## TASK-1648 - Panel administrador Marketplace compacto y scrolleable

**Fecha:** 2026-05-14  
**Modo:** GIPROY CLASICO  
**Area:** Frontend clasico / Otros Servicios / Panel administrador Tienda

### Objetivo

Corregir el panel administrador de Tienda para que los paneles de seleccion no ocupen una altura excesiva y la pantalla permita desplazamiento vertical dentro del layout protegido.

### Alcance autorizado

- Solo capa clasica.
- Solo presentacion y layout del panel administrador de Marketplace.
- Sin cambios en backend, API, datos, persistencia, PostgreSQL ni UX BIM.

### Implementacion

- `MarketplaceShell` acepta clases opcionales para permitir variantes de viewport sin cambiar su comportamiento por defecto.
- `MarketplaceAdminDashboard` usa un contenedor de altura completa con scroll vertical interno.
- Las tarjetas de seleccion del panel administrador reducen altura minima, padding, iconos, tipografia y footer para ganar densidad operativa.
- El viewport principal del selector usa `MotionScrollbar`, ocultando la barra nativa y reutilizando el rail/pieza movil diseñado de GiProy.
- Ajuste posterior: el tablero pasa a tres columnas en escritorio amplio, integra icono/titulo en una cabecera compacta y ubica la scrollbar en un gutter propio para evitar que quede aislada visualmente.
- Saneamiento posterior: las listas internas del panel administrador (`Formas de pago`, `Ventas Sistema`, `Licencias/Productos registrados`, editor generico y previo de portal) reutilizan un wrapper local con `MotionScrollbar` para evitar barras nativas grises.
