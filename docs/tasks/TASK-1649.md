# TASK-1649 - Control visual de scrollbars en Otros Servicios

## Modo
GIPROY CLASICO.

## Objetivo
Auditar integralmente las superficies de Otros Servicios / Marketplace clasico para detectar scrollbars nativas, `custom-scrollbar` heredadas o barras visibles incoherentes con el sistema visual GiProy.

## Alcance de control
- Tienda / catalogo publico de Marketplace.
- Panel Administrador de Marketplace.
- Mis compras / buyer dashboard.
- Panel vendedor / seller dashboard.
- Modales operativos asociados a detalle, checkout, listas, editores y formularios de administracion.

## Criterios
- Usar el componente existente `MotionScrollbar` ya empleado en Proyectos.
- Ocultar la barra nativa con `giproy-motion-scrollbar-hide` en superficies con scrollbar visible diseñada.
- No crear contratos visuales paralelos ni dependencias nuevas hacia Marketplace.
- No tocar backend, API, datos, persistencia ni PostgreSQL.
- No activar ni mostrar UX BIM.

## Validacion
- Busqueda focal sin `custom-scrollbar` en `Marketplace.jsx`, `MarketplaceAdminDashboard.jsx`, `MarketplaceBuyerDashboard.jsx`, `SellerDashboard.jsx` y `MarketplaceVisualSystem.jsx`.
- `npm run build` OK.
- `node scripts\smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.

## No interferencia BIM
Sin rutas BIM, UX BIM, imports BIM, modelos BIM ni acoplamientos hacia BIM.
