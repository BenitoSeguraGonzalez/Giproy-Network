# TASK-1650 - Implementacion saneamiento scrollbars Otros Servicios

## Modo
GIPROY CLASICO.

## Objetivo
Aplicar el saneamiento visual de scrollbars en Otros Servicios usando el componente existente `MotionScrollbar`, sin crear un componente paralelo y sin contaminar la capa BIM.

## Implementacion
- `Marketplace.jsx`: catalogo principal, sidebar de opciones, detalle de producto, modales PayPhone, PayPal y carrito usan `MotionScrollbar`.
- `MarketplaceAdminDashboard.jsx`: selector principal, listas internas, tablas, editor generico, editor avanzado de Portal de Compras Publicas y preview usan el patron `giproy-motion-scrollbar-hide + MotionScrollbar`.
- `MarketplaceBuyerDashboard.jsx`: modales de compras y biblioteca usan scrollbar diseñada.
- `SellerDashboard.jsx`: modales de editor, catalogo, ventas, moderacion y categorias usan scrollbar diseñada.
- `MarketplaceVisualSystem.jsx`: no mantiene wrapper nuevo; se conserva el sistema visual sin contrato adicional.

## Alcance protegido
- Sin cambios en handlers, formularios, filtros, llamadas API, modelos, datos ni persistencia.
- Sin backend.
- Sin PostgreSQL.
- Sin UX BIM.

## Validacion
- `npm run build` OK.
- Busqueda focal sin `custom-scrollbar` ni `MarketplaceDesignedScrollArea` en las superficies saneadas.
- `node scripts\smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.

## No interferencia BIM
Sin rutas BIM, UX BIM, imports BIM, modelos BIM, feature flags BIM ni acoplamientos hacia BIM.
