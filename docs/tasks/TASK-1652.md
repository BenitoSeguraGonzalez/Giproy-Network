# TASK-1652 - Adecuacion compacta de menu y botones Marketplace

## Modo
GIPROY CLASICO.

## Objetivo
Recuperar una presentacion operativa compacta en `Otros Servicios` y `Panel Administrador` de Marketplace, alineando los botones de acceso con la normativa visual usada en Proyectos.

## Implementacion
- `Placeholders.jsx`
  - El menu `Otros Servicios` deja de separar y centrar filas por etapa.
  - Los items se presentan en un grid unico, compacto y alineado al inicio, equivalente al patron operativo del Panel Administrador.
  - Las cards reducen ancho, altura, padding, icono, tipografia y footer.
  - Ajuste posterior: se elimina la presentacion tipo vitrina/carrusel horizontal y el badge `Modulo n`; se adopta cabecera soft, grid 1/2/3 columnas y cards de submodulo con `Submodulo activo / Proximamente`.
  - El contenedor principal usa `MotionScrollbar` con `giproy-motion-scrollbar-hide` para scroll vertical GiProy.
- `MarketplaceAdminDashboard.jsx`
  - Las cards del menu de panel administrador reducen altura minima, padding, icono y densidad tipografica.
  - El grid queda alineado al inicio y preparado para crecer con nuevos submodulos sin bloquear desplazamiento.
  - El boton visual de accion cambia de caracter `↗` a icono `ArrowUpRight` con skin neumorfico compacto.
- `MarketplaceVisualSystem.jsx`
  - `MarketplaceModuleCard` se compacta y adopta `ArrowUpRight` con skin de boton iconografico, evitando caracteres sueltos.

## Alcance protegido
- Solo frontend clasico.
- Sin cambios en handlers, rutas, permisos, backend, API, datos, persistencia ni PostgreSQL.
- Sin UX BIM.

## Validacion
- `npm run build` OK.
- `node scripts\smoke-classic-no-bim-contamination.mjs` OK desde `frontend/`.
- Busqueda focal sin `↗`, `custom-scrollbar`, `scrollbar-hide`, carrusel horizontal ni `MarketplaceDesignedScrollArea` en superficies saneadas.
- Busqueda focal sin referencias BIM en archivos tocados.

Sin rutas BIM, UX BIM, imports BIM, modelos BIM, feature flags BIM ni acoplamientos hacia BIM.
