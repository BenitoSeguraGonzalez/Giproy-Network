# TASK-1653 - Reajuste visual de barra lateral de filtros Marketplace

## Modo
- MODO 1: GIPROY CLASICO.

## Objetivo
Sanear la barra lateral de filtros de Tienda Marketplace para recuperar densidad operativa, lectura clara y scrollbar GiProy integrada.

## Alcance autorizado
- Frontend clasico.
- Superficie: `frontend/src/pages/Marketplace.jsx`.
- Barra lateral de opciones: categorias, precio, recientes y scrollbar interna.

## Cambios implementados
- Se reduce el tamano visual del contenedor lateral y de sus secciones internas.
- Las filas de categorias bajan altura, padding y tamano tipografico, preservando contador y estado activo.
- Los textos largos de categorias mantienen alineacion y lectura sin romper el layout.
- La seccion Precio usa controles mas compactos y botones alineados con la normativa visual operativa.
- La seccion Recientes reduce tarjeta, miniatura y estado vacio.
- `MotionScrollbar` queda reposicionada dentro del panel, iniciando bajo el header y con margen inferior.

## Impacto GiProy Clasico
