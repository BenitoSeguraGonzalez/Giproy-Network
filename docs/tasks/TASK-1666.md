# TASK-1666 - Alta administrativa temporal de Portal Compras Publicas para Santiago Bermeo

## Modo
GIPROY CLASICO.

## Objetivo
Corregir la creacion de `Portal de compras publicas` desde `Marketplace > Administrador` para respetar el permiso temporal que permite al administrador de la empresa `Santiago Bermeo` actuar como administrador global solo dentro de esta seccion.

## Alcance autorizado
- Backend comun de Marketplace.
- Frontend clasico de `MarketplaceAdminDashboard`.
- Cliente API clasico de Marketplace.

## Implementacion
- Se agrega `POST /api/v1/marketplace/admin/products` como ruta administrativa de alta de productos.
- La ruta usa la validacion administrativa existente de Marketplace, que ya contempla la excepcion temporal para `Santiago Bermeo`.
- `MarketplaceService.create_product` recibe contexto administrativo interno para permitir tipos de sistema solo cuando la llamada viene por la ruta admin.
- La ruta normal `POST /api/v1/marketplace/products` conserva la restriccion de vendedor: APUs, Bases Maestras y Proyectos.
- El panel administrador deja de crear productos mediante la ruta de vendedor y usa `marketplaceApi.createAdminProduct`.

## Impacto GiProy Clasico
- El administrador temporal de `Santiago Bermeo` puede crear portales de compras publicas desde el panel administrador de Marketplace.
- No se relaja la politica general de vendedores de empresa fuera del panel administrador.
- No cambia el importador tecnico, checkout, pagos, ordenes ni entrega de productos.
