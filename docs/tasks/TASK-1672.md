# TASK-1672 - Plan rector migracion Compras Publicas a Proyectos

## Modo
GIPROY CLASICO.

## Estado
Planificada. Sin implementacion funcional en esta TASK.

## Objetivo
Definir el contrato rector para mover la creacion tecnica de compras publicas fuera de Marketplace y ubicarla en `Proyectos`, conservando Marketplace solo como canal comercial de publicacion, aprobacion, venta, compra y entrega.

## Decision arquitectonica
- La creacion tecnica de proyectos desde PDF no debe seguir creciendo dentro de Marketplace.
- El creador actual de `Portal de compras publicas` queda como legado transitorio hasta reemplazo validado.
- El nuevo importador nace en `Proyectos`, solo visible para Superadministrador dentro de la empresa `Administradores Generales`.
- El backend sigue siendo unico y comun; las capas funcionales se separan por servicios y permisos, no por duplicar backend.
- Ninguna pieza de este frente puede depender de BIM ni mostrar UX BIM.

## Alcance
- Congelar el mapa de responsabilidades entre `Proyectos`, `Presupuesto/APUs/Recursos/EDT/Cronogramas` y `Marketplace`.
- Definir permisos, restricciones multiempresa, trazabilidad de origen y estados de migracion.
- Preparar la secuencia de TASK-1673 a TASK-1681 como slices pequenos y verificables.

## Fuera de alcance
- Implementar endpoints, modelos, migraciones o pantallas.
- Eliminar el flujo Marketplace actual.
- Cambiar checkout, pagos, pedidos o entrega actual.

## Puertas de seguridad
- No eliminar compatibilidad de productos existentes en Marketplace.
- No activar la nueva experiencia hasta tener importer + materializer + locks + QA.
- Todo apagado del creador Marketplace debe ser posterior y reversible por feature flag/capability.
- Cualquier permiso temporal debe estar aislado, auditado y documentado.

## No interferencia BIM
- Sin rutas BIM.
- Sin UX BIM.
- Sin modelos BIM.
- Sin imports BIM.
- Sin dependencias hacia feature flags BIM.

## Validacion requerida al ejecutar el frente
- Parseo JSON documental.
- Build frontend si se toca UI.
- Pytest/py_compile backend si se toca servicio, permisos, modelos o endpoints.
- Smoke `classic-no-bim-contamination`.
- QA manual de visibilidad por rol/empresa.
