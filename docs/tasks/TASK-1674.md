# TASK-1674 - Importador Proyectos solo Superadministrador Administradores Generales

## Modo
GIPROY CLASICO.

## Estado
Implementada para importacion inicial. Slices 1 y 2 backend implementados; slice 3 UI de preview implementado; slice 4 materializacion inicial implementado.

## Objetivo
Crear la superficie del nuevo importador dentro del menu `Proyectos`, restringida inicialmente a usuarios con rol `Superadministrador` en la empresa `Administradores Generales`.

## Alcance
- Se agrega base backend de autorizacion en `public_procurement_project_import_access.py`.
- Se fija la regla: solo `Superadministrador` en empresa `Administradores Generales`.
- Se agrega validador que devuelve 403 claro para futuros endpoints.
- Se agrega `POST /api/v1/proyectos/public-procurement-import/preview` como preview backend puro.
- El endpoint lee archivos multipart `files`/`file`, deduplica por nombre + SHA1, acepta roles manuales y bundle existente, y llama al analizador comun con `include_parser_contract=True`.
- La respuesta queda bajo `import_source_kind = proyecto_import_preview` y contiene `technical_import_contract`.
- Entrada visible solo en Proyectos para la empresa y rol autorizados.
- Subida de PDF/Excel y preview tecnico basado en TASK-1673.
- Modal clasico de analisis previo sin persistencia durante el preview.
- Endpoint protegido `POST /api/v1/proyectos/public-procurement-import/materialize`.
- Materializacion transaccional inicial: crea proyecto clasico, base de trabajo, subcategorias generales, recursos importados, APUs, EDT por capitulos, presupuesto y rubros vinculados.
- UI permite crear el proyecto desde el preview y abrirlo en Proyectos.
- UI alineada al look & feel de Proyectos: botones iconograficos, modales comunes y densidad operativa.
- Auditoria de intentos bloqueados por rol o empresa.

## Fuera de alcance
- Publicar en Marketplace.
- Permitir acceso a administradores de empresa normales.
- Crear stakeholders o EDO desde la compra publica.
- Exportar o vender el proyecto importado.
- Crear cronograma Gantt manual detallado o valorizacion temporal; queda presupuesto operativo inicial listo para la capa clasica existente.

## Reglas de permisos
- La empresa debe resolverse por identificador estable si existe; si no, por nombre protegido `Administradores Generales` con validacion defensiva.
- El frontend solo oculta; el backend debe bloquear.
- Un superadministrador fuera de esa empresa no accede al importador en esta fase.
