# TASK-1677 - Exportador publicador Proyecto hacia Marketplace

## Modo
GIPROY CLASICO.

## Estado
Planificada. Sin implementacion funcional en esta TASK.

## Objetivo
Crear un exportador/publicador desde un proyecto existente hacia Marketplace, generando un item de venta pendiente de aprobacion.

## Alcance
- Entrada desde Proyectos para elegir un proyecto vendible.
- Inicialmente visible solo para Superadministradores; preparar politica futura para Administradores.
- Crear ficha comercial pendiente de aprobacion en ventas/Marketplace.
- Adjuntar trazabilidad del proyecto origen, version, empresa propietaria y estado de aprobacion.
- Reutilizar el flujo comercial existente de Marketplace sin crear proyecto tecnico desde Marketplace.

## Fuera de alcance
- Permitir exportar proyectos comprados.
- Aprobar automaticamente publicaciones.
- Cambiar checkout o pagos.
- Crear una nueva tienda paralela.

## Reglas de seguridad
- Backend debe verificar que el proyecto pertenece a la empresa exportadora.
- Backend debe rechazar proyectos con origen comprado o bloqueados para exportacion.
- La UI no basta como control; el bloqueo debe vivir en servicio comun.

## Validacion
- Proyecto propio exportable genera producto pendiente.
- Proyecto comprado o bloqueado no se exporta.
- Producto queda en flujo de aprobacion existente.
- Smoke no contaminacion BIM.
