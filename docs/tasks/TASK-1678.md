# TASK-1678 - Compra y entrega privada de Proyecto vendido

## Modo
GIPROY CLASICO.

## Estado
Planificada. Sin implementacion funcional en esta TASK.

## Objetivo
Al comprar un proyecto publicado, entregar una copia privada dentro de la empresa compradora, lista para aparecer en sus proyectos.

## Alcance
- Integrar fulfillment de proyecto con el flujo de ordenes Marketplace existente.
- Clonar proyecto, base, recursos, APUs, presupuesto, EDT, Gantt y Valorado necesarios para uso interno.
- Mantener ownership en la empresa compradora.
- Registrar origen marketplace, vendedor, producto, orden, fecha de compra y bloqueo de reexportacion.
- Evitar clonar datos no incluidos o sensibles del vendedor.

## Fuera de alcance
- Reexportar la compra.
- Compartir el proyecto entre empresas.
- Copiar stakeholders/EDO si no forman parte del paquete permitido.
- Tocar BIM.

## Reglas multiempresa
- La copia entregada pertenece solo a la empresa compradora.
- El vendedor no puede ver ni editar la copia del comprador.
- El comprador no obtiene permisos sobre el proyecto origen.

## Validacion
- Compra confirmada crea proyecto visible para comprador.
- Orden fallida o pendiente no crea proyecto.
- Verificar ownership y aislamiento empresa a empresa.
- Smoke no contaminacion BIM.
