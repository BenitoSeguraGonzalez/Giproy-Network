# TASK-1680 - Adecuacion UI Marketplace y Proyectos para nuevo flujo

## Modo
GIPROY CLASICO.

## Estado
Planificada. Sin implementacion funcional en esta TASK.

## Objetivo
Ajustar las superficies visibles para que el usuario entienda el nuevo flujo: importar/crear tecnicamente en Proyectos, publicar/vender/comprar en Marketplace.

## Alcance
- Proyectos: entrada del importador, preview tecnico, confirmacion y resultado.
- Proyectos: entrada del exportador/publicador cuando aplique.
- Marketplace admin: congelar o deprecar la creacion tecnica de `Portal de compras publicas` una vez el reemplazo este validado.
- Ventas: mostrar productos pendientes de aprobacion generados desde proyectos.
- Compras: mostrar proyecto adquirido y acceso a su copia interna.
- Mensajes claros para proyectos comprados no exportables.

## Fuera de alcance
- Redisenar Marketplace completo.
- Activar BIM o rutas BIM.
- Eliminar productos historicos.

## Reglas visuales
- Usar modales y botones existentes de Proyectos/Marketplace.
- Botones con icono cuando el espacio sea estrecho.
- No introducir cards anidadas ni patrones visuales ajenos al sistema.
- Mantener lenguaje operativo, no marketing.

## Validacion
- QA responsive escritorio y ancho intermedio.
- Build frontend.
- Smoke no contaminacion BIM.
- QA manual de permisos y mensajes.
