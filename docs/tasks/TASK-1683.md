# TASK-1683 - Homologar cierres de modales clasicos

## Modo
GIPROY CLASICO

## Objetivo
Unificar los botones de cierre de modales que conservaban el formato circular/neumorfico antiguo para que usen el formato compacto cuadrado definido por el componente comun de modales.

## Alcance implementado
- Se centraliza el estilo de cierre en `APP_MODAL_CLOSE_BUTTON_CLASS` dentro de `frontend/src/components/ui/app-modal.jsx`.
- `AppModalHeader` y el cierre base de `dialog.jsx` pasan a reutilizar el mismo patron.
- Se actualizan cierres manuales en modales clasicos de registro, recursos, subcategorias, stakeholders, presupuesto, Pareto, indirectos, notas, EDO/EDT, datos de proyecto y reporting.
- Se mantienen intactos botones internos que no son cierre de modal aunque usen icono `X`.

## Impacto GiProy Clasico
- Mejora visual transversal y coherente en modales clasicos.
- No cambia flujos de datos, permisos, persistencia, rutas ni llamadas API.

## No interferencia BIM
- No se modifican componentes BIM, rutas BIM, APIs BIM, hooks BIM ni feature flags BIM.
- La validacion de no contaminacion BIM queda ejecutada.

## Validacion

- `node scripts\smoke-classic-no-bim-contamination.mjs` OK desde `frontend`.
