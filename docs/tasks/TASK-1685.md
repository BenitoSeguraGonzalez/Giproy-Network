# TASK-1685 - Importador SOCE/SERCOP multiperfil para proyectos clasicos

## Estado
Completada.

## Contexto
El importador de compras publicas en Proyectos clasico debia dejar de depender del flujo de Marketplace y soportar documentos SOCE/SERCOP con varios perfiles:
- PDF integrado con presupuesto y APUs por codigo.
- PDF de resumen VAE donde el presupuesto referencia CPC de APU y los APUs se enlazan por descripcion, unidad y precio unitario.
- Multi-documento preparado para presupuesto y APUs en fuentes separadas.

## Cambios
- El analizador tecnico comun ahora expone perfil de parser, incidencias bloqueantes, avisos y requisito de consentimiento.
- El parser PDF escanea todos los APUs y evita la lectura parcial que dejaba rubros sin correspondencia.
- Se agrego perfil VAE SOCE/SERCOP con lectura de presupuesto resumen, CPC de APU, recursos con CPC/NP/EP/ND/VAE y APUs sin codigo.
- Se agrego conciliacion:
  - por codigo para PDFs integrados;
  - por descripcion + unidad + precio unitario para perfil VAE;
  - creacion de APU vacio cuando un rubro no tiene APU tecnico correspondiente.
- Se agrego deteccion de APUs duplicados por codigo con composicion divergente como incidencia bloqueante.
- Se corrigieron falsos positivos en `compras publicas prueba1.pdf`: el parser ya no trata cierres de costo, importes escritos en letras ni recursos incompletos por salto de pagina como diferencias reales de composicion.
- La deteccion de APUs anidados ya no intenta enlazar recursos normales por similitud de descripcion; solo revisa referencias marcadas como APU/anidadas.
- La lectura VAE corrige totales de presupuesto partidos por linea usando cantidad x precio unitario cuando el total extraido es incoherente.
- Las incidencias ambiguas de perfil VAE incluyen rubro, descripcion, unidad, precio unitario y candidatos tecnicos para revision expresa.
- La materializacion exige consentimiento expreso de superadministrador cuando hay incidencias bloqueantes.
- La materializacion guarda CPC de recursos y CPC de APU de proyecto usando `ProyectoApuCpc`.
- El modal clasico de Proyectos muestra incidencias bloqueantes y avisos antes de crear el proyecto.
- El modal clasico ya no inserta mensajes largos de error en linea; muestra un resumen y abre una ventana `Diagnostico SOCE/SERCOP` con el detalle tecnico.
