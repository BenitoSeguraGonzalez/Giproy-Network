# TASK-1688 - Exportador de proyecto clasico a Marketplace

## Objetivo

Crear una salida conservadora desde Proyectos clasico hacia Marketplace para vender proyectos propios sin reactivar la creacion tecnica dentro de Marketplace.

## Alcance

- Backend comun: nuevo servicio `project_marketplace_exporter` y endpoint `POST /proyectos/marketplace-export`.
- Acceso backend: `Administrador` y `Superadministrador`.
- Visibilidad frontend inicial: solo `Superadministrador`, hasta validar apertura a administradores.
- Producto creado: tipo `proyecto`, origen referenciado `source_type=proyecto`, inactivo y en estado `pending`.
- Precio comercial: calculado con la tabla GIPROY ya existente para compras publicas, usando como base el presupuesto estimado u operativo del proyecto.
- Proteccion inamovible: se reutiliza la politica `purchase_bound_no_reexport`; proyectos comprados o adquiridos no pueden publicarse.
- Sincronizacion: si el producto ya existe, la reexportacion recalcula precio, total tecnico, metadatos y vista previa antes de devolverlo a moderacion.
- Trazabilidad: los proyectos importados desde SOCE/SERCOP publican en la vista previa comercial el estado tecnico minimo del importador.

## No alcance

- No se toca BIM.
- No se reintroduce el importador tecnico dentro de Marketplace.
- No se aprueban productos automaticamente.
- No se habilita todavia la visibilidad para administradores en UI.

## Validacion prevista

- Sintaxis backend.
- Pytest focal de exportador.
- Build frontend.
- Smoke clasico de no contaminacion BIM.

## Resultado

- El exportador ya reconstruye siempre el payload Marketplace antes de crear o reenviar a moderacion: precio, total tecnico, fuente del total, metadatos, trazabilidad y vista previa.
- La fuente economica queda sincronizada con el presupuesto operativo vigente; si no existe presupuesto usable, cae al presupuesto estimado.
- La reexportacion de un producto existente ya no conserva precio/metadatos antiguos.
- La UI clasica de Proyectos mantiene `ProjectSectionIconButton` + hint GIPROY y ajusta el copy para explicar que la accion sincroniza el producto comercial.
- Validado con py_compile y pytest focal de exportador.
