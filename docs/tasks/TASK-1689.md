# TASK-1689 - Rendimientos SOCE/SERCOP y borrado de proyectos importados

## Objetivo

Corregir la materializacion clasica de compras publicas importadas desde SOCE/SERCOP para que los APUs conserven el rendimiento tecnico de Equipos y Mano de Obra, y desbloquear el borrado de proyectos importados incorrectamente.

## Alcance

- Backend comun clasico: `public_procurement_project_materializer` persiste `rendimiento` y `rendimiento_original` en lineas APU aplicables.
- Regla clasica de APUs: Materiales, Transporte y APUs anidados mantienen rendimiento `1`, como en el editor de APUs.
- Backend de Proyectos: el borrado de proyecto elimina cronogramas, calendarios, asignaciones, stakeholders, base de proyecto, APUs, recursos y asignaciones CPC antes de eliminar revisiones.
- Sincronizacion comercial: si un proyecto importado tenia producto Marketplace pendiente, el borrado lo retira; si ya estaba aprobado/activo o vendido, el borrado se bloquea con mensaje operativo.

## No alcance

- No se modifica el analizador PDF ni los perfiles de lectura.
- No se ejecuta borrado manual de datos de usuario.
- No se toca UX BIM ni se agregan dependencias hacia BIM.

## Validacion prevista

- Comparar `prueba1.pdf`: el analizador ya entrega rendimientos distintos de `1` en Equipos y Mano de Obra.
- Sintaxis backend.
- Prueba focal de materializador.
- Smoke clasico de no contaminacion BIM.

## Resultado

- `prueba1.pdf` confirma 1560 recursos detectados y 920 lineas de Equipos/Mano de Obra con rendimiento distinto de `1`; la importacion previa en base `42` habia quedado con `rendimiento=1` en sus lineas.
- El materializador conserva `rendimiento` y `rendimiento_original` en Equipos/Mano de Obra y mantiene `1` en Materiales, Transporte y APUs anidados.
- El borrado completo de proyecto limpia dependencias operativas antes de eliminar presupuestos, revisiones y base de proyecto.
- El materializador deja trazabilidad minima `public_procurement_import` en `plantillas_config` para que el exportador pueda sincronizar la venta con el estado tecnico importado.
- El borrado completo de proyecto sincroniza productos Marketplace vinculados: pendientes se retiran, aprobados/activos o con ventas bloquean el borrado.
- Validado con py_compile, pytest focal `5 passed`, JSON documental y smoke clasico anti-contaminacion BIM.
