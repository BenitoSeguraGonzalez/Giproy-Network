# TASK-1690 - Motor declarativo de modelos SOCE/SERCOP

## Estado

Completada el 2026-05-19.

## Objetivo

Sacar el importador de compras publicas de una lectura fija por parches y dejar una capa declarativa gobernable por superadministracion para reconocer modelos SOCE/SERCOP, validar diagnosticos y sincronizar la futura exportacion a Marketplace.

## Alcance implementado

- Se integra `public_procurement_import_profile_engine` al contrato comun `public_procurement_technical_analysis_service` cuando Proyectos solicita `include_parser_contract=True`.
- Se conservan perfiles iniciales en `backend/app/resources/public_procurement_import_profiles.json`:
  - `soce_sercop_pdf_integrado_codigo_v1`
  - `soce_sercop_pdf_vae_resumen_v1`
- El contrato tecnico devuelve modelo reconocido, version, estado, diagnosticos, validacion economica y `export_readiness`.
- Formatos no reconocidos quedan bloqueados antes de materializar proyecto.
- La trazabilidad del proyecto importado conserva modelo, diagnosticos, validacion economica y readiness.
- El exportador de proyectos a Marketplace bloquea proyectos importados cuyo `export_readiness.can_export_marketplace` sea falso.
- Nueva API superadmin:
  - `GET /api/v1/admin-import-models/`
  - `GET /api/v1/admin-import-models/{profile_id}`
  - `PUT /api/v1/admin-import-models/{profile_id}`
  - `POST /api/v1/admin-import-models/{profile_id}/clone`
  - `POST /api/v1/admin-import-models/{profile_id}/activate`
  - `POST /api/v1/admin-import-models/{profile_id}/deactivate`
  - `POST /api/v1/admin-import-models/autocreate-preview`
- Nueva vista clasica `Administracion Global > Modelos Importacion`, con editor visual de chips para hooks, deteccion, estados, clonado y autocreacion desde PDF de muestra.
