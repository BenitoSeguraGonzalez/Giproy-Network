# TASK-1692 - Restauracion del puerto frontend clasico 5173

> Nota de cierre posterior: esta TASK queda como antecedente historico. `TASK-1694` revierte el cambio y restaura el contrato vigente de convivencia: GiProy clasico en `localhost:3010` y `5173` libre para NurIA/Core.

## Modo
GIPROY CLASICO.

## Objetivo
Restaurar el contrato operativo del frontend clasico en `http://localhost:5173`, alineado con el tunel Cloudflare publicado en `https://giproy-network.excompc.dpdns.org`, y evitar que el launcher o los scripts de respaldo vuelvan a iniciar el frontend en `3010`.

## Analisis
- La configuracion local de `cloudflared` en `%USERPROFILE%\.cloudflared` solo contiene `cert.pem`.
- El servicio Windows `cloudflared` corre como `cloudflared tunnel run --token ...`, sin `config.yml` local de ingress.
- Por tanto, la ruta publica se gobierna desde Cloudflare Zero Trust y el repo debe respetar el destino local esperado por el tunel: `localhost:5173`.
- El desvio a `3010` estaba en `frontend/vite.config.js`, `tools/launcher/launcher_app/config.py`, scripts `.bat` de respaldo y `repair_and_verify_services.ps1`.

## Alcance autorizado
- Configuracion frontend clasica Vite.
- Configuracion del GiProy Control Center / launcher.
- Scripts operativos Windows de respaldo.
- Documentacion operativa TASK, CHANGELOG y estado runtime.

## Implementacion
- `frontend/vite.config.js` vuelve a `server.port = 5173`, conserva `strictPort` y mantiene `allowedHosts` para el dominio publico.
- `tools/launcher/launcher_app/config.py` fija `frontend_ports` en `(5173, 8080)`.
- El servicio frontend del launcher sigue usando `cfg.frontend_ports[0]`, por lo que al reparar/reinstalar `GiProy-Frontend` quedara en `5173`.
- `iniciar_sistema.bat`, `iniciar_sistema_fixed.bat` y `giproy_service_start.bat` vuelven a `FRONTEND_PORT=5173`.
- `tools/launcher/scripts/repair_and_verify_services.ps1` limpia y verifica `3001/5173` en lugar de `3001/3010`.
- `tools/launcher/README.md` documenta el estado de puertos `3001 / 5173 / 8080`.

## Impacto GiProy Clasico
- El frontend clasico vuelve a escuchar en `http://localhost:5173`.
- El tunel `https://giproy-network.excompc.dpdns.org` queda alineado con el destino local esperado.
- No se modifica backend funcional, modelos, persistencia ni reglas de negocio.

## No interferencia BIM
- Sin rutas BIM nuevas.
- Sin UX BIM activada.
- Sin imports BIM nuevos.
- Sin modelos BIM modificados.
- Sin feature flags BIM modificadas.
