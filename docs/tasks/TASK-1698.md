# TASK-1698 - Politicas base Marketplace para ventas, compras y republicacion

## Modo

- MODO 1: GIPROY CLASICO
- Capa autorizada: Marketplace clasico, Proyectos clasico y checkout marketplace.
- Restriccion BIM: sin rutas, UX, modelos ni dependencias BIM.

## Objetivo

Definir el ciclo base de venta/compra para proyectos y compras publicas:

- Un proyecto ya enviado o publicado no debe republicarse desde Proyectos.
- Si la publicacion esta pendiente de revision, el propietario puede corregirla y reenviarla sustituyendo la pendiente anterior.
- Si ya esta publicada o tiene ventas, la gestion pasa a `Mis ventas`.
- El propietario puede pausar o retirar la venta; si hay ordenes, se conserva el historico y se oculta del catalogo.
- `Mis ventas`, `Mis compras` y el panel administrador deben operar con dashboards y datos de devolucion automatica.

## Cambios

- Backend:
  - Se agrega `GET /proyectos/marketplace-export/statuses` para devolver estado Marketplace por proyecto clasico.
  - El exportador bloquea la republicacion de productos aprobados o con ventas.
  - Si un producto pendiente se reenvia, se elimina la publicacion pendiente anterior y se crea una nueva ficha en revision.
  - `delete_seller_product` conserva historico cuando existen ventas: marca `cancelled`, `activo=False` y guarda metadata de retirada.
  - Las estadisticas de vendedor/empresa incluyen ventas reembolsadas, monto reembolsado, productos activos/pausados, productos por estado y politica de devolucion automatica.
  - Las ventas de vendedor/empresa incluyen pedidos `completed` y `refunded`, con neto/comision y snapshot de politica de devolucion.
  - La normalizacion de `portal_meta.project_delivery_policy` preserva `clone_source_project_on_purchase` y `source_project_id` para que una compra publica exportada desde proyecto clone el proyecto origen real al comprador.
  - La politica de autodevolucion normaliza fechas naive/aware antes de comparar ventana de 30 minutos, evitando dependencia del driver de base de datos.
- Frontend:
  - Proyectos consulta el estado Marketplace de sus proyectos al cargar y tras enviar a revision.
  - El boton `Exportar a Marketplace` cambia de tono cuando el proyecto ya esta en revision/publicado.
  - Si el proyecto ya no es editable desde exportacion, el click avisa y redirige a `Mis ventas`.
  - `Mis ventas`, `Mis compras` y administrador reutilizan los dashboards existentes, ahora alimentados con estado de pausa/retiro/devolucion.
  - `Mis ventas` muestra bruto, neto, devoluciones y monto devuelto; las ventas reembolsadas se distinguen en tarjetas y listados para no confundirse con ingresos activos.

## Politica de devolucion

- Ventana automatica: 30 minutos desde la orden.
- Tipos con devolucion automatica: `apu`, `base_maestra`, `proyecto`.
- Los pedidos reembolsados se mantienen visibles para trazabilidad, pero no suman neto/comision al vendedor.
