- `backend/app/api/endpoints/auth.py`

- La traza `AUTH DEBUG` deja de registrar longitud de password.
- Los logs de fallo dejan de incluir el email ingresado.
- Se conserva informacion operativa minima: si el login llego con empresa seleccionada.

## Cambios no realizados

- No se modifica generacion JWT.
- No se modifica seleccion de empresa.
- No se modifica sesion, device_id, licencia ni auditoria.
- No se modifica respuesta de error al cliente.
- No se toca BIM.
