## Objetivo

Cerrar la fase inicial de saneamiento de logging con una politica explicita que evite cambios masivos y reduzca riesgo de exposicion sensible en futuras sesiones.

## Alcance autorizado

- `docs/LOGGING_POLICY.md`
- `docs/tasks/TASK-1709.md`
- `docs/CHANGELOG.md`

## Cambios realizados

- Se crea una politica de logging seguro para GiProy Clasico.
- Se documentan datos que no deben registrarse: passwords, tokens, cabeceras `Authorization`, session IDs, device IDs y payloads sensibles.
- Se definen excepciones conservadoras para scripts CLI, mock email, seeders, launcher y fallbacks de emergencia.
- Se explicita que los logs BIM no se tocan en MODO 1.
- Se fijan validaciones minimas por tipo de cambio.

## Cambios no realizados

- No se modifica codigo backend productivo.
- No se modifica frontend.
- No se eliminan `print()` de scripts, mock email ni tooling local.
- No se cambia DB, auth, tenant, licencias, sesiones, permisos, presupuestos, EDT, cronogramas ni BIM.

## Impacto sobre GiProy Clasico

Impacto funcional nulo. El cambio es documental y establece gobierno para futuros micro-refactors.

## No interferencia BIM

Sin cambios en codigo BIM, UX BIM, feature flags BIM ni dependencias nuevas hacia BIM.
