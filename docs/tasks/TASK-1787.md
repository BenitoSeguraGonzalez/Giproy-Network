# TASK-1787 - AuthContext via cliente auth

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Eliminar las llamadas API directas restantes en `AuthContext` mediante un cliente API focal, sin cambiar el flujo de autenticacion, refresh, logout, licencia, tenant, interceptores, backend, DB ni BIM.

## Alcance

- `frontend/src/api/auth.js`
- `frontend/src/api/adminLicenses.js`
- `frontend/src/context/AuthContext.jsx`
- `docs/frontend_dependency_inventory.json`
- Documentacion de progreso y contexto IA.

## Cambios realizados

- Se crea `authApi` para:
  - `POST /login/refresh`
  - `GET /usuarios/me`
  - `POST /login/access-token`
  - `POST /login/logout`
- `AuthContext` usa `authApi` para refresh, check de conectividad, rehidratacion de usuario, login y logout.
- `adminLicensesApi.getMyLicense(params)` acepta parametros opcionales para conservar `empresa_id` en la lectura de licencia.
- `AuthContext` usa `adminLicensesApi.getMyLicense()` para cargar licencia.

## No cambios

- No se modificaron interceptores de `axiosConfig`.
- No se modifico almacenamiento de token ni seleccion de empresa/base/proyecto.
- No se modificaron rutas backend, payloads, headers ni `skipTenant`.
- No se modifico backend, DB ni migraciones.
- No se modifico codigo BIM ni se activo UX BIM.
