Proteger la cadena clasica de logo de empresa seleccionada despues del refactor de clientes API, sin cambiar comportamiento productivo.

## Cambios realizados

- Se crea smoke estatico `smoke-classic-company-logo-boundary.mjs`.
- Se agrega script npm `smoke:classic-company-logo`.
- El baseline enterprise ejecuta el smoke cuando se usa `--include-frontend`.
- El smoke valida que:
  - `AppLayout` renderice `selectedEmpresa.logo_url` mediante `resolveMediaUrl`.
  - `Settings` previsualice `miEmpresa.logo_url` mediante `resolveMediaUrl`.
  - `Settings` use `empresasApi.uploadLogo()` en alta/edicion y Mi Empresa.
  - `empresasApi.uploadLogo()` conserve endpoint y multipart.
  - Backend mantenga `/uploads` montado.
  - `resolveMediaUrl()` conserve rutas `/uploads/logos` y normalice barras Windows.

## No cambios

- No se modificaron rutas, UI, backend productivo, DB, auth, tenant ni BIM.
