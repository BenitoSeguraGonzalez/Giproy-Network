## Cambios realizados

- Se crea smoke estatico `smoke-classic-formula-polinomica-api-boundary.mjs`.
- Se agrega script npm `smoke:classic-formula-polinomica`.
- El baseline enterprise ejecuta el smoke cuando se usa `--include-frontend`.
- El smoke valida que:
  - `FormulaPolinomicaTab` no importe `axiosConfig` directamente.
  - `FormulaPolinomicaTab` use `polinomicaApi` y `presupuestosApi`.
  - `polinomicaApi` conserve endpoints de indices, recursos, formula, regeneracion, asignaciones e indices guardados.
  - `presupuestosApi.getByProyecto()` conserve `withTenantParams` con `proyecto_id` y `empresaId`.
