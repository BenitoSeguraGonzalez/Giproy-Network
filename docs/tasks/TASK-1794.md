# TASK-1794 - Smoke focal de Community clasica

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Proteger la frontera API clasica de Community, incluyendo publicaciones, respuestas, adjuntos, mensajes directos, moderacion, sanciones, apelaciones y usuarios, sin modificar comportamiento productivo.

## Alcance

- `frontend/scripts/smoke-classic-community-api-boundary.mjs`
- `frontend/package.json`
- `tools/ai_tools/validate_enterprise_baseline.py`
- Documentacion de progreso y contexto IA.

## Cambios realizados

- Se crea smoke estatico `smoke-classic-community-api-boundary.mjs`.
- Se agrega script npm `smoke:classic-community`.
- El baseline enterprise ejecuta el smoke cuando se usa `--include-frontend`.
- El smoke valida que:
  - `Community` no importe `axiosConfig` directamente.
  - `Community` conserve `communityApi`, `maestrosApi` y `usuariosApi`.
  - La empresa activa siga derivando de `selectedEmpresa` o `user.empresa_id`.
  - Se mantengan usos criticos de bootstrap, categorias, temas, posts, respuestas, adjuntos, DM, moderacion, sanciones, apelaciones, alertas e infracciones.
  - `communityApi` conserve metodos y endpoints criticos.
  - Los uploads de adjuntos sigan usando multipart.
  - `usuariosApi.create()` conserve params tenant.
  - `maestrosApi.getPaises()` conserve lectura tenantless.

## No cambios

- No se modifico `Community.jsx`.
- No se modificaron clientes API productivos.
- No se modificaron rutas, UI, backend, DB, auth, tenant runtime ni BIM.

## Validacion

- `npm run smoke:classic-community`: OK.
- `npm run build`: OK.
- `tools/ai_tools/validate_enterprise_baseline.py --include-frontend`: OK.
- Smoke anti-BIM incluido en baseline: OK.

## Resultado

El baseline detecta regresiones especificas en la frontera API de Community antes de continuar con cualquier modularizacion futura del modulo.
