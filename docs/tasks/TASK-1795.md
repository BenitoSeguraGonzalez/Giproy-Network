- Se agrega script npm `smoke:classic-marketplace-admin`.
- El baseline enterprise ejecuta el smoke cuando se usa `--include-frontend`.
- El smoke valida que:

  - `maestrosApi` conserve lecturas tenantless de paises, provincias y cantones.
