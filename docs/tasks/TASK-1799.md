# TASK-1799 - BasesTrabajo sin trazas DEBUG productivas

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Retirar trazas `console.log` de depuracion en Bases de Trabajo que exponian empresa activa y payload de creacion en consola, sin alterar comportamiento funcional ni contratos API.

## Alcance

- `frontend/src/pages/BasesTrabajo.jsx`
- `frontend/scripts/smoke-classic-bases-trabajo-api-boundary.mjs`
- `docs/logging_inventory.json`
- Documentacion de progreso y contexto IA.

## Cambios realizados

- Se eliminan `console.log` productivos asociados a `DEBUG BASES` y `DEBUG CREATE`.
- Se normalizan mensajes `console.error` de carga/codigo para que dejen de usar prefijo DEBUG.
- Se refuerza el smoke focal de BasesTrabajo para fallar si regresan los tokens `DEBUG BASES` o `DEBUG CREATE`.
- Se regenera `docs/logging_inventory.json` para reflejar la limpieza.

## No cambios

- No se modifico UI.
- No se modificaron rutas frontend ni backend.
- No se modificaron clientes API, payloads, auth, tenant runtime, DB ni BIM.
- No se eliminaron diagnosticos de error; solo trazas DEBUG productivas.
