## Objetivo

- `tools/ai_tools/validate_enterprise_baseline.py`

- Documentacion de progreso y contexto IA.

- Se eliminan `console.log` de creacion de proyecto y apertura/seleccion de revisiones.
- Se crea smoke estatico `smoke-classic-proyectos-logging-boundary.mjs`.
- Se agrega script npm `smoke:classic-proyectos`.
- El baseline enterprise ejecuta el smoke cuando se usa `--include-frontend`.
- Se regenera `docs/logging_inventory.json`.

## No cambios

- No se modificaron creacion de proyectos, apertura de revisiones, modal de revisiones, presupuestos por revision, clientes API, rutas backend, payloads, DB, auth, tenant runtime ni BIM.
- No se eliminaron diagnosticos de error.
