# TASK-1812 - Desactivacion de bases al cambiar empresa superadmin

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Confirmar y aplicar la regla operativa: cuando un `superadministrador` cambia de empresa, no debe quedar ninguna base de trabajo activa arrastrada desde la empresa anterior ni preactivada en la empresa destino.

## Alcance

- Frontend clasico: `frontend/src/context/AuthContext.jsx`.
- Usa el cliente existente `basesTrabajoApi.deactivateAll`.
- Sin cambios de backend.
- Sin cambios de base de datos destructivos.
- Sin cambios de contratos API, rutas, auth, JWT ni permisos.
- Sin cambios en EDT, presupuestos, cronogramas ni datos de negocio.
- Sin cambios BIM, UX BIM ni acoplamientos hacia BIM.
- Sin Docker, Coolify, CI/CD, staging ni produccion.

## Cambios

- `selectEmpresa` detecta si el usuario es `superadministrador`.
- Al cambiar empresa, dispara desactivacion de bases para la empresa saliente y la empresa entrante usando el endpoint existente `bases-trabajo/deactivate-all`.
- Se mantiene la limpieza frontend ya existente de `selectedBaseTrabajo`, `activeProject`, `giproy_working_base` y `giproy_working_project`.
- No se elimina ninguna base, proyecto, recurso, APU ni presupuesto.
