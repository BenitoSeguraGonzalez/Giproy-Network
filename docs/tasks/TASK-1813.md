# TASK-1813 - Norma certificadora de grafo Compras Publicas

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Formalizar la regla de integridad para importaciones certificadas de Compras Publicas:

- Las lineas de presupuesto originan APUs raiz.
- Los APUs raiz deben tener composicion real.
- La composicion puede usar recursos normales o APUs anidados.
- Los APUs anidados no necesitan existir como lineas de presupuesto, pero si deben tener composicion real.
- No pueden existir recursos fuera del grafo alcanzable desde APUs.
- No pueden existir APUs fuera de lineas de presupuesto o uso como APU anidado.
- No pueden materializarse recursos semanticos invalidos generados por lecturas desplazadas del PDF, incluyendo filas partidas por salto de linea.

## Alcance

Control backend clasico para Compras Publicas. No toca frontend, BIM, Docker, Coolify, CI/CD, staging ni produccion.

## Criterio de aceptacion

El sistema debe disponer de un certificador reutilizable que reporte y bloquee:

- Rubros sin APU.
- APUs alcanzables sin lineas.
- Lineas APU sin recurso ni APU hijo, o con ambos.
- Recursos no alcanzables desde ningun APU del grafo.
- APUs no alcanzables desde presupuesto ni como APU anidado.
- Ciclos de APUs anidados.
- Recursos con descripcion basura tipo `Hora 1,00000 0,35000`.
- Recursos fallback tipo `Material MAT-xxxxx`, `Equipo EQU-xxxxx`, `Mano de obra MAN-xxxxx` o equivalentes cuando el parser no logro recuperar una descripcion real.

## No interferencia BIM

Sin cambios BIM, sin UX BIM y sin acoplamientos hacia BIM.
