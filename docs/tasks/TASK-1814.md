# TASK-1814 - Implementacion certificador y correccion importador Compras Publicas

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Implementar y conectar el certificador de grafo `presupuesto -> APUs -> recursos/APUs anidados` en la materializacion de Compras Publicas, corrigiendo ademas la causa raiz detectada en `tmp/compras publicas prueba1.pdf` y `tmp/compras publicas prueba2.pdf`.

## Cambios previstos

- Crear servicio backend puro de certificacion.
- Corregir el importador PDF para unir etiquetas de recursos partidas por salto de linea antes de crear recursos.
- Corregir el resolutor de APUs anidados para impedir autoenlaces por coincidencia de descripcion entre un recurso y su APU padre.
- Integrarlo como gate transaccional tras materializar y antes del `commit`.
- Cubrir casos focales:
  - grafo valido,
  - recurso fantasma,
  - recursos fallback por descripcion perdida,
  - APU/recurso huerfano,
  - ciclo de APUs anidados,
  - materializacion bloqueada cuando el grafo no cumple la norma.
  - regresion real con `prueba1.pdf` y `prueba2.pdf`.
  - materializacion completa certificada de `prueba1.pdf`.

## Validacion prevista

- `py_compile` focal.
- `pytest` focal de Compras Publicas.
- Baseline enterprise sin frontend.
- Sin frontend porque el cambio queda limitado al backend clasico y documentacion.
