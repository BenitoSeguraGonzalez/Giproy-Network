# TASK-1817 - Compactacion editor APU clasico

Fecha: 2026-05-25

Modo: GIPROY CLASICO

## Objetivo

Ajustar la densidad visual del editor de APUs en Precios Unitarios para reducir altura de cabeceras, buscador, encabezado de partida y filas de recursos, manteniendo la coherencia con el skin clasico.

## Alcance

- Cabecera negra del catalogo lateral.
- Buscador lateral de recursos disponibles.
- Cabecera negra del editor APU.
- Botones de accion del editor APU en modo icono.
- Encabezado de datos de partida.
- Filas y cabeceras de recursos por categoria.
- Selector de unidad sin doble flecha visual.
- Regla responsive del editor con baseline desktop minimo `1920x1080`.
- Densidad operativa de listados en APUs, Recursos y Subcategorias.

## Criterio de aceptacion

- Las cabeceras negras izquierda y derecha tienen altura comun y contenido alineado.
- El modo desktop se conserva desde `1920x1080`; por debajo de ese baseline el editor entra en modo compacto.
- El buscador lateral queda compacto sin perder legibilidad.
- Los botones de cabecera del editor APU son reducidos y solo con icono, conservando `title` y `aria-label`.
- Las filas de recursos reducen espacio vertical sin ocultar datos economicos.
- Los listados principales aprovechan el ancho disponible y reducen padding/gaps internos para mostrar mas elementos por pantalla.
- No se cambian contratos API, datos, auth, tenant, presupuestos ni cronogramas.
- No se introduce UX BIM ni dependencia hacia BIM.

Implementado.
