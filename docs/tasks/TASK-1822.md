# TASK-1822 - Suite visual clasica Precios Unitarios

Fecha: 2026-05-26

Modo: GIPROY CLASICO

## Objetivo

Cerrar la debilidad de modales, z-index y densidad visual de Precios Unitarios con una guarda automatizada de UI clasica.

## Alcance

- Modales de Recursos, APUs y Subcategorias.
- `AppModalShell` como shell comun.
- Z-index por encima de cabeceras operativas.
- Footer con acciones compactas y botones de icono.
- Listados densos de APUs, recursos y subcategorias.

## Criterio de aceptacion

- Los modales criticos de Precios Unitarios usan `AppModalShell`.
- Los modales criticos declaran `z-[1000]`.
- El editor de recursos conserva footer compacto con botones iconograficos.
- El editor/listado APU conserva densidad compacta.
- No se reintroducen dependencias BIM.

## Resultado

Implementado como smoke de guardas UI clasicas.

## No interferencia BIM

Sin cambios BIM, sin UX BIM y sin acoplamientos hacia BIM.
