# TASK-1841 - Vista operacional Recursos read-only en Cronogramas

Fecha: 2026-05-26

## Objetivo

Abrir el primer acceso visible del eje operacional `Recursos` dentro de Cronogramas, como capa exterior read-only sobre el endpoint creado en TASK-1839/TASK-1840.

## Alcance implementado

- Se agrega la pestaña `Recursos` junto a `Gantt` y `Valorado`.
- La vista consume `cronogramasApi.getRecursos(presupuestoId, empresaId)`.
- La presentación agrupa recursos finales por categoria y subcategoria.
- Cada recurso conserva todos sus periodos, incluidos los periodos con cantidad/costo cero.
- Se muestran indicadores de recursos, periodos, costo directo y periodo pico.
- Se evita una tabla tipo Excel; la lectura queda como listado operacional categorizado.
