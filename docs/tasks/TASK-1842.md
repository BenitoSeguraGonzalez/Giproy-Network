## Objetivo

Crear la primera capa persistente colaborativa para `Recursos` en Cronogramas, sin aplicar todavia nivelacion ni modificar Gantt/Valorado.

## Alcance implementado

- Se agrega el modelo `CronogramaRecursosState`.
- Se agrega migracion Alembic para `cronogramas_recursos_state`.
- Se expone lectura:
  - `GET /api/v1/cronogramas/valorados/{presupuesto_id}/recursos/state`
- Se expone guardado:
  - `PUT /api/v1/cronogramas/valorados/{presupuesto_id}/recursos/state`
- El estado guarda `adjustments` JSON por presupuesto y `version`.
- El guardado usa version optimista para evitar pisadas multiusuario.
- Se registra auditoria al actualizar el estado.
