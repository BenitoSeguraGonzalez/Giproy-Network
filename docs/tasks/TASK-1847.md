# TASK-1847 - Simulacion automatica no destructiva Recursos

Fecha: 2026-05-26  
Modo: GIPROY CLASICO

## Objetivo

Agregar una primera simulacion automatica de nivelacion dentro de la vista operacional `Recursos`, usando la demanda consolidada y las capacidades manuales persistidas.

## Alcance implementado

- Se calcula una propuesta local de movimientos desde periodos sobrecargados hacia periodos posteriores con capacidad disponible.
- Se muestran movimientos sugeridos por recurso, periodo origen, periodo destino y cantidad.
- Se muestran remanentes pendientes cuando no existe capacidad posterior suficiente.
- Se agrega KPI de simulacion en la cabecera de `Recursos`.
- Se refuerza el smoke clasico para proteger el contrato visual/operativo de simulacion.

## Politica aplicada

- La simulacion no se guarda como movimiento aplicado.
- No se modifican barras, fechas, duraciones, predecesoras ni rutas del Gantt.
- No se recalcula Valorado ni Flujo.
- No se cambia backend, DB, auth, tenant ni permisos.
- Sin tocar `CronogramaGantt.jsx`.
- Sin BIM, UX BIM, Docker, Coolify, CI/CD, staging ni produccion.

## Validacion esperada

- Build frontend.
- Smoke anti-BIM.
- JSON documental.
- Hash de `CronogramaGantt.jsx` igual al backup.
- Baseline enterprise con frontend.
