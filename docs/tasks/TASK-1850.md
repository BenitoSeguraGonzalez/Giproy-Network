# TASK-1850 - Previsualizacion no destructiva de aplicacion Recursos

Fecha: 2026-05-26  
Modo: GIPROY CLASICO

## Objetivo

Mostrar una previsualizacion de aplicacion para propuestas de nivelacion aprobadas en `Recursos`, sin ejecutar todavia cambios sobre el cronograma.

## Alcance implementado

- La vista `Recursos` detecta propuestas persistidas con `status: approved`.
- Se muestra un bloque de `Previsualizacion de aplicacion`.
- Se resumen movimientos, recursos afectados, cantidad sugerida y pendientes.
- Se muestra condicion de seguridad explicita: la propuesta aprobada no modifica Gantt, Valorado ni Flujo.
- Se refuerza el smoke clasico para proteger el contrato visual no destructivo.

## Politica aplicada

- No se aplica nivelacion real.
- No se modifican Gantt, fechas, barras, duraciones ni predecesoras.
- No se recalcula Valorado ni Flujo.
- No se guarda `applied: true`.
- No crea backend, tabla, endpoint ni migracion nueva.
- Sin tocar `CronogramaGantt.jsx`.
- Sin BIM, UX BIM, Docker, Coolify, CI/CD, staging ni produccion.

## Validacion esperada

- Smoke clasico de frontera Cronogramas.
- Build frontend.
- Smoke anti-BIM.
- JSON documental.
- Hash de `CronogramaGantt.jsx` igual al backup.
- Baseline enterprise con frontend.
