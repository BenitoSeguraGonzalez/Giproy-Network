# TASK-1851 - Intencion persistente de aplicacion Recursos

Fecha: 2026-05-26  
Modo: GIPROY CLASICO

## Objetivo

Registrar una intencion colaborativa de aplicacion para propuestas aprobadas de `Recursos`, sin ejecutar todavia la redistribucion real.

## Alcance implementado

- La previsualizacion de aplicacion permite preparar una intencion persistente.
- La accion usa confirmacion explicita con `appConfirm`.
- La intencion se guarda como `adjustments.leveling_application_intent`.
- La intencion queda en `status: ready_to_apply` con `applied: false`.
- Se puede cancelar la intencion sin eliminar la propuesta aprobada.
- Se refuerza el smoke clasico para proteger el contrato.

## Politica aplicada

- Preparar aplicacion no aplica nivelacion real.
- No se modifican Gantt, fechas, barras, duraciones ni predecesoras.
- No se recalcula Valorado ni Flujo.
- No se guarda `applied: true`.
- No crea backend, tabla, endpoint ni migracion nueva.
- Sin tocar `CronogramaGantt.jsx`.
- Sin BIM, UX BIM, Docker, Coolify, CI/CD, staging ni produccion.

## Validacion esperada

- Smoke clasico de frontera Cronogramas.
- Build frontend.
- Smoke anti-BIM.

- Hash de `CronogramaGantt.jsx` igual al backup.
