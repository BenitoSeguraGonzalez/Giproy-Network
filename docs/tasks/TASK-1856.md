# TASK-1856 - Matriz de periodos Recursos

Fecha: 2026-05-27  
Modo: GIPROY CLASICO

## Objetivo

Homologar la lectura por periodos de Recursos con la logica visual de Cronogramas, sin recrear una tabla Excel.

## Alcance implementado

- Cada subcategoria muestra una cabecera de periodos.
- Cada recurso se presenta como fila operacional con tira de periodos.
- Todos los periodos siguen visibles, incluidos los periodos con demanda o costo cero.
- La capacidad manual permanece editable por recurso y periodo.
- Las sobrecargas mantienen resaltado y exceso visible.

## Politica aplicada

- La matriz no modifica Gantt.
- La edicion de capacidad sigue guardando solo `adjustments.manual_limits`.
- Sin cambios backend ni DB.
- Sin BIM.

## Validacion esperada

- Build frontend.
- Smoke de frontera Cronogramas.
- Verificacion manual de periodos completos.
