## Objetivo

Ajustar el tamaño visual de las salidas y entradas de dependencias del Gantt
clasico para acercarlas al patron de MS Project: codos muy cortos, lineas
ortogonales finas y recorridos compactos.

## Implementacion

- Reducir el codo base de dependencias de `14px` a `8px`.
- Mantener cuantizacion a medio pixel para estabilidad bajo zoom.
- Conservar rutas ortogonales sin diagonales ni curvas.
- Mantener evasion minima cuando un tramo horizontal invadiria el cuerpo de una
  barra Gantt.
- Afinar el grosor visual de las lineas de enlace para acercarlo a MS Project,
  conservando el area invisible de interaccion.
