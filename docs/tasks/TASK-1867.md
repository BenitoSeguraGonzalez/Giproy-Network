## Objetivo

Compactar el panel de dependencia seleccionada para que muestre solo controles
operativos necesarios y reduzca informacion explicativa superflua.

## Implementacion

- Reducir ancho, padding y densidad visual del panel.
- Mantener shortcode, par de anclajes y restriccion calculada como informacion
  minima de contexto.
- Conservar controles editables: relacion, desfase y unidad.
- Cambiar acciones principales a botones de icono:
  - `Trash2` para romper dependencia.
  - `Check` para guardar dependencia.
  - `X` solo para cerrar el editor.
- Mantener `title` y `aria-label` en acciones por accesibilidad.

## Validacion esperada

- Smoke focal de dependencias verifica iconos/semanticas del panel compacto.
- Build frontend debe compilar sin errores.

## No interferencia

- Sin cambios backend.
- Sin cambios API, auth, tenant, EDT, presupuestos, calendario, cronogramas de
  datos ni DB.
- Sin BIM, UX BIM ni dependencia nueva hacia BIM.
- Sin Docker/Coolify/CI/CD.

## Rollback

- Restaurar el panel anterior en `CronogramaGantt.jsx`.
- Revertir las aserciones focales agregadas al smoke.
