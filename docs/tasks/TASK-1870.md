## Objetivo

En el modal de registro de cuenta (`RegisterModal`), cuando el usuario sale del
campo "Identificación fiscal" (RUC), validar contra el servicio SRI y mostrar
error visual si no se encuentra o no es verificable, siguiendo el mismo patrón
visual usado en la validación de contraseña.

## Cambio realizado

**Archivo**: `frontend/src/components/PersonnelFormFields.jsx`

**Antes** (comportamiento):
- Validación estructural `validarRucEcuador` → `rucError` si fallaba ✅
- Consulta `publicAuthApi.validarRuc()` → autocompletaba datos si `valido=true`
  con datos ✅
- Si `valido=false` o error de red → **silencioso, sin mensaje al usuario** ❌

**Después** (comportamiento corregido):
1. Validación estructural `validarRucEcuador` → `rucError` si falla → return
   inmediato ✅
2. Consulta `publicAuthApi.validarRuc()`:
   - Si `!data.valido` → `setRucError(data.mensaje || 'El RUC no pudo ser
     verificado contra el registro civil.')` → return

     `nombre_completo` → `setRucError('')`
3. Catch (error de red) → `setRucError('No se pudo verificar el RUC. Verifica
   tu conexión e intenta de nuevo.')`
