# TASK-1871: plan de adecuacion Marketplace para productos SaaS

## Modo

## Tipo

## Objetivo

Analizar el plan de negocio aprobado y dejar documentada una ruta de adecuacion
para convertir licencias, packs y modulos SaaS en productos vendibles dentro del
Marketplace clasico de GiProy.

## Resultado

- Se resume la estructura comercial del documento fuente.
- Se contrasta contra los dominios existentes de Licencias y Marketplace.
- Se identifican brechas, contradicciones y riesgos.
- Se propone una arquitectura de adecuacion por fases sin escribir codigo.
- Se deja un backlog sugerido de TASKs futuras.
- Posteriormente el usuario acepta la direccion propuesta y se abre el programa
  documental/ejecutivo `TASK-1872` a `TASK-1885`.

## No implementado

- No se escribe codigo.
- No se crean migraciones.
- No se modifican modelos, endpoints, schemas, rutas ni UI.
- No se modifica base de datos.
- No se crean productos reales en Marketplace.

## No interferencia

- Sin BIM, UX BIM ni dependencias hacia BIM.
- Sin Docker, Coolify, CI/CD, staging ni produccion.
- Sin cambios de auth, tenant, EDT, presupuestos, cronogramas ni datos.
- Sin impacto sobre el baseline `TASK-1807` ni sus guardas.

## Validacion esperada

- Lectura documental del DOCX fuente.
- Verificacion de existencia de modelos/servicios actuales de Licencias y Marketplace.
- Revisión documental de `CHANGELOG` y `HANDOFF`.
