Crear o adaptar el catalogo administrado por GiProy para listar licencias, packs
y modulos como productos vendibles en Marketplace.

## Alcance realizado

- Se adecuo el bootstrap de categorias Marketplace con `Packs SaaS` y `Modulos y servicios`.
- Se adecuo el catalogo sistema a los productos del plan aprobado:
  - licencias comerciales vendibles: Estandar mensual/anual y Profesional mensual/anual;
  - entradas de control no vendibles: Express Trial, Tester, Academica y Capacitacion;
  - packs vendibles: Planifica, Licita, Conecta y Equipo por colaborador, mensual/anual;
  - modulos independientes vendibles: Fusion y Migracion.
- Se reutilizan productos sistema existentes mediante `legacy_slugs` cuando hay equivalencia, conservando IDs/historial local.
- Productos sistema antiguos fuera del plan quedan inactivos.
- Todos los productos SaaS del plan incluyen metadata `commercial_code`, `activation_policy` y `requires_superadmin_edit`.
- Las categorias y productos fueron sembrados en la base local con scripts idempotentes.
- Sin entrega automatica nueva para packs/modulos; licencias base conservan el flujo existente de `license_offer`.
