## Objetivo

Adaptar las empresas actuales y el catalogo de licencias local a las nuevas
politicas de productos SaaS Marketplace, sin eliminar empresas ni datos
operativos.

## Alcance realizado

- Se alinea `DEFAULT_LICENSE_CATALOG` con el plan aprobado:
  - `EXPRESS`: trial/control de 30 dias, 1 proyecto, 50 MB, marca de agua y sin Excel.
  - `STANDARD`: USD 25 mensual / USD 250 anual, proyectos/almacenamiento operativo amplio y packs opcionales.
  - `PROFESSIONAL`: USD 40 mensual / USD 400 anual, incluye `Planifica` y `Licita`, con `Conecta` y `Equipo` opcionales.
- Se crea `backend/scripts/align_companies_to_saas_policy.py` como script idempotente de alineacion.
- Se normalizan licencias especiales:
  - `TESTER`
  - `ACADEMIC`
  - `TRAINING`
- Se desactivan licencias legacy fuera del plan vendible:
  - `EXPRES`
  - `ENTERPRISE`
- Se alinea la asignacion activa de `Administradores Generales` desde `ENTERPRISE` hacia `PROFESSIONAL`.
- Se conserva trazabilidad en `EmpresaLicencia.detalles`.
- Se registra `LicenseEvent` tipo `license_saas_policy_alignment`.
- Se recalculan metricas de uso de las 3 empresas actuales.
