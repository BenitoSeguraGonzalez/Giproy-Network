# TASK-1888: endpoints clasicos Conecta y frontera API

## Modo
GIPROY CLASICO

## Tipo
EJECUCION BACKEND + SMOKES

## Objetivo

Exponer endpoints clasicos para listar, crear, liberar y auditar conexiones
`Conecta`, consumiendo el servicio de `TASK-1887` sin alterar contratos
existentes de auth, tenant, empresa activa ni permisos.

## Estado

CERRADA - 2026-06-08

## Dependencias

- `TASK-1887` implementada.

## Alcance

- Endpoints bajo prefijo clasico `/api/v1`.
- Validacion server-side de empresa activa.
- Rechazo por cupo agotado.
- Rechazo por regla de 30 dias.
- Accion superadministrador auditada para forzar liberacion/reasignacion.
- Smoke de frontera API clasica.

## Implementacion realizada

- Se agrego router clasico `conecta` bajo `/api/v1/conecta`.
- Se agregaron schemas `SaasConecta*` para request/response.
- Endpoints implementados:
  - `GET /api/v1/conecta/limits`
  - `GET /api/v1/conecta/slots`
  - `POST /api/v1/conecta/slots`
  - `POST /api/v1/conecta/slots/{slot_id}/release`
- Los usuarios no superadministradores operan siempre sobre su empresa activa.
- El superadministrador puede indicar `empresa_id`.
- La creacion delega en `saas_conecta_service` y respeta cupos disponibles.
- La liberacion delega en `saas_conecta_service`, respeta bloqueo de 30 dias y solo permite `force=true` al superadministrador.
- La respuesta no expone ni concede acceso automatico a proyectos, EDT, presupuestos ni cronogramas.
