# TASK-1889: UI clasica Conecta en SaaS, Settings y AdminGlobal

## Modo
GIPROY CLASICO

## Tipo
IMPLEMENTADO FRONTEND

## Objetivo

Implementar la UI clasica minima para ver y gestionar cupos `Conecta`, separada
de licencias de funcionamiento y productos SaaS adicionales.

## Dependencias

- `TASK-1888` implementada.

## Alcance implementado

- Cliente de dominio en `frontend/src/api`.
- Vista de cupos Conecta en Settings o SaaS segun patron vigente.
- Vista de control por empresa para superadministrador.
- Mensajes claros de cupo, estado, bloqueo por 30 dias y excepciones.
- Sin acceso ni navegacion automatica a proyectos, EDT, presupuestos o
  cronogramas.

## Cambios realizados

- Se agrega `frontend/src/api/conecta.js` como cliente de dominio para
  `/api/v1/conecta`.
- `Settings` muestra el producto SaaS Conecta separado de la licencia base:
  cupos contratados, usados, disponibles, invitaciones/asignaciones y accion de
  liberacion normal.
- `AdminGlobalLicencias` muestra por empresa los cupos Conecta dentro de
  SaaS / Superadministrador y permite liberacion excepcional `force=true` solo
  desde ese panel.
- Se agrega `frontend/scripts/smoke-classic-conecta-api-boundary.mjs` para
  validar frontera API clasica, ausencia de rutas `/conecta` hardcodeadas fuera
  del cliente y ausencia de imports directos de `axiosConfig` en UI.
