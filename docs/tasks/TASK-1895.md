# TASK-1895: adecuacion del registro publico de empresa administradora

## Modo
GIPROY CLASICO

## Tipo
FRONTEND FOCAL + UX DE REGISTRO

## Estado
Cerrada

## Objetivo

Alinear el registro publico con el contrato real de negocio: crear una empresa
nueva y su usuario administrador inicial, evitando que la UI parezca un alta
generica de colaborador.

## Cambios realizados

- `RegisterModal` usa el modal de advertencia `appAlert` para datos faltantes,
  email invalido, contrasenas no coincidentes, privacidad pendiente y movil
  invalido.
- El registro exige todos los datos visibles antes de enviar, excepto `alias`.
- Se elimina la confirmacion de contrasena duplicada que quedaba sobrante al
  final del formulario.
- El scroll interno del formulario pasa al patron especifico
  `MotionScrollbar` + `giproy-motion-scrollbar-hide`.
- `PersonnelFormFields` agrega la variante acotada `publicRegister`:
  - etiqueta `Email (login)`;
  - email en una fila completa;
  - contrasena y confirmacion debajo;
  - campos mas compactos;
  - selector `Rol de Colaborador` oculto en registro publico;
  - ubicacion en flujo `Pais -> Provincia -> Canton -> Ciudad`.
- El pais del registro publico queda preseleccionado como `Ecuador`.
- El copy inferior aclara que se crea una empresa y que la cuenta queda como
  administrador inicial.
