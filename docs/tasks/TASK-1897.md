# TASK-1897: licencia activa visible en header principal

Descripcion

El header principal clasico no mostraba de forma permanente el tipo de licencia
activa de la empresa operativa. La informacion existia en `AuthContext` como
`licenseInfo`, pero solo se usaba para banners, limites, bloqueos y pantallas de
ajustes.

Archivos afectados

- `frontend/src/layouts/AppLayout.jsx`
- `docs/tasks/TASK-1897.md`
- `docs/CHANGELOG.md`
- `docs/HANDOFF.md`

Cambios realizados

- Se muestra `Licencia activa: <plan>` debajo del nombre de empresa, quedando el
  orden visual `Contexto Operativo -> Empresa -> Licencia activa`.
- Se reutiliza `licenseInfo` ya cargado por `AuthContext`; no se crean llamadas
  API nuevas ni contratos backend.
- Se reutilizan `getLicenseStatusLabel` y `getLicenseStatusTone` para mostrar
  estado compacto de licencia en escritorio.
- El modo portatil conserva lectura compacta sin agregar superficies nuevas.

Impacto

Frontend clasico, header principal (`AppLayout`). Sin backend, DB,
migraciones, auth/JWT/tenant, contratos API, EDT, presupuestos, cronogramas,
BIM, Docker/Coolify/CI/CD ni archivos runtime.
