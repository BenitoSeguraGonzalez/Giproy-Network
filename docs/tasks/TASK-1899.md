# TASK-1899 - Cola idempotente de avisos de licencia

Fecha: 2026-06-09
Modo: GIPROY CLASICO

## Objetivo

Crear una fundacion backend no destructiva para registrar avisos de ciclo de vida de licencia por canal, destinatario, estado y clave de deduplicacion.

## Alcance

- Modelo `LicenseNotificationEvent`.
- Migracion Alembic no destructiva.
- Servicio `license_notifications`.
- Test focal de idempotencia.

## Fuera de alcance

- Configuracion de proveedor SMTP real en entorno.
- Borrado, backup o recuperacion de datos.
- Cambios en auth/JWT/tenant.

## Cambios realizados

- Se crea `LicenseNotificationEvent` para cola/auditoria de avisos de licencia.
- Se agrega migracion no destructiva `de1899f0a1b2_license_notification_events.py`.
- Se crea `license_notifications` con payload de bienvenida, compra formalizada, fin de compra con vigencia y deduplicacion por `dedupe_key`.
- `assign_license_to_company` cola bienvenida email/in-app cuando la licencia comercial queda pagada/confirmada.
- Marketplace cola `purchase_formalized` al completar compras por PayPal/confirmacion online, transferencia validada y checkout clasico.
- Los productos con `product_meta.duration_months` pueden colar `purchase_lifecycle_ended` al llegar a su fecha de fin.
- Los payloads de cliente incluyen `title`, `subject`, `body`, `severity`, `action_label` y datos estructurados para email/in-app.
- Se expone `/api/v1/license-notifications/me` para avisos internos pendientes del usuario.
- Se expone `/api/v1/license-notifications/{event_id}/ack` para marcar avisos internos como leidos.
- Se expone `/api/v1/license-notifications/dispatch-email` solo superadministrador para despacho mock de emails pendientes.
- Se expone `/api/v1/license-notifications/housekeeping/purchase-lifecycle` solo superadministrador para detectar productos vencidos y, opcionalmente, despachar emails mock de fin de compra.
- Se expone `/api/v1/license-notifications/housekeeping/run` solo superadministrador para barrido integral de fin de compra, caducidad de licencia, solo lectura y despacho opcional.
- `AppLayout` consume `/license-notifications/me` y muestra avisos internos pendientes en el header principal; los avisos `display_once` se marcan leidos al cerrar.
- Se agrega pytest focal de bienvenida, compra formalizada, fin de vigencia, caducidad de licencia, solo lectura, no aviso prematuro e idempotencia.
