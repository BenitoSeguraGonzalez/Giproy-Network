# TASK-1910 - Normalizacion internacional de movil en registro publico

Fecha: 2026-06-10
Modo: GIPROY CLASICO

## Objetivo

Normalizar el numero movil del modal clasico de crear cuenta al formato
internacional al salir del campo, usando las reglas existentes del sistema y
avisando cuando el movil no cumpla los digitos esperados.

## Alcance

- Frontend clasico de registro publico.
- Variante `publicRegister` de `PersonnelFormFields`.
- Utilidad compartida `phoneFormatter`.
- Sin cambios backend, auth, JWT, tenant, licencias, EDT, presupuestos,
  cronogramas, BIM, Docker/Coolify/CI/CD ni PostgreSQL.

## Cambios realizados

- Se centraliza una validacion de telefono internacional en
  `phoneFormatter`.
- Para Ecuador se acepta movil local `09XXXXXXXX`, nacional `9XXXXXXXX` o
  internacional `+593 9XXXXXXXX`.
- Al salir del campo `Movil de Contacto`, el numero valido se normaliza a
  prefijo internacional, quitando el `0` local ecuatoriano cuando corresponde.
- Si el movil no cumple longitud/formato, el campo muestra aviso inline y
  resaltado visual.
- El submit del registro publico usa la misma validacion antes de enviar al
  backend.
