# TASK-1918 - Codigos publicos y destinatarios de transferencia

Estado: Cerrada

Fecha: 2026-06-16

Modo: GIPROY CLASICO

## Objetivo

Implementar codigos publicos `XXX - XXX`, saneamiento de administradores
existentes y gestion de empresas destino fijas/adicionales para envios.

## Alcance

- Backend clasico.
- Endpoints de validacion/asociacion de destinatarios.
- Saneamiento no destructivo de administradores existentes.
- Auditoria de intentos fallidos, pausas y baneo.

## Dependencias

- `TASK-1917`
- `TASK-1924` para activacion completa de destinatarios adicionales comprados.

## Aceptacion

- Codigo generado para administradores nuevos.
- Saneamiento genera codigo a administradores existentes sin pisar codigos
  validos.
- El codigo resuelve empresa destino, no usuario receptor.
- La UI/API solo devuelve descripcion/nombre de empresa y alias si existe.
- Maximo 3 empresas destino fijas por empresa emisora.
- Destinatarios fijos inmutables mientras el plan siga activo.
- Alta con tres capas: codigo, resolucion de empresa y confirmacion explicita.
- Anti-enumeracion: 3 fallos consecutivos -> pausa 5 minutos.
- Abuso: 12 fallos en 24 horas por empresa emisora -> baneo 7 dias.
- `EXPRESS`, `TESTER`, `ACADEMIC` y `TRAINING` bloqueados.

## Verificacion

- pytest focal backend de codigos/destinatarios.
- Tests de abuso, pausa y baneo.
- Smoke de frontera API clasica.
- Sin cambios en auth/JWT/tenant.

## Cambios realizados

- Se crea `app.services.transferencias` con generacion unica de codigos
  publicos `XXX - XXX`, saneamiento de administradores existentes y politica
  de destinatarios.
- Se agregan endpoints clasicos:
  - `GET /api/v1/transferencias/my-code`
  - `POST /api/v1/transferencias/recipient-code/resolve`
  - `GET /api/v1/transferencias/recipients`
  - `POST /api/v1/transferencias/recipients`
  - `POST /api/v1/transferencias/admin/sanitize-codes`
- Se engancha la generacion automatica de codigo al crear o promocionar
  usuarios `administrador` / `superadministrador`.
- Se agrega script operativo no destructivo
  `backend/scripts/sanitize_transfer_admin_codes.py`.
- La resolucion de codigo devuelve solo empresa, alias y nombre legal; no
  expone identidad del usuario administrador propietario del codigo.
- Se implementa limite de 3 destinatarios fijos y soporte preparado para
  paquetes adicionales `transfer_extra_recipient_packs`.
- Se implementan guardas de abuso: 3 fallos consecutivos generan pausa de
  5 minutos; 12 fallos en 24 horas generan baneo de 7 dias.
