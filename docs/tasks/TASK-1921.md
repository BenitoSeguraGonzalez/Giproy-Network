# TASK-1921 - Bandeja API de entrada y salida

Estado: Cerrada

Fecha: 2026-06-16

Modo: GIPROY CLASICO

## Objetivo

Exponer API de bandeja de entrada/salida con filtros, busqueda omni, estados,
timeline y metricas minimas.

## Alcance

- Backend clasico.
- API para bandeja, timeline y metricas.
- Sin UI final salvo smokes si se agrega cliente.

## Dependencias

- `TASK-1917`
- `TASK-1919`
- `TASK-1920`

## Aceptacion

- Filtro `Todos`, `Entrada`, `Salida`.
- Filtro por estado.
- Filtro fecha inicio/fecha fin.
- Rango por defecto: un mes atras hasta fecha actual.
- Busqueda omni por nombre legal, alias, descripcion y activo.
- Alias como etiqueta visual preferente sin perder nombre legal.
- Orden por fecha/hora recepcion descendente.
- Historico permanente, filtros solo acotan vista.
- Estado `fallo_importacion` representado como recuperable y auditable.
- Timeline visible resumido disponible por envio.
- Metricas minimas: enviados, recibidos, nuevos, bloqueados, listos,
  importados, rechazados, cancelados, expirados y fallos de importacion.

## Verificacion

- pytest endpoints de bandeja.
- pytest filtros, busqueda omni y rango por defecto.
- pytest timeline/metricas.
- Smoke frontera API clasica si se agrega cliente frontend.

## Ejecucion 2026-06-16

- Se agregan respuestas API de bandeja con `direction=todos|entrada|salida`,
  filtro por estado, rango de fechas, paginacion y busqueda omni.
- El rango por defecto queda en los ultimos 30 dias hasta la fecha/hora actual.
- La ordenacion usa fecha/hora de recepcion y, cuando aun no existe,
  `sent_at` / `created_at` como fallback operativo.
- El alias de empresa se usa como etiqueta visual preferente y se conserva el
  nombre legal en la respuesta para busqueda y trazabilidad.
- Se agregan labels, colores y bandera `recoverable` por estado; el estado
  `fallo_importacion` queda marcado como recuperable.
- Se expone timeline resumido por envio con hitos de fechas y eventos de
  auditoria vinculados.
- Se expone resumen de bandeja de entrada para futuro semaforo de header sin UI.
- Metricas minimas implementadas: enviados, recibidos, nuevos, bloqueados,
  listos, importados, rechazados, cancelados, expirados y fallos de importacion.
