Estado: Cerrada

Modo: GIPROY CLASICO

## Objetivo

Mostrar en el header principal un indicador permanente y simple de
comunicaciones/transferencias para Administrador y Superadministrador.

## Alcance

- Frontend clasico.
- Cliente API de metricas en `frontend/src/api`.
- Sin WebSocket/SSE en primera implementacion.

## Dependencias

- `TASK-1921`

## Aceptacion

- Visible solo para Administrador/Superadministrador.
- Visible siempre para esos roles, con o sin nuevos envios.
- Muestra conteo total y nuevos, por ejemplo `Comunicacion: 14` y `Nuevos: 2`.
- Indicador visual simple tipo circulo/parpadeo sobrio.
- Click navega a bandeja de entrada.
- Polling ligero cada 30 o 60 segundos.
- Sin desplegable complejo ni resumen avanzado.
- Sin imports directos de `axiosConfig` fuera de `frontend/src/api`.
- Sin `console.log` productivo.

## Verificacion

- `npm run build`.
- Smoke header/roles.
- Smoke anti-BIM.
- Guarda `axiosConfig`/`console.log`.

## Ejecucion 2026-06-16

  `GET /transferencias/tray-summary`.
- `AppLayout` muestra un indicador permanente de comunicacion para roles
