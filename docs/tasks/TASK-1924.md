# TASK-1924 - Producto Conecta para destinatarios adicionales

Estado: Cerrada

Fecha: 2026-06-16

Modo: GIPROY CLASICO

## Objetivo

Adecuar `Conecta` como producto Marketplace exclusivo de `Envios y
Transferencias` para ampliar empresas destino adicionales.

## Alcance

- Backend clasico Marketplace/licencias.
- Catalogo/derechos SaaS existentes.
- Sin crear producto duplicado.

## Dependencias

- `TASK-1917`
- `TASK-1918`

## Aceptacion

- Producto visible como `Conecta`.
- Contexto/subtitulo `Envios y Transferencias` cuando haga falta claridad.
- Precio inicial `24,99 USD`.
- Cada compra activa 3 empresas destino adicionales.
- Vigencia de 30 dias desde fecha/hora exacta de compra.
- Compras acumulables pero independientes.
- Destinatarios adicionales asociados a la compra concreta.
- Expiracion inactiva slots adicionales para nuevos envios.
- Nueva compra exige nuevo proceso de asociacion.
- Historico de envios se conserva.

## Verificacion

- pytest focal Marketplace/licencias.
- pytest expiracion y acumulacion.
- pytest sin reactivacion automatica de relaciones expiradas.
- Sin romper compra/venta general.

## Ejecucion 2026-06-16

- El catalogo sistema define un unico producto `Conecta` para
  `Envios y Transferencias`.
- El producto queda con precio inicial `24,99 USD`.
- Se reutiliza/desplaza el antiguo slug mensual mediante legacy slug y el
  producto anual anterior queda fuera del catalogo activo en bootstrap.
- `commercial_code=CONECTA_TRANSFERENCIAS`.
- Metadata comercial:
  - `recipient_slots=3`
  - `duration_days=30`
  - `accumulative=true`
  - `independent_purchase=true`
  - `requires_new_recipient_association=true`
- Checkout activa un `TransferExtraRecipientPack` independiente por item de
  pedido confirmado.
- Cada pack expira a los 30 dias desde `purchased_at` exacto.
- Compras con cantidad mayor a 1 generan packs independientes y acumulables.
- Los destinatarios adicionales siguen asociados al pack concreto mediante
  `source_pack_id`.
- Packs expirados no se usan para nuevos destinatarios adicionales y no
  reactivan relaciones expiradas automaticamente.
- No se modifica la compra/venta general de Marketplace ni productos ajenos.
