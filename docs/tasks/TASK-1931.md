# TASK-1931 - Semaforizacion compacta y gestion visible de empresas

Estado: Cerrada

Fecha: 2026-06-16

Modo: GIPROY CLASICO

## Objetivo

Reestructurar `Otros Servicios > Envios y Transferencias` para que la gestion
de empresas para comunicarse sea visible, separada del envio y alineada con la
semaforizacion compacta usada como referencia en `Proyectos > Cronogramas >
Gantt`.

## Alcance

- Frontend clasico de `EnviosTransferencias`.
- Modal propio `Empresas para comunicarse`.
- Barra compacta de filtros/semaforos.
- Contrato backend aditivo de capacidad de destinatarios.
- Smoke focal y tests de contrato de destinatarios.

## Fuera de alcance

- No cambios destructivos de DB.
- No cambios en auth, JWT, tenant ni permisos.
- No cambios en compra de Marketplace ni flujo comercial de `Conecta`.
- No cambios en importacion/exportacion de activos.
- No UX BIM ni dependencia hacia BIM.
- No Docker/Coolify/CI-CD/staging/produccion.

## Cambios realizados

- Se agrega boton `Empresas` antes de `Nuevo envio` en la cabecera de la
  seccion.
- Se crea modal propio `Empresas para comunicarse`.
- El modal muestra:
  - codigo publico propio;
  - entrada de codigo de conexion;
  - validacion y confirmacion explicita;
  - resumen de empresas fijas usadas/disponibles;
  - resumen de empresas adicionales `Conecta` usadas/disponibles;
  - listado separado de fijas y adicionales;
  - fecha de expiracion visible para adicionales.
- La barra principal integra semaforos compactos estilo Gantt:
  - `Empresas`;
  - `Enviados`;
  - `Recibidos`;
  - `Nuevos`;
  - `Bloqueados`.
- Se elimina la fila grande de KPIs para no duplicar informacion.
- `Nuevo envio` queda solo para seleccionar destinatario ya habilitado y
  ejecutar preflight/envio.
- El endpoint `GET /api/v1/transferencias/recipients` agrega campos aditivos:
  - `fixed_available`;
  - `additional_limit`;
  - `additional_used`;
  - `additional_available`.
- Los selectores del modulo se compactan para alinearse mejor con barra
  tecnica y modales.

## Aceptacion

- La gestion de empresas no queda oculta dentro de `Nuevo envio`.
- Las empresas fijas y adicionales se distinguen visualmente.
- Las adicionales muestran expiracion.
- La pantalla indica usadas/disponibles tanto para fijas como para Conecta.
- Los semaforos viven en la barra principal y no como cards grandes.
- Los combobox no usan select nativo y conservan patron `SearchableSelect`.
- Sin imports directos de `axiosConfig` fuera de `frontend/src/api`.
- Sin `console.log` productivo.
- Sin contaminacion BIM.
