# TASK-1939 - Estado visible contextual en bandeja de Transferencias

Estado: Cerrada
Fecha: 2026-06-17
Modo: GiProy Clasico

## Objetivo

Corregir la confusion de estado en `Otros Servicios > Envios y Transferencias`:
un envio creado por la empresa emisora queda persistido como `enviado`, pero
para la empresa receptora no debe mostrarse como `Enviado`, sino como
`Recibido`.

## Alcance

- Backend clasico de transferencias.
- Serializacion de items de bandeja.
- Tests focales de bandeja emisor/receptor.
- Documentacion funcional del plan.

## Cambios realizados

- `serialize_tray_item` calcula la presentacion visible del estado segun la
  direccion de bandeja.
- `status=enviado` + `direction=salida` se muestra como `Enviado`.
- `status=enviado` + `direction=entrada` se muestra como `Recibido`.
- El color visible del receptor cambia a `cyan`, alineado con el estado de
  recepcion.
- Se preserva el estado interno `enviado` para no romper filtros, auditoria,
  acciones ni compatibilidad de contratos existentes.
- Pytest focal cubre que el mismo envio se ve como `Enviado` para emisor y
  `Recibido` para receptor.

## No interferencia

- Sin UX BIM.
- Sin dependencia hacia BIM.
- Sin cambios DB, migraciones, auth/JWT ni tenant.
- Sin Docker, Coolify, CI/CD, staging ni produccion.
