# TASK-1947 - Reconexion de Nuevo Proyecto con empresa activa

Estado: cerrada
Fecha: 2026-06-18
Modo: GIPROY CLASICO

## Objetivo

Corregir la desconexion del boton `Nuevo proyecto` en `Proyectos`, que en la
rama visual activa no llegaba a mostrar el modal de creacion y ademas no
conservaba explicitamente la empresa activa al crear.

## Diagnostico

La rama activa `PROJECTS_HTML_REFERENCE_LANDING` renderizaba el boton y
ejecutaba `setShowCreateModal(true)`, pero no montaba el modal
`showCreateModal`, que seguia viviendo solo en la rama legacy del componente.

Adicionalmente, `Proyectos.jsx` ya calculaba `empId` y llamaba
`proyectosApi.create(payload, empId)`, pero `frontend/src/api/proyectos.js`
definia `create` solo con `proyectoData` y ejecutaba `POST /proyectos/` sin
`withTenantConfig`.

Esto dejaba el boton visualmente desconectado para administradores y
superadministradores en la vista activa, y dejaba fragil la creacion frente al
tenant operativo.

## Alcance

- Frontend clasico de `Proyectos`.
- Cliente API de dominio `frontend/src/api/proyectos.js`.
- Guarda focal frontend para preservar el contrato.

## No alcance

- No modificar backend, DB, rutas ni contratos API.
- No cambiar auth, JWT, permisos, licencias ni multi-tenant backend.
- No tocar EDT, presupuestos, cronogramas ni datos.
- No tocar BIM, Docker, Coolify, CI/CD, staging ni produccion.
- No reabrir TASK-1807.

## Cambios

- `proyectosApi.create` acepta `empresaId = null`.
- La creacion usa `withTenantConfig({}, empresaId)`.
- El modal de creacion se extrae a `renderCreateProjectModal()`.
- La rama `PROJECTS_HTML_REFERENCE_LANDING` monta tambien
  `renderCreateProjectModal()`.
- `smoke-classic-proyectos-logging-boundary.mjs` valida que el cliente conserve
  `empresaId` via `withTenantConfig` y que la rama HTML activa monte el modal.

## Validaciones

- `cmd /c node frontend\\scripts\\smoke-classic-proyectos-logging-boundary.mjs`: OK.
- `cmd /c node frontend\\scripts\\smoke-classic-project-manager-api-boundary.mjs`: OK.

## Resultado

El flujo `Nuevo proyecto` vuelve a abrir el modal en la vista activa y a enviar
la empresa activa desde el cliente de dominio. Queda protegido por smoke focal.
