# TASK-1948 - Proyecto transferido con Base/APUs acotados al presupuesto

Fecha: 2026-06-18
Modo: GiProy Clasico
Estado: Cerrada

## Objetivo

Optimizar `Envios y Transferencias` para que un Proyecto enviado no arrastre
la totalidad de su Base de Proyecto. El envio/importacion debe transportar solo
los APUs usados por el presupuesto y sus dependencias transitivas: APUs hijos,
recursos, unidades, categorias y subcategorias necesarias.

## Alcance

- Backend clasico de `Envios y Transferencias`.
- Motor comun `classic_asset_portability_service`.
- Snapshot de Proyecto en `transferencias_service`.
- Tests focales de importacion/snapshot.
- Plan funcional de `Envios y Transferencias`.

Queda fuera:

- UX BIM, dependencias BIM o activacion BIM.
- Docker, Coolify, CI/CD, staging o produccion.
- Cambios de auth, JWT, tenant global, licencias o permisos.
- Cambios de contenido completo para transferencias de Base de Trabajo.

## Cambios realizados

- Se agrega colector de grafo transitivo en el motor comun de portabilidad
  clasica:
  - APUs directos usados por lineas operativas de presupuesto.
  - APUs hijos anidados por `APULinea.apu_hijo_id`.
  - Recursos usados por lineas de esos APUs.
  - Unidades de esos recursos.
  - Categorias y subcategorias necesarias para APUs/recursos.
- La importacion viva de Proyecto por Transferencias usa el motor comun con
  `restrict_base_to_budget_apus=True`.
- El snapshot de Proyecto usa `_build_base_snapshot(..., apu_scope_ids=...)`
  para incluir solo la Base de Proyecto acotada al presupuesto.
- Las transferencias de Base de Trabajo conservan comportamiento completo.
- Se documenta que categorias y subcategorias deben viajar sincronizadas con
  recursos/APUs para evitar referencias cruzadas o recursos sin alineamiento.

## Guardas

- Test focal de importacion viva: un proyecto con APU padre, APU hijo anidado y
  contenido no usado importa solo el grafo presupuestado.
- Test focal de snapshot: el payload de proyecto excluye APU/recurso/categoria/
  subcategoria no usados y conserva la relacion padre-hijo.
- Tests existentes de portabilidad y fallback siguen cubriendo integridad
  Presupuesto/APU.
