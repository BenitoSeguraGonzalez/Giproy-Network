# TASK-1963 - Reporte de recursos por rango y catalogo Settings

Fecha: 2026-06-21

Modo: GIPROY CLASICO

## Objetivo

Agregar en `Proyecto > Cronogramas > Recursos` un reporte adicional de
`Uso de Recursos por Rango`, con fecha de inicio y fecha final, usando como
valores por defecto el periodo completo del proyecto.

## Cambios realizados

- Se agrega la variante clasica `resources_range` para
  `cronograma_valorado`.
- El contrato comun de reporting acepta `filters` en preview/export.
- La cache de exportacion incluye los filtros normalizados para no mezclar
  rangos distintos.
- El backend calcula cantidades y costos por solape temporal de periodos:
  solo suma la fraccion de recurso necesaria dentro del rango seleccionado.
- El reporte genera:
  - preview especializado de recursos;
  - Excel con matriz periodo/cantidad/costo;
  - PDF ejecutivo;
  - PDF desde Excel.
- `Cronogramas > Recursos` muestra un menu con:
  - `Uso de Recursos completo`;
  - `Uso de Recursos por rango`.
- El modal de rango inicializa fechas desde el primer y ultimo periodo del
  cronograma, con fallback a fechas del proyecto.
- Settings > Plantillas muestra las salidas clasicas actuales de cronogramas:
  Gantt, integrado, flujo de caja, Pareto, uso de recursos, uso de recursos por
  rango y Curva S.
- Se agrega `docs/reportes/cronograma_uso_recursos_rango.config.json`.

## Funcion del reporte

El reporte `Uso de Recursos por Rango` responde que recursos finales son
necesarios dentro de una ventana de tiempo especifica. Para cada fila del
cronograma valorado explota el APU hasta sus recursos finales, toma la
distribucion por periodos y prorratea la demanda segun el porcentaje de cada
periodo que cae dentro del rango solicitado.
