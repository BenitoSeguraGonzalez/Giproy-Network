# TASK-1964 - Autoridad temporal Gantt/Datos Proyecto y documentacion de duracion

## Modo

GIPROY CLASICO.

## Objetivo

Corregir la incidencia de sincronizacion entre `Datos Proyecto.fecha_inicio` y el Gantt clasico, manteniendo la funcionalidad existente y documentando la logica de duracion con anidados y ruta critica.

## Alcance autorizado

- Backend comun de cronograma de trabajo.
- Esquema de configuracion de Gantt con campos aditivos.
- Etiquetas visuales focales de periodos en Cronograma Valorado/Gantt.
- Smoke focal de frontera de Cronogramas.
- Documentacion tecnica de Gantt.

## Regla funcional

- Si cambia `fecha_inicio` en Datos Proyecto, el Gantt se autoajusta por delta temporal.
- Si luego se cambia la fecha dentro de Gantt, Gantt queda como guia operativa.
- Si despues vuelve a cambiar `fecha_inicio` en Datos Proyecto, Datos Proyecto vuelve a dirigir y desplaza el Gantt.
- El ajuste no modifica importes, porcentajes, rutas API, auth, tenant, EDT ni presupuestos.

## Implementacion

- `CronogramaTrabajoConfig` agrega:
  - `fecha_inicio_referencia_proyecto`.
  - `fecha_inicio_autoridad`.
- El servicio de cronograma de trabajo:
  - detecta cambios externos de fecha de inicio del proyecto;
  - desplaza lineas, ventanas manuales y subbarras con la logica existente de delta;
  - marca autoridad `datos_proyecto` o `gantt` segun origen;
  - conserva la referencia externa para detectar el siguiente cambio real.
- La nomenclatura visual focal pasa de `Tn` a `Pn` y las acciones principales usan `periodo`.
