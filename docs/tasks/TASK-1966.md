# TASK-1966 - Migracion de Ajuste SaaS fuera de Settings Empresa

## Modo

GIPROY CLASICO.

## Objetivo

Mover las funciones globales que vivian bajo `Settings > Ajuste SaaS` hacia
`Administracion Global`, dejando `Settings Empresa` limitado a configuracion de
empresa activa.

## Alcance autorizado

- Frontend clasico.
- Menu SaaS de `Administracion Global`.
- Rutas protegidas de superadministracion.
- Smokes focales de frontera visual/API.
- Documentacion TASK/CHANGELOG/HANDOFF.

## Implementacion

- Se crea `frontend/src/pages/AdminGlobalSuperadministradores.jsx`.
- Se crea `frontend/src/pages/AdminGlobalIntegraciones.jsx`.
- `Administracion Global > Superadministradores` apunta a
  `/admin-global/superadministradores`.
- `Administracion Global > Integraciones` apunta a
  `/admin-global/integraciones`.
- `EcuadorAPI` queda en `Integraciones`, usando `adminConfigApi`.
- La gestion de cuentas superadministradoras queda en `Superadministradores`,
  usando `usuariosApi`.
- `usuariosApi` agrega operaciones globales tenantless controladas
  `getAllGlobal` y `updateGlobal` para evitar filtrar Superadministradores por
  empresa activa.
- `Settings` deja de mostrar la opcion lateral `Ajuste SaaS`.
- `Settings` redirige `/settings?tab=superadmins` hacia
  `/admin-global/superadministradores`.
- `Settings` redirige la edicion del propio perfil superadministrador hacia
  `/admin-global/superadministradores?edit_user=me`.
- Se agrega `frontend/scripts/smoke-classic-saas-settings-migration.mjs`.
- Se integra la smoke nueva en
  `tools/ai_tools/validate_enterprise_baseline.py --include-frontend`.
- Se actualiza `frontend/scripts/smoke-classic-admin-config-email-boundary.mjs`
  para el nuevo destino de Superadministradores.

## Fuera de alcance

- No se modifica backend.
- No se cambian endpoints ni contratos API.
- No se cambia auth/JWT, tenant, empresa activa ni permisos.
- No se toca DB.
- No se toca BIM, Docker/Coolify, CI/CD, staging ni produccion.
- No se reabre el baseline `TASK-1807`.
