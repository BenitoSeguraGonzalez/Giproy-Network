Fecha: 2026-06-22

Modo: GIPROY CLASICO

## Objetivo

Corregir el solapamiento visual del modal `Rendimientos operativos` del Gantt
clasico con el header global en equipos con DPI/escalado diferente.

## Alcance

- El overlay del modal de recursos operativos sube por encima del header global.
- El modal pasa a alinearse desde arriba con respiracion superior estable en
  desktop.
- El panel conserva scroll interno/externo controlado mediante altura maxima
  relativa al viewport.

## No alcance

- No se cambia logica de Gantt, calculo de recursos, persistencia ni contratos.
- No se modifica backend, DB, auth, tenant, EDT, presupuestos ni datos.
- No se toca BIM, Docker/Coolify, CI/CD, staging ni produccion.

## Validacion

- `npm run build` desde `frontend`: OK, con warning conocido de chunks grandes
  Vite.
- `cmd /c node frontend\scripts\smoke-classic-no-bim-contamination.mjs`: OK.
- `cmd /c node frontend\scripts\smoke-classic-cronogramas-api-boundary.mjs`:
  OK.

## Riesgos residuales

  para conservar acceso al header interno y acciones.
