# TASK-1976 - Saneamiento global Gantt por snapshots operativos de APUs anidados

Fecha: 2026-06-24

Modo: GIPROY CLASICO

## Objetivo

Saneamiento global de los cronogramas Gantt existentes para que todos los
diagramas actuales trabajen con la nueva operativa de APUs anidados explotados
como recursos funcionales del APU padre.

## Alcance

- Se corrige `Cronograma Trabajo` para que `schedule_data` conserve
  `apu_operational_resources_v1` al aplicar filas computadas.
- La respuesta del backend devuelve las lineas con snapshot operativo aunque el
  cronograma historico aun no lo tuviera persistido.
- Se crea el script
  `backend/scripts/sanitize_gantt_operational_apu_snapshots.py`.
- El script audita y sanea todos los `cronogramas_trabajo` existentes de todas
  las empresas.
- El saneamiento persiste snapshots operativos; no modifica APUs, presupuestos,
  cantidades de obra ni base global de proyecto.
