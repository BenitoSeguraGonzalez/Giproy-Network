# TASK-1977 - Ajuste visual de metricas y origen de recursos en Gantt

Fecha: 2026-06-24

Modo: GIPROY CLASICO

## Objetivo

Ajustar el editor ligero de recursos del Gantt para que las metricas principales
queden en una sola linea y el listado de recursos comunique visualmente el
origen operativo de cada recurso.

## Alcance

- `Precio en presupuesto` se mueve a la fila principal de metricas junto a:
  `Cantidad`, `Cantidad presupuesto`, `Trabajo gobernante` y `Jornada`.
- La fila principal queda preparada para cinco tarjetas en escritorio, manteniendo
  reflujo responsive en pantallas menores.
- Se retira la tarjeta duplicada de `Precio en presupuesto` del bloque inferior
  de totales.
- El listado de recursos aplica color a descripcion, unidad de medida y etiqueta
  de origen segun el tipo operativo:
  - directo;
  - anidado;
  - consolidado;
  - no fusionado;
  - modificacion activa.
- La marca visual no cambia cantidades, rendimientos, costos ni propagacion de
  APUs; solo mejora lectura del estado operativo ya calculado.

## No alcance

- No se modifican contratos API, backend, base de datos, auth/JWT, tenant, EDT,
  Presupuestos, APUs contractuales ni cronogramas persistidos.
- No se toca BIM, Docker/Coolify, CI/CD, staging ni produccion.
- No se reabre `TASK-1807`.

## Validacion

- `npm run build` desde `frontend`: OK, con warning conocido de chunks grandes
  Vite.
- `cmd /c node frontend\scripts\smoke-classic-no-bim-contamination.mjs`: OK.
- `cmd /c node frontend\scripts\smoke-classic-cronogramas-api-boundary.mjs`: OK.

## No interferencia

Cambio acotado a presentacion del Gantt clasico. Sin dependencia nueva hacia BIM
y sin alteracion funcional de la operativa de APUs anidados definida en
`TASK-1975` y saneada en `TASK-1976`.
