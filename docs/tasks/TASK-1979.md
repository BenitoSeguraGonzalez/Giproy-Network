# TASK-1979 - Restaurar doble click para editar APU desde lineas de presupuesto

Fecha: 2026-06-24

Modo: GIPROY CLASICO

## Objetivo

Corregir la regresion en Presupuestos donde el doble click sobre una linea de
presupuesto asociada a un APU dejo de abrir directamente el editor del APU.

## Alcance

- Se restaura `onDoubleClick` en las dos rutas de renderizado de lineas de
  presupuesto dentro de `LineasPresupuestoTab`.
- El doble click solo abre el editor cuando la linea tiene `apu_id`.
- Se evita interferir con inputs de cantidad, botones de acciones y el handle de
  arrastre.
- Se conserva el boton explicito de editar APU como alternativa visual.
- Se refuerza el smoke de Presupuestos para exigir la conducta de doble click.

  `TASK-1978`.

  `apu_operational_resources_v1`.
