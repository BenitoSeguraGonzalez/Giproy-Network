# TASK-1981 - Entrada natural en cantidad y rendimiento del editor light Gantt

## Modo

GIPROY CLASICO.

## Objetivo

Corregir la experiencia de escritura en el editor light de APU de Gantt para que
los campos `Cantidad` y `Rendimiento` no se reformateen mientras el usuario esta
tecleando.

## Alcance

- Mantener el valor escrito por el usuario como texto crudo durante la edicion.
- Actualizar los calculos locales del modal en vivo con el valor parseado.
- Formatear y persistir la metadata solo al confirmar el campo con `blur`.
- Reforzar el smoke clasico de Cronogramas para bloquear la reintroduccion de
  persistencia/formateo en cada tecla.

## Fuera de alcance

- Sin cambios en explosion de APUs anidados.
- Sin cambios en consolidacion de recursos, snapshots operativos, ruta critica,
  cantidad de obra del presupuesto, backend, API ni base de datos.
- Sin cambios BIM, Docker, Coolify, CI/CD, staging ni produccion.

## Validacion prevista

- `cmd /c node frontend\scripts\smoke-classic-cronogramas-api-boundary.mjs`
- `cmd /c node frontend\scripts\smoke-classic-no-bim-contamination.mjs`
- `npm run build`
- `.\.venv\Scripts\python.exe tools\ai_tools\validate_enterprise_baseline.py --include-frontend`

## Resultado

Implementado y validado.

- `Cantidad` y `Rendimiento` mantienen el texto crudo mientras el input esta
  enfocado.
- Al recibir foco, `Cantidad` y `Rendimiento` seleccionan todo su contenido para
  que el siguiente tipeo reemplace el valor completo.
- La sincronizacion interna del modal no sobrescribe el input activo con
  `formatoCantidad`.
- `resourceLines` queda estabilizado con `useMemo` para evitar bucles de render
  al entrar o interactuar con Gantt.
- `blur` confirma, normaliza visualmente y persiste metadata.
- `Escape` cancela la edicion sin persistir el valor parcial.
- Intento de reinicio de servicios Windows bloqueado por permisos locales:
  `OpenService ERROR 5: Acceso denegado`.
