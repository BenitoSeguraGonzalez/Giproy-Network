# TASK-1991 - Resolvedor comun inicial de fuente funcional APU

## Estado

Implementado y validado focalmente.

## Contexto

La politica transversal exige que Presupuesto, APUs, APU Analysis, Gantt,
Valorados, Recursos y reportes no calculen fuentes oficiales en paralelo.
Antes de crear una modificacion activa formal, hay que sacar del servicio de
Gantt la primera resolucion ya existente de modificacion APU para que pueda ser
reutilizada por otros modulos.

## Objetivo

Extraer la resolucion de `apu_resource_modifications_v1` a un servicio comun
sin cambiar comportamiento visible ni recalcular precios oficiales.

## Cambios realizados

- Se crea `backend/app/services/functional_source.py`.
- Se agrega `resolve_active_apu_resource_modification(...)`.
- `cronograma_trabajo_service` deja de resolver directamente
  `apu_resource_modifications_v1` y consume el nuevo servicio comun.
- Se agregan tests unitarios del resolvedor.
- Se mantiene la paridad del modelo de duracion/coste actual.

## Fuera de alcance

- No se crea todavia la tabla de modificacion activa.
- No se aplica Gantt global como fuente oficial transversal.
- No se modifican Presupuesto, APUs ni APU Analysis.
- No se cambia UX ni se toca BIM.

## Validacion

- `py_compile` focal backend: OK.
- `pytest app/tests/test_functional_source.py app/tests/test_cronograma_trabajo_duration_model.py`: OK, `24 passed`.

## Siguiente slice natural

Crear el contrato de `modificacion_activa` por proyecto/revision con modelo,
schema y servicio de consulta, inicialmente sin alterar calculos visibles.
