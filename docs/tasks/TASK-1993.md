# TASK-1993 - Resolvedor de fuente oficial determinada

## Estado

Implementado y validado focalmente.

## Contexto

Con `ProjectFunctionalModification` creado, el sistema necesita una funcion
unica que responda que fuente oficial debe usar un modulo:

```text
modificacion_activa si existe; si no, base_proyecto
```

## Objetivo

Añadir el resolvedor backend inicial de fuente oficial determinada sin migrar
todavia consumidores ni cambiar calculos visibles.

## Cambios realizados

- `project_functional_modification_service.resolve_official_source(...)`
  devuelve:
  - `source=modificacion_activa` cuando existe una modificacion activa del
    alcance solicitado;
  - `source=base_proyecto` cuando no existe modificacion activa.
- El resolvedor entrega `snapshot`, `patch`, `source_ref`, `origin`,
  `active_modification_id` y alcance normalizado.
- Se agregan tests de precedencia entre base y modificacion activa.

## Fuera de alcance

- No se migran todavia Presupuesto, APUs, APU Analysis, Gantt ni reportes a
  consumir el resolvedor.
- No se recalculan precios.
- No se aplica Gantt global contra `ProjectFunctionalModification`.

## Validacion

- `py_compile` focal backend: OK.
- `pytest app/tests/test_project_functional_modification_service.py`: OK,
  `3 passed`.

## Siguiente slice natural

Conectar la aplicacion global de Gantt para registrar una
`ProjectFunctionalModification` cuando el borrador se marca aplicado, conservando
la persistencia actual de filas y Valorado.
