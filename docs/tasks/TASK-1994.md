# TASK-1994 - Registro de modificacion activa al aplicar Gantt global

## Estado

Implementado y validado focalmente.

## Contexto

La aplicacion global de Gantt ya persistia filas, sincronizaba Valorado y
cerraba el borrador. Faltaba registrar ese cierre como modificacion funcional
activa para empezar a cumplir la regla de fuente oficial unica.

## Objetivo

Conectar el endpoint de aplicacion global Gantt con
`ProjectFunctionalModification` sin cambiar todavia el calculo oficial visible.

## Cambios realizados

- `mark_gantt_draft_applied` crea una `ProjectFunctionalModification` despues
  de validar y marcar aplicado el borrador Gantt.
- La modificacion activa conserva:
  - `source=gantt`;
  - referencia al borrador y cronograma;
  - `work_origin`;
  - intenciones aplicadas;
  - lineas persistidas;
  - snapshot de preview y firma de aplicacion.
- El audit log del borrador aplicado recibe `active_modification_id`.
- Se infiere `base_trabajo_id` desde la primera linea APU del presupuesto, con
  fallback seguro a `None`.

## Fuera de alcance

- No se recalculan APUs ni Presupuesto desde la nueva modificacion.
- No se migran consumidores al resolvedor oficial.
- No se cambia UX.
- No se toca BIM.

## Validacion

- `smoke-classic-cronogramas-api-boundary`: OK.
