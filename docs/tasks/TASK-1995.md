# TASK-1995 - Contrato normalizado de modificacion oficial activa

## Estado

Implementado y validado focalmente.

## Contexto

`ProjectFunctionalModification` ya registraba la aplicacion global de Gantt,
pero los consumidores no debian interpretar JSON opaco de `patch` o `snapshot`.
Para poder migrar Presupuesto, APUs, Cronogramas, Recursos y reportes hacia una
fuente oficial unica, la modificacion activa necesita una vista normalizada y
estable.

## Objetivo

Exponer desde `resolve_official_source(...)` una `summary` funcional que permita
identificar, sin recalculo todavia:

- lineas de presupuesto afectadas;
- APUs afectados;
- recursos afectados;
- payloads de lineas aplicadas;
- snapshots operativos de recursos del editor light.

## Cambios realizados

- `project_functional_modification_service.resolve_official_source(...)`
  devuelve `summary` junto con `patch`, `snapshot` y `source_ref`.
- `CronogramaGantt` adjunta `price_preview` a la intencion del editor light al
  aceptar el modal, sin propagarlo todavia fuera del borrador.
- La `summary` normaliza:
  - `affected_line_ids`;
  - `affected_apu_ids`;
  - `affected_resource_ids`;
  - `line_payload_map`;
  - conteos de intenciones;
  - `operational_snapshots` con recursos, cantidades, rendimientos, precios y
    trazabilidad de origen.
  - `price_previews` con precio directo unitario, indirecto unitario, precio
    total unitario, cantidad de presupuesto, total antes/despues y delta.
- El fallback `base_proyecto` devuelve una `summary` vacia y estable.
- Se añade cobertura focal para snapshot operativo de Gantt con APU anidado
  explotado.

## Fuera de alcance

- No se recalculan todavia precios de Presupuesto/APUs.
- No se migran todavia consumidores visuales ni reportes.
- No se cambia UX.
- No se toca BIM.

## Validacion

- `py_compile` focal backend: OK.
- `smoke-classic-no-bim-contamination`: OK.
- `npm run build`: OK, con warning conocido de chunks grandes Vite.
- `pytest app/tests/test_project_functional_modification_service.py`: OK,
  `4 passed`.
