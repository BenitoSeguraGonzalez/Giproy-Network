# TASK-2004 - Restauracion de empresas asociadas en Transferencias

Fecha: 2026-07-07

Modo: GIPROY CLASICO

## Objetivo

Corregir la regresion local de `Otros Servicios > Envios y Transferencias`
donde una empresa asociada historica ya no aparecia en la gestion de
destinatarios.

## Diagnostico

- El contrato vigente guarda destinatarios salientes en
  `transfer_allowed_company_recipients`.
- La base local actual conservaba solo la relacion
  `Jesus Benito Segura Gonzalez -> Santiago Bermeo`.
- El backup historico de la limpieza global de TASK-1955 contenia tambien:
  - `Administradores Generales -> Santiago Bermeo`.
  - `Santiago Bermeo -> Jesus Benito Segura Gonzalez`.
- La UI estaba solicitando destinatarios con `selectedEmpresa.id` correctamente;
  el problema era dato local ausente, no contrato frontend/backend.

## Cambios realizados

- Se restauraron de forma idempotente, usando el servicio de dominio de
  Transferencias, las dos asociaciones historicas ausentes:
  - `Administradores Generales -> Santiago Bermeo`.
  - `Santiago Bermeo -> Jesus Benito Segura Gonzalez`.
- Se conservaron codigos publicos, envios historicos, importaciones, snapshots,
  licencias y packs Conecta.
- No se modifico codigo fuente, migraciones, rutas, auth/JWT, tenant, API,
  Marketplace, BIM ni Docker/Coolify.

## Validacion

- Endpoint local `/api/v1/transferencias/recipients` con superadmin y
  `empresa_id=1`: OK, devuelve `Santiago Bermeo`.
- Endpoint local `/api/v1/transferencias/recipients` con superadmin y
  `empresa_id=2`: OK, devuelve `Santiago Bermeo`.
- Endpoint local `/api/v1/transferencias/recipients` con superadmin y
  `empresa_id=3`: OK, devuelve `Jesus Benito Segura Gonzalez`.
- `..\.venv\Scripts\python.exe -m pytest app\tests\test_transferencias_recipients.py app\tests\test_transferencias_tray.py -q`: OK, 15 passed.
- `node frontend/scripts/smoke-classic-transferencias-ui.mjs`: OK.
- `node frontend/scripts/smoke-classic-no-bim-contamination.mjs`: OK.

Warnings conocidos:

- Pydantic `model_name/model_id`.
- Deprecaciones conocidas de Pydantic config y `httpx` en tests.

## No interferencia

- Sin cambios BIM ni UX BIM.
- Sin cambios Docker/Coolify/CI/CD/staging/produccion.
- Sin tocar baseline TASK-1807 ni sus guardas.
- Sin cambios destructivos de PostgreSQL; solo alta controlada de dos
  destinatarios clasicos faltantes.

## Rollback

Eliminar solo las filas nuevas de `transfer_allowed_company_recipients`:

- `Administradores Generales -> Santiago Bermeo`.
- `Santiago Bermeo -> Jesus Benito Segura Gonzalez`.

Opcionalmente eliminar tambien los eventos de auditoria
`transfer_recipient_added` generados por esta restauracion si se requiere dejar
el rastro local exactamente como antes del fix.
