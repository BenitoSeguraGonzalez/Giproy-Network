# TASK-2007 - Refresco de revisiones y Pareto Gantt clasico

Fecha: 2026-07-07

Modo: GIPROY CLASICO

## Objetivo

Corregir regresiones en la capa clasica:

- Al eliminar una revision, la UI seguia mostrando la revision eliminada hasta
  refrescar toda la pagina.
- El clonado completo de proyecto/presupuesto podia dejar caches de revisiones
  incoherentes tras crear la nueva revision.
- El boton de clonado completo quedaba escondido dentro de la vista interna del
  proyecto y no estaba disponible en el portafolio/listado.
- Al activar Pareto en Gantt aparecia `ReferenceError: AnimatedSelectedIcon is
  not defined`.

## Diagnostico

- `handleDeleteRevision` actualizaba `projectRevisions` y `revisionBudgetMap`,
  pero no limpiaba las colecciones derivadas usadas por historial inline,
  selector Kanban y calendario de portafolio.
- `handleCreateRevision` refrescaba parcialmente la familia y usaba la revision
  creada como semilla visual, no necesariamente la raiz R000 de la familia.
- `GanttParetoModal.jsx` referenciaba un componente inexistente
  `AnimatedSelectedIcon`.

## Cambios realizados

- `frontend/src/pages/Proyectos.jsx`:
  - Se agrega `refreshRevisionFamilyState` para refrescar una familia de
    revisiones de forma unica y coherente.
  - Se restaura la accion `Clonar Proyecto Completo` en cada fila del
    portafolio/listado.
  - Se eliminan las cards KPI independientes del portafolio y se integran como
    chips informativos dentro de la barra de busqueda/filtros/vistas para
    recuperar espacio vertical sin perder lectura.
  - La lista incrementa altura util al ajustar el calculo del viewport tras
    retirar la fila KPI.
  - El clonado completo usa esa utilidad para actualizar historial inline,
    mapa de presupuestos, selector Kanban y calendario.
  - El borrado de revision usa la misma utilidad y, si la revision activa fue
    eliminada, redirige a R000 o cierra la vista si no hay fallback.
- `frontend/src/components/projects/GanttParetoModal.jsx`:
  - Se reemplaza `AnimatedSelectedIcon` por `CheckCircle2` importado desde
    `lucide-react`.
- `frontend/scripts/smoke-classic-proyectos-logging-boundary.mjs`:
  - Se agrega guarda para conservar el refresco centralizado de revisiones.
  - Se agrega guarda para impedir referencias runtime a `AnimatedSelectedIcon`.
