# TASK-2012 - Lazy metadata Gantt y catalogos APU resumidos

Fecha: 2026-07-08

Modo: GIPROY CLASICO

## Objetivo

Reducir tiempos de presentacion inicial en Gantt y Presupuesto clasicos, con
foco en metadatos pesados de Gantt, lineas de presupuesto relacionadas y listados
de APU usados por Catalogo APU y ApuBudgetEditor.

## Cambios realizados

- `GET /cronogramas-trabajo/{presupuesto_id}` mantiene contrato completo por
  defecto y agrega `metadata_mode=summary` como opcion opt-in combinable con
  `compact=true`.
- En modo `compact=true&metadata_mode=summary`, Gantt conserva los metadatos
  necesarios para pintar y navegar, pero marca cada fila con `metadata_lazy=true`
  y omite metadatos operativos pesados de edicion hasta que se soliciten.
- Se agrega endpoint opt-in de lectura:
  `GET /cronogramas-trabajo/{presupuesto_id}/lineas/{linea_id}/metadata`.
- `Cronogramas.jsx` carga Gantt con `compact=true` y `metadataMode='summary'`.
- `CronogramaGantt.jsx` hidrata metadatos completos bajo demanda al seleccionar
  una linea lazy o abrir el editor de recursos, sin escribir en `drafts` para no
  generar cambios pendientes falsos.
- `GET /apus/` agrega `summary=true` opt-in.
- `apusApi.getAll(...)` acepta `{ summary: true }`.
- Catalogo APU y los listados laterales de `ApuBudgetEditor` usan APUs
  resumidos; la edicion sigue usando `getById(...)` completo.
- Se actualizan smokes clasicos de Cronogramas y Presupuesto para proteger las
  nuevas fronteras API.

## Medicion servidor

Caso medido en beta existente: `presupuesto_id=29`, `empresa_id=1`,
`base_trabajo_id=48`, `revision=0`.

- Gantt compact con metadata completa:
  - `GET /cronogramas-trabajo/29?compact=true&metadata_mode=full`
  - ~2,65-2,71 s.
  - ~364 KB gzip.
- Gantt compact con metadata resumida:
  - `GET /cronogramas-trabajo/29?compact=true&metadata_mode=summary`
  - ~2,40-2,47 s.
  - ~153 KB gzip.
- Hidratacion puntual de metadata de una linea:
  - `GET /cronogramas-trabajo/29/lineas/{linea_id}/metadata`
  - ~2,29-2,39 s.
  - ~2,7 KB gzip.
  - No bloquea la presentacion inicial; se ejecuta bajo demanda.
- Listado APU completo:
  - `GET /apus/?limit=1000&base_trabajo_id=48&revision=0`
  - ~405-525 ms.
  - ~45,9 KB gzip.
- Listado APU resumido:
  - `GET /apus/?limit=1000&base_trabajo_id=48&revision=0&summary=true`
  - ~22-23 ms.
  - ~8,2 KB gzip.
