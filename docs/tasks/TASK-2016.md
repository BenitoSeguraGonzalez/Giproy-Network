# TASK-2016 - Lazy-load de Tanteo y editor APU en Presupuesto clasico

Fecha: 2026-07-08

Modo: GIPROY CLASICO

## Objetivo

Continuar la optimizacion de velocidad de presentacion en Presupuesto,
retirando del primer render componentes que solo se usan bajo interaccion
explicita.

## Alcance

- Diferir el panel lateral de Tanteo.
- Diferir el drawer de edicion APU de presupuesto, que arrastra
  `ApuBudgetEditor`.
- Mantener sin cambios la carga inicial de lineas, catalogo APU y contratos API.
- Reforzar smoke focal de Presupuesto para evitar regresion a imports eager.

## Cambios

- `TanteoTab` pasa de import estatico a `React.lazy(...)`.
- `ApuEditorModal` pasa de import estatico a `React.lazy(...)`.
- Ambos se montan bajo `React.Suspense fallback={null}` solo cuando
  `tanteoVisible` o `editingApuId` estan activos.
- El smoke `smoke-classic-presupuesto-api-boundary.mjs` valida que `TanteoTab`
  y `ApuEditorModal` no vuelvan al chunk inicial de `PresupuestoDetail`.

## Resultado de rendimiento

- Antes del slice: `PresupuestoDetail` ~153,8 KB, gzip ~42,5 KB.
- Despues del slice: `PresupuestoDetail` ~104,1 KB, gzip ~29,8 KB.
- Chunks diferidos generados:
  - `ApuEditorModal` ~34,4 KB, gzip ~10,3 KB.
  - `TanteoTab` ~16,9 KB, gzip ~5,5 KB.
