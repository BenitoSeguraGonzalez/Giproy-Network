# TASK-2017 - Optimizar presentacion clasica de APUs

Fecha: 2026-07-08

Modo: GIPROY CLASICO

## Objetivo

Reducir carga inicial y payload de la pantalla clasica de APUs, dentro del
objetivo global de mejorar cuellos de botella en Gantt y Presupuesto, sin
alterar contratos API ni funcionalidad establecida.

## Alcance

- Frontend clasico: `frontend/src/pages/APUs.jsx`.
- Smoke clasico: `frontend/scripts/smoke-classic-precios-unitarios-ui-guards.mjs`.
- Sin cambios backend, migraciones, auth, tenant, permisos ni datos.
- Sin UX BIM ni dependencias hacia BIM.

## Cambios

- Se difieren con `React.lazy` modales secundarios que no son necesarios para
  el primer render de APUs:
  - `BulkDeleteConfirmModal`
  - `ResourceEditorModal`
  - `CommonReportPreviewModal`
  - `ReportGenerationModal`
- Los modales se montan bajo `React.Suspense fallback={null}` solo cuando su
  estado de apertura esta activo.
- El listado principal de APUs usa `apusApi.getAll(..., { summary: true })`
  para evitar traer `lineas` completas en la presentacion inicial.
- El listado de APUs de una base fuente para importacion tambien usa
  `summary: true`.
- Se conserva sin `summary` el catalogo anidado `nestedApusCatalog`, porque
  sus `lineas` se usan para validar ciclos entre APUs.
- El smoke de Precios Unitarios protege contra regresion a imports eager y
  contra perdida del catalogo anidado completo.
