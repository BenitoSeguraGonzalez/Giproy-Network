# TASK-2023 - Foco BIM hacia EDT

Fecha: 2026-07-13

Modo: INTEGRACION CONTROLADA CLASICO <-> BIM

Estado: DONE

## Objetivo

Resolver un vínculo BIM `edt` hasta el nodo EDT exacto sin cambiar el contrato,
persistencia ni comportamiento ordinario del módulo clásico.

## Implementación

- `Proyectos` conserva en memoria el `target_id` del vínculo seleccionado.
- Al abrir `edt_wbs`, pasa el ID mediante `initialFocusNodeId`, contrato ya
  existente en `Edt`.
- EDT selecciona, expande, cambia a vista árbol y desplaza el nodo al viewport.
- Al cambiar de proyecto se limpia el contexto de navegación.

## Validación

- `smoke-bim-classic-navigation-gate.mjs`: OK.
- BIM apagado/encendido, build y baseline enterprise: OK.

## Rollback

Retirar únicamente el prop `initialFocusNodeId` y el contexto efímero en
`Proyectos.jsx`. EDT y sus datos no requieren rollback.
