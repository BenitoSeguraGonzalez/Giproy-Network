# TASK-2027 - Derecho comercial BIM y licencias de empresas piloto

Estado: cerrada localmente y desplegada en beta el 2026-07-13.

## Objetivo

Incorporar BIM al contrato comercial de GiProy sin exponerlo fuera del rollout
piloto: incluido en Empresarial, Tester, Academica y Capacitacion; disponible
como modulo mensual de USD 99.99 para Estandar y Profesional.

## Alcance conservador

- El acceso efectivo exige simultaneamente derecho comercial y puerta BIM.
- Express no incluye ni puede comprar BIM.
- Estandar y Profesional solo obtienen BIM tras una orden Marketplace confirmada.
- Empresarial, Tester, Academica y Capacitacion lo incluyen por licencia.
- La allowlist persistida sigue limitada a empresas `1,3`.
- No se modificaron auth, JWT, tenant, proyectos, presupuestos ni contratos API
  clasicos.

## Cambios

- `commercial_capabilities` reconoce `PACK_BIM_MONTHLY`, vencimiento del derecho
  y las familias de licencia incluidas.
- Marketplace publica `sistema-pack-bim-mensual` por USD 99.99 y valida que el
  comprador tenga plan Estandar o Profesional antes del checkout y delivery.
- La puerta BIM combina rollout y entitlement comercial; ninguna de las dos
  condiciones puede habilitar BIM por separado.
- El bootstrap de catalogo consulta solo el ID del superadministrador y el
  helper de vigencia actualiza solo sus dos columnas, manteniendo compatibilidad
  con las ramas Alembic locales sin migrarlas.
- `assign_bim_pilot_enterprise.py` convierte las asignaciones piloto de forma
  transaccional, preserva fechas, genera respaldo y registra
  `bim_pilot_license_changed`.
