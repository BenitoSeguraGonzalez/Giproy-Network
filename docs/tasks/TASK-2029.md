# TASK-2029 - Resincronización transaccional del editor light APU Gantt

Fecha: 2026-07-20

Modo: GIPROY CLASICO

Estado: DONE

Tipo: bugfix frontend

## Objetivo

Corregir la divergencia visual del editor light de APUs cuando el usuario
cancela o restaura los datos iniciales: el preview exterior y el detalle
trazable podían reflejar el cambio mientras la tabla principal del modal
conservaba una copia local anterior.

## Diagnóstico

- El editor mantiene estado local de rendimientos, cantidades, líneas fuente y
  política de trabajo, además del borrador exterior usado por el preview.
- `TASK-1983` ya invalida emisiones tardías hacia el borrador padre al cancelar,
  pero el componente del modal permanecía montado y podía reutilizar su estado
  local al reabrir la misma línea.
- La acción Restaurar limpiaba el borrador exterior, pero dependía de una
  resincronización indirecta; un input activo podía conservar su valor visual.

## Cambios realizados

- Cada apertura incrementa una versión de sesión y monta una instancia limpia
  de `GanttResourceEditorModal`.
- Restaurar incrementa una versión explícita de reset además de limpiar el
  borrador exterior.
- El modal invalida el input activo y la cancelación parcial de teclado antes de
  reconstruir sus estados locales desde los datos restaurados.
- Se conserva el preview en vivo durante la edición y la invalidación tardía de
  `TASK-1983`.
- El smoke clásico protege montaje limpio por sesión, señal explícita de reset y
  resincronización de la tabla local.
