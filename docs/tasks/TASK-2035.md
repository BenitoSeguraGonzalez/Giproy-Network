# TASK-2035 - Correccion de deteccion de resolucion de pantalla

Fecha: 2026-07-22

Modo: INTEGRACION CONTROLADA CLASICO / BIM

Estado: DONE en beta

## Objetivo

Evitar el aviso global incorrecto de resolucion y el bloqueo del workspace BIM
en pantallas fisicas de al menos `1920 x 1080`, incluidos escritorios con
escalado de Windows y ventanas de navegador menores que la pantalla.

## Supuestos y tradeoffs

- El minimo acordado corresponde a la pantalla fisica, no al viewport ni al
  marco exterior del navegador.
- Los navegadores exponen dimensiones de pantalla en pixeles CSS. La mejor
  estimacion interoperable disponible es `screen * devicePixelRatio`.
- No se cambia el requisito minimo ni se habilita soporte movil.

## Cambios realizados

- Se centraliza la lectura de resolucion fisica estimada y el umbral desktop.
- `AppLayout` deja de usar `outerWidth/outerHeight` para mostrar el aviso.
- El workspace BIM usa la misma politica y conserva el bloqueo bajo el minimo.
- Se agregan regresiones para 1920x1080 nativo, escalado 125%, pantalla mayor
  con ventana menor y una pantalla real 1600x900 no compatible.
