# TASK-2039 - Fundacion global de adecuacion visual escritorio y tablet

Fecha: 2026-07-24

Modo: INTEGRACION CONTROLADA GIPROY CLASICO <-> GIPROY BIM

Estado: COMPLETE

Tipo: refactor seguro frontend

Prioridad: critical

## Objetivo

Crear la fundacion comun que permita adaptar GiProy Clasico y GiProy BIM por
espacio logico util, contenedor e interaccion, sin cambiar resolucion, escalar
globalmente la UI ni alterar contratos funcionales.

## Trazabilidad BIM

Relacionado con `BIM-TASK-0192`.

## Alcance

- Contrato global en `docs/architecture/ADAPTIVE_UI_MASTER_PLAN.md`.
- Detector local de viewport, visual viewport, contenedor, orientacion y touch.
- Perfiles de composicion y preferencia automatica/manual segura.
- Feature flag maestra apagable.
- Integracion inicial con AppLayout sin modificar contratos ni navegacion.
- Harness de perfiles Windows/tablet y pruebas de no escalado.
- Baseline visual y ejecutable conservado.

## No alcance

- Adecuar en esta TASK todos los modulos funcionales.
- Cambiar backend, PostgreSQL, auth, JWT, tenant, permisos o licencias.
- Desplegar en beta o produccion.
- Modificar Docker, Coolify o CI/CD.

## Fuentes de verdad

- Layout: viewport CSS, visual viewport y contenedor.
- Nitidez: DPR y presupuesto grafico.
- Tenant/licencias/permisos: contratos clasicos existentes.
- BIM: flags, entitlement, licencia, permisos y allowlist existentes.

## Criterios de aceptacion

- 1920x1080 logico conserva el layout clasico existente.
- QHD/4K con escalado Windows seleccionan perfil por espacio CSS, no por
  resolucion fisica.
- Lenovo Tab P12 no se clasifica como desktop amplio solo por su panel 3K.
- No se usa `transform: scale`, zoom CSS ni reduccion global de fuentes.
- Preferencia manual no puede forzar una geometria insegura.
- BIM apagado conserva shell y rutas clasicas sin contaminacion.
- Build, smokes focales y baseline enterprise pasan.
