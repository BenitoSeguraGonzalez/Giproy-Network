# TASK-2042 - Primera edicion autonoma del manual de usuario

Fecha: 2026-07-29

Modo: GIPROY CLASICO con documentacion controlada de capacidades BIM

Estado: REABIERTA; PRIMERA VERSION INSUFICIENTE EN PROFUNDIDAD FUNCIONAL

## Objetivo

Crear una primera version HTML autonoma del manual de usuario de GiProy para
empresas y sus equipos, excluyendo la Administracion Global de plataforma.

## Alcance

- Sitio estatico separado de la aplicacion y publicable de forma independiente.
- Lenguaje humano, explicativo y orientado a tareas.
- Navegacion, busqueda, lectura responsive e impresion.
- Cobertura inicial de empresa, precios unitarios, proyectos, EDO/EDT,
  presupuesto, cronogramas, BIM y servicios.
- Caso practico completo desde recursos/APU hasta proyecto y BIM.
- Inventario de capturas reales pendientes de una sesion de demostracion segura.

## No alcance

- Modificar la aplicacion productiva o sus contratos.
- Documentar Administracion Global o funciones exclusivas de superadministrador.
- Publicar en Internet o montar el manual dentro de GiProy en esta primera etapa.
- Usar datos personales o productivos en capturas.

## Criterios de aceptacion

- El manual abre directamente desde `manual-usuario/index.html`.
- No depende del backend, autenticacion ni paquetes de la aplicacion.
- El flujo APU -> proyecto -> EDT -> presupuesto -> cronograma -> BIM queda
  explicado con un ejemplo continuo.
- La navegacion y busqueda funcionan con teclado y en pantalla movil.
- Las capturas no disponibles se declaran pendientes, sin simulaciones
  presentadas como evidencia real.

## Rollback

Eliminar exclusivamente `manual-usuario` y esta TASK. No existen cambios de
datos, backend, frontend productivo, migraciones ni despliegue.
