# TASK-2045 - Version visible y obligatoria por despliegue

Estado: BETA_DEPLOYED_PENDING_PHYSICAL_DEVICE_CONFIRMATION

## Problema

La portada y el registro mostraban `V3.0` escrito directamente en JSX, mientras
el paquete declaraba `0.0.0`. Docker y el flujo de lanzamiento no transportaban
ni validaban una version, por lo que no existia evidencia visual fiable de que
un dispositivo estuviera usando el ultimo despliegue.

## Solucion

- Se adopta SemVer con `frontend/package.json` como fuente canonica.
- Vite inyecta la version en las superficies visibles y emite `version.json`.
- Docker Compose exige `GIPROY_APP_VERSION` como argumento de build.
- El preflight valida formato y coincidencia con el paquete.
- El deploy rechaza reutilizar la version activa y verifica el manifiesto al
  finalizar.
- Los tres prompts de activacion/desarrollo incorporan el contrato obligatorio.
- HTML y manifiesto quedan sin cache; assets con hash, inmutables.

## Primera release

`3.1.0-beta.1`, correspondiente a la adecuacion adaptativa Classic/BIM en
certificacion fisica.
