# TASK-2045 - Expediente legal-tecnico previo a produccion

Fecha: 2026-08-11

Estado: EN PROGRESO - PRECERTIFICACION CON BLOQUEOS

Tipo: docs / compliance

Prioridad: critical

## Objetivo

Construir un expediente verificable del artefacto publicado en el servidor beta
de GiProy Network que cubra composicion de software, licencias de terceros,
preparacion tecnica para produccion y documentacion base para el registro del
programa de ordenador en Ecuador.

El servidor beta es el artefacto de referencia. Un despliegue futuro de
produccion solo podra heredar el resultado si reproduce 1:1 las imagenes,
hashes, configuracion relevante y avisos legales certificados.

## Alcance

- Frontend efectivamente servido al navegador.
- Backend y dependencias runtime presentes en la imagen publicada.
- PostgreSQL y WAF que integran el stack beta.
- Assets incorporados al artefacto distribuido.
- Evidencia de imagenes, hashes internos y salud del despliegue.
- Matriz de obligaciones open source y titularidad pendiente.
- Preparacion posterior de descripcion de software y terminos contractuales.

## Exclusiones

- Herramientas locales, tests, linters, Playwright y launchers no publicados.
- Directorios `Complementos`, claves y licencias locales que los Dockerfiles no
  copian a las imagenes.
- Declaraciones juridicas absolutas que requieren revision y firma profesional.
- Certificacion automatica de produccion sin comparar previamente sus hashes.

## Criterios de cierre

- [x] Identidad tecnica del beta congelada mediante IDs de imagen y hashes.
- [x] Servicios beta comprobados saludables por lectura remota.
- [x] Inventario inicial de dependencias frontend y backend runtime.
- [x] Ausencia de Aspose comprobada dentro del backend publicado.
- [x] Matriz formal de pendientes de licenciamiento y registro creada.
- [ ] SBOM final y textos de licencia reproducibles.
- [ ] Resolver avisos para MPL-2.0, GPLv3, Hippocratic-2.1 y licencias duales.
- [ ] Acreditar titularidad de codigo propio, marcas, imagenes, fuentes y datos.
- [ ] Completar observacion WAF TASK-2044 y decidir gate de bloqueo.
- [ ] Incorporar Terminos, Privacidad y consentimiento versionado en producto.
- [ ] Ejecutar baseline final y ensayo de despliegue/rollback 1:1.
- [ ] Revision y firma de abogado o agente de propiedad intelectual ecuatoriano.
