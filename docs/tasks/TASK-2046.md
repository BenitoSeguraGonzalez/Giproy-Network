# TASK-2046 - Version visible y footer alcanzable

Estado: IMPLEMENTED_PENDING_BETA_DEPLOYMENT

## Incidencia

La release `3.1.0-beta.1` existia en el bundle y en `/version.json`, pero el
indicador se habia colocado en superficies no fiables: el footer del Dashboard
y el modal de registro. En un viewport bajo, el login recortaba su footer por
usar `overflow-hidden`. Una SPA que permanecia abierta tampoco consultaba si
habia una release posterior.

## Causa raiz

- Se valido presencia de texto, no visibilidad en la superficie solicitada.
- Login no mostraba la version principal.
- La cabecera protegida no mostraba la version.
- Login prohibia scroll aunque su contenido podia superar la altura util.
- No existia monitor de release para sesiones abiertas.

## Correccion

- Version visible en el login y en la cabecera persistente Classic/BIM.
- Login con viewport dinamico y scroll vertical cuando sea necesario.
- Dashboard compacto en alturas de tablet y footer identificado/alcanzable.
- Monitor global que consulta el manifiesto sin cache al iniciar, cada minuto y
  al recuperar visibilidad; recarga una sola vez cuando detecta otra version.
- Gate Playwright en escritorio, tablet de altura reducida y tablet vertical.
- Nueva release: `3.1.0-beta.2`.
