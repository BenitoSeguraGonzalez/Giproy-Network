# TASK-2060 - Evidencia pública vinculada al release

Fecha: 2026-08-12

Estado: COMPLETADA Y DESPLEGADA EN BETA

Tipo: legal / compliance / frontend / despliegue

Prioridad: high

## Objetivo

Publicar junto con cada release un manifiesto técnico navegable desde
`/legal/licencias`, con SBOM CycloneDX, avisos, manifiesto de hashes y
certificado técnico, sin convertir la evidencia en una certificación jurídica.

## Alcance

- El generador copia cuatro artefactos y un manifiesto público a
  `frontend/public/legal/release` antes del build.
- El centro legal carga el manifiesto si está disponible y enlaza los
  artefactos en una nueva pestaña.
- El estado técnico expone `REVIEW_REQUIRED`, `NON_COMPLIANT` o
  `TECHNICALLY_REPRODUCIBLE` sin reinterpretarlo como dictamen legal.
- El script beta incorpora la URL de despliegue desde `.env` sin imprimir sus
  valores.
- El despliegue exige un checkout Git limpio y el SHA completo explícito de la
  release; el script de checkout materializa esa carpeta sin alterar beta.

## Exclusiones

- No despliega ni modifica el beta vigente.
- No elimina el gate WAF en observación.
- No acredita titularidad, fuentes, marcas, datos ni cumplimiento jurídico.
- No introduce cambios en autenticación, base de datos, tenant, Classic o BIM.
- No convierte el árbol activo de beta en un checkout ni publica un commit sin
  que esté disponible en el remoto Git autorizado.

## Criterios de cierre

- [x] Smoke Playwright público en 375 px y 1440 px.
- [x] Generación local con hashes y los cuatro artefactos publicados.
- [x] Build, lint focal, aislamiento Classic/BIM y baseline empresarial.
- [x] Changelog y evidencia de validación actualizados.
