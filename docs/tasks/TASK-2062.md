# TASK-2062 - Integracion controlada del visor IFC real en Modelo BIM

Fecha: 2026-08-20

Modo: INTEGRACION CONTROLADA GIPROY CLASICO <-> GIPROY BIM

Estado: IN_PROGRESS

Relacionado: BIM-TASK-0196

## Objetivo

Conectar la pantalla BIM de Modelo 3D con la geometria IFC real por version,
sin cambiar contratos clasicos, autenticacion, tenant, presupuesto, EDT ni
cronogramas. La capa BIM debe seguir siendo opcional, aislada y apagable.

## Criterios de aceptacion

- La pantalla productiva Modelo 3D intenta cargar Fragments para la version
  seleccionada, con artifacts tenant-scoped.
- Si solo existe el artifact IFC fuente, el frontend puede convertirlo a
  Fragments con el stack BIM autorizado; no se usa la cuadricula sintetica como
  resultado de una carga IFC disponible.
- La seleccion nativa por GUID continua sincronizada con el explorador BIM.
- Aceptar o activar una version refresca el workspace y permite verla sin
  recarga manual de la pagina.
- BIM apagado y el flujo clasico conservan la misma navegacion y contratos.
- Build, smokes BIM focales, smoke anti-BIM y lint focal pasan.

## Fuera de alcance

- No se modifican tablas, rutas o datos clasicos.
- No se agregan Dockerfiles, despliegue, Coolify ni configuracion CI/CD.
- No se reemplaza la geometria IFC por datos sintéticos; versiones sin fuente
  o artifact válido muestran un estado vacío/indisponible.

## Rollback

Retirar el montaje productivo Fragments, la conversion IFC en cliente y el
refresh posterior a revision; mantener los estados vacíos y contratos
existentes.
